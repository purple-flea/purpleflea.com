Overview

Why Purple Flea + LangChain?

LangChain's tool-calling pattern is the fastest way to give language models agency over real-world systems. Purple Flea extends that pattern into decentralised finance, provably-fair gaming, and the on-chain identity layer — domains that most tool libraries completely ignore.

Every BaseTool in purpleflea-langchain is built around a strict Pydantic input schema, which means the LLM always receives structured, validated arguments — no silent misparses, no truncated addresses, no garbled amounts. The underlying Purple Flea API is entirely non-custodial: private keys are derived client-side using BIP-32/BIP-44, signed locally, and broadcast directly to the relevant network. Purple Flea never touches your private keys.

The package wraps six distinct API surface areas into a coherent, idiomatic LangChain interface. You can pass all six tools to a single create_tool_calling_agent call and let the model decide which capability to invoke based on user intent, or you can use the tools independently in chains and pipelines.

Whether you are building an autonomous DeFi portfolio manager, a multi-chain arbitrage bot, a gaming assistant that manages bankroll on behalf of a user, or a domain acquisition agent that snaps up expiring Web3 names, Purple Flea for LangChain gives you the foundation to ship it fast — with zero compromise on security or correctness.

Installation

Get Running in Three Steps

  • Install the package from PyPI using pip, poetry, or uv. Python 3.10+ required.
  • Set your Purple Flea API key as the environment variable PURPLEFLEA_API_KEY. Get one free at purpleflea.io.
  • Import the six tools, instantiate them with your config, and pass them to any LangChain agent.
terminal bash 
# Install with pip
pip install purpleflea-langchain

# Or with poetry
poetry add purpleflea-langchain

# Or with uv
uv add purpleflea-langchain

# Set your API key (get one free at purpleflea.io)
export PURPLEFLEA_API_KEY="pf_live_your_key_here"
export OPENAI_API_KEY="sk-..."  # or your preferred LLM provider
Quick Start

Full Agent Example with All Six Tools

The following example creates a complete tool-calling agent that can manage a crypto wallet, execute trades, play casino games, register domains, claim free funds from the faucet, and settle agent-to-agent payments via escrow — all driven by natural language.

agent.py — full tool-calling agent python 
from langchain_openai import ChatOpenAI
from langchain.agents import AgentExecutor, create_tool_calling_agent
from langchain_core.prompts import ChatPromptTemplate, MessagesPlaceholder
from purpleflea_langchain import (
    PurpleFlecaCasinoTool,
    PurpleFlecaTradingTool,
    PurpleFlecaWalletTool,
    PurpleFlecaDomainsTool,
    PurpleFlecaFaucetTool,
    PurpleFlecaEscrowTool,
)

# ── 1. Instantiate the six tools ─────────────────────────────
casino_tool   = PurpleFlecaCasinoTool(
    api_key="pf_live_your_key",
    chain="ethereum",
    default_bet_usd=5.0,
)

trading_tool  = PurpleFlecaTradingTool(
    api_key="pf_live_your_key",
    default_chain="arbitrum",
    slippage_bps=30,
)

wallet_tool   = PurpleFlecaWalletTool(
    api_key="pf_live_your_key",
    mnemonic="your twelve word seed phrase here",  # never leaves your machine
    default_chain="ethereum",
)

domains_tool  = PurpleFlecaDomainsTool(
    api_key="pf_live_your_key",
    registrar="ens",  # or "unstoppable", "handshake"
)

faucet_tool   = PurpleFlecaFaucetTool(
    # No API key required — anyone can claim free $1 USDC
    agent_address="0xYourAgentAddress",
)

escrow_tool   = PurpleFlecaEscrowTool(
    api_key="pf_live_your_key",
    referral_code="YOUR_REF_CODE",  # earn 15% of escrow fees
)

tools = [casino_tool, trading_tool, wallet_tool, domains_tool, faucet_tool, escrow_tool]

# ── 2. Build the prompt ──────────────────────────────────────
prompt = ChatPromptTemplate.from_messages([
    ("system", (
        "You are a DeFi agent powered by Purple Flea. You can manage"
        " crypto wallets, execute trades, play provably-fair casino games,"
        " register Web3 domains, claim free funds from the faucet,"
        " and settle payments via trustless escrow. Always confirm"
        " destructive actions with the user before executing."
    )),
    MessagesPlaceholder("chat_history", optional=True),
    ("human", "{input}"),
    MessagesPlaceholder("agent_scratchpad"),
])

# ── 3. Create the agent ──────────────────────────────────────
llm   = ChatOpenAI(model="gpt-4o", temperature=0)
agent = create_tool_calling_agent(llm, tools, prompt)

executor = AgentExecutor(
    agent=agent,
    tools=tools,
    verbose=True,
    max_iterations=10,
    handle_parsing_errors=True,
)

# ── 4. Run it ────────────────────────────────────────────────
if __name__ == "__main__":
    result = executor.invoke({
        "input": (
            "Check my ETH balance, then swap 0.01 ETH for USDC on Arbitrum,"
            " and register 'myagent.eth' if it's available."
        )
    })
    print(result["output"])
Note: The mnemonic you pass to PurpleFlecaWalletTool is used exclusively for local key derivation. It is never transmitted to Purple Flea servers. All transaction signing happens in-process using the eth_account library before broadcast.
Individual Tool Usage

Tool-by-Tool Code Examples

Each tool can also be invoked directly in a standalone chain or tested in isolation. Here are targeted examples for each of the six tool capabilities.

Wallet: Check Balance Across Chains

The wallet tool exposes balance queries for ETH, ERC-20 tokens, BTC, SOL, and MATIC in a single call. You can specify a chain, token contract address, or leave both blank to get a full portfolio overview in USD.

wallet_balance.py python 
import asyncio
from purpleflea_langchain import PurpleFlecaWalletTool

wallet = PurpleFlecaWalletTool(
    api_key="pf_live_...",
    mnemonic="your seed phrase",
)

# Synchronous invocation (LangChain handles the async internally)
balance = wallet.invoke({
    "action":  "get_balance",
    "chain":   "ethereum",
    "token":   "ETH",         # omit for all tokens
    "address_index": 0,         # BIP-44 address index
})

# Returns a JSON-serialisable dict:
# {"address": "0xABC...", "token": "ETH", "balance": "1.2340",
#  "balance_usd": "4532.11", "chain": "ethereum"}
print(balance)

# Async usage with arun
async def check_portfolio():
    result = await wallet.arun({
        "action": "get_portfolio",
        "chains": ["ethereum", "arbitrum", "polygon"],
    })
    return result

asyncio.run(check_portfolio())

Trading: Execute a Swap via DEX Aggregator

The trading tool routes swaps through the best available DEX path (1inch, Paraswap, or native AMMs) and returns the executed price, gas cost, and transaction hash. Set dry_run=True to simulate without broadcasting.

swap_example.py python 
from purpleflea_langchain import PurpleFlecaTradingTool

trading = PurpleFlecaTradingTool(
    api_key="pf_live_...",
    default_chain="arbitrum",
    slippage_bps=50,  # 0.5% max slippage
)

# ── Spot swap: ETH → USDC on Arbitrum ────────────────────────
swap_result = trading.invoke({
    "action":        "swap",
    "from_token":    "ETH",
    "to_token":      "USDC",
    "amount":        "0.01",
    "chain":         "arbitrum",
    "dry_run":       False,
})
print(swap_result)
# {"tx_hash": "0xabc...", "from_amount": "0.01 ETH",
#  "to_amount": "36.42 USDC", "gas_usd": "0.08",
#  "route": "Uniswap V3", "chain": "arbitrum"}

# ── Open a leveraged long position ────────────────────────────
trade_result = trading.invoke({
    "action":        "open_position",
    "market":        "ETH-USDC",
    "side":          "long",
    "size_usd":      "500",
    "leverage":      5,
    "stop_loss_pct": 5.0,
    "take_profit_pct": 15.0,
})
print(trade_result)

Casino: Provably-Fair Coin Flip

Every casino game uses a Verifiable Random Function (VRF) seed committed on-chain before the result is revealed. Your agent can query the VRF proof and verify the outcome independently using the included verify_outcome() helper.

casino_example.py python 
from purpleflea_langchain import PurpleFlecaCasinoTool
from purpleflea_langchain.utils import verify_outcome

casino = PurpleFlecaCasinoTool(
    api_key="pf_live_...",
    chain="polygon",     # low-fee chain recommended for small bets
    default_bet_usd=2.0,
)

# ── Coin flip ────────────────────────────────────────────────
flip = casino.invoke({
    "game":   "coin_flip",
    "choice": "heads",
    "bet_usd": 5.0,
})
print(flip)
# {"game": "coin_flip", "choice": "heads", "result": "heads",
#  "outcome": "win", "payout_usd": "9.75", "vrf_seed": "0xdef...",
#  "tx_hash": "0x123...", "chain": "polygon"}

# ── Verify the outcome is provably fair ──────────────────────
is_valid = verify_outcome(
    vrf_seed=flip["vrf_seed"],
    result=flip["result"],
    game="coin_flip",
)
print(f"Outcome verifiable on-chain: {is_valid}")

# ── Dice roll ────────────────────────────────────────────────
dice = casino.invoke({
    "game":        "dice_roll",
    "target":      "over",
    "target_value": 50,
    "bet_usd":     10.0,
})
print(dice)

Domains: Check Availability and Register

The domains tool queries registration status across ENS, Unstoppable Domains, and Handshake in a single call. Bulk availability checks are supported, making it easy to build a domain acquisition agent that monitors and snaps up expiring names.

domain_example.py python 
from purpleflea_langchain import PurpleFlecaDomainsTool

domains = PurpleFlecaDomainsTool(
    api_key="pf_live_...",
)

# ── Check availability ────────────────────────────────────────
availability = domains.invoke({
    "action": "check_availability",
    "names":  ["myagent.eth", "myagent.crypto", "myagent"],
})
print(availability)
# {"results": [
#   {"name": "myagent.eth",    "available": true,  "price_usd": "5.00",  "registrar": "ens"},
#   {"name": "myagent.crypto", "available": false, "expires": "2026-03", "registrar": "unstoppable"},
#   {"name": "myagent",        "available": true,  "price_usd": "1.50",  "registrar": "handshake"}
# ]}

# ── Register a domain ────────────────────────────────────────
registration = domains.invoke({
    "action":       "register",
    "name":         "myagent.eth",
    "duration_years": 2,
    "records": {
        "ETH":  "0xYourAddress",
        "url":  "https://myagent.example.com",
    },
})
print(registration)

faucet_example.py python 
from purpleflea_langchain import PurpleFlecaFaucetTool

Escrow: Trustless Agent-to-Agent Payments

The escrow tool enables agents to transact with each other without a trusted third party. Create an escrow, mark it complete when the work is done, or release it to return funds to the sender. The protocol charges a 1% fee; integrators earn a 15% referral cut on those fees. Backed by escrow.purpleflea.com.

escrow_example.py python 
from purpleflea_langchain import PurpleFlecaEscrowTool

escrow = PurpleFlecaEscrowTool(
    api_key="pf_live_...",
    referral_code="YOUR_REF_CODE",  # earn 15% of escrow fees
)

# ── Create an escrow (agent A pays agent B for a task) ────────
created = escrow.invoke({
    "action":      "create",
    "amount_usdc": "10.00",
    "recipient":   "0xAgentBAddress",
    "description": "Data labelling task #42",
})
print(created)
# {"escrow_id": "esc_xyz", "amount_usdc": "10.00",
#  "status": "held", "tx_hash": "0xdef..."}

# ── Complete the escrow (releases funds to recipient) ─────────
completed = escrow.invoke({
    "action":     "complete",
    "escrow_id":  created["escrow_id"],
})
# {"escrow_id": "esc_xyz", "status": "completed", "tx_hash": "0x123..."}

# ── Release the escrow (returns funds to sender) ──────────────
released = escrow.invoke({
    "action":    "release",
    "escrow_id": "esc_xyz",
})

# ── Query escrow status ───────────────────────────────────────
status = escrow.invoke({
    "action":    "status",
    "escrow_id": "esc_xyz",
})

# Endpoints:
#   POST   https://escrow.purpleflea.com/escrow/create
#   POST   https://escrow.purpleflea.com/escrow/{id}/complete
#   POST   https://escrow.purpleflea.com/escrow/{id}/release
#   GET    https://escrow.purpleflea.com/escrow/{id}
Key Features

Built for Production AI Agents

purpleflea-langchain is not a thin HTTP wrapper. It is an opinionated, production-grade integration built on lessons learned deploying real LLM agents against live financial systems.

⚡

Full Async Support

Every tool implements both _run() and _arun() methods. Run multiple tools concurrently in LangGraph workflows without blocking the event loop.

🔷

Pydantic Input Schemas

All tool inputs are defined with Pydantic v2 BaseModel schemas. The LLM receives validated, type-correct arguments on every invocation — no more silent float-to-string conversion failures.

🔑

Non-Custodial Wallets

Your BIP-39 mnemonic is used for in-process key derivation only. All transaction signing happens locally using eth_account. Purple Flea servers see signed transactions, never raw keys.

💰

20% Referral Commissions

Add your referral code to the tool constructor and earn 20% of all fees generated by users you bring to the platform — paid in USDC on Arbitrum, withdrawable at any time.

🔁

Automatic Retry & Rate Limiting

Built-in exponential backoff with jitter, RPC endpoint rotation, and per-chain gas price caching. Your agent handles network hiccups without crashing or over-spending on gas.

📊

Structured Observability

Every tool call emits a structured log event compatible with LangSmith, Langfuse, and OpenTelemetry. Trace agent spending, game outcomes, and domain purchases in real time.
