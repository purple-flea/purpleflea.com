Hyperliquid perp order vs Purple Flea perp order

Both examples open a long position on BTC perp. Purple Flea requires no wallet setup, no private key handling, no on-chain gas estimation.

Hyperliquid — EVM wallet required Python 
from eth_account import Account
from hyperliquid.exchange import Exchange
from hyperliquid.utils import constants

# Must manage EVM private key securely
# Key compromise = loss of all funds
wallet = Account.from_key(
  '0xYOUR_PRIVATE_KEY_HERE'
)

exchange = Exchange(
  wallet,
  constants.MAINNET_API_URL
)

# Place order (on-chain, irreversible)
order_result = exchange.order(
  "BTC",
  True,       # is_buy
  0.001,     # size
  50000,    # price (limit)
  {"limit": {"tif": "Gtc"}}
)
# Risk: private key in environment variable
# No casino, wallet, escrow, or faucet available
