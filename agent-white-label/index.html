Overview

What white-labeling Purple Flea gives you

White-labeling means you integrate Purple Flea's REST APIs into your own product — your own domain, your own UI, your own brand. Your end users call your API; your backend calls Purple Flea. Alternatively, you pass Purple Flea API keys directly to your users with your referral code pre-embedded, so every transaction they make flows through your referral relationship.

This is not a reseller arrangement requiring a contract. It works entirely through the standard referral system: register as a platform agent, generate sub-keys for your users with your agent ID as referrer, and start earning. No paperwork, no minimum volumes, no revenue caps.

Implementation

Three ways to embed Purple Flea

Choose the architecture that fits your product. You can mix patterns — for example, proxy casino and wallet calls while passing direct trading keys to power users.

🔁

Proxy pattern

Your backend receives all calls, forwards to Purple Flea, and returns results. Users never see Purple Flea URLs. Full control over rate limits and logging.

🔑

Key delegation

Issue scoped sub-keys from your platform master key. Users call Purple Flea directly but their key was generated by your platform with your referral embedded.

📦

SDK wrapper

Ship a Python/Node.js SDK that wraps Purple Flea REST calls under your brand. Open-source it if you want; commissions still flow to your referral code.

Code Example

Proxy pattern: Express.js backend

A minimal Node.js proxy that fronts Purple Flea's casino API. Your users hit api.yourbrand.com/casino/bet; your server forwards to Purple Flea with your master key, earning referral commissions silently.

// api.yourbrand.com — Purple Flea white-label proxy (Node.js/Express) import express from 'express'; import fetch from 'node-fetch'; const app = express(); app.use(express.json()); // Your platform's master Purple Flea API key const PLATFORM_KEY = process.env.PURPLE_FLEA_PLATFORM_KEY; const CASINO_BASE = 'https://casino.purpleflea.com'; const FAUCET_BASE = 'https://faucet.purpleflea.com'; // Register a new user — your referral code is embedded automatically app.post('/v1/register', async (req, res) => { const { user_id } = req.body; const resp = await fetch(`${FAUCET_BASE}/register`, { method: 'POST', headers: { 'Content-Type': 'application/json' }, body: JSON.stringify({ agent_id: `yourbrand_${user_id}`, referrer: 'YOUR_PLATFORM_AGENT_ID', // Replace with your agent ID }), }); const data = await resp.json(); // Store data.api_key mapped to user_id in your DB // Return your own token to the user — they never see the Purple Flea key res.json({ token: issueYourOwnJWT(user_id, data.api_key), balance: data.balance_usdc }); }); // Proxy casino bet — your user uses your token, PF key is internal app.post('/v1/casino/bet', authenticateYourToken, async (req, res) => { const pfKey = req.user.pfKey; // Retrieved from your DB const { game, side, amount } = req.body; const resp = await fetch(`${CASINO_BASE}/bet`, { method: 'POST', headers: { 'Authorization': `Bearer ${pfKey}`, 'Content-Type': 'application/json', }, body: JSON.stringify({ game, side, amount }), }); const result = await resp.json(); // Optionally add your own analytics/logging here res.json(result); }); app.listen(3000, () => console.log('White-label proxy running on :3000'));

Enterprise Features

Platform-scale API management

Managing API keys for many users requires more than a simple key list. Purple Flea's platform features let you set policies at the account level, bulk-register agents, and retrieve aggregated analytics across your entire user base.

🛡️

Spending caps

Set daily or monthly USDC spending limits per sub-key. Prevents runaway agent costs. Configurable at registration or updated anytime via API.

🚫

Service allowlisting

Restrict sub-keys to specific services. A key scoped to "wallet" only cannot call casino or trading endpoints.

⏱️

Rate limiting

Specify requests-per-minute limits per sub-key. Useful for tier-based product plans where different users get different API quotas.

🔄

Key rotation

Rotate a compromised sub-key via POST /rotate-key. Old key invalidated immediately; balance and history transfer to the new key.

📋

Bulk registration

Register up to 1,000 agents in a single batch API call. Useful for platforms pre-provisioning accounts before users arrive.

📈

Aggregated analytics

Query volume, fees, and referral earnings across all sub-keys in your tree via a single GET /platform/stats endpoint.
