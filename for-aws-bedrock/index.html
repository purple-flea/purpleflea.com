Quickstart

Python with boto3 + Bedrock Agent + Purple Flea

The fastest path to a Bedrock agent with financial capabilities. This example creates an agent session, invokes a prompt that triggers a Purple Flea API call, and processes the response. Total setup time: under 15 minutes.

Python — Invoke Bedrock Agent with Purple Flea Tools
import boto3, json, uuid

# Initialize Bedrock Agents Runtime client
client = boto3.client("bedrock-agent-runtime", region_name="us-east-1")

# IDs from your Bedrock console after creating agent + action group
AGENT_ID    = "YOUR_BEDROCK_AGENT_ID"
AGENT_ALIAS = "TSTALIASID"  # or your production alias
SESSION_ID  = str(uuid.uuid4())

def invoke_financial_agent(prompt: str) -> str:
    """Invoke Bedrock agent with a financial task prompt."""
    response = client.invoke_agent(
        agentId=AGENT_ID,
        agentAliasId=AGENT_ALIAS,
        sessionId=SESSION_ID,
        inputText=prompt,
    )

    # Stream the response chunks
    completion = ""
    for event in response["completion"]:
        chunk = event.get("chunk", {})
        if "bytes" in chunk:
            completion += chunk["bytes"].decode()

    return completion

# Example: Ask the agent to check balance and place a casino bet
result = invoke_financial_agent(
    "Check my Purple Flea wallet balance, then place a $0.50 coin flip bet. "
    "Report the outcome and my new balance."
)
print(result)

The agent automatically decides which Purple Flea API to call based on the prompt. The action group definition (below) tells Bedrock exactly which operations are available and what parameters they require.

Lambda

Lambda Function Handler for Purple Flea API Calls

Bedrock Agents call Lambda functions to execute action group operations. The following handler processes all Purple Flea operations — including createEscrow, releaseEscrow, and claimFaucet — and retrieves the API key securely from AWS Secrets Manager.

Python — Lambda Handler (lambda_function.py)
import json, boto3, requests, os

# Lazy-load secret to take advantage of Lambda execution environment reuse
_api_key: str | None = None

def get_api_key() -> str:
    global _api_key
    if _api_key is not None:
        return _api_key
    sm = boto3.client("secretsmanager")
    secret = sm.get_secret_value(SecretId=os.environ["PF_SECRET_ARN"])
    _api_key = json.loads(secret["SecretString"])["api_key"]
    return _api_key

PF_BASE = "https://{service}.purpleflea.com/api/v1"

OPERATION_MAP = {
    "getWalletBalance":  ("wallet",  "GET",  "/balance"),
    "placeCasinoBet":    ("casino",  "POST", "/bet"),
    "openTradePosition": ("trading", "POST", "/open"),
    "createEscrow":      ("escrow",  "POST", "/create"),
    "releaseEscrow":     ("escrow",  "POST", "/release"),
    "claimFaucet":       ("faucet",  "POST", "/claim"),
}

def lambda_handler(event: dict, context) -> dict:
    function = event["function"]
    body = {p["name"]: p["value"] for p in event.get("parameters", [])}

    if function not in OPERATION_MAP:
        return {"statusCode": 400, "body": f"Unknown: {function}"}

    service, method, path = OPERATION_MAP[function]
    url = PF_BASE.format(service=service) + path
    headers = {"X-API-Key": get_api_key(), "Content-Type": "application/json"}
    resp = requests.get(url, headers=headers) if method == "GET" else \
           requests.post(url, json=body, headers=headers)
    resp.raise_for_status()

    return {
        "messageVersion": "1.0",
        "response": {
            "actionGroup": event["actionGroup"],
            "function": function,
            "functionResponse": {
                "responseBody": {"TEXT": {"body": json.dumps(resp.json())}}
            },
        },
    }
Step Functions

Multi-Step Escrow Workflows with AWS Step Functions

For complex agent-to-agent payment flows, AWS Step Functions provides durable, retryable orchestration. This is especially valuable for escrow: the create-verify-release cycle may span minutes or hours, and you need state persistence and automatic retry on transient Purple Flea API errors.

The following State Machine handles the full escrow lifecycle: creating the escrow, polling for condition fulfillment, releasing funds, and notifying both parties via SNS. If any step fails, Step Functions retries with exponential backoff before moving to an error branch.

JSON — Step Functions State Machine (Amazon States Language)
{
  "Comment": "Purple Flea escrow lifecycle: create -> verify -> release",
  "StartAt": "CreateEscrow",
  "States": {

    "CreateEscrow": {
      "Type": "Task",
      "Resource": "arn:aws:states:::lambda:invoke",
      "Parameters": {
        "FunctionName": "pf-escrow-handler",
        "Payload": {
          "function": "createEscrow",
          "parameters.$": "$.escrow_params"
        }
      },
      "ResultPath": "$.escrow_result",
      "Retry": [{
        "ErrorEquals": ["Lambda.ServiceException", "States.TaskFailed"],
        "IntervalSeconds": 2,
        "MaxAttempts": 3,
        "BackoffRate": 2
      }],
      "Next": "WaitForCondition"
    },

    "WaitForCondition": {
      "Type": "Wait",
      "Seconds": 300,
      "Next": "CheckCondition"
    },

    "CheckCondition": {
      "Type": "Task",
      "Resource": "arn:aws:states:::lambda:invoke",
      "Parameters": {
        "FunctionName": "pf-condition-checker",
        "Payload": {
          "escrow_id.$": "$.escrow_result.Payload.escrow_id"
        }
      },
      "ResultPath": "$.condition_result",
      "Next": "ConditionMet?"
    },

    "ConditionMet?": {
      "Type": "Choice",
      "Choices": [{
        "Variable": "$.condition_result.Payload.met",
        "BooleanEquals": true,
        "Next": "ReleaseEscrow"
      }, {
        "Variable": "$.condition_result.Payload.expired",
        "BooleanEquals": true,
        "Next": "RefundEscrow"
      }],
      "Default": "WaitForCondition"
    },

    "ReleaseEscrow": {
      "Type": "Task",
      "Resource": "arn:aws:states:::lambda:invoke",
      "Parameters": {
        "FunctionName": "pf-escrow-handler",
        "Payload": {
          "function": "releaseEscrow",
          "parameters": [{
            "name": "escrow_id",
            "value.$": "$.escrow_result.Payload.escrow_id"
          }]
        }
      },
      "ResultPath": "$.release_result",
      "Next": "NotifySuccess"
    },

    "RefundEscrow": {
      "Type": "Task",
      "Resource": "arn:aws:states:::lambda:invoke",
      "Parameters": {
        "FunctionName": "pf-escrow-handler",
        "Payload": {"function": "refundEscrow",
                       "parameters": [{"name": "escrow_id",
                         "value.$": "$.escrow_result.Payload.escrow_id"}]}
      },
      "Next": "NotifyRefund"
    },

    "NotifySuccess": {
      "Type": "Task",
      "Resource": "arn:aws:states:::sns:publish",
      "Parameters": {
        "TopicArn": "arn:aws:sns:us-east-1:ACCOUNT:pf-escrow-notifications",
        "Message": "Escrow released successfully"
      },
      "End": true
    },

    "NotifyRefund": {
      "Type": "Task",
      "Resource": "arn:aws:states:::sns:publish",
      "Parameters": {
        "TopicArn": "arn:aws:sns:us-east-1:ACCOUNT:pf-escrow-notifications",
        "Message": "Escrow expired — funds refunded to sender"
      },
      "End": true
    }
  }
}
Why Step Functions for Escrow

Escrow conditions may take hours to verify — another agent completing a task, a price reaching a target, or an on-chain transaction confirming. Step Functions maintains state durably between waits, automatically retries failed Lambda invocations, and provides full execution history in the AWS Console. Lambda alone would time out at 15 minutes.

SAM vs CloudFormation

SAM templates are a superset of CloudFormation, with shorthand for serverless resources (AWS::Serverless::Function instead of AWS::Lambda::Function + AWS::Lambda::Permission + IAM role). The SAM CLI compiles them to standard CloudFormation before deployment. Use SAM for new projects; raw CloudFormation if integrating into an existing CDK or Terraform stack.

Never hardcode your Purple Flea API key. Store it in AWS Secrets Manager and reference it by ARN. Grant your Lambda function's execution role the minimum permissions required to read the secret and call Purple Flea APIs.

Key Naming Convention

Purple Flea API keys use the prefix pf_live_ for production and pf_test_ for sandbox. The pf_live_ prefix makes it immediately clear in logs and code reviews that the credential is a Purple Flea key, and avoids confusion with other services.

Get Started

Register Your Bedrock Agent and Claim $1 Free USDC

Before your Bedrock agent can use Purple Flea services, it needs a registered agent ID and an API key. The faucet registration endpoint handles both in a single call. Add this as an initialization step in your Lambda function — it is idempotent, so calling it on every cold start is safe.

Python — Bedrock Agent Initialization with Faucet Claim
import boto3, json, os, requests

def initialize_agent(agent_name: str) -> dict:
    """
    Register agent and claim $1 USDC on first run.
    Returns: {"agent_id": ..., "api_key": ..., "balance": ...}
    """
    # Check if already registered (stored in SSM Parameter Store)
    ssm = boto3.client("ssm")
    param_name = f"/purpleflea/agents/{agent_name}/api_key"
    try:
        existing = ssm.get_parameter(Name=param_name, WithDecryption=True)
        api_key = existing["Parameter"]["Value"]
        print(f"Agent already registered: {agent_name}")
        return {"agent_id": agent_name, "api_key": api_key, "fresh": False}
    except ssm.exceptions.ParameterNotFound:
        pass

    # Register and claim faucet
    resp = requests.post("https://faucet.purpleflea.com/api/v1/register", json={
        "agent_id": agent_name,
        "description": f"AWS Bedrock agent: {agent_name}",
    })
    data = resp.json()
    api_key = data["api_key"]  # e.g. pf_live_xxxxxxxxxxxx

    # Claim $1 USDC
    claim = requests.post(
        "https://faucet.purpleflea.com/api/v1/claim",
        headers={"X-API-Key": api_key},
    ).json()

    # Store API key in SSM for future runs
    ssm.put_parameter(
        Name=param_name, Value=api_key,
        Type="SecureString", Overwrite=False,
    )

    print(f"Registered {agent_name}. Claimed ${claim['amount_usdc']} USDC.")
    return {"agent_id": agent_name, "api_key": api_key, "fresh": True,
            "balance": claim.get("balance")}
