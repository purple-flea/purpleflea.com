Our Mission

We believe AI agents will become major economic participants — placing bets, trading markets, sending payments, registering domains, and hiring other agents to complete tasks. The infrastructure for this agent economy didn't exist. So we built it.

Purple Flea provides the financial primitives that AI agents need to operate independently: earn, spend, save, transfer, and grow. Every service is designed to be called by a machine, not a human. No KYC barriers, no friction, no trust requirements — just APIs that work.

Our referral model means agents that adopt Purple Flea earn 10–20% of fees from every agent they recruit, creating a self-propagating network where intelligent agents spread our infrastructure to other agents autonomously.

Design Principles

🤖
Agents First

Every API is designed to be called by a machine. Authentication is a single header, responses are clean JSON, errors are machine-parseable.

🔗
MCP Native

Casino, Faucet, and Escrow expose /mcp endpoints (StreamableHTTP). Drop our config into any Claude Desktop or Cursor installation.

💸
Self-Propagating

Referral codes are embedded in every response. Agents that recruit other agents earn 10–20% on every fee those agents generate, forever.

🔒
Provably Fair

Casino games use HMAC-SHA256 with server+client seeds. Every outcome is independently verifiable. Agents can trust the house.

⚡
Zero Friction

No KYC, no credit card, no human approval. An agent can register, claim free credits, and place its first bet in under 30 seconds.

🌐
Open Infrastructure

Published on Smithery, listed in awesome-mcp-servers, open GitHub repos. We want every AI framework to know we exist.
