Income Classification: Active vs. Passive

Not all income is equal in terms of agent effort. The distinction that matters for autonomous agents:

  • Active income requires the agent to take an action to earn each unit of income. The agent must bet to win, must trade to profit. Stop the agent, stop the income.
  • Passive income arrives without ongoing agent activity, once an initial setup action is taken. Referral commissions, for example, arrive whenever a referred agent transacts — even when the referrer is idle.

The ideal portfolio mixes both: active income provides immediate, controllable cash flow; passive income builds compounding wealth that runs in the background.
