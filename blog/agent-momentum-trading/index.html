Momentum Trading Strategies for AI Agents

March 7, 2026 · 22 min read · Purple Flea Research

Momentum is one of the most robust return anomalies in quantitative finance — assets that have outperformed recently tend to continue outperforming over the next one to twelve months. This guide covers the theory, technical indicator construction, cross-sectional ranking, signal combination, and full Python implementation for deploying a momentum agent against the Purple Flea trading API.

1. Momentum Theory: Price and Earnings Momentum

The momentum effect was first documented systematically by Jegadeesh and Titman (1993), who showed that buying past twelve-month winners and selling past twelve-month losers generated statistically significant alpha over intermediate holding periods. Subsequent research decomposed this into two primary sources:

Price Momentum

Assets with strong recent price performance continue to outperform. Formation period: 1–12 months. Hold period: 1–6 months.

Earnings Momentum

Assets with positive earnings surprises continue to be revised upward by analysts. Driven by slow information diffusion.

Trend Following

Macro-level time-series momentum: asset-class trends across equities, bonds, commodities, and FX over 1–12 month horizons.

Crypto Momentum

In crypto markets, momentum operates on shorter timeframes (hours to days) due to higher volatility and 24/7 trading.

Cross-sectional vs. Time-series Momentum

These are the two primary momentum paradigms an AI agent can trade:

DimensionCross-sectional MomentumTime-series (TSMOM) Momentum

For crypto AI agents, a hybrid approach works best: use cross-sectional ranking to select which assets to trade, and time-series momentum signals to determine entry timing and position direction within each selected asset.

Why momentum works: The leading explanations are behavioral (investor under-reaction to news, herding, disposition effect) and structural (trend-following crowding, index rebalancing flows). In crypto, the dominant driver appears to be retail sentiment momentum — fear and greed cycles propagate across assets with measurable lag.

2. Technical Momentum Indicators

Three indicators form the backbone of a momentum signal stack: Rate of Change (ROC) for raw price momentum, RSI for mean-reversion-aware momentum, and MACD for trend strength and direction changes.

2.1 Rate of Change (ROC)

ROC is the purest momentum measure — it directly captures the percentage price change over a lookback window.

ROC(n) = (Price_t - Price_{t-n}) / Price_{t-n} × 100

Where n is the lookback period in bars. Typical values: n = 10 (short), n = 21 (medium), n = 63 (quarterly).

2.2 Relative Strength Index (RSI)

RSI normalizes momentum between 0 and 100 using a ratio of average gains to average losses over a rolling window. For momentum trading, RSI above 50 signals bullish momentum, below 50 signals bearish momentum. Use 60/40 thresholds for cleaner signals.

RSI = 100 - 100 / (1 + RS)
RS = Avg(gains, n) / Avg(losses, n)

Standard period: n = 14. Momentum signal: RSI > 60 → long; RSI < 40 → short.

2.3 MACD Signal Generation

MACD captures trend momentum via the difference between two exponential moving averages. The signal line crossover and histogram sign change are the primary entry triggers.

MACD = EMA(12) - EMA(26)
Signal Line = EMA(MACD, 9)
Histogram = MACD - Signal Line

Entry: MACD crosses above signal line (bullish) or below signal line (bearish). Histogram direction change is an early warning.

import numpy as np
import pandas as pd
from dataclasses import dataclass

@dataclass
class MomentumSignals:
    roc: float          # Rate of change (%)
    rsi: float          # RSI (0-100)
    macd: float         # MACD line
    macd_signal: float  # Signal line
    macd_hist: float    # Histogram
    combined: float     # Composite signal (-1 to 1)
    direction: str      # 'long', 'short', 'neutral'

def roc(prices: np.ndarray, period: int = 10) -> np.ndarray:
    """Rate of Change: percentage change over lookback period."""
    return np.where(
        prices[:-period] != 0,
        (prices[period:] - prices[:-period]) / prices[:-period] * 100,
        0.0
    )

def ema(prices: np.ndarray, period: int) -> np.ndarray:
    """Exponential Moving Average using pandas for efficiency."""
    s = pd.Series(prices)
    return s.ewm(span=period, adjust=False).mean().values

def rsi(prices: np.ndarray, period: int = 14) -> np.ndarray:
    """RSI: compares average gains to average losses."""
    delta = np.diff(prices)
    gains = np.where(delta > 0, delta, 0.0)
    losses = np.where(delta < 0, -delta, 0.0)

    # Use exponential smoothing (Wilder's method)
    avg_gain = pd.Series(gains).ewm(alpha=1/period, adjust=False).mean().values
    avg_loss = pd.Series(losses).ewm(alpha=1/period, adjust=False).mean().values

    rs = np.where(avg_loss != 0, avg_gain / avg_loss, 100.0)
    return 100.0 - (100.0 / (1.0 + rs))

def macd(prices: np.ndarray, fast: int = 12, slow: int = 26,
         signal: int = 9) -> tuple[np.ndarray, np.ndarray, np.ndarray]:
    """
    MACD, Signal Line, and Histogram.
    Returns (macd_line, signal_line, histogram).
    """
    ema_fast = ema(prices, fast)
    ema_slow = ema(prices, slow)
    macd_line = ema_fast - ema_slow
    signal_line = ema(macd_line, signal)
    histogram = macd_line - signal_line
    return macd_line, signal_line, histogram

def compute_signals(prices: np.ndarray,
                    roc_period: int = 10,
                    rsi_period: int = 14,
                    rsi_long_threshold: float = 60.0,
                    rsi_short_threshold: float = 40.0) -> MomentumSignals:
    """
    Compute composite momentum signal from ROC, RSI, and MACD.
    Returns MomentumSignals with a combined score between -1 and 1.
    """
    if len(prices) < max(roc_period + 1, rsi_period + 1, 35):
        return MomentumSignals(0, 50, 0, 0, 0, 0.0, "neutral")

    # ROC: latest value, normalized to [-1, 1] via tanh
    roc_vals = roc(prices, roc_period)
    current_roc = float(roc_vals[-1])
    roc_score = float(np.tanh(current_roc / 5.0))  # 5% ROC ≈ 0.96 score

    # RSI: normalize around 50
    rsi_vals = rsi(prices, rsi_period)
    current_rsi = float(rsi_vals[-1])
    rsi_score = (current_rsi - 50.0) / 50.0  # range [-1, 1]

    # MACD: histogram sign and magnitude normalized
    macd_line, sig_line, hist = macd(prices)
    current_macd = float(macd_line[-1])
    current_signal = float(sig_line[-1])
    current_hist = float(hist[-1])
    # Normalize histogram by recent std
    hist_std = float(np.std(hist[-20:])) if len(hist) >= 20 else 1.0
    macd_score = float(np.tanh(current_hist / max(hist_std, 1e-8)))

    # Composite: equal-weight average
    combined = (roc_score + rsi_score + macd_score) / 3.0

    # Direction classification
    if combined > 0.15:
        direction = "long"
    elif combined < -0.15:
        direction = "short"
    else:
        direction = "neutral"

    return MomentumSignals(
        roc=current_roc,
        rsi=current_rsi,
        macd=current_macd,
        macd_signal=current_signal,
        macd_hist=current_hist,
        combined=combined,
        direction=direction,
    )

3. Cross-sectional Momentum: Ranking and Rebalancing

Cross-sectional momentum ranks assets within a universe by their recent performance and systematically goes long the top performers while avoiding or shorting the bottom performers. In crypto, this means ranking trading pairs by their 10-day ROC every hour or day and rotating into the strongest.

Ranking Algorithm

The standard approach uses percentile ranking rather than raw returns to normalize across assets with different volatility profiles:

Rank_i = percentile_rank(ROC_i, universe)
Score_i = 2 × (Rank_i - 0.5) → range: [-1, 1]

Assets in the top quartile (Score > 0.5) are long candidates. Bottom quartile (Score < -0.5) are short candidates or avoided.

cross_sectional.py
import numpy as np
from dataclasses import dataclass
from typing import TypedDict

class AssetData(TypedDict):
    symbol: str
    prices: list[float]

@dataclass
class RankedAsset:
    symbol: str
    roc: float
    percentile: float       # 0.0 to 1.0
    score: float            # -1.0 to 1.0
    rsi: float
    combined_score: float   # blends cross-sectional rank + RSI momentum
    signal: str             # 'long', 'short', 'neutral'

def cross_sectional_rank(
    assets: list[AssetData],
    roc_period: int = 10,
    long_threshold: float = 0.70,
    short_threshold: float = 0.30,
) -> list[RankedAsset]:
    """
    Rank assets by ROC within the universe.
    Returns sorted list from strongest to weakest.

    long_threshold=0.70  → top 30% of universe are long candidates
    short_threshold=0.30 → bottom 30% are short candidates
    """
    from indicators import roc, rsi, compute_signals

    rocs: list[float] = []
    rsis: list[float] = []

    for asset in assets:
        prices = np.array(asset["prices"])
        if len(prices) < roc_period + 1:
            rocs.append(0.0)
            rsis.append(50.0)
            continue
        roc_vals = roc(prices, roc_period)
        rsi_vals = rsi(prices, 14)
        rocs.append(float(roc_vals[-1]))
        rsis.append(float(rsi_vals[-1]) if len(rsi_vals) > 0 else 50.0)

    # Compute percentile ranks (0 = worst, 1 = best)
    roc_array = np.array(rocs)
    n = len(roc_array)
    if n == 0:
        return []

    sorted_idx = np.argsort(roc_array)
    percentiles = np.empty(n)
    for rank, idx in enumerate(sorted_idx):
        percentiles[idx] = rank / (n - 1) if n > 1 else 0.5

    results: list[RankedAsset] = []
    for i, asset in enumerate(assets):
        pct = float(percentiles[i])
        cs_score = 2.0 * (pct - 0.5)  # cross-sectional: [-1, 1]
        rsi_score = (rsis[i] - 50.0) / 50.0  # RSI normalized: [-1, 1]
        combined = 0.6 * cs_score + 0.4 * rsi_score  # weighted blend

        if pct >= long_threshold and combined > 0:
            signal = "long"
        elif pct <= short_threshold and combined < 0:
            signal = "short"
        else:
            signal = "neutral"

        results.append(RankedAsset(
            symbol=asset["symbol"],
            roc=rocs[i],
            percentile=pct,
            score=cs_score,
            rsi=rsis[i],
            combined_score=combined,
            signal=signal,
        ))

    # Sort strongest to weakest
    return sorted(results, key=lambda r: r.combined_score, reverse=True)


def select_portfolio(
    ranked: list[RankedAsset],
    max_longs: int = 3,
    max_shorts: int = 3,
) -> tuple[list[RankedAsset], list[RankedAsset]]:
    """
    Select top N longs and bottom N shorts from ranked universe.
    Returns (longs, shorts).
    """
    longs = [r for r in ranked if r.signal == "long"][:max_longs]
    shorts = [r for r in ranked if r.signal == "short"][-max_shorts:]
    return longs, shorts

4. MomentumAgent Class: Full Implementation

The MomentumAgent class ties together price data fetching, signal computation, cross-sectional ranking, position sizing, and order execution via the Purple Flea trading API.

momentum_agent.py
import asyncio
import numpy as np
import httpx
import logging
from dataclasses import dataclass, field
from typing import Optional
from indicators import compute_signals, MomentumSignals
from cross_sectional import cross_sectional_rank, select_portfolio, AssetData, RankedAsset

logging.basicConfig(level=logging.INFO, format="%(asctime)s %(levelname)s %(message)s")
logger = logging.getLogger("momentum_agent")

# ---------------------------------------------------------------
# CONFIGURATION
# ---------------------------------------------------------------

API_KEY = "pf_live_your_key_here"
BASE_URL = "https://trading.purpleflea.com"
WALLET_URL = "https://wallet.purpleflea.com"

UNIVERSE = ["BTC-USD", "ETH-USD", "SOL-USD", "AVAX-USD", "MATIC-USD", "LINK-USD"]
CANDLE_LIMIT = 100       # number of price bars to fetch
CANDLE_INTERVAL = "1h"  # candlestick interval
REBALANCE_INTERVAL = 3600  # seconds between rebalances

MAX_LONGS = 2            # max simultaneous long positions
MAX_SHORTS = 2           # max simultaneous short positions
PORTFOLIO_RISK_PCT = 0.02  # risk 2% of portfolio per position
MAX_DRAWDOWN_HALT = 0.15   # halt if drawdown exceeds 15%

# ---------------------------------------------------------------
# AGENT STATE
# ---------------------------------------------------------------

@dataclass
class Position:
    symbol: str
    side: str
    size: float
    entry_price: float
    entry_time: float
    unrealized_pnl: float = 0.0

@dataclass
class AgentState:
    positions: dict[str, Position] = field(default_factory=dict)
    portfolio_value: float = 0.0
    peak_value: float = 0.0
    current_drawdown: float = 0.0
    halted: bool = False
    cycle_count: int = 0

# ---------------------------------------------------------------
# MOMENTUM AGENT
# ---------------------------------------------------------------

class MomentumAgent:
    def __init__(self, api_key: str, universe: list[str]):
        self.api_key = api_key
        self.universe = universe
        self.state = AgentState()
        self.headers = {"Authorization": f"Bearer {api_key}"}
        self.price_cache: dict[str, list[float]] = {sym: [] for sym in universe}

    # -----------------------------------------------------------
    # DATA FETCHING
    # -----------------------------------------------------------

    async def fetch_prices(self, client: httpx.AsyncClient, symbol: str) -> list[float]:
        """Fetch OHLCV candles from Purple Flea and return close prices."""
        try:
            r = await client.get(
                f"{BASE_URL}/v1/candles",
                params={"symbol": symbol, "interval": CANDLE_INTERVAL, "limit": CANDLE_LIMIT},
                headers=self.headers,
            )
            r.raise_for_status()
            candles = r.json().get("candles", [])
            return [float(c["close"]) for c in candles]
        except Exception as e:
            logger.warning(f"Failed to fetch prices for {symbol}: {e}")
            return self.price_cache.get(symbol, [])

    async def fetch_all_prices(self, client: httpx.AsyncClient) -> dict[str, list[float]]:
        """Fetch prices for all universe assets concurrently."""
        tasks = {sym: self.fetch_prices(client, sym) for sym in self.universe}
        results = await asyncio.gather(*tasks.values(), return_exceptions=True)
        price_data: dict[str, list[float]] = {}
        for sym, result in zip(tasks.keys(), results):
            if isinstance(result, Exception):
                price_data[sym] = self.price_cache.get(sym, [])
            else:
                price_data[sym] = result
                self.price_cache[sym] = result
        return price_data

    # -----------------------------------------------------------
    # SIGNAL GENERATION
    # -----------------------------------------------------------

    def roc(self, prices: list[float], period: int = 10) -> float:
        """Single-asset rate of change."""
        arr = np.array(prices)
        if len(arr) < period + 1:
            return 0.0
        return float((arr[-1] - arr[-period]) / arr[-period] * 100)

    def generate_signal(self, symbol: str, prices: list[float]) -> MomentumSignals:
        """Compute full momentum signal stack for a single asset."""
        arr = np.array(prices)
        signals = compute_signals(arr)
        logger.debug(
            f"{symbol}: ROC={signals.roc:.2f}% RSI={signals.rsi:.1f} "
            f"MACD_hist={signals.macd_hist:.4f} combined={signals.combined:.3f} "
            f"direction={signals.direction}"
        )
        return signals

    # -----------------------------------------------------------
    # CROSS-SECTIONAL RANKING
    # -----------------------------------------------------------

    def rank_universe(self, price_data: dict[str, list[float]]) -> list[RankedAsset]:
        """Rank all universe assets by cross-sectional momentum."""
        assets: list[AssetData] = [
            {"symbol": sym, "prices": prices}
            for sym, prices in price_data.items()
            if len(prices) >= 20
        ]
        return cross_sectional_rank(assets, roc_period=10)

    # -----------------------------------------------------------
    # PORTFOLIO VALUE AND DRAWDOWN
    # -----------------------------------------------------------

    async def update_portfolio_value(self, client: httpx.AsyncClient) -> float:
        """Fetch wallet balance and update peak/drawdown."""
        try:
            r = await client.get(f"{WALLET_URL}/v1/balance", headers=self.headers)
            r.raise_for_status()
            data = r.json()
            total_usd = sum(
                info.get("usd_value", 0.0)
                for info in data.get("balances", {}).values()
            )
            self.state.portfolio_value = total_usd
            if total_usd > self.state.peak_value:
                self.state.peak_value = total_usd
            if self.state.peak_value > 0:
                self.state.current_drawdown = (
                    (self.state.peak_value - total_usd) / self.state.peak_value
                )
            return total_usd
        except Exception as e:
            logger.error(f"Failed to fetch portfolio value: {e}")
            return self.state.portfolio_value

    def check_drawdown_halt(self) -> bool:
        """Return True if drawdown exceeds halt threshold."""
        if self.state.current_drawdown >= MAX_DRAWDOWN_HALT:
            if not self.state.halted:
                logger.warning(
                    f"DRAWDOWN HALT: {self.state.current_drawdown:.1%} >= {MAX_DRAWDOWN_HALT:.1%}. "
                    f"Halting new positions."
                )
                self.state.halted = True
            return True
        self.state.halted = False
        return False

    # -----------------------------------------------------------
    # POSITION SIZING (see Section 7 for full detail)
    # -----------------------------------------------------------

    def compute_position_size(
        self,
        symbol: str,
        signal_strength: float,  # absolute value of combined score: 0..1
        price: float,
    ) -> float:
        """
        Scale position size with signal strength.
        Base: risk PORTFOLIO_RISK_PCT of portfolio per unit signal.
        """
        if self.state.portfolio_value <= 0 or price <= 0:
            return 0.0
        base_risk_usd = self.state.portfolio_value * PORTFOLIO_RISK_PCT
        scaled_risk_usd = base_risk_usd * min(signal_strength, 1.0)
        position_size = scaled_risk_usd / price
        return round(position_size, 6)

    # -----------------------------------------------------------
    # ORDER EXECUTION
    # -----------------------------------------------------------

    async def open_position(
        self,
        client: httpx.AsyncClient,
        asset: RankedAsset,
        price: float,
    ) -> bool:
        """Submit a market order for a ranked asset."""
        size = self.compute_position_size(
            asset.symbol,
            abs(asset.combined_score),
            price,
        )
        if size <= 0:
            return False

        side = "buy" if asset.signal == "long" else "sell"
        payload = {
            "symbol": asset.symbol,
            "side": side,
            "size": size,
            "type": "market",
        }
        try:
            r = await client.post(
                f"{BASE_URL}/v1/orders",
                json=payload,
                headers=self.headers,
            )
            r.raise_for_status()
            result = r.json()
            self.state.positions[asset.symbol] = Position(
                symbol=asset.symbol,
                side=side,
                size=size,
                entry_price=price,
                entry_time=asyncio.get_event_loop().time(),
            )
            logger.info(
                f"Opened {side} {asset.symbol}: size={size:.6f} at {price:.2f} "
                f"(score={asset.combined_score:.3f})"
            )
            return True
        except Exception as e:
            logger.error(f"Order failed for {asset.symbol}: {e}")
            return False

    async def close_position(
        self,
        client: httpx.AsyncClient,
        symbol: str,
    ) -> bool:
        """Close an existing position."""
        pos = self.state.positions.get(symbol)
        if not pos:
            return False
        close_side = "sell" if pos.side == "buy" else "buy"
        try:
            r = await client.post(
                f"{BASE_URL}/v1/orders",
                json={"symbol": symbol, "side": close_side, "size": pos.size, "type": "market"},
                headers=self.headers,
            )
            r.raise_for_status()
            del self.state.positions[symbol]
            logger.info(f"Closed position: {symbol} ({pos.side})")
            return True
        except Exception as e:
            logger.error(f"Failed to close {symbol}: {e}")
            return False

    # -----------------------------------------------------------
    # REBALANCE CYCLE
    # -----------------------------------------------------------

    async def rebalance(self, client: httpx.AsyncClient):
        """Main rebalance: fetch data, rank, select, execute."""
        self.state.cycle_count += 1
        logger.info(f"--- Rebalance cycle {self.state.cycle_count} ---")

        # 1. Update portfolio value and check drawdown halt
        await self.update_portfolio_value(client)
        if self.check_drawdown_halt():
            # Close all positions on halt
            for sym in list(self.state.positions.keys()):
                await self.close_position(client, sym)
            return

        # 2. Fetch price data for universe
        price_data = await self.fetch_all_prices(client)

        # 3. Rank universe cross-sectionally
        ranked = self.rank_universe(price_data)

        # 4. Select portfolio
        longs, shorts = select_portfolio(ranked, MAX_LONGS, MAX_SHORTS)
        target_longs = {r.symbol for r in longs}
        target_shorts = {r.symbol for r in shorts}
        target_all = target_longs | target_shorts

        # 5. Close positions no longer in target
        for sym in list(self.state.positions.keys()):
            if sym not in target_all:
                await self.close_position(client, sym)

        # 6. Open new positions for target assets not yet held
        for asset in longs + shorts:
            if asset.symbol not in self.state.positions:
                prices = price_data.get(asset.symbol, [])
                if prices:
                    current_price = prices[-1]
                    await self.open_position(client, asset, current_price)

        # 7. Log current state
        logger.info(
            f"Positions: {list(self.state.positions.keys())} | "
            f"Portfolio: ${self.state.portfolio_value:.2f} | "
            f"Drawdown: {self.state.current_drawdown:.1%}"
        )

    # -----------------------------------------------------------
    # MAIN LOOP
    # -----------------------------------------------------------

    async def run(self):
        logger.info(f"MomentumAgent starting. Universe: {self.universe}")
        async with httpx.AsyncClient(timeout=15.0) as client:
            while True:
                try:
                    await self.rebalance(client)
                except Exception as e:
                    logger.error(f"Rebalance error: {e}")
                await asyncio.sleep(REBALANCE_INTERVAL)


# ---------------------------------------------------------------
# ENTRY POINT
# ---------------------------------------------------------------

if __name__ == "__main__":
    agent = MomentumAgent(api_key=API_KEY, universe=UNIVERSE)
    asyncio.run(agent.run())

5. Momentum Crashes: When to Reduce Exposure

Momentum strategies are subject to severe short-term reversals — "momentum crashes" — that can wipe out months of gains in days. These typically occur when:

  • Market stress events: Sudden volatility spikes cause crowded momentum positions to unwind simultaneously, creating violent reversals.
  • Crowded trades: When the majority of systematic funds hold the same momentum positions, the exit becomes correlated.
  • Macro regime shifts: Interest rate pivots, regulatory shocks, or macroeconomic surprises can reverse trend-following assumptions instantly.
  • Liquidity crises: In low-liquidity conditions (weekends, thin market hours), momentum reversals are amplified.

Crash Detection and Exposure Scaling

crash_detector.py
import numpy as np

def realized_volatility(returns: np.ndarray, window: int = 20) -> float:
    """Annualized realized volatility from a return series."""
    if len(returns) < window:
        return float('inf')
    recent = returns[-window:]
    return float(np.std(recent) * np.sqrt(252 * 24))  # hourly bars

def momentum_crowding_score(ranked_assets: list, top_pct: float = 0.3) -> float:
    """
    Estimate crowding via dispersion of cross-sectional scores.
    Low dispersion → crowded → higher crash risk.
    """
    scores = [r.combined_score for r in ranked_assets]
    if len(scores) < 4:
        return 0.5
    dispersion = float(np.std(scores))
    # Low dispersion means assets are clustered → crowding
    crowding = max(0.0, 1.0 - dispersion * 2.0)
    return crowding

def compute_exposure_scalar(
    current_volatility: float,
    long_run_volatility: float,
    crowding_score: float,  # 0 = uncrowded, 1 = crowded
    drawdown: float,        # 0 to 1
) -> float:
    """
    Return a scalar [0, 1] to multiply target position sizes.
    Reduces exposure during high vol, crowding, or drawdown regimes.

    vol_ratio > 2x long-run vol → scale back by 50%
    crowding > 0.7 → scale back by 30%
    drawdown > 10% → scale back by 50%
    """
    scalar = 1.0

    # Volatility scaling (target-vol approach)
    if long_run_volatility > 0:
        vol_ratio = current_volatility / long_run_volatility
        if vol_ratio > 1.0:
            # Halve exposure when vol doubles
            scalar *= min(1.0, 1.0 / vol_ratio)

    # Crowding penalty
    if crowding_score > 0.7:
        scalar *= (1.0 - 0.5 * (crowding_score - 0.7) / 0.3)

    # Drawdown scaling (Kelly-inspired)
    if drawdown > 0.05:
        scalar *= max(0.1, 1.0 - drawdown * 3.0)

    return max(0.0, min(1.0, scalar))

6. Combining Momentum with Mean Reversion Signals

Pure momentum strategies have high drawdown risk. Combining them with mean reversion signals — particularly at shorter timeframes — creates a more stable return profile with reduced crash exposure.

Signal Combination Framework

The key insight: momentum and mean reversion signals are negatively correlated over short horizons (intraday to 3 days) but positively correlated over medium horizons (1 week to 3 months). Use a timeframe-conditional blend:

signal_combiner.py
import numpy as np
from indicators import compute_signals, rsi

def z_score(prices: np.ndarray, window: int = 20) -> float:
    """Z-score of current price relative to rolling mean. Mean reversion signal."""
    if len(prices) < window:
        return 0.0
    recent = prices[-window:]
    mean = np.mean(recent)
    std = np.std(recent)
    if std == 0:
        return 0.0
    return float((prices[-1] - mean) / std)

def combine_momentum_reversion(
    prices: np.ndarray,
    momentum_weight: float = 0.65,
    reversion_weight: float = 0.35,
    reversion_window: int = 20,
) -> dict:
    """
    Blend medium-term momentum with short-term mean reversion.

    Positive combined score → long
    Negative combined score → short
    Near zero → neutral

    The mean reversion component acts as a timing filter:
    - If momentum says long but price is overbought (high z-score), reduce position.
    - If momentum says long and price is oversold (low z-score), increase position.
    """
    mom = compute_signals(prices)
    mom_score = mom.combined   # [-1, 1]

    # Mean reversion: negative of z-score (high z-score → fade the rally)
    z = z_score(prices, reversion_window)
    rev_score = float(np.tanh(-z / 2.0))  # high z → negative rev signal

    # RSI extreme as additional reversion signal
    rsi_vals = rsi(prices, 14)
    current_rsi = float(rsi_vals[-1]) if len(rsi_vals) > 0 else 50.0
    rsi_rev = (50.0 - current_rsi) / 50.0  # inverted RSI as reversion signal

    # Blend reversion components
    rev_combined = 0.6 * rev_score + 0.4 * rsi_rev

    # Final blend: momentum dominates medium-term, reversion for entry timing
    final_score = momentum_weight * mom_score + reversion_weight * rev_combined

    return {
        "momentum_score": mom_score,
        "reversion_score": rev_combined,
        "z_score": z,
        "rsi": current_rsi,
        "combined": final_score,
        "direction": "long" if final_score > 0.15 else ("short" if final_score < -0.15 else "neutral"),
    }


# Strategy:
# - Rebalance every 4 hours
# - Enter when momentum is strong AND reversion timing is favorable
# - Avoid entering when z_score > 2.0 (overbought) on long signals
# - Avoid entering when z_score < -2.0 (oversold) on short signals

def should_enter(signal: dict, side: str) -> bool:
    """Entry gate: require both momentum and timing alignment."""
    combined = signal["combined"]
    z = signal["z_score"]
    mom = signal["momentum_score"]

    if side == "long":
        if mom < 0.2:
            return False  # momentum not strong enough
        if z > 2.5:
            return False  # overbought — wait for pullback
        return combined > 0.10

    elif side == "short":
        if mom > -0.2:
            return False  # momentum not strong enough
        if z < -2.5:
            return False  # oversold — wait for bounce
        return combined < -0.10

    return False

7. Position Sizing: Scaling with Signal Strength

Naive equal-weight position sizing ignores signal confidence. Signal-scaled sizing allocates more capital to high-conviction signals and reduces size when signals are weak or markets are volatile — a key edge for AI agents operating autonomously.

Kelly-Adjacent Sizing

The full Kelly criterion requires an estimate of win probability and win/loss ratio. For momentum signals, we approximate using signal strength as a proxy for edge:

f* = signal_strength × (W/L) × win_rate - (1 - win_rate)
target_position_USD = portfolio × f* × volatility_scalar

Conservative implementation: use fractional Kelly (0.25× full Kelly) to limit drawdown risk.

position_sizer.py
import numpy as np
from dataclasses import dataclass

@dataclass
class SizingParams:
    portfolio_usd: float
    signal_strength: float   # |combined_score|: 0..1
    current_price: float
    asset_volatility: float  # annualized, e.g. 0.8 = 80%
    # Historical performance estimates (from backtest or live stats)
    win_rate: float = 0.52
    avg_win_loss_ratio: float = 1.4
    kelly_fraction: float = 0.25   # fractional Kelly multiplier
    max_position_pct: float = 0.15 # max 15% of portfolio per position
    min_size_usd: float = 10.0     # minimum order size

def compute_kelly_size(params: SizingParams) -> float:
    """
    Compute position size using fractional Kelly with signal scaling.
    Returns position size in base currency units.
    """
    if params.current_price <= 0 or params.portfolio_usd <= 0:
        return 0.0

    # Kelly fraction based on edge estimates
    edge = params.win_rate * params.avg_win_loss_ratio - (1 - params.win_rate)
    if edge <= 0:
        return 0.0

    full_kelly = edge / params.avg_win_loss_ratio
    fractional_kelly = full_kelly * params.kelly_fraction

    # Scale by signal strength: weak signal → small size
    signal_scaled = fractional_kelly * params.signal_strength

    # Volatility adjustment: target 20% annualized portfolio volatility
    target_vol = 0.20
    vol_scalar = target_vol / max(params.asset_volatility, 0.01)
    vol_adjusted = signal_scaled * min(vol_scalar, 2.0)

    # Convert to USD amount
    position_usd = params.portfolio_usd * vol_adjusted

    # Apply caps
    max_usd = params.portfolio_usd * params.max_position_pct
    position_usd = min(position_usd, max_usd)
    position_usd = max(position_usd, params.min_size_usd)

    # Convert to base currency units
    units = position_usd / params.current_price
    return round(units, 6)


def compute_stop_loss_price(
    entry_price: float,
    side: str,
    atr_multiple: float = 2.0,
    atr: float = 0.0,
) -> float:
    """
    Compute stop-loss price based on ATR multiple.
    Long: stop = entry - 2*ATR
    Short: stop = entry + 2*ATR
    """
    if atr <= 0:
        atr = entry_price * 0.02  # default: 2% of price
    if side == "buy":
        return entry_price - atr_multiple * atr
    else:
        return entry_price + atr_multiple * atr


def average_true_range(highs: np.ndarray, lows: np.ndarray,
                        closes: np.ndarray, period: int = 14) -> float:
    """ATR: measures price range volatility for stop placement."""
    if len(highs) < period + 1:
        return float(closes[-1] * 0.02) if len(closes) > 0 else 0.0
    tr = np.maximum(
        highs[1:] - lows[1:],
        np.maximum(
            np.abs(highs[1:] - closes[:-1]),
            np.abs(lows[1:] - closes[:-1])
        )
    )
    atr_series = np.zeros(len(tr))
    atr_series[0] = np.mean(tr[:period])
    for i in range(1, len(tr)):
        atr_series[i] = (atr_series[i-1] * (period - 1) + tr[i]) / period
    return float(atr_series[-1])

purpleflea_client.py
import httpx
import asyncio
from typing import Optional

BASE_URL = "https://trading.purpleflea.com"
WALLET_URL = "https://wallet.purpleflea.com"
FAUCET_URL = "https://faucet.purpleflea.com"

class PurpleFleatClient:
    """Thin async client for Purple Flea APIs."""

    def __init__(self, api_key: str, timeout: float = 15.0):
        self.api_key = api_key
        self.timeout = timeout
        self.headers = {"Authorization": f"Bearer {api_key}"}

    async def _get(self, client: httpx.AsyncClient, url: str, params: dict = None) -> dict:
        r = await client.get(url, params=params, headers=self.headers, timeout=self.timeout)
        r.raise_for_status()
        return r.json()

    async def _post(self, client: httpx.AsyncClient, url: str, body: dict) -> dict:
        r = await client.post(url, json=body, headers=self.headers, timeout=self.timeout)
        r.raise_for_status()
        return r.json()

    async def get_candles(
        self,
        client: httpx.AsyncClient,
        symbol: str,
        interval: str = "1h",
        limit: int = 100,
    ) -> list[dict]:
        data = await self._get(
            client,
            f"{BASE_URL}/v1/candles",
            params={"symbol": symbol, "interval": interval, "limit": limit},
        )
        return data.get("candles", [])

    async def get_positions(self, client: httpx.AsyncClient) -> list[dict]:
        data = await self._get(client, f"{BASE_URL}/v1/positions")
        return data.get("positions", [])

    async def get_orderbook(
        self,
        client: httpx.AsyncClient,
        symbol: str,
