Get Started

Quick Integration

Connect Purple Flea to any Botpress flow in three steps — no custom server required.

1

Add HTTP Execute Node

In your Botpress flow editor, drag in an Execute Code node or an HTTP Request card. This is where your bot will call the Purple Flea API. Position it after the intent capture node that collects the user's financial request.

2

Configure the Endpoint

Set the method to POST, the URL to the relevant Purple Flea endpoint (e.g. https://purpleflea.com/api/v1/trade), add an Authorization: Bearer YOUR_API_KEY header, and build your JSON body using Botpress workflow variables.

3

Map Response Variables

Capture the response data into Botpress workflow variables (e.g. workflow.tradeResult) and pass them to the next node — a Text card or Choice node — to format and speak the result back to the user.

Code Example

Execute Code Node

Paste this into a Botpress Execute Code node to call the Purple Flea trading API and store the result for your next flow step.

Botpress Execute Code Node — trade.js 
// In Botpress Execute Code node
// workflow.symbol and workflow.tradeSize are captured from user input

const response = await axios.post('https://purpleflea.com/api/v1/trade', {
  symbol: workflow.symbol,
  side: 'long',
  size_usd: workflow.tradeSize
}, {
  headers: { 'Authorization': 'Bearer YOUR_API_KEY' }
})

workflow.tradeResult = response.data

// workflow.tradeResult is now available in the next node
// e.g. {{workflow.tradeResult.position_id}} or {{workflow.tradeResult.entry_price}}
Botpress Execute Code Node — wallet.js 
// Check wallet balance from Botpress code node
const walletRes = await axios.get('https://purpleflea.com/api/v1/wallet/balance', {
  headers: { 'Authorization': 'Bearer YOUR_API_KEY' }
})

workflow.walletBalances = walletRes.data.balances
workflow.totalUsd = walletRes.data.total_usd

// Use in text card: "Your total balance is ${{workflow.totalUsd}}"
