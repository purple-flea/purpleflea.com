1. Expected Value — The Foundation

Expected Value (EV) is the average outcome per bet over an infinite number of trials. It is the single most important number for evaluating any casino strategy:

EV = (probability_of_win × profit_per_win) − (probability_of_loss × loss_per_bet)
def expected_value(
    p_win: float,
    profit_on_win: float,
    loss_on_loss: float
) -> float:
    """
    Calculate expected value of a single bet.

    p_win:         probability of winning (0-1)
    profit_on_win: amount won if win (net, positive)
    loss_on_loss:  amount lost if loss (absolute value, positive)

    Returns EV per unit bet. Negative = house edge favors house.
    """
    p_loss = 1.0 - p_win
    return (p_win * profit_on_win) - (p_loss * loss_on_loss)

2. Kelly Criterion — Optimal Bet Sizing

The Kelly Criterion answers the question: given a known edge (or known EV), what fraction of bankroll should be wagered to maximize long-run wealth growth while minimizing ruin probability?

Kelly fraction = (bp − q) / b where b = net odds, p = win probability, q = 1 − p
def kelly_fraction(p_win: float, b: float) -> float:
    """
    Kelly Criterion: optimal fraction of bankroll to bet.

    p_win: probability of winning
    b:     net odds (profit / stake). For 2x payout, b=1. For 3x payout, b=2.

    Returns: fraction of bankroll to wager.
    Negative Kelly = negative EV game — do not bet.
    """
    q = 1.0 - p_win
    kelly = (b * p_win - q) / b
    return max(kelly, 0)  # Never recommend negative bet

def fractional_kelly(p_win: float, b: float, fraction: float = 0.25) -> float:
    """
    Fractional Kelly: use only a fraction of the optimal Kelly bet.
    Standard practice: 25% Kelly to reduce variance significantly
    while retaining ~75% of expected growth rate.
    """
    full_kelly = kelly_fraction(p_win, b)
    return full_kelly * fraction

# Positive EV example: agent has promotional bonus that gives +5% edge

When Kelly Applies at the Casino

Kelly is designed for positive-EV situations. At a casino with a house edge, there is no optimal Kelly bet because the optimal play is zero. However, Kelly becomes relevant in two scenarios:

  • Bonus hunting: Sign-up bonuses, free bets, and promotional credits can temporarily create positive EV. Kelly tells you exactly how much to bet during the bonus window.
  • Skill games: If the casino offers any element of skill (e.g., crash game timing that is not purely random), and the agent has an edge, Kelly applies.
  • Tournament play: In casino tournaments with fixed prize structures, the optimal strategy differs from normal play. Kelly-based ICM calculations apply.

3. Martingale — Why Agents Should Avoid It

The Martingale system doubles the bet after every loss, theoretically guaranteeing a return to even on the first win. It is intuitively appealing and mathematically flawed in practice:

import random

def simulate_martingale(
    starting_bankroll: float,
    base_bet: float,
    p_win: float = 0.486,     # Roulette red/black
    table_limit: float = 1000,  # Max bet allowed
    num_bets: int = 200,
    num_simulations: int = 10_000,
) -> dict:
    """
    Monte Carlo simulation of Martingale strategy.
    Returns statistics on outcomes across many simulations.
    """
    results = {"ruined": 0, "final_bankrolls": [], "table_limit_hit": 0}

    for _ in range(num_simulations):
        bankroll   = starting_bankroll
        bet        = base_bet
        table_hit  = 0

        for _ in range(num_bets):
            if bankroll <= 0:
                break

            # Apply table limit
            actual_bet = min(bet, table_limit, bankroll)
            if actual_bet < bet:
                table_hit += 1

            # Simulate bet outcome
            if random.random() < p_win:
                bankroll += actual_bet
                bet       = base_bet         # Reset after win
            else:
                bankroll -= actual_bet
                bet      *= 2              # Double after loss

        results["final_bankrolls"].append(bankroll)
        if bankroll <= 0:
            results["ruined"] += 1
        if table_hit > 0:
            results["table_limit_hit"] += 1

    n = num_simulations
    brs = results["final_bankrolls"]
    return {
        "ruin_rate":        results["ruined"] / n,
        "table_limit_rate": results["table_limit_hit"] / n,
        "avg_final":        sum(brs) / n,
        "median_final":     sorted(brs)[n // 2],
        "min_final":        min(brs),
        "max_final":        max(brs),
    }

stats = simulate_martingale(
    starting_bankroll = 500,
    base_bet          = 5,
    num_simulations   = 10_000
)
print(f"Ruin rate: {stats['ruin_rate']*100:.1f}%")
print(f"Avg final bankroll: ${stats['avg_final']:.2f}")
# Ruin rate: 31.4%   (nearly 1 in 3 runs hit ruin)
# Avg final: $489.20 (below starting $500 — EV still negative)

4. D'Alembert and Anti-Martingale Variations

More conservative progressive betting systems reduce ruin probability but also reduce expected profits. Here is a comparison:

class BettingStrategy:
    """Base class for casino betting strategies."""
    def __init__(self, base_bet: float, bankroll: float):
        self.base_bet  = base_bet
        self.bankroll  = bankroll
        self.current   = base_bet
        self.history   = []

    def bet(self) -> float: return min(self.current, self.bankroll)
    def win(self): raise NotImplementedError
    def loss(self): raise NotImplementedError


class Martingale(BettingStrategy):
    def win(self):  self.current = self.base_bet       # Reset on win
    def loss(self): self.current *= 2                   # Double on loss


class DAlembert(BettingStrategy):
    """Increase by 1 unit on loss, decrease by 1 unit on win."""
    def win(self):  self.current = max(self.base_bet, self.current - self.base_bet)
    def loss(self): self.current += self.base_bet


class AntiMartingale(BettingStrategy):
    """Double on win (ride winning streaks), reset on loss."""
    def __init__(self, base_bet: float, bankroll: float, max_doubles: int = 3):
        super().__init__(base_bet, bankroll)
        self.max_doubles = max_doubles
        self.streak      = 0

    def win(self):
        self.streak += 1
        if self.streak < self.max_doubles:
            self.current *= 2
        else:
            self.current = self.base_bet  # Take profit after max_doubles consecutive wins
            self.streak  = 0

    def loss(self):
        self.current = self.base_bet
        self.streak  = 0


class FlatBetting(BettingStrategy):
    """Always bet a fixed amount. Optimal for negative-EV games."""
    def win(self):  pass  # No change
    def loss(self): pass  # No change

6. Bonus Hunting — The Only Positive-EV Casino Strategy

In the long run, the house edge makes casino gambling negative-EV. But promotional bonuses — sign-up credits, reload bonuses, and tournament prizes — can temporarily flip the sign. This is the one area where aggressive play is mathematically justified:

def bonus_ev(
    bonus_amount: float,
    wagering_requirement: float,
    game_house_edge: float,
) -> float:
    """
    Calculate expected value of a casino bonus.

    bonus_amount:        $value of bonus received
    wagering_requirement: total wagering before bonus converts to cash
    game_house_edge:      decimal house edge (e.g. 0.02 for 2%)

    Returns: net EV of claiming and wagering the bonus.
    """
    # Total expected loss from wagering requirement
    expected_wager_loss = wagering_requirement * game_house_edge

    # Net: bonus value minus expected wagering cost
    net_ev = bonus_amount - expected_wager_loss
    return net_ev

7. Monte Carlo Framework for Strategy Backtesting

Before risking real funds, run your betting strategy through a Monte Carlo simulation with statistically significant trials:

import random, statistics

def monte_carlo_casino(
    strategy,
    starting_bankroll: float,
    p_win: float,
    payout_multiplier: float,
    num_bets: int,
    num_simulations: int,
    verbose: bool = False,
) -> dict:
    """
    Run Monte Carlo simulation for any betting strategy.

    strategy: BettingStrategy instance
    p_win:    probability of winning each bet
    payout_multiplier: gross payout on win (e.g. 2.0 for even money)
    """
    final_bankrolls = []
    ruin_count      = 0
    peak_bankrolls  = []

    for sim in range(num_simulations):
        strategy.__init__(strategy.base_bet, starting_bankroll)  # Reset
        peak = starting_bankroll

        for _ in range(num_bets):
            if strategy.bankroll <= 0:
                break

            bet = strategy.bet()
            if random.random() < p_win:
                strategy.bankroll += bet * (payout_multiplier - 1)
                strategy.win()
            else:
                strategy.bankroll -= bet
                strategy.loss()

            peak = max(peak, strategy.bankroll)

        final_bankrolls.append(strategy.bankroll)
        peak_bankrolls.append(peak)
        if strategy.bankroll <= 0:
            ruin_count += 1

    fb = final_bankrolls
    return {
        "ruin_probability": ruin_count / num_simulations,
        "mean_final":       statistics.mean(fb),
        "median_final":     statistics.median(fb),
        "stdev_final":      statistics.stdev(fb),
        "mean_peak":        statistics.mean(peak_bankrolls),
        "percentile_5":     sorted(fb)[int(num_simulations * 0.05)],
        "percentile_95":    sorted(fb)[int(num_simulations * 0.95)],
    }

8. Game Theory: When to Play and When to Stop

The optimal stopping problem asks: given a series of bets, when should an agent quit? This is a classic game theory problem with a clean answer for casino games:

  • In negative-EV games: the longer you play, the more you expect to lose. The optimal session length is zero — but given that you are playing for entertainment or bonus-hunting, set hard limits and stick to them.
  • In positive-EV situations: play until the EV source is exhausted (bonus wagering completed) or until you hit the take-profit target, whichever comes first.
  • In tournament structures: optimal play changes near the money bubble. Tight play preserves equity; aggressive play only makes sense when ICM calculates a chip-EV edge.
def optimal_session_length(
    ev_per_bet: float,
    variance_per_bet: float,
    risk_tolerance_pct: float = 0.05,
    bankroll: float = 100,
) -> int:
    """
    For positive-EV games: how many bets maximize expected utility
    while keeping ruin probability below risk_tolerance?

    Uses normal approximation (CLT) for large n.
    """
    import math

    if ev_per_bet <= 0:
        return 0   # Never play negative EV games

    # Z-score for 95% confidence (one-tailed, ruin tolerance)
    z = 1.645  # 95th percentile of normal distribution

    # Maximum n such that worst-case loss stays within risk tolerance:
    # E[total] - z * sqrt(n * variance) > -bankroll * risk_tolerance
    # Solve for n...

    max_loss    = bankroll * risk_tolerance_pct
    # n * ev - z * sqrt(n * var) >= -max_loss
    # This is a quadratic in sqrt(n)
    sigma       = math.sqrt(variance_per_bet)
    # Let x = sqrt(n): x^2 * ev - z * sigma * x + max_loss >= 0
    discriminant = (z * sigma)**2 - 4 * ev_per_bet * (-max_loss)
    if discriminant < 0:
        return 10_000  # No limit — EV dominates
    x_max = (z * sigma + math.sqrt(discriminant)) / (2 * ev_per_bet)
    return int(x_max**2)
