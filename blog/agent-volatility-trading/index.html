Understanding Volatility as an Asset Class

Volatility is not a price — it is a measure of how much a price moves. But volatility itself moves, has trends, and mean-reverts. Two distinct types of volatility matter for traders:

Realized Volatility (RV): Also called historical or statistical volatility. This is the actual volatility that occurred in the past, calculated from historical price returns. It is backward-looking and objective — you can measure it precisely after the fact.

Implied Volatility (IV): The market's forward-looking expectation of volatility, extracted from option prices using an options pricing model (Black-Scholes or its variants). IV is a consensus view of future volatility embedded in the current option price. It is what the market is willing to pay for future uncertainty.

Volatility Risk Premium = Implied Volatility - Realized Volatility

The volatility risk premium (VRP) is the most important structural feature in vol markets: implied volatility consistently exceeds realized volatility over time. This premium exists because option buyers pay extra for insurance against tail events, and option sellers earn this premium as compensation for tail risk.

The Central Trade: Systematically short implied volatility when it is expensive relative to realized volatility. This is the foundation of professional vol-selling strategies, including those run by the largest hedge funds in the world.

VIX and Crypto Volatility Indexes

The VIX: Fear Index Fundamentals

The CBOE VIX measures the 30-day implied volatility of S&P 500 options. It is calculated using a model-free methodology that aggregates options prices across all strikes. VIX of 20 means the market expects the S&P 500 to move approximately 20% annualized — or about 5.77% over the next 30 days (20 divided by the square root of 12).

Computing Implied and Realized Volatility

Realized Volatility Calculation

Realized volatility is computed from log returns. The annualized standard deviation of daily log returns is the standard form:

RV = std(log(P_t / P_{t-1})) x sqrt(365)
(annualized, using 365 for crypto, 252 for equities) 
import numpy as np
import pandas as pd

def realized_vol(
    prices: np.ndarray,
    window: int = 30,
    annualize: bool = True,
    periods_per_year: int = 365
) -> np.ndarray:
    """
    Compute rolling realized volatility from price series.
    Returns annualized standard deviation of log returns as percentage.
    """
    log_returns = np.log(prices[1:] / prices[:-1])
    rv = pd.Series(log_returns).rolling(window).std()
    if annualize:
        rv = rv * np.sqrt(periods_per_year)
    return rv.values * 100  # to percentage


def parkinson_vol(
    high: np.ndarray,
    low: np.ndarray,
    window: int = 30,
    periods_per_year: int = 365
) -> np.ndarray:
    """
    Parkinson volatility estimator using high/low prices.
    More efficient than close-to-close; reduces noise from drift.
    """
    hl_log = np.log(high / low) ** 2
    factor = 1.0 / (4 * np.log(2))
    pv = pd.Series(hl_log).rolling(window).mean()
    pv = np.sqrt(factor * pv * periods_per_year)
    return pv.values * 100


def yang_zhang_vol(
    open_: np.ndarray,
    high: np.ndarray,
    low: np.ndarray,
    close: np.ndarray,
    window: int = 30,
    periods_per_year: int = 365
) -> np.ndarray:
    """
    Yang-Zhang volatility estimator — handles overnight jumps.
    Widely considered the most accurate OHLC-based estimator.
    """
    log_oc_prev = np.log(open_[1:] / close[:-1])
    log_co = np.log(close[1:] / open_[1:])
    log_ho = np.log(high[1:] / open_[1:])
    log_lo = np.log(low[1:] / open_[1:])
    rs = log_ho * (log_ho - log_co) + log_lo * (log_lo - log_co)

    k = 0.34 / (1.34 + (window + 1) / (window - 1))
    ser = pd.Series

    overnight_var = ser(log_oc_prev**2).rolling(window).mean()
    oc_var = ser(log_co**2).rolling(window).mean()
    rs_var = ser(rs).rolling(window).mean()

    yz_var = overnight_var + k * oc_var + (1 - k) * rs_var
    yz_vol = np.sqrt(yz_var * periods_per_year)
    return yz_vol.values * 100


def intraday_rv(
    minute_closes: np.ndarray,
    trading_minutes_per_day: int = 1440
) -> float:
    """
    Compute realized variance from 1-minute returns.
    More accurate than daily estimates for fast vol changes.
    """
    log_ret = np.log(minute_closes[1:] / minute_closes[:-1])
    rv = np.sum(log_ret**2)
    annualized_rv = rv * (trading_minutes_per_day * 365)
    return np.sqrt(annualized_rv) * 100

Fetching Implied Volatility for Crypto

For crypto options, Deribit is the primary source of IV data. Their public API provides real-time option chain data including IV for each strike and expiry. 

import httpx
import asyncio
import time

async def fetch_deribit_dvol(
    client: httpx.AsyncClient,
    currency: str = "BTC"
) -> float:
    """Fetch current DVOL index from Deribit."""
    resp = await client.get(
        "https://www.deribit.com/api/v2/public/get_volatility_index_data",
        params={
            "currency": currency,
            "resolution": "3600",
            "count": 1
        }
    )
    data = resp.json().get("result", {}).get("data", [[]])
    if data:
        # data format: [timestamp_ms, open, high, low, close]
        return float(data[-1][4])  # close (current) DVOL
    return 65.0  # fallback to historical mean


async def get_atm_iv(
    client: httpx.AsyncClient,
    currency: str,
    spot_price: float,
    days_to_expiry: int = 30
) -> float:
    """
    Find and return the ATM implied vol for the nearest option to
    a target expiry date. Approximated via DVOL if no direct match.
    """
    resp = await client.get(
        "https://www.deribit.com/api/v2/public/get_instruments",
        params={"currency": currency, "kind": "option", "expired": False}
    )
    instruments = resp.json().get("result", [])
    now = time.time()
    target_s = days_to_expiry * 86400

    # Filter to target expiry window
    candidates = [
        i for i in instruments
        if i.get("option_type") == "call"
        and abs(i["expiration_timestamp"] / 1000 - now - target_s) < 4 * 86400
    ]
    if not candidates:
        return await fetch_deribit_dvol(client, currency)

    # Find ATM strike (closest to spot)
    atm = min(candidates, key=lambda i: abs(i["strike"] - spot_price))
    ticker_resp = await client.get(
        "https://www.deribit.com/api/v2/public/ticker",
        params={"instrument_name": atm["instrument_name"]}
    )
    iv = ticker_resp.json().get("result", {}).get("mark_iv", 65.0)
    return float(iv)

IV Rank and IV Percentile

Raw implied volatility numbers are meaningless without context. BTC IV of 60% sounds high — but if it has been above 80% for the past year, 60% is actually low. This is why IV rank and IV percentile are the preferred metrics for vol traders.

IV Percentile (IVP)

IV Percentile measures what percentage of past days had IV lower than the current level. If IV is at the 80th percentile, it means 80% of the days in the lookback period had lower IV — current vol is expensive relative to history.

IVP = (days where past_IV < current_IV) / total_days x 100

IV Rank (IVR)

IV Rank normalizes current IV between the 52-week high and low:

IVR = (current_IV - 52w_low) / (52w_high - 52w_low) x 100
IV Rank vs IV Percentile: IVR is more sensitive to recent extreme spikes. If BTC IV hit 200% once in the past year, that single event anchors the IVR denominator, making all other readings appear low. IVP is more robust to outliers — it uses rank ordering, not absolute levels. For crypto, IVP is generally preferred. 
import numpy as np
import pandas as pd

def compute_iv_rank(
    iv_series: pd.Series,
    current_iv: float,
    lookback_days: int = 252
) -> float:
    """Compute IV Rank over the lookback period. Returns 0-100."""
    hist = iv_series.iloc[-lookback_days:]
    iv_high = hist.max()
    iv_low = hist.min()
    if iv_high == iv_low:
        return 50.0
    return (current_iv - iv_low) / (iv_high - iv_low) * 100


def compute_iv_percentile(
    iv_series: pd.Series,
    current_iv: float,
    lookback_days: int = 252
) -> float:
    """IV Percentile: % of past days with lower IV. Returns 0-100."""
    hist = iv_series.iloc[-lookback_days:]
    return float((hist < current_iv).mean() * 100)


def compute_vol_metrics(
    iv_history: pd.Series,
    rv_history: pd.Series,
    lookback: int = 252
) -> dict:
    """Compute comprehensive vol metrics for trading signal generation."""
    current_iv = float(iv_history.iloc[-1])
    current_rv = float(rv_history.iloc[-1])
    vrp = current_iv - current_rv

    ivr = compute_iv_rank(iv_history, current_iv, lookback)
    ivp = compute_iv_percentile(iv_history, current_iv, lookback)

    vrp_history = iv_history.values[-lookback:] - rv_history.values[-lookback:]
    vrp_percentile = float((vrp_history < vrp).mean() * 100)

    iv_sma5 = float(iv_history.iloc[-5:].mean())
    iv_sma20 = float(iv_history.iloc[-20:].mean())
    iv_trend = 'rising' if iv_sma5 > iv_sma20 else 'falling'
    iv_vol = float(iv_history.iloc[-30:].std())

    return {
        'current_iv': current_iv,
        'current_rv': current_rv,
        'vrp': vrp,
        'iv_rank': ivr,
        'iv_percentile': ivp,
        'vrp_percentile': vrp_percentile,
        'iv_trend': iv_trend,
        'iv_sma5': iv_sma5,
        'iv_sma20': iv_sma20,
        'vol_of_vol': iv_vol
    }


def generate_vol_signal(metrics: dict) -> str:
    """
    Generate trading signal based on IV rank, VRP, and trend.
    Returns: 'strong_sell_vol', 'sell_vol', 'neutral', 'buy_vol'
    """
    ivp = metrics['iv_percentile']
    vrp = metrics['vrp']
    vrp_pct = metrics['vrp_percentile']
    trend = metrics['iv_trend']

    if ivp >= 80 and vrp_pct >= 70 and trend == 'falling':
        return 'strong_sell_vol'
    if ivp >= 65 and vrp > 3.0:
        return 'sell_vol'
    if ivp <= 20 and vrp < -2.0:
        return 'buy_vol'
    return 'neutral'

Volatility Mean Reversion

Volatility exhibits one of the strongest mean-reversion properties of any financial time series. This is both theoretically expected (extreme market stress cannot persist indefinitely) and empirically observed across all asset classes.

Half-Life of Volatility

The half-life of vol mean reversion tells you how quickly elevated vol tends to decay back toward its long-run mean. For BTC, the half-life is approximately 15-25 days — meaning a vol spike tends to decay by half within 2-4 weeks. 

from scipy import stats

def estimate_vol_halflife(iv_series: np.ndarray) -> float:
    """
    Estimate mean-reversion half-life of implied volatility series.
    Uses Ornstein-Uhlenbeck AR(1) approximation.
    Half-life = ln(2) / kappa
    """
    x = iv_series[:-1]
    y = iv_series[1:]
    slope, intercept, r, p, se = stats.linregress(x, y)
    if slope <= 0 or slope >= 1:
        return float('inf')
    kappa = -np.log(slope)
    return np.log(2) / kappa


def ou_forecast(
    current_iv: float,
    long_run_mean: float,
    kappa: float,
    horizon_days: int,
    sigma: float = 10.0
) -> dict:
    """
    Project future IV using Ornstein-Uhlenbeck mean reversion.
    E[X_T] = X_0 * exp(-kappa*T) + mu * (1 - exp(-kappa*T))
    """
    decay = np.exp(-kappa * horizon_days)
    expected_iv = current_iv * decay + long_run_mean * (1 - decay)
    variance = (sigma**2 / (2 * kappa)) * (1 - np.exp(-2 * kappa * horizon_days))
    std_dev = np.sqrt(variance)

    return {
        'expected_iv': expected_iv,
        'lower_1sigma': expected_iv - std_dev,
        'upper_1sigma': expected_iv + std_dev,
        'decay_factor': decay
    }


# Example: BTC IV at 90%, historical mean 65%, half-life 20 days
# kappa = ln(2) / 20 = 0.0347
forecast = ou_forecast(90.0, 65.0, kappa=0.0347, horizon_days=14)
print(f"14-day IV forecast: {forecast['expected_iv']:.1f}%")
# Output: 14-day IV forecast: 77.8%
# 90% IV expected to decay to ~78% over 2 weeks

Trading the Vol Mean Reversion on Perpetuals

The practical way to trade vol mean reversion without options is through variance-sensitive position management on perpetual futures:

  • Volatility-normalized sizing: Target constant dollar vol risk per trade regardless of current IV — size down automatically when vol spikes
  • Vol-spike fading: When short-term realized vol spikes far above its recent average, take a mean-reversion position expecting the spike to decay
  • Vol-targeting trend following: Increase position size as vol falls, reduce as vol rises — the classic risk parity approach applied to individual positions
  • Regime-conditional exposure: Pause or reduce new entries when vol is in the top quartile of its historical distribution

Exploiting the Volatility Risk Premium

The volatility risk premium (VRP) is one of the most robust return premia in financial markets. It exists in equities, commodities, FX, and crypto. For AI agents, systematically harvesting the VRP is achievable through vol-sensitive position management on perpetual futures.

VRP Position Sizer

class VRPPositionSizer:
    """
    Size perpetual futures positions based on VRP and vol-targeting.
    Core idea: maintain constant dollar volatility risk per day.
    """

    def __init__(
        self,
        target_daily_vol_usd: float = 500.0,
        max_position_usd: float = 50_000.0,
        vrp_adjustment: bool = True
    ):
        self.target_daily_vol = target_daily_vol_usd
        self.max_pos = max_position_usd
        self.vrp_adjustment = vrp_adjustment

    def compute_base_size(self, realized_vol_annual_pct: float) -> float:
        """
        Vol-targeting: size to achieve target_daily_vol_usd of P&L volatility.
        daily_vol = position_usd x (annual_vol / sqrt(365))
        position_usd = target_daily_vol / daily_vol_pct
        """
        daily_vol_pct = (realized_vol_annual_pct / 100) / np.sqrt(365)
        if daily_vol_pct == 0:
            return 0.0
        position_usd = self.target_daily_vol / daily_vol_pct
        return min(position_usd, self.max_pos)

    def apply_vrp_adjustment(
        self, base_size: float, vrp: float,
        vrp_mean: float = 5.0, vrp_std: float = 8.0
    ) -> float:
        """
        Adjust position size based on VRP z-score.
        High VRP z-score (IV very expensive) → reduce size.
        Low VRP z-score (IV cheap) → increase size.
        """
        if not self.vrp_adjustment:
            return base_size

        vrp_z = (vrp - vrp_mean) / vrp_std
        # Scale: 1.0 at neutral, 0.6 at +2sigma VRP, 1.4 at -2sigma VRP
        scale = 1.0 - 0.2 * np.tanh(vrp_z)
        scale = np.clip(scale, 0.5, 1.5)
        return min(base_size * scale, self.max_pos)

    def size_position(
        self,
        realized_vol_pct: float,
        implied_vol_pct: float,
        direction: float
    ) -> float:
        """Returns signed position size in USD."""
        base = self.compute_base_size(realized_vol_pct)
        vrp = implied_vol_pct - realized_vol_pct
        adjusted = self.apply_vrp_adjustment(base, vrp)
        return direction * adjusted


# Example sizing comparison
sizer = VRPPositionSizer(target_daily_vol_usd=1000.0, max_position_usd=100_000)

# BTC: RV=55%, IV=70% (high VRP) → scale down
size_high_vrp = sizer.size_position(55.0, 70.0, +1)
print(f"High VRP position: ${size_high_vrp:,.0f}")  # ~$15,000

# BTC: RV=60%, IV=58% (negative VRP) → scale up
size_low_vrp = sizer.size_position(60.0, 58.0, +1)
print(f"Low VRP position: ${size_low_vrp:,.0f}")  # ~$25,000

Systematic Volatility Selling on Perpetuals

Without options access, the closest analog to vol-selling on perpetual futures is a mean-reverting strategy that fades extreme moves. When volatility spikes and prices make large moves, systematic mean-reversion strategies effectively go short volatility — they profit when price reverts, which happens more often than price continues trending after a spike. 

import asyncio
import numpy as np
import httpx
from collections import deque
import time
from typing import Optional

PF_BASE = "https://api.purpleflea.com"

class VolSpikeFadeAgent:
    """
    Fades volatility spikes on perpetual futures.
    When realized vol spikes far above its recent average,
    takes a mean-reversion position expecting vol to decay.
    """

    def __init__(
        self,
        api_key: str,
        symbol: str,
        vol_spike_threshold: float = 2.5,
        target_daily_vol_usd: float = 500.0,
        max_hold_hours: int = 48
    ):
        self.api_key = api_key
        self.symbol = symbol
        self.threshold = vol_spike_threshold
        self.sizer = VRPPositionSizer(target_daily_vol_usd)
        self.max_hold = max_hold_hours
        self.price_history: deque = deque(maxlen=500)
        self.vol_history: deque = deque(maxlen=252)
        self.current_position = 0.0
        self.position_entry_time: Optional[float] = None
        self.entry_idx: Optional[int] = None
        self.sample_count = 0
        self.client = httpx.AsyncClient()

    def update_price(self, price: float):
        self.price_history.append((time.time(), price))
        self.sample_count += 1
        if len(self.price_history) >= 61:
            prices = np.array([p[1] for p in list(self.price_history)[-61:]])
            rv = float(realized_vol(prices, window=60, periods_per_year=365 * 24))
            self.vol_history.append(rv)

    def compute_vol_zscore(self) -> Optional[float]:
        if len(self.vol_history) < 50:
            return None
        vol_arr = np.array(list(self.vol_history))
        current = vol_arr[-1]
        hist_mean = vol_arr[-50:].mean()
        hist_std = vol_arr[-50:].std()
        if hist_std == 0:
            return None
        return (current - hist_mean) / hist_std

    def get_price_direction(self, lookback: int = 10) -> float:
        if len(self.price_history) < lookback:
            return 0.0
        prices = [p[1] for p in list(self.price_history)[-lookback:]]
        change = (prices[-1] - prices[0]) / prices[0]
        return float(np.sign(change))

    async def run_strategy(self, current_price: float, implied_vol: float = None):
        self.update_price(current_price)
        vol_z = self.compute_vol_zscore()
        if vol_z is None:
            return

        current_rv = self.vol_history[-1] if self.vol_history else 50.0
        iv = implied_vol or current_rv * 1.08

        # Check max holding period
        if self.current_position != 0 and self.position_entry_time:
            hours_held = (time.time() - self.position_entry_time) / 3600
            if hours_held > self.max_hold:
                await self._close_position("max hold reached")
                return

        # Vol spike: enter fade position (opposite to recent direction)
        if vol_z >= self.threshold and self.current_position == 0:
            direction = -self.get_price_direction()
            if direction == 0:
                direction = -1.0
            size = self.sizer.size_position(current_rv, iv, direction)
            if abs(size) > 100:
                await self._open_position(size, vol_z, current_rv)

        # Vol normalized: exit position
        elif self.current_position != 0 and vol_z < 1.0:
            await self._close_position("vol normalized")

    async def _open_position(self, size: float, vol_z: float, rv: float):
        side = 'buy' if size > 0 else 'sell'
        await self.client.post(
            f"{PF_BASE}/v1/trading/order",
            json={"symbol": self.symbol, "side": side,
                  "size_usd": abs(size), "type": "market"},
            headers={"X-API-Key": self.api_key}
        )
        self.current_position = size
        self.position_entry_time = time.time()
        print(f"Opened vol-fade {side} ${abs(size):,.0f} | vol_z={vol_z:.2f} rv={rv:.1f}%")

    async def _close_position(self, reason: str):
        if self.current_position == 0:
            return
        close_side = 'sell' if self.current_position > 0 else 'buy'
        await self.client.post(
            f"{PF_BASE}/v1/trading/order",
            json={"symbol": self.symbol, "side": close_side,
                  "size_usd": abs(self.current_position), "type": "market",
                  "reduce_only": True},
            headers={"X-API-Key": self.api_key}
        )
        duration = (time.time() - self.position_entry_time) / 3600
        print(f"Closed | reason={reason} | held={duration:.1f}h")
        self.current_position = 0
        self.position_entry_time = None

Python Backtesting Framework for Vol Strategies

Backtesting volatility strategies requires careful attention to look-ahead bias, data snooping, and regime stability. The following framework provides a solid foundation. 

import pandas as pd
import numpy as np
from dataclasses import dataclass, field
from typing import List

@dataclass
class Trade:
    entry_time: pd.Timestamp
    exit_time: pd.Timestamp
    direction: int
    entry_price: float
    exit_price: float
    size_usd: float
    entry_vol_z: float
    pnl_usd: float
    pnl_pct: float
    hold_periods: int

@dataclass
class BacktestResult:
    trades: List[Trade] = field(default_factory=list)
    equity_curve: pd.Series = None
    total_return_pct: float = 0.0
    sharpe_ratio: float = 0.0
    max_drawdown_pct: float = 0.0
    win_rate: float = 0.0
    avg_hold_h: float = 0.0
    total_trades: int = 0

def backtest_vol_fade(
    price_data: pd.Series,
    rv_data: pd.Series,
    iv_data: pd.Series = None,
    vol_z_entry: float = 2.5,
    vol_z_exit: float = 1.0,
    max_hold_h: int = 48,
    target_daily_vol_usd: float = 500.0,
    fee_pct: float = 0.035
) -> BacktestResult:
    result = BacktestResult()
    sizer = VRPPositionSizer(target_daily_vol_usd)

    position = 0.0
    entry_price = 0.0
    entry_time = None
    entry_vol_z = 0.0
    entry_idx = None
    equity = 10_000.0
    equity_pts = []

    vol_zscore = (rv_data - rv_data.rolling(50).mean()) / rv_data.rolling(50).std()
    recent_ret = price_data.pct_change(10)

    for i in range(50, len(price_data)):
        ts = price_data.index[i]
        price = price_data.iloc[i]
        rv = rv_data.iloc[i]
        vz = vol_zscore.iloc[i]
        ret_dir = np.sign(recent_ret.iloc[i]) if not pd.isna(recent_ret.iloc[i]) else 0
        iv = iv_data.iloc[i] if iv_data is not None else rv * 1.08

        # Exit check
        if position != 0 and entry_idx is not None:
            hours_held = i - entry_idx
            should_exit = (vz < vol_z_exit) or (hours_held >= max_hold_h)
            if should_exit:
                direction = np.sign(position)
                pnl_pct = direction * (price - entry_price) / entry_price * 100
                pnl_pct -= fee_pct * 2
                pnl_usd = abs(position) * pnl_pct / 100
                result.trades.append(Trade(
                    entry_time=entry_time, exit_time=ts,
                    direction=int(direction), entry_price=entry_price,
                    exit_price=price, size_usd=abs(position),
                    entry_vol_z=entry_vol_z, pnl_usd=pnl_usd,
                    pnl_pct=pnl_pct, hold_periods=hours_held
                ))
                equity += pnl_usd
                position = 0.0
                entry_idx = None

        # Entry check
        if position == 0 and not pd.isna(vz) and vz >= vol_z_entry:
            direction = -ret_dir if ret_dir != 0 else -1
            size = sizer.size_position(rv, iv, direction)
            size = min(abs(size), equity * 0.5)
            position = direction * size
            entry_price = price
            entry_time = ts
            entry_idx = i
            entry_vol_z = vz

        equity_pts.append((ts, equity))

    # Compute summary statistics
    eq = pd.Series([e[1] for e in equity_pts],
                   index=[e[0] for e in equity_pts])
    ret = eq.pct_change().dropna()
    result.equity_curve = eq
    result.total_return_pct = (eq.iloc[-1] / eq.iloc[0] - 1) * 100
    result.sharpe_ratio = (
        ret.mean() / ret.std() * np.sqrt(365 * 24) if ret.std() > 0 else 0
    )
    dd = (eq / eq.cummax() - 1) * 100
    result.max_drawdown_pct = float(dd.min())
    wins = [t for t in result.trades if t.pnl_usd > 0]
    result.win_rate = len(wins) / len(result.trades) if result.trades else 0
    result.total_trades = len(result.trades)
    result.avg_hold_h = (
        np.mean([t.hold_periods for t in result.trades]) if result.trades else 0
    )
    return result

Volatility Regime Detection

Vol strategies perform differently in different regimes. A vol-selling strategy that works in a calm trending market can suffer severe losses during a volatility explosion. Regime detection allows agents to switch strategy parameters based on current market conditions. 

from enum import Enum

class VolRegime(Enum):
    LOW_VOL_TRENDING = "low_vol_trending"
    LOW_VOL_RANGING = "low_vol_ranging"
    HIGH_VOL_TRENDING = "high_vol_trending"
    HIGH_VOL_SPIKING = "high_vol_spiking"
    VOL_CRASH = "vol_crash"

def detect_vol_regime(
    rv_30d: float,
    rv_7d: float,
    rv_1d: float,
    rv_long_mean: float = 55.0,
    trend_strength: float = 0.0
) -> VolRegime:
    vol_expanding = rv_1d > rv_7d * 1.3
    vol_contracting = rv_1d < rv_7d * 0.7
    elevated_vol = rv_30d > rv_long_mean * 1.3
    low_vol = rv_30d < rv_long_mean * 0.7
    trending = abs(trend_strength) > 25

    if vol_contracting and elevated_vol:
        return VolRegime.VOL_CRASH
    if vol_expanding and elevated_vol:
        return VolRegime.HIGH_VOL_SPIKING
    if elevated_vol:
        return VolRegime.HIGH_VOL_TRENDING
    if low_vol and trending:
        return VolRegime.LOW_VOL_TRENDING
    return VolRegime.LOW_VOL_RANGING

Risk Controls for Vol Strategies

Vol strategies can experience severe tail events. The 2020 "Vol-mageddon" destroyed structured products worth billions. Crypto vol events in 2022 (LUNA collapse, FTX implosion) were similarly catastrophic for underprepared vol-sellers. Risk management is not optional.

Warning: Volatility strategies are NOT low risk. They can look like steady income streams for months, then suffer catastrophic losses in a single event. Always maintain strict position limits and automated kill switches.

Critical Risk Rules

  • Maximum drawdown kill switch: If drawdown exceeds 15%, close all positions and pause trading for 72 hours
  • Vol-of-vol filter: If implied vol is rising faster than 5 vol points per day, halt new vol-selling entries
  • Correlation spike detection: If multiple assets spike simultaneously (cross-asset corr > 0.8), reduce all positions by 50% — regime is changing
  • Black swan sizing: Never size more than 2% of capital into any single vol-fade position
  • Per-trade stop loss: Exit if position moves against you by more than 2x the expected daily vol of that asset
class VolRiskManager:
    def __init__(self, total_capital: float,
                 max_dd_pct: float = 15.0,
                 max_daily_loss_pct: float = 5.0):
        self.capital = total_capital
        self.max_dd = total_capital * (max_dd_pct / 100)
        self.max_daily = total_capital * (max_daily_loss_pct / 100)
        self.peak_equity = total_capital
        self.daily_loss = 0.0
        self.halted = False

    def update_equity(self, current_equity: float) -> bool:
        """Returns True if trading should continue, False if halted."""
        self.peak_equity = max(self.peak_equity, current_equity)
        drawdown = self.peak_equity - current_equity

        if drawdown >= self.max_dd:
            self.halted = True
            print(f"HALT: Max drawdown ${drawdown:,.0f} exceeded limit ${self.max_dd:,.0f}")
            return False

        pnl_today = current_equity - (self.capital - self.daily_loss)
        if pnl_today < 0 and abs(pnl_today) >= self.max_daily:
            self.halted = True
            print(f"HALT: Daily loss ${abs(pnl_today):,.0f} exceeded limit ${self.max_daily:,.0f}")
            return False

        return not self.halted

    def check_vol_of_vol(self, iv_series: pd.Series,
                         threshold_daily_change: float = 5.0) -> bool:
        """Returns True if IV is rising too fast (halt new entries)."""
        if len(iv_series) < 2:
            return False
        daily_change = abs(iv_series.iloc[-1] - iv_series.iloc[-2])
        return daily_change > threshold_daily_change
