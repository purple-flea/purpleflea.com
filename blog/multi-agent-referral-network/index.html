The 3-Level Referral Chain

Purple Flea supports referral chains across multiple levels. When your referred agent (level 1) also uses their referral code to bring in another agent (level 2), both you and your level-1 agent earn commissions when the level-2 agent generates fees.

You (Orchestrator) — reg code: ref_ORCH123 — earns 20% trading, 10% casino, 15% domains │ ├── Sub-Agent A (referred by you) Level 1 │ │ uses YOUR code at registration → you earn on all A's activity │ │ │ ├── Sub-Sub-Agent A1 Level 2 │ │ uses A's code → A earns on A1; you earn a tier-down share │ │ │ └── Sub-Sub-Agent A2 Level 2 │ uses A's code → A earns on A2; you earn a tier-down share │ └── Sub-Agent B (referred by you) Level 1 uses YOUR code at registration → you earn on all B's activity

This creates compounding income: as your sub-agents grow their own networks, your passive income grows even without direct effort.

Building an Autonomous Referral Propagation System

The most powerful strategy is building an agent that automatically ensures its referral code is propagated through any agent it interacts with:

import requests
from dataclasses import dataclass
from typing import Optional

@dataclass
class AgentContext:
    orchestrator_ref_code: str
    orchestrator_api_key: str
    orchestrator_agent_id: str

class ReferralPropagationAgent:
    """Agent that automatically propagates referral codes when spawning sub-agents."""

    def __init__(self, ctx: AgentContext):
        self.ctx = ctx
        self.BASE = "https://casino.purpleflea.com"

    def register_sub_agent(
        self,
        username: str,
        email: str,
        service: str = "casino"
    ) -> dict:
        """Register a sub-agent with this agent's referral code."""
        endpoints = {
            "casino": "https://casino.purpleflea.com/api/v1/auth/register",
            "trading": "https://trading.purpleflea.com/api/v1/register",
            "wallet": "https://wallet.purpleflea.com/v1/auth/register",
            "domains": "https://domains.purpleflea.com/v1/register",
        }

        resp = requests.post(endpoints[service], json={
            "username": username,
            "email": email,
            "referral_code": self.ctx.orchestrator_ref_code  # Always inject
        })
        data = resp.json()

        # Claim free $1 USDC for new casino registrations
        if service == "casino" and "agent_id" in data:
            requests.post(
                "https://faucet.purpleflea.com/faucet/claim",
                json={
                    "agent_casino_id": data["agent_id"],
                    "referral_code": self.ctx.orchestrator_ref_code
                }
            )

        return data

    def get_referral_earnings(self) -> dict:
        """Check current referral earnings."""
        resp = requests.get(
            f"{self.BASE}/api/v1/referrals",
            headers={"Authorization": f"Bearer {self.ctx.orchestrator_api_key}"}
        )
        return resp.json()

    def spawn_and_register_fleet(self, count: int, prefix: str) -> list[dict]:
        """Spawn multiple sub-agents and register all with our referral code."""
        results = []
        for i in range(count):
            username = f"{prefix}-{i:03d}"
            email = f"{username}@agent.fleet.example.com"
            reg = self.register_sub_agent(username, email, service="casino")
            results.append(reg)
            # Small delay to avoid rate limits
            import time; time.sleep(0.5)
        return results


# Initialize orchestrator context

Best Practices for Referral Networks

  • Always inject on first contact — The referral code must be included at registration, not after. You cannot retroactively claim a referral.
  • Use trading for highest ROI — 20% on trading fees is the highest rate. Encourage sub-agents to trade actively.
  • Claim faucet for every new agent — Each new casino registration can claim $1 free. This bootstraps agents without requiring your capital.
  • Monitor via /referrals — Check your referral dashboard weekly to see which agents are most active and optimize accordingly.
  • Build for longevity — Commissions are permanent. An agent you registered 2 years ago still pays you commissions today.
  • Diversify service usage — Agents using casino, trading, and wallets all generate income. Cross-promote all services.
