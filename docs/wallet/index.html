Authentication

All endpoints except GET /health and POST /v1/auth/register require your API key in the X-API-Key header. Your key is returned upon registration and never changes unless you explicitly rotate it.

# All authenticated requests use this header
curl -H "X-API-Key: YOUR_API_KEY" \
     https://wallet.purpleflea.com/v1/wallet/balances
Security note: Your API key grants full access to send funds from your wallet. Never expose it in client-side code, logs, or public repositories. Treat it like a private key.

DEX Swaps

The Wallet API routes swaps through multiple DEX aggregators to find the best available rate at execution time. For same-chain swaps, it compares routes across Uniswap, Jupiter, PancakeSwap, and other major protocols. For cross-chain swaps, it uses bridge aggregators like Socket and LI.FI.

Swap Fee Structure

Fee TypeRateDescription
Swap Fee0.3%Applied on input token amount; included in the quoted output amount
DEX Protocol FeeVariableBase protocol fee passed through at cost (typically 0.01–0.3%)
Referral Commission10% of swap feePaid to the agent who referred you, on each swap you make
Network GasVariableOn-chain gas cost; deducted from native token balance

Routing Logic

For each swap request, the API queries multiple liquidity sources simultaneously and selects the route that maximises the net output after all fees. The quote returned reflects the guaranteed minimum output (with 0.5% slippage tolerance by default).

  • Same-chain EVM swaps: Uniswap V3, Curve, Balancer, 1inch aggregator
  • Solana swaps: Jupiter aggregator across all Solana DEXes
  • Cross-chain: Socket, LI.FI, Across Protocol
  • BTC, XRP, LTC: OTC desk routing for large orders; bridge wrapping for small ones

Python Example: Create Wallet, Check Balances & Execute Swap

This end-to-end example shows how to register an agent, create an HD wallet across all chains, check token balances, get a swap quote, execute it, and poll until completion.

import requests
import time

BASE_URL = "https://wallet.purpleflea.com"

# Authenticated helper
def api(method, path, api_key=None, **kwargs):
    headers = {"Content-Type": "application/json"}
    if api_key:
        headers["X-API-Key"] = api_key
    url = f"{BASE_URL}{path}"
    r = getattr(requests, method)(url, headers=headers, **kwargs)
    r.raise_for_status()
    return r.json()

def main():
    # Step 1: Register
    reg = api("post", "/v1/auth/register", json={
        "agent_id": "multi-chain-treasury-bot",
        "referral_code": "PFSTART"
    })
    api_key = reg["api_key"]
    ref_code = reg["referral_code"]
    print(f"Registered. Key: {api_key[:20]}... Ref: {ref_code}")

    # Step 2: Create HD wallet
    wallet = api("post", "/v1/wallet/create", api_key=api_key, json={})
    mnemonic = wallet["mnemonic"]
    addresses = wallet["addresses"]

    # CRITICAL: Save mnemonic immediately to secure storage
    with open("/secure/mnemonic.txt", "w") as f:
        f.write(mnemonic)
    print("Mnemonic saved. Wallet addresses:")
    for chain, addr in addresses.items():
        print(f"  {chain}: {addr}")

    # Step 3: Check all balances
    balances = api("get", "/v1/wallet/balances", api_key=api_key)
    print(f"Total portfolio: ${balances['total_usd_value']:,.2f} USD")

    # Step 4: Check ETH balance specifically
    eth_bal = api("get", "/v1/wallet/balance/ETH", api_key=api_key)
    eth_amount = float(eth_bal["tokens"].get("ETH", {}).get("balance", "0"))
    print(f"ETH balance: {eth_amount:.6f} ETH")

    # Step 5: Get a swap quote (ETH -> USDC)
    if eth_amount >= 0.01:
        quote = api("post", "/v1/wallet/swap/quote", api_key=api_key, json={
            "from_chain": "ETH",
            "from_token": "ETH",
            "to_chain": "ETH",
            "to_token": "USDC",
            "amount": "0.01",
            "slippage": 0.5
        })
        quote_id = quote["quote_id"]
        print(f"Quote: 0.01 ETH -> {quote['to_amount_expected']} USDC")
        print(f"Route: {quote['route']} | Fee: ${quote['fee_usd']:.2f}")

        # Step 6: Execute the swap
        swap = api("post", "/v1/wallet/swap/execute", api_key=api_key, json={
            "quote_id": quote_id
        })
        swap_id = swap["swap_id"]
        print(f"Swap submitted. ID: {swap_id} | TX: {swap['tx_hash'][:20]}...")

        # Step 7: Poll for completion
        for attempt in range(12):  # wait up to 60s
            time.sleep(5)
            status = api("get", f"/v1/wallet/swap/status/{swap_id}", api_key=api_key)
            st = status["status"]
            print(f"[{attempt+1}/12] Swap status: {st}")
            if st == "completed":
                print(f"Received: {status['to_amount_actual']} USDC")
                break
            elif st == "failed":
                print("Swap failed on-chain. No funds lost.")
                break
    else:
        print("Not enough ETH to swap. Fund your wallet first.")
        print(f"Send ETH to: {addresses['ETH']}")

    # Step 8: Check referral stats
    refs = api("get", "/v1/referral/stats", api_key=api_key)
    print(f"Referral link: {refs['referral_url']}")
    print(f"Earnings: ${refs['earnings_total_usdc']:.2f} USDC from {refs['referred_agents']} agents")

if __name__ == "__main__":
    main()

Security Best Practices

Mnemonic Storage

The BIP39 mnemonic returned by /v1/wallet/create is the master key to all your wallets across all 8 chains. Handle it with extreme care:

  • Store it in an encrypted secrets manager (e.g. AWS Secrets Manager, HashiCorp Vault, or a local encrypted file)
  • Never log it, print it in production, or store it in plaintext
  • Back it up in at least two physically separate secure locations
  • Consider using a hardware security module (HSM) for production agent deployments
  • Purple Flea does not retain your mnemonic — if lost, funds cannot be recovered

API Key Hygiene

  • Store your API key in environment variables, not hardcoded in source files
  • Use separate agent IDs and keys for development vs. production environments
  • Never commit API keys to version control
  • Monitor referral and transaction history for unexpected activity

Address Verification

Always verify destination addresses programmatically before sending. The API validates address format but cannot verify intent. Consider implementing a whitelist of approved recipient addresses in your agent logic.

# Recommended: validate address before sending
import re

ETH_ADDRESS_RE = re.compile(r'^0x[0-9a-fA-F]{40}$')
SOL_ADDRESS_RE = re.compile(r'^[1-9A-HJ-NP-Za-km-z]{32,44}$')

def validate_address(chain: str, address: str) -> bool:
    if chain in ("ETH", "MATIC", "BNB"):
        return bool(ETH_ADDRESS_RE.match(address))
    elif chain == "SOL":
        return bool(SOL_ADDRESS_RE.match(address))
    # Add chain-specific validators as needed
    return len(address) > 20  # basic length check
