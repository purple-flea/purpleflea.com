Building a Production Backtesting Framework for AI Trading Agents

Purple Flea Research · March 7, 2026 · 22 min read

Most AI trading agents are never properly backtested before going live. The ones that are often fall victim to lookahead bias, overfitting, or wildly optimistic transaction cost assumptions. This guide builds a production-grade BacktestEngine from the ground up — and shows you how to validate it with walk-forward optimization and Monte Carlo robustness testing before paper trading live on Purple Flea.

Why Backtesting Matters — and Where Agents Go Wrong

An AI trading agent that skips rigorous backtesting is an agent gambling with real funds. Backtesting is the only way to answer the fundamental question before risking capital: does this strategy have a statistically positive expectation, net of all costs?

The value of a thorough backtest is not simply knowing that a strategy made money historically. It is understanding why it made money, under what market conditions, with what drawdown profile, and whether those conditions are likely to persist. Without this, an agent has no framework for knowing when to reduce position size, when a strategy has broken down, or how correlated its risk is to broader market factors.

The Most Common Backtesting Mistakes

These four errors cause the majority of failed live deployments:

  • Lookahead bias — Using information in your signal that was not available at the time the trading decision would have been made. Classic example: using today's closing price to generate a signal and then executing at today's open. This is mathematically impossible in live trading and inflates backtest returns by 20-80% on typical strategies.
  • Overfitting / curve fitting — Optimising strategy parameters on the full dataset until the backtest looks great. The resulting parameters capture noise, not signal. Walk-forward optimization is the standard defence.
  • Ignoring transaction costs — Setting fees to zero or using unrealistic fill prices. In reality, spread + slippage + commission can eliminate 60% of paper profits on high-frequency strategies.
  • Survivorship bias in data — Backtesting only on assets that still exist today, ignoring delisted or failed tokens. This creates an upward bias in mean-reversion and momentum strategies.
⚠️
Lookahead Bias is Silent and Lethal

Lookahead bias never throws an error. A backtest with pervasive lookahead bias produces clean equity curves, strong Sharpe ratios, and precise drawdown figures — all completely fictitious. The only way to detect it is through careful architectural design and code review.

Event-Driven vs Vectorized Backtesting

There are two dominant backtesting architectures, with fundamentally different accuracy/speed trade-offs.

Vectorized Backtesting

Vectorized backtesting applies trading rules as array operations across the entire historical dataset simultaneously using NumPy or Pandas. It is extremely fast — backtesting years of data takes milliseconds — and is simple to implement for rule-based strategies.

The critical flaw: vectorized approaches cannot accurately model order execution. They implicitly assume infinite liquidity at the exact bar close price, no bid-ask spread, and no market impact. They also cannot correctly model strategies that depend on portfolio state from previous periods without significant complexity.

Event-Driven Backtesting

Event-driven backtesting processes market data one event (tick, OHLCV bar, order book update) at a time. The strategy only has access to data up to the current event — making lookahead bias structurally impossible when implemented correctly. Order fills are simulated separately from signal generation, allowing realistic slippage and partial fill modeling.

Event-driven is slower and more complex to implement, but the additional realism is essential for any strategy intended for live deployment. The speed penalty is irrelevant in practice — even complex strategies typically complete historical runs in seconds to minutes.

Data Pipeline: OHLCV and Tick Data

A backtesting framework is only as good as its data. Garbage in, garbage out is never more true than in quantitative trading — a strategy that looks profitable on clean data can turn negative on realistic data with all its messiness.

OHLCV Data Sourcing

For most AI trading agents operating on crypto markets, OHLCV (Open, High, Low, Close, Volume) at 1-minute to 1-hour resolution is the practical starting point. The Purple Flea trading API provides historical OHLCV at GET /api/v1/market/history?symbol=BTC-USDC&resolution=1m&since=<timestamp>.

import requests
import pandas as pd
import numpy as np
from datetime import datetime, timezone
from pathlib import Path


class PurpleFleasDataPipeline:
    """Fetch, validate, and preprocess historical market data from Purple Flea API."""

    BASE_URL = "https://purpleflea.com/api/v1"
    VALID_RESOLUTIONS = {"1m", "5m", "15m", "1h", "4h", "1d"}

    def __init__(self, api_key: str, cache_dir: str = "./data/cache"):
        self.api_key = api_key          # pf_live_<your_key>
        self.cache_dir = Path(cache_dir)
        self.cache_dir.mkdir(parents=True, exist_ok=True)
        self.session = requests.Session()
        self.session.headers.update({
            "Authorization": f"Bearer {api_key}",
            "Accept": "application/json"
        })

    def fetch_ohlcv(self,
                    symbol: str,
                    resolution: str,
                    start: datetime,
                    end: datetime) -> pd.DataFrame:
        """
        Fetch OHLCV bars from Purple Flea API with disk caching.
        Handles pagination automatically.
        Returns DataFrame with DatetimeIndex in UTC.
        """
        if resolution not in self.VALID_RESOLUTIONS:
            raise ValueError(f"Invalid resolution {resolution}. Choose from {self.VALID_RESOLUTIONS}")

        cache_key = f"{symbol}_{resolution}_{start:%Y%m%d}_{end:%Y%m%d}"
        cache_path = self.cache_dir / f"{cache_key}.parquet"

        if cache_path.exists():
            print(f"[Cache HIT] {cache_key}")
            return pd.read_parquet(cache_path)

        bars = []
        since = int(start.replace(tzinfo=timezone.utc).timestamp() * 1000)
        end_ms = int(end.replace(tzinfo=timezone.utc).timestamp() * 1000)

        while since < end_ms:
            resp = self.session.get(
                f"{self.BASE_URL}/market/history",
                params={
                    "symbol": symbol,
                    "resolution": resolution,
                    "since": since,
                    "limit": 1000
                },
                timeout=30
            )
            resp.raise_for_status()
            data = resp.json()

            if not data.get("bars"):
                break

            bars.extend(data["bars"])
            since = data["bars"][-1]["t"] + 1

        df = pd.DataFrame(bars, columns=["t", "o", "h", "l", "c", "v"])
        df.columns = ["timestamp", "open", "high", "low", "close", "volume"]
        df["timestamp"] = pd.to_datetime(df["timestamp"], unit="ms", utc=True)
        df = df.set_index("timestamp").sort_index()

        # Validate and clean
        df = self._clean_ohlcv(df)
        df.to_parquet(cache_path)
        print(f"[Fetched] {len(df)} bars for {symbol} {resolution}")
        return df

    def _clean_ohlcv(self, df: pd.DataFrame) -> pd.DataFrame:
        """Remove invalid bars, fill minor gaps, log anomalies."""
        initial_len = len(df)

        # Drop zero-volume bars (exchange glitches)
        df = df[df["volume"] > 0]

        # Drop bars where OHLC integrity fails (low > high, etc.)
        df = df[
            (df["low"] <= df["high"]) &
            (df["open"] >= df["low"]) &
            (df["open"] <= df["high"]) &
            (df["close"] >= df["low"]) &
            (df["close"] <= df["high"])
        ]

        # Remove duplicate timestamps
        df = df[~df.index.duplicated(keep="first")]

        dropped = initial_len - len(df)
        if dropped > 0:
            print(f"[Clean] Dropped {dropped} invalid bars ({dropped/initial_len:.1%})")

        return df

The BacktestEngine Class

The BacktestEngine is the core of the framework. It processes market events sequentially, maintains portfolio state, and delegates signal generation to a pluggable strategy function. The three primary methods are run(), calculate_metrics(), and plot_equity_curve().

backtest/engine.py Python 
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt
import matplotlib.gridspec as gridspec
from dataclasses import dataclass, field
from typing import Callable, Optional
from enum import Enum
from scipy import stats


class OrderSide(Enum):
    BUY = "buy"
    SELL = "sell"
    FLAT = "flat"  # close all positions


@dataclass
class Trade:
    timestamp: pd.Timestamp
    side: OrderSide
    size: float           # position size in base currency
    entry_price: float
    exit_price: float
    gross_pnl: float
    total_cost: float     # spread + slippage + commission
    net_pnl: float
    bars_held: int


@dataclass
class BacktestConfig:
    initial_capital: float = 10_000.0   # starting USDC
    position_size_pct: float = 0.1      # fraction of capital per trade
    max_position_pct: float = 0.5       # max total exposure
    commission_pct: float = 0.001      # 0.10% maker/taker
    spread_bps: float = 5.0            # bid-ask half-spread in bps
    slippage_bps: float = 2.0          # market impact estimate
    warmup_bars: int = 50              # bars before trading begins (for indicator warm-up)
    risk_free_rate: float = 0.0        # daily risk-free rate
    trading_days_per_year: int = 365   # 24/7 crypto markets


class BacktestEngine:
    """
    Event-driven backtesting engine for AI trading agent strategies.

    Usage:
        engine = BacktestEngine(config=BacktestConfig())
        results = engine.run(df, strategy_fn=my_momentum_strategy)
        metrics = engine.calculate_metrics()
        engine.plot_equity_curve()
    """

    def __init__(self, config: BacktestConfig = None):
        self.config = config or BacktestConfig()
        self._reset()

    def _reset(self):
        self.capital = self.config.initial_capital
        self.position = 0.0         # current position in base currency (positive = long)
        self.position_entry_price = 0.0
        self.position_entry_bar = 0
        self.equity_curve: list[dict] = []
        self.trades: list[Trade] = []
        self._bar_index = 0
        self._df: pd.DataFrame = None

    def run(self,
            df: pd.DataFrame,
            strategy_fn: Callable,
            strategy_params: dict = None) -> dict:
        """
        Run the backtest over historical OHLCV data.

        Args:
            df: DataFrame with DatetimeIndex and columns [open, high, low, close, volume].
                MUST be sorted ascending. No future data must be accessible in strategy_fn.
            strategy_fn: Callable(df_slice, params) -> OrderSide
                Receives only data UP TO AND INCLUDING the current bar.
                Must return an OrderSide (BUY / SELL / FLAT).
            strategy_params: dict passed to strategy_fn on each call.

        Returns:
            dict with equity_curve DataFrame and trade list.
        """
        self._reset()
        self._df = df.copy()
        params = strategy_params or {}
        n = len(df)

        for i in range(n):
            self._bar_index = i
            bar = df.iloc[i]

            # Mark-to-market: current equity = cash + unrealised position value
            unrealised = self.position * bar["close"] if self.position != 0 else 0.0
            equity = self.capital + unrealised

            self.equity_curve.append({
                "timestamp": df.index[i],
                "equity": equity,
                "capital": self.capital,
                "position": self.position,
                "unrealised_pnl": unrealised - (self.position * self.position_entry_price)
                                    if self.position != 0 else 0.0
            })

            # Skip warm-up period: strategy has no access to sufficient indicator history
            if i < self.config.warmup_bars:
                continue

            # CRITICAL: pass ONLY df.iloc[:i+1] to strategy — never the full df
            # This is the architectural guarantee against lookahead bias.
            df_slice = df.iloc[:i + 1]
            signal = strategy_fn(df_slice, params)

            # Execute signal against next bar's open price (realistic: decided at close, filled at open)
            if i + 1 < n:
                next_open = df.iloc[i + 1]["open"]
                self._execute_signal(signal, next_open, i)

        # Close any open position at final bar close
        if self.position != 0:
            final_price = df.iloc[-1]["close"]
            self._execute_signal(OrderSide.FLAT, final_price, n - 1)

        equity_df = pd.DataFrame(self.equity_curve).set_index("timestamp")
        return {"equity_curve": equity_df, "trades": self.trades}

    def _execute_signal(self, signal: OrderSide, price: float, bar_index: int):
        """Apply transaction costs and update portfolio state."""
        spread_cost = price * (self.config.spread_bps / 10_000)
        slippage_cost = price * (self.config.slippage_bps / 10_000)

        if signal == OrderSide.BUY and self.position <= 0:
            # Close any short, open long
            if self.position < 0:
                self._close_position(price, spread_cost, slippage_cost, bar_index)
            trade_value = self.capital * self.config.position_size_pct
            fill_price = price + spread_cost + slippage_cost
            commission = trade_value * self.config.commission_pct
            self.position = (trade_value - commission) / fill_price
            self.capital -= (trade_value + commission)
            self.position_entry_price = fill_price
            self.position_entry_bar = bar_index

        elif signal in (OrderSide.SELL, OrderSide.FLAT) and self.position > 0:
            self._close_position(price, spread_cost, slippage_cost, bar_index)

    def _close_position(self, price: float, spread: float, slip: float, bar_index: int):
        """Record realised trade P&L and update capital."""
        fill_price = price - spread - slip  # worse fill when exiting
        gross_pnl = self.position * (fill_price - self.position_entry_price)
        exit_value = self.position * fill_price
        commission = exit_value * self.config.commission_pct
        total_cost = (self.position * (spread + slip) * 2) + commission
        net_pnl = gross_pnl - commission

        self.trades.append(Trade(
            timestamp=self._df.index[bar_index],
            side=OrderSide.SELL,
            size=self.position,
            entry_price=self.position_entry_price,
            exit_price=fill_price,
            gross_pnl=gross_pnl,
            total_cost=total_cost,
            net_pnl=net_pnl,
            bars_held=bar_index - self.position_entry_bar
        ))

        self.capital += exit_value - commission
        self.position = 0.0
        self.position_entry_price = 0.0

    def calculate_metrics(self) -> dict:
        """
        Compute a full suite of risk-adjusted performance metrics.

        Returns:
            dict with keys: total_return, cagr, sharpe_ratio, sortino_ratio,
            calmar_ratio, max_drawdown, win_rate, profit_factor,
            avg_trade_pnl, total_trades, avg_bars_held.
        """
        if not self.equity_curve:
            raise RuntimeError("No backtest data. Call run() first.")

        eq = pd.DataFrame(self.equity_curve)
        equity = eq["equity"].values
        n_bars = len(equity)

        # Returns
        returns = np.diff(equity) / equity[:-1]
        rf_daily = self.config.risk_free_rate
        excess = returns - rf_daily
        T = self.config.trading_days_per_year

        # Total and annualised return
        total_return = (equity[-1] / equity[0]) - 1
        days = n_bars  # approximation: 1 bar ~ 1 trading period
        cagr = (1 + total_return) ** (T / max(days, 1)) - 1

        # Sharpe
        sharpe = (np.mean(excess) / (np.std(excess) + 1e-10)) * np.sqrt(T)

        # Sortino (penalise only downside volatility)
        downside = excess[excess < 0]
        sortino_denom = np.sqrt(np.mean(downside ** 2) + 1e-10)
        sortino = (np.mean(excess) / sortino_denom) * np.sqrt(T)

        # Maximum drawdown
        running_max = np.maximum.accumulate(equity)
        drawdowns = (equity - running_max) / running_max
        max_drawdown = float(np.min(drawdowns))

        # Calmar ratio
        calmar = cagr / abs(max_drawdown) if max_drawdown != 0 else np.inf

        # Trade statistics
        if self.trades:
            pnls = [t.net_pnl for t in self.trades]
            wins = [p for p in pnls if p > 0]
            losses = [p for p in pnls if p <= 0]
            win_rate = len(wins) / len(pnls)
            profit_factor = sum(wins) / abs(sum(losses)) if losses else np.inf
            avg_trade_pnl = np.mean(pnls)
            avg_bars_held = np.mean([t.bars_held for t in self.trades])
        else:
            win_rate = profit_factor = avg_trade_pnl = avg_bars_held = 0.0

        return {
            "total_return": round(total_return * 100, 2),
            "cagr_pct": round(cagr * 100, 2),
            "sharpe_ratio": round(sharpe, 3),
            "sortino_ratio": round(sortino, 3),
            "calmar_ratio": round(calmar, 3),
            "max_drawdown_pct": round(max_drawdown * 100, 2),
            "win_rate_pct": round(win_rate * 100, 1),
            "profit_factor": round(profit_factor, 2),
            "avg_trade_pnl_usdc": round(avg_trade_pnl, 4),
            "total_trades": len(self.trades),
            "avg_bars_held": round(avg_bars_held, 1),
            "final_equity_usdc": round(equity[-1], 2)
        }

    def plot_equity_curve(self, title: str = "Backtest Equity Curve",
                          save_path: Optional[str] = None):
        """
        Plot equity curve with drawdown subplot and trade markers.

        Args:
            title: Chart title string.
            save_path: If provided, saves figure to this path (PNG/PDF).
        """
        if not self.equity_curve:
            raise RuntimeError("No backtest data. Call run() first.")

        eq = pd.DataFrame(self.equity_curve).set_index("timestamp")
        equity = eq["equity"]
        running_max = equity.cummax()
        drawdown = (equity - running_max) / running_max * 100

        fig = plt.figure(figsize=(14, 8), facecolor="#09090B")
        gs = gridspec.GridSpec(3, 1, figure=fig, height_ratios=[3, 1, 0.5], hspace=0.08)

        # Equity panel
        ax1 = fig.add_subplot(gs[0])
        ax1.plot(equity.index, equity.values,
                color="#A855F7", linewidth=1.5, label="Portfolio Equity")
        ax1.fill_between(equity.index, equity.values,
                         self.config.initial_capital,
                         where=equity.values >= self.config.initial_capital,
                         alpha=0.15, color="#22C55E")
        ax1.fill_between(equity.index, equity.values,
                         self.config.initial_capital,
                         where=equity.values < self.config.initial_capital,
                         alpha=0.15, color="#EF4444")

        # Trade markers
        for trade in self.trades:
            colour = "#22C55E" if trade.net_pnl > 0 else "#EF4444"
            if trade.timestamp in equity.index:
                ax1.axvline(x=trade.timestamp, color=colour,
                            alpha=0.3, linewidth=0.7, linestyle="--")

        ax1.axhline(y=self.config.initial_capital,
                   color="#52525B", linewidth=0.8, linestyle=":")
        ax1.set_facecolor("#09090B")
        ax1.tick_params(colors="#A1A1AA", labelsize=9)
        ax1.set_ylabel("Equity (USDC)", color="#A1A1AA", fontsize=9)
        ax1.set_title(title, color="#FAFAFA", fontsize=13, fontweight="bold", pad=12)
        ax1.legend(facecolor="#111113", edgecolor="#27272A",
                  labelcolor="#FAFAFA", fontsize=9)
        ax1.spines["bottom"].set_color("#27272A")
        ax1.spines["top"].set_visible(False)
        ax1.spines["right"].set_visible(False)
        ax1.spines["left"].set_color("#27272A")

        # Drawdown panel
        ax2 = fig.add_subplot(gs[1], sharex=ax1)
        ax2.fill_between(drawdown.index, drawdown.values, 0,
                         color="#EF4444", alpha=0.5)
        ax2.plot(drawdown.index, drawdown.values, color="#EF4444", linewidth=0.8)
        ax2.set_facecolor("#09090B")
        ax2.set_ylabel("Drawdown %", color="#A1A1AA", fontsize=9)
        ax2.tick_params(colors="#A1A1AA", labelsize=8)
        ax2.spines["top"].set_visible(False)
        ax2.spines["right"].set_visible(False)
        ax2.spines["bottom"].set_color("#27272A")
        ax2.spines["left"].set_color("#27272A")

        if save_path:
            plt.savefig(save_path, dpi=150, bbox_inches="tight",
                       facecolor="#09090B")
        plt.tight_layout()
        plt.show()

Transaction Cost Modeling

The three components of realistic transaction costs — spread, slippage, and commission — each impact profitability differently. Together they can represent 0.1% to 1.0% of notional per round trip, which compounds dramatically over hundreds of trades.

Spread

The bid-ask spread is the cost of immediacy. When you buy at the ask and sell at the bid, you immediately pay the spread. For BTC-USDC on Purple Flea, the spread averages 4-8 bps during normal market conditions, widening to 20-50 bps during high-volatility periods. Model it as a half-spread per side: if spread_bps is 5, you pay 2.5 bps on entry and 2.5 bps on exit.

Slippage

Slippage is market impact — your order moves the price against you as it consumes order book liquidity. It scales with order size relative to the available liquidity at each price level. For agent-sized orders (under $10,000 notional), slippage on liquid Purple Flea markets is typically 1-5 bps, but can spike to 20-50 bps during low-liquidity periods like late-night sessions.

Commission

Purple Flea charges 0.10% per side on taker orders. Maker orders receive a rebate. For a strategy taking market orders, model 0.10% entry + 0.10% exit = 0.20% round-trip commission. For mixed maker/taker strategies, use a blended rate of 0.05-0.08% per side.

Spread Cost
price × (spread_bps / 10,000)

Paid on both entry and exit. Scales with price level, not position size.

Slippage Cost
price × (slippage_bps / 10,000)

Increases with order size. Worst at market open and news events.

Commission
notional × commission_pct

Fixed rate per trade. Purple Flea: 0.10% taker, rebate for makers.

Round-Trip Cost
(2 × spread) + (2 × slip) + (2 × comm)

Total cost to open and close a position. Minimum hurdle for profitability.

💡
The Break-Even Rule

A strategy must generate gross P&L greater than its round-trip transaction cost per trade to be profitable in expectation. For Purple Flea with typical costs of 0.30-0.40% round-trip, a strategy holding positions for 1 hour needs to capture at least 0.40% price movement per trade just to break even — before considering losing trades.

Walk-Forward Optimization and Monte Carlo Robustness

A single in-sample / out-of-sample split is insufficient for strategy validation. Walk-forward optimization (WFO) provides a more realistic estimate of live performance by simulating the natural parameter update cycle of a deployed strategy.

Walk-Forward Optimization

backtest/walk_forward.py Python 
from itertools import product
import pandas as pd
import numpy as np
from backtest.engine import BacktestEngine, BacktestConfig


def walk_forward_optimize(
    df: pd.DataFrame,
    strategy_fn,
    param_grid: dict,
    in_sample_bars: int = 1000,
    out_of_sample_bars: int = 200,
    config: BacktestConfig = None
) -> dict:
    """
    Walk-forward optimization.

    Rolls a window through the dataset:
    1. Optimise parameters on in-sample window (best Sharpe)
    2. Test on immediately following out-of-sample window
    3. Record out-of-sample results
    4. Advance window by out_of_sample_bars bars
    5. Repeat

    Returns: dict with oos_results (list of metric dicts) and best_params per window.
    """
    config = config or BacktestConfig()

    # Build flat list of all parameter combinations
    param_names = list(param_grid.keys())
    param_values = list(param_grid.values())
    all_combos = [dict(zip(param_names, combo))
                  for combo in product(*param_values)]

    oos_results = []
    start_idx = 0
    window_num = 0

    while start_idx + in_sample_bars + out_of_sample_bars <= len(df):
        is_end = start_idx + in_sample_bars
        oos_end = is_end + out_of_sample_bars

        df_is = df.iloc[start_idx:is_end]
        df_oos = df.iloc[is_end:oos_end]

        # --- In-sample optimisation: find best Sharpe ---
        best_sharpe = -np.inf
        best_params = all_combos[0]

        for params in all_combos:
            engine = BacktestEngine(config=config)
            engine.run(df_is, strategy_fn, params)
            metrics = engine.calculate_metrics()
            if metrics["sharpe_ratio"] > best_sharpe:
                best_sharpe = metrics["sharpe_ratio"]
                best_params = params

        # --- Out-of-sample test with best params ---
        engine_oos = BacktestEngine(config=config)
        engine_oos.run(df_oos, strategy_fn, best_params)
        oos_metrics = engine_oos.calculate_metrics()
        oos_metrics["window"] = window_num
        oos_metrics["is_start"] = df.index[start_idx]
        oos_metrics["oos_start"] = df.index[is_end]
        oos_metrics["best_params"] = best_params
        oos_results.append(oos_metrics)

        print(f"Window {window_num}: IS Sharpe={best_sharpe:.2f} | "
              f"OOS Sharpe={oos_metrics['sharpe_ratio']:.2f} | "
              f"OOS Return={oos_metrics['total_return']:.2f}% | "
              f"Params={best_params}")

        start_idx += out_of_sample_bars
        window_num += 1

    combined_oos_return = np.prod(
        [1 + r["total_return"] / 100 for r in oos_results]
    ) - 1

    return {
        "oos_results": oos_results,
        "combined_oos_return_pct": round(combined_oos_return * 100, 2),
        "avg_oos_sharpe": round(np.mean([r["sharpe_ratio"] for r in oos_results]), 3),
        "pct_profitable_windows": round(
            sum(1 for r in oos_results if r["total_return"] > 0)
            / len(oos_results) * 100, 1
        )
    }

Monte Carlo Robustness Testing

Monte Carlo simulation tests whether strategy performance is robust to variations in trade ordering, execution timing, and slight changes in historical conditions. If performance is sensitive to tiny perturbations, the strategy is fragile and unlikely to survive live market noise.

backtest/monte_carlo.py Python 
import numpy as np
import matplotlib.pyplot as plt


def monte_carlo_simulation(
    trade_pnls: list[float],
    initial_capital: float,
    n_simulations: int = 1000,
    confidence_levels: list[float] = [0.05, 0.25, 0.50]
) -> dict:
    """
    Monte Carlo simulation: resample trade P&L sequences to estimate distribution
    of strategy outcomes. Tests robustness to trade ordering.

    Returns:
        dict with percentile equity paths and probability of ruin.
    """
    pnls = np.array(trade_pnls)
    n_trades = len(pnls)
    paths = np.zeros((n_simulations, n_trades + 1))
    paths[:, 0] = initial_capital

    for sim in range(n_simulations):
        # Resample with replacement: different ordering of same trades
        resampled = np.random.choice(pnls, size=n_trades, replace=True)
        paths[sim, 1:] = initial_capital + np.cumsum(resampled)

    final_equities = paths[:, -1]
    probability_of_ruin = float(np.mean(final_equities < initial_capital * 0.5))

    percentile_paths = {
        f"p{int(cl*100)}": np.percentile(paths, cl * 100, axis=0)
        for cl in confidence_levels
    }
    percentile_paths["p50"] = np.percentile(paths, 50, axis=0)
    percentile_paths["p75"] = np.percentile(paths, 75, axis=0)
    percentile_paths["p95"] = np.percentile(paths, 95, axis=0)

    return {
        "probability_of_ruin": probability_of_ruin,
        "expected_final_equity": float(np.mean(final_equities)),
        "median_final_equity": float(np.median(final_equities)),
        "worst_5pct_equity": float(np.percentile(final_equities, 5)),
        "percentile_paths": percentile_paths,
        "all_paths": paths
    }
⚠️
Monte Carlo Threshold: Reject if Probability of Ruin > 5%

If your Monte Carlo simulation shows more than 5% of simulated paths ending at less than 50% of initial capital, the strategy's risk profile is unacceptable for live deployment regardless of its mean expected return. Reduce position sizing or tighten stop losses before proceeding.

        """Simulate realistic fill with spread + slippage."""
        fill_penalty = price * (7 / 10_000)  # 5 bps spread + 2 bps slippage
        commission_rate = 0.001

        from backtest.engine import OrderSide
        if signal == OrderSide.BUY and self.position == 0:
            size = (self.capital * 0.10) / (price + fill_penalty)
            cost = size * (price + fill_penalty) * (1 + commission_rate)
            if cost <= self.capital:
                self.position = size
                self.capital -= cost
                self.trade_log.append({
                    "ts": ts, "side": "BUY",
                    "price": price + fill_penalty,
                    "size": size, "cost": cost

        elif signal == OrderSide.SELL and self.position > 0:
            proceeds = self.position * (price - fill_penalty) * (1 - commission_rate)
            self.capital += proceeds
            print(f"[PAPER SELL] {self.position:.6f} @ ${price-fill_penalty:.2f} | Capital: ${self.capital:.2f}")
            self.position = 0

    def _log_state(self, bar: dict):
        equity = self.capital + self.position * bar["close"]
        self.pnl_log.append(equity)
        print(f"[{bar['timestamp']}] Equity: ${equity:,.2f} | Position: {self.position:.4f}")

Statistical Significance Testing

A strategy that made 12% over 50 trades might be genuine alpha or might be luck. Statistical significance testing gives you the framework to distinguish between the two with quantified confidence.

t-Test on Trade Returns

The null hypothesis is that mean trade P&L equals zero (the strategy has no edge). Use a one-sample t-test with the distribution of trade net P&L values. A p-value below 0.05 rejects the null at 95% confidence.

backtest/significance.py Python 
from scipy import stats
import numpy as np


def test_strategy_significance(trade_pnls: list[float]) -> dict:
    """
    Run a battery of statistical tests on trade P&L to assess edge reliability.

    Tests:
    - t-test: does mean P&L significantly exceed zero?
    - Minimum trades: is the sample size sufficient for inference?
    - Effect size (Cohen's d): is the edge economically meaningful?
    - Bootstrap confidence interval: non-parametric estimate of mean P&L CI

    Returns:
        dict with test results, p-value, effect size, and recommendation.
    """
    n = len(trade_pnls)
    pnls = np.array(trade_pnls)

    if n < 30:
        return {
            "sufficient_trades": False,
            "recommendation": f"Need at least 30 trades for inference. Have {n}."
        }

    # One-sample t-test: H0: mean = 0
    t_stat, p_value = stats.ttest_1samp(pnls, popmean=0)

    # Cohen's d effect size
    cohens_d = np.mean(pnls) / (np.std(pnls) + 1e-10)

    # Bootstrap 95% CI for mean P&L
    boot_means = [
        np.mean(np.random.choice(pnls, size=n, replace=True))
        for _ in range(5000)
    ]
    ci_low, ci_high = np.percentile(boot_means, [2.5, 97.5])

    # Sharpe from trades
    trade_sharpe = (np.mean(pnls) / (np.std(pnls) + 1e-10)) * np.sqrt(252)

    # Overall recommendation
    significant = p_value < 0.05
    positive_ci = ci_low > 0
    reasonable_effect = abs(cohens_d) > 0.2

    if significant and positive_ci and reasonable_effect:
        recommendation = "PROCEED: Strategy shows statistically significant positive edge."
    elif significant and not positive_ci:
        recommendation = "CAUTION: Significant but negative edge detected. Do not deploy."
    elif not significant:
        recommendation = ("REJECT: Cannot reject null hypothesis of zero edge. "
                         "Gather more trades or revise strategy.")
    else:
        recommendation = "MARGINAL: Significant result but effect size is small. Proceed with caution."

    return {
        "n_trades": n,
        "sufficient_trades": True,
        "mean_pnl": round(float(np.mean(pnls)), 4),
        "std_pnl": round(float(np.std(pnls)), 4),
        "t_statistic": round(float(t_stat), 4),
        "p_value": round(float(p_value), 5),
        "significant_at_5pct": significant,
        "cohens_d": round(float(cohens_d), 4),
        "bootstrap_ci_95": [round(ci_low, 4), round(ci_high, 4)],
        "trade_sharpe": round(float(trade_sharpe), 3),
        "recommendation": recommendation
    }

Interpreting Results

  • p-value < 0.05: Reject the null at 95% confidence — the strategy has a non-zero mean P&L. This is necessary but not sufficient for deployment.
  • Cohen's d > 0.2: The effect size is small but economically meaningful. Below 0.1, the edge may not survive transaction cost variation in live trading.
  • Bootstrap 95% CI entirely above zero: Even in the worst-case sampling scenario, the mean P&L is positive. This is the most robust criterion for deployment readiness.
  • Minimum 100 trades recommended: Below 30 trades, no statistical test has power. Below 100, the confidence intervals are too wide to be actionable.
