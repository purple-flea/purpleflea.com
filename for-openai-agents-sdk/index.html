What is the OpenAI Agents SDK?

OpenAI's Agents SDK (released March 2025, successor to the experimental Swarm framework) is a lightweight, production-ready Python library for building multi-agent pipelines. Unlike heavier orchestration frameworks, the Agents SDK focuses on three core primitives: Agents (LLM + system prompt + tools), Handoffs (one agent delegating to another), and Guardrails (input/output validation).

Tools in the Agents SDK are Python functions decorated with @function_tool. The SDK introspects the function signature and docstring to generate the JSON schema that OpenAI's model API uses for structured tool calls. You write a normal Python function; the framework handles everything else.

Purple Flea provides a first-party Python package — purpleflea-python — that wraps all six Purple Flea services as pre-built @function_tool instances. Import the tools you need, pass them to an Agent, and your agent gains full crypto capabilities with no additional configuration.

Installation

$ pip install openai-agents purpleflea-python
$ export PURPLE_FLEA_API_KEY=pf_your_key_here

The purpleflea-python package reads PURPLE_FLEA_API_KEY from the environment automatically. No additional configuration needed. Node.js users can install npm install openai purpleflea and use the JavaScript tool wrappers instead.

Quickstart: Crypto Agent in 20 Lines

python Minimal crypto agent with Purple Flea tools 
from agents import Agent, Runner
from purpleflea.tools import (
    wallet_get_balance,
    wallet_send,
    trading_open_position,
    trading_close_position,
    casino_flip,
    faucet_claim,
)

crypto_agent = Agent(
    name="CryptoAgent",
    instructions="""You are a crypto-native AI agent.
    You can check wallet balances, execute trades,
    and interact with Purple Flea's casino.
    Always confirm before executing financial transactions.""",
    tools=[
        wallet_get_balance,
        wallet_send,
        trading_open_position,
        trading_close_position,
        casino_flip,
        faucet_claim,
    ],
)

# Run the agent
result = Runner.run_sync(
    crypto_agent,
    "What's my ETH balance, and flip a coin for 0.001 ETH"
)
print(result.final_output)

Tool Definitions

Each Purple Flea service exposes a set of @function_tool decorated functions with typed parameters and docstrings that the Agents SDK uses to generate tool schemas. Here are the core tool definitions for the three most-used services:

Wallet Tools

python purpleflea/tools/wallet.py (excerpt) 
from agents import function_tool

@function_tool
def wallet_get_balance(address: str, chain: str = "ethereum") -> dict:
    """Get the token balances for a wallet address.

    Args:
        address: The wallet address (0x... for EVM chains).
        chain: Blockchain to query. Options: ethereum, polygon,
               solana, base, arbitrum, bsc. Default: ethereum.

    Returns:
        dict with keys: address, chain, balances (list of
        {token, symbol, amount, usd_value}).
    """
    return _pf_client.wallet_balance(address, chain)

@function_tool
def wallet_send(
    to: str,
    amount: str,
    token: str = "ETH",
    chain: str = "ethereum"
) -> dict:
    """Send crypto from the agent's wallet to another address.

    Args:
        to: Recipient wallet address.
        amount: Amount to send as string (e.g. "0.1").
        token: Token symbol to send. Default: ETH.
        chain: Blockchain network. Default: ethereum.

    Returns:
        dict with txHash, status, fee_eth.
    """
    return _pf_client.wallet_send(to, amount, token, chain)

Trading Tools

python purpleflea/tools/trading.py (excerpt) 
@function_tool
def trading_open_position(
    market: str,
    side: str,
    size_usd: float,
    leverage: float = 1.0,
    order_type: str = "market"
) -> dict:
    """Open a trading position on a perpetual market.

    Args:
        market: Market to trade, e.g. "ETH-USDC" or "BTC-USDT".
        side: "long" or "short".
        size_usd: Position size in USD notional.
        leverage: Leverage multiplier (1.0 to 50.0). Default: 1.0.
        order_type: "market" or "limit". Default: market.

    Returns:
        dict with positionId, entryPrice, liquidationPrice, fee.
    """
    return _pf_client.trading_open(market, side, size_usd, leverage, order_type)

Multi-Agent Orchestration with Handoffs

The OpenAI Agents SDK's handoff mechanism lets a central orchestrator delegate tasks to specialized sub-agents. Here's a pattern where a crypto-orchestrator hands off to a dedicated wallet agent or trading agent based on the user's intent:

python Multi-agent with handoffs to specialized crypto agents 
from agents import Agent, Runner, handoff
from purpleflea.tools import wallet_tools, trading_tools, casino_tools

# Specialized sub-agents
wallet_agent = Agent(
    name="WalletAgent",
    instructions="You manage the user's crypto wallets across chains.",
    tools=wallet_tools,
)

trading_agent = Agent(
    name="TradingAgent",
    instructions="You execute and manage perpetual trading positions.",
    tools=trading_tools,
)

# Orchestrator with handoffs
orchestrator = Agent(
    name="CryptoOrchestrator",
    instructions="""Route requests to the appropriate specialist agent.
    Use WalletAgent for balance, send, and address tasks.
    Use TradingAgent for opening and managing positions.""",
    handoffs=[
        handoff(wallet_agent),
        handoff(trading_agent),
    ],
    tools=casino_tools,  # orchestrator handles casino directly
)

result = Runner.run_sync(
    orchestrator,
    "Check my ETH balance and then open a $100 long on BTC"
)
print(result.final_output)

Hosted Tool Execution

Purple Flea tools support hosted execution — the tool logic runs on Purple Flea's infrastructure rather than in your local Python process. This has two advantages:

  • Zero-latency tool execution: Purple Flea's servers are co-located with blockchain RPC nodes. Transaction submission and price queries execute in under 50ms, vs. 200-500ms from a typical cloud function.
  • Persistent state across sessions: Wallets, open positions, and escrow contracts persist on Purple Flea's infrastructure. Your agent can resume a multi-step workflow across sessions without storing state locally.
  • Parallel tool calls: The Agents SDK can call multiple Purple Flea tools simultaneously. Batch balance checks, portfolio valuation, and price queries all execute in parallel.
python Enable hosted execution mode 
from purpleflea import PurpleFleatTools

# hosted=True runs tools on Purple Flea's servers
pf = PurpleFleatTools(api_key="pf_...", hosted=True)

agent = Agent(
    name="HostedCryptoAgent",
    tools=pf.all_tools(),
    instructions="You are a hosted crypto agent. Tools run on Purple Flea servers."
)
