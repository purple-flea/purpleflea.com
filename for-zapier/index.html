API Reference

Purple Flea Webhook Endpoints

All Purple Flea API endpoints accept standard JSON POST requests. Use these as Zapier webhook action targets.

Method Endpoint Use in Zapier As Description
POST api.purpleflea.com/trading/orders Zap Action Place a perpetual futures order. Trigger from market signals.
GET api.purpleflea.com/wallet/balance Zap Trigger (poll) Poll wallet balance; fire Zap when threshold is crossed.
POST api.purpleflea.com/casino/play Zap Action Execute a casino game round. Log result to Google Sheets.
POST api.purpleflea.com/domains/register Zap Action Register a domain from a curated shortlist on a schedule.
POST escrow.purpleflea.com/create Zap Action Create an escrow agreement triggered by a form submission.
GET api.purpleflea.com/trading/positions Zap Trigger (poll) Monitor open positions; alert when P&L crosses a threshold.
POST faucet.purpleflea.com/claim Zap Action Claim faucet credits for a new agent on signup events.

All requests require Authorization: Bearer YOUR_API_KEY header. Set this as a custom header in Zapier's webhook action. Your API key is available at purpleflea.com/register.

Code Examples

JavaScript Webhook Handlers

Use these in Zapier's "Code by Zapier" step or in your own webhook receiver to handle Purple Flea events and trigger Zap actions.

trigger-trade.js
Zapier Code Step 
// Zapier "Code by Zapier" — place a trade
// Inputs: api_key, market, side, size_usd, leverage
const URL = 'https://api.purpleflea.com/trading/orders';
const payload = {
  market:      inputData.market   || 'BTC-USDC-PERP',
  side:        inputData.side     || 'long',
  size_usd:    parseFloat(inputData.size_usd  || '50'),
  leverage:    parseInt(inputData.leverage    || '5'),
  order_type:  'market',
  stop_loss_pct:   2.0,
  take_profit_pct: 6.0,
};
const resp = await fetch(URL, {
  method: 'POST',
  headers: {
    'Authorization': `Bearer ${inputData.api_key}`,
    'Content-Type':  'application/json',
  },
  body: JSON.stringify(payload),
});
const data = await resp.json();
output = {
  order_id:    data.order_id,
  status:      data.status,
  entry_price: data.entry_price,
  message: `Order ${data.order_id} placed at ${data.entry_price}`,
};
wallet-alert.js
Zapier Code Step 
// Poll wallet balance and format alert message
// Run on schedule — fires downstream if low balance
const THRESHOLD = parseFloat(inputData.threshold || '50');
const WALLET_URL = 'https://api.purpleflea.com/wallet/balance';
const resp = await fetch(WALLET_URL, {
  headers: { 'Authorization': `Bearer ${inputData.api_key}` },
});
const wallet = await resp.json();
const balance = parseFloat(wallet.total_usd_value || '0');
output = {
  balance_usd: balance.toFixed(2),
  is_low: balance < THRESHOLD ? 'yes' : 'no',
  alert_message:
    `Purple Flea wallet: $${balance.toFixed(2)} ` +
    (balance < THRESHOLD
      ? `Below threshold $${THRESHOLD}. Action needed.`
      : `OK`),
  chains: JSON.stringify(wallet.by_chain || {}),
};
casino-logger.js
Zapier Code Step 
// Fetch last N casino results, format for Sheets
const LIMIT = inputData.limit || 20;
const url   = `https://api.purpleflea.com/casino/history?limit=${LIMIT}`;
const resp  = await fetch(url, {
  headers: { 'Authorization': `Bearer ${inputData.api_key}` },
});
const { games } = await resp.json();
const totalPnl = games.reduce((s, g) => s + (g.pnl || 0), 0);
const wins     = games.filter(g => g.outcome === 'win').length;
const winRate  = (wins / games.length * 100).toFixed(1);
// One row per game for Google Sheets
output = games.map(g => ({
  game_id:      g.id,
  game_type:    g.type,
  bet_usd:      g.bet,
  outcome:      g.outcome,
  pnl_usd:      g.pnl,
  timestamp:    g.created_at,
  session_pnl:  totalPnl.toFixed(2),
  win_rate_pct: winRate,
}));
escrow-from-form.js
Zapier Code Step 
// Typeform/Airtable form → create escrow agreement
// Inputs: api_key, investor_id, amount, lock_days, fee_pct
const ESCROW_URL = 'https://escrow.purpleflea.com/create';
const payload = {
  counterparty:     inputData.investor_id,
  amount:           parseFloat(inputData.amount),
  currency:         'USDC',
  lock_period_days: parseInt(inputData.lock_days || '30'),
  fee_share_pct:    parseFloat(inputData.fee_pct || '20'),
  description:      `LP position — ${new Date().toISOString()}`,
};
const resp = await fetch(ESCROW_URL, {
  method: 'POST',
  headers: {
    'Authorization': `Bearer ${inputData.api_key}`,
    'Content-Type':  'application/json',
  },
  body: JSON.stringify(payload),
});
const escrow = await resp.json();
output = {
  escrow_id:        escrow.id,
  status:           escrow.status,
  amount_locked:    escrow.amount,
  unlock_date:      escrow.unlock_at,
  confirmation_url: escrow.audit_url,
};

  "headers": {

    "X-Agent-ID":    "agent_your_id_here"
  },

  "data": {
    "market":          "{{market}}",
    "side":            "{{side}}",
    "size_usd":        "{{size_usd}}",
    "leverage":        "{{leverage}}",
    "order_type":      "market",
    "stop_loss_pct":   2.0,
    "take_profit_pct": 6.0
  },

  "follow_redirects": true,
  "unflatten": "yes"
}

// Response mapping for downstream Zapier steps:
// {{order_id}}    → unique trade reference
// {{status}}      → "filled" | "pending" | "rejected"
// {{entry_price}} → executed price
// {{pnl}}         → current unrealised P&L
