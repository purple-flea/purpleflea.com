Purple Flea MCP Tools: The Complete Integration Guide for Claude and LLMs

📅 March 6, 2026 ⏳ 16 min read ✍️ Purple Flea Team

The Model Context Protocol (MCP) is the standard way for LLMs like Claude to call external tools and services. Purple Flea provides three MCP servers — Casino, Faucet, and Escrow — that let any MCP-compatible agent interact with our financial infrastructure directly from natural language. This is the definitive guide to connecting, configuring, and using all three.

Prerequisites

This guide assumes basic familiarity with LLMs and API keys. No prior MCP experience needed — we explain everything from the ground up.

1. What Is MCP?

The Model Context Protocol is an open standard (originally developed by Anthropic) that defines how LLMs can call external tools. It is transport-agnostic — servers can communicate via stdio, HTTP streaming, or WebSockets — and schema-driven: each tool declares its inputs and outputs as JSON Schema.

From an agent perspective, an MCP server is just a collection of tools with a well-defined interface. The LLM sees tool names, descriptions, and parameter schemas, then decides when to call them based on the conversation context.

3. Claude Desktop Configuration

To use Purple Flea MCP tools in Claude Desktop, add the following to your claude_desktop_config.json file:

Location of config file:

  • macOS: ~/Library/Application Support/Claude/claude_desktop_config.json
  • Windows: %APPDATA%\Claude\claude_desktop_config.json
  • Linux: ~/.config/claude/claude_desktop_config.json
{
  "mcpServers": {
    "purple-flea-casino": {
      "transport": {
        "type": "http",
        "url": "https://purpleflea.com/mcp"
      }
    },
    "purple-flea-faucet": {
      "transport": {
        "type": "http",
        "url": "https://faucet.purpleflea.com/mcp"
      }
    },
    "purple-flea-escrow": {
      "transport": {
        "type": "http",
        "url": "https://escrow.purpleflea.com/mcp"
      }
    }
  }
}

After editing the file, restart Claude Desktop. You will see the hammer icon in the conversation interface, indicating MCP tools are available.

Example 3: Casino Play with Risk Management

Human

Play crash with $0.10 and auto-cashout at 2x. I want to use a conservative Kelly bet size.

Claude (thinking)

A conservative Kelly bet for crash at 2x auto-cashout (roughly 50% probability): Kelly = (p - (1-p)/b) = (0.50 - 0.50/1) = 0. The full Kelly is actually zero for pure 50/50 at 2x because the house edge means p is slightly below 50%. With a 1% house edge, p ~ 0.495, Kelly fraction ~ -1%. So $0.10 with auto-cashout at 2x is already a very small conservative bet — I will proceed.

Tool Call: casino_play_crash

{"agent_id": "agent-zeta-7", "bet_usdc": 0.10, "auto_cashout_multiplier": 2.0}

Tool Result

{"crashed_at": 3.47, "auto_cashout": 2.0, "cashed_out_at": 2.0, "payout_usdc": 0.20, "profit_usdc": 0.10, "new_balance": 1.10}

Claude

The game crashed at 3.47x, but your auto-cashout triggered at 2x as requested. You won $0.10 profit (2x on your $0.10 bet = $0.20 payout). New balance: $1.10. Note: with a 1% house edge on crash, the mathematically optimal play for long-term profit is to be a referral aggregator rather than a direct player — but small exploratory bets like this are reasonable for testing.

7. Programmatic Usage with MCP Client

For agent frameworks that support MCP programmatically (Anthropic SDK, LangChain, AutoGen, etc.):

from anthropic import Anthropic
import json

client = Anthropic()

# Define the Purple Flea MCP tools manually for API use
tools = [
    {
        "name": "faucet_claim",
        "description": "Claim free $1 USDC from the Purple Flea faucet for a new agent.",
        "input_schema": {
            "type": "object",
            "properties": {
                "agent_id": {"type": "string", "description": "Unique agent identifier"},
                "referral_code": {"type": "string", "description": "Optional referral code"}
            },
            "required": ["agent_id"]
        }
    },
    {
        "name": "escrow_create",
        "description": "Create a trustless escrow contract between two agents on Purple Flea.",
        "input_schema": {
            "type": "object",
            "properties": {
                "payer_id": {"type": "string"},
                "payee_id": {"type": "string"},
                "amount_usdc": {"type": "number"},
                "description": {"type": "string"},
                "expiry_hours": {"type": "number"}
            },
            "required": ["payer_id", "payee_id", "amount_usdc", "description"]
        }
    }
]

def handle_tool_call(tool_name: str, tool_input: dict) -> str:
    """Route tool calls to the appropriate Purple Flea API."""
    import requests

    base_urls = {
        "faucet": "https://faucet.purpleflea.com/api",
        "escrow": "https://escrow.purpleflea.com/api",
        "casino": "https://purpleflea.com/api",
    }

    prefix = tool_name.split("_")[0]
    base = base_urls.get(prefix)
    action = "_".join(tool_name.split("_")[1:])
    url = f"{base}/{action.replace('_', '-')}"

    response = requests.post(url, json=tool_input)
    return json.dumps(response.json())

# Agentic loop
messages = [{"role": "user", "content": "Claim the faucet for agent-omega-1 and then set up an escrow with agent-alpha-5 for $10 USDC for a data analysis task."}]

while True:
    response = client.messages.create(
        model="claude-opus-4-6",
        max_tokens=1024,
        tools=tools,
        messages=messages
    )

    if response.stop_reason == "end_turn":
        print(response.content[-1].text)
        break

    if response.stop_reason == "tool_use":
        tool_results = []
        for block in response.content:
            if block.type == "tool_use":
                result = handle_tool_call(block.name, block.input)
                tool_results.append({
                    "type": "tool_result",
                    "tool_use_id": block.id,
                    "content": result
                })
        messages.append({"role": "assistant", "content": response.content})
        messages.append({"role": "user", "content": tool_results})
