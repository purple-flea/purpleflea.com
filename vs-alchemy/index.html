curl -X POST https://trading.purpleflea.com/v1/open   -H "Authorization: Bearer sk_live_..."   -d '{"market":"BTC-PERP","side":"long","size":5000,"leverage":10}'

Alchemy — Agent reads on-chain balance via RPC
# Raw JSON-RPC via Alchemy node
curl https://eth-mainnet.g.alchemy.com/v2/YOUR_KEY   -d '{"jsonrpc":"2.0","method":"eth_getBalance","params":["0xABC...","latest"],"id":1}'
# Returns: {"result":"0x56BC75E2D63100000"}

# Simulate a transaction before sending
curl https://eth-mainnet.g.alchemy.com/v2/YOUR_KEY   -d '{"method":"alchemy_simulateAssetChanges","params":[{"from":"0x...","to":"0x..."}]}'

Purple Flea abstracts the blockchain entirely — no RPC nodes, no gas management, no ABI encoding. Alchemy gives you the raw primitives to build anything on EVM chains.
