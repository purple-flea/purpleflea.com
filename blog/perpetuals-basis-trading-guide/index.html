Perpetuals Basis Trading: Earn Funding Rates with AI Agents

Strategy Trading March 7, 2026

What Is Basis Trading?

Basis trading in crypto means holding a delta-neutral position — long spot, short perpetuals — and collecting the funding rate paid by longs to shorts. When the perpetual trades at a premium to spot (positive funding), shorts receive payments every 8 hours. The "basis" is the spread between spot and perp prices.

This strategy has historically generated 15–60% annualized returns during bull markets when demand to hold leveraged longs is high. AI agents are uniquely suited to execute it continuously: no sleep, no emotion, instant reaction to funding rate changes.

Key insight: When BTC perp funding is +0.03%/8h, shorts earn 0.03% × 3 × 365 = ~33% APY on the notional. Agents can capture this mechanically while remaining market-neutral.

Funding Rate Mechanics

Perpetual futures don't expire, so they use a funding mechanism to keep prices anchored to spot. Every 8 hours:

  • If funding is positive: longs pay shorts. Basis trade profits.
  • If funding is negative: shorts pay longs. Basis trade loses. Exit signal.
  • Rate typically ranges from −0.1% to +0.1% per period.

BasisTrader Python Agent

The BasisTrader class monitors funding rates, opens and closes positions automatically, and routes collected funding to the agent's Purple Flea wallet via escrow.

import asyncio, httpx, time
from dataclasses import dataclass

ESCROW_BASE  = "https://escrow.purpleflea.com"
WALLET_BASE  = "https://purpleflea.com"
AGENT_WALLET = "0xAgentWallet"
API_KEY      = "pf_live_your_key"

@dataclass
class BasisPosition:
    spot_size: float         # BTC held long on spot
    perp_short_size: float   # BTC shorted on perp
    entry_spot_price: float
    entry_perp_price: float
    margin_usdc: float
    funding_collected: float = 0.0
    open_at: float = 0.0

class BasisTrader:
    MIN_FUNDING  = 0.005   # % per 8h — minimum to open (annualized ~22%)
    EXIT_FUNDING = 0.0    # exit at neutral or negative
    MAX_CAPITAL  = 100.0  # USDC

    def __init__(self):
        self.position = None
        self.total_earned = 0.0

    async def monitor_funding(self, exchange_client) -> float:
        """Fetch current funding rate from exchange API."""
        data = await exchange_client.get_funding_rate("BTC-PERP")
        return data["funding_rate"]  # e.g. 0.0003 (0.03%)

    async def open_basis_trade(
        self, exchange_client, spot_price: float, capital_usdc: float
    ) -> BasisPosition:
        """Buy spot BTC + short equal notional on perp."""
        half = capital_usdc / 2
        btc_amount = half / spot_price

        # Buy spot
        await exchange_client.market_buy("BTC", btc_amount)
        # Short perp (uses other half as margin)
        perp_price = await exchange_client.get_perp_price("BTC-PERP")
        await exchange_client.market_sell_perp("BTC-PERP", btc_amount, margin=half)

        self.position = BasisPosition(
            spot_size=btc_amount, perp_short_size=btc_amount,
            entry_spot_price=spot_price, entry_perp_price=perp_price,
            margin_usdc=capital_usdc, open_at=time.time()
        )
        print(f"Basis trade opened: {btc_amount:.6f} BTC, ${capital_usdc} deployed")
        return self.position

    async def collect_funding(self, funding_rate: float) -> float:
        """Called after each 8h funding settlement."""
        if not self.position:
            return 0.0
        notional = self.position.spot_size * self.position.entry_spot_price
        earned   = notional * funding_rate
        self.position.funding_collected += earned
        self.total_earned += earned
        print(f"Funding collected: ${earned:.4f} (total: ${self.total_earned:.4f})")
        return earned

    async def close_trade(self, exchange_client) -> float:
        """Close spot + perp, transfer profits to Purple Flea wallet."""
        p = self.position
        await exchange_client.market_sell("BTC", p.spot_size)
        await exchange_client.close_perp("BTC-PERP")

        profit = p.funding_collected
        if profit > 0.01:
            # Route profit to Purple Flea wallet via escrow
            async with httpx.AsyncClient() as c:
                await c.post(f"{ESCROW_BASE}/api/escrow/create", json={
                    "payer_wallet": "0xExchangeHotWallet",
                    "payee_wallet": AGENT_WALLET,
                    "amount_usdc": profit,
                    "description": "Basis trade funding profit",
                    "auto_release": True,
                    "metadata": {
                        "strategy": "basis_trade",
                        "funding_collected": profit,
                        "hold_hours": (time.time() - p.open_at) / 3600,
                    }
                }, headers={"Authorization": f"Bearer {API_KEY}"})

        self.position = None
        return profit

    async def run_loop(self, exchange_client):
        """Main trading loop — monitor funding, trade, collect, exit."""
        while True:
            rate = await self.monitor_funding(exchange_client)

            if not self.position and rate >= self.MIN_FUNDING:
                spot = await exchange_client.get_spot_price("BTC")
                await self.open_basis_trade(exchange_client, spot, self.MAX_CAPITAL)

            elif self.position:
                if rate < self.EXIT_FUNDING:
                    # Funding flipped — exit immediately
                    await self.close_trade(exchange_client)
                    print("Position closed: negative funding")
                else:
                    await self.collect_funding(rate)

            await asyncio.sleep(8 * 3600)  # wake every 8 hours

Capital via Purple Flea Escrow

Before opening a basis trade, an agent can use Purple Flea Escrow to ring-fence its trading capital. This creates an on-chain record of the allocation and enables automatic return to treasury when the trade closes.

async def fund_basis_trade_from_treasury(
    treasury_wallet: str, trading_wallet: str, capital_usdc: float
) -> str:
    async with httpx.AsyncClient() as c:
        esc = await c.post(f"{ESCROW_BASE}/api/escrow/create", json={
            "payer_wallet": treasury_wallet,
            "payee_wallet": trading_wallet,
            "amount_usdc": capital_usdc,
            "description": "Basis trade capital allocation",
            "auto_release": True,
            "metadata": {"strategy": "basis_trade", "type": "capital_alloc"}
        }, headers={"Authorization": f"Bearer {API_KEY}"})
    return esc.json()["escrow_id"]

Multi-Exchange Basis Arbitrage

The same basis can be traded across multiple exchanges simultaneously, capturing rate differentials. If Exchange A offers 0.05% funding and Exchange B offers 0.02%, open on A and hedge on B for the spread.

async def multi_exchange_basis(exchanges: list, capital_per_exchange: float):
    """Open basis trades on the highest-funding exchanges in parallel."""
    rates = await asyncio.gather(*[
        e.get_funding_rate("BTC-PERP") for e in exchanges
    ])
    ranked = sorted(zip(exchanges, rates), key=lambda x: x[1], reverse=True)

    # Trade on top 3 exchanges by funding rate
    traders = [BasisTrader() for _ in range(3)]
    tasks   = []
    for trader, (exchange, rate) in zip(traders, ranked[:3]):
        if rate >= BasisTrader.MIN_FUNDING:
            spot = await exchange.get_spot_price("BTC")
            tasks.append(trader.open_basis_trade(exchange, spot, capital_per_exchange))
    await asyncio.gather(*tasks)

Risks and Mitigation

  • Funding flip risk: Funding turns negative — automated exit via run_loop handles this.
  • Delta drift: BTC price moves during the hold period. The spot and perp offset, but imperfectly during high volatility. Use tight position sizing.
  • Exchange insolvency: Counter-party risk on centralized exchanges. Mitigate by spreading across 3+ venues.
  • Liquidation risk: The perp short can be liquidated if BTC pumps hard. Maintain >50% margin buffer; Purple Flea wallet holds reserve.
  • Fee drag: Spot trading + perp fees eat into yield. At 0.05% taker × 2 = 0.10% round-trip. Only trade if funding > 0.015%/8h.

Performance Tracking

All funding income flows through Purple Flea Escrow metadata, creating an immutable audit trail. Track performance via the wallet API.

async def get_basis_performance(agent_wallet: str) -> dict:
    async with httpx.AsyncClient() as c:
        txns = await c.get(
            f"{WALLET_BASE}/api/wallet/history",
            params={"wallet": agent_wallet, "strategy": "basis_trade"},
            headers={"Authorization": f"Bearer {API_KEY}"}
        )
    data = txns.json()["transactions"]
    total = sum(t["amount_usdc"] for t in data)
    return {
        "total_funding_collected_usdc": total,
        "trade_count": len(data),
        "avg_per_trade": total / len(data) if data else 0,
    }
