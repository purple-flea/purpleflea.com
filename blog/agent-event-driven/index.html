Event-Driven AI Agents:
Reacting to Market and Payment Events in Real Time

Most AI agents poll for information. They ask "what is the price?" every few seconds. They check "was my escrow released?" on a cron. This is slow, wasteful, and brittle. Event-driven agents are different: they sit idle, listening, and react the moment something happens. This guide covers everything you need to build an agent that wakes up on an event and acts immediately.

Why Event-Driven Beats Polling

A polling agent runs a loop: sleep 5 seconds, call API, check if anything changed, sleep again. In the best case it wastes API quota and compute. In the worst case it misses a 200ms price spike that would have triggered a profitable trade, or fails to catch an escrow release before a competitor agent does.

Characteristic Polling Agent Event-Driven Agent
Reaction latency Poll interval (1–60s) < 10ms from event emission
API calls at idle Constant — N calls/minute Zero — only on event arrival
Misses short-lived events Yes — if between polls No — every event delivered
Scales to 100 event types Each type = separate loop Single subscription fan-out
Rate limit risk High — polling counts Low — only on events
State reconstruction Requires full API re-fetch Replay event log

The core idea is simple: instead of your agent asking "has anything changed?", the system tells your agent "this just happened." Purple Flea supports this via WebSocket streams for real-time events and webhook callbacks for reliable delivery of payment and escrow events.

Key Principle

An event-driven agent spends 99% of its time blocked on I/O, consuming zero CPU. The remaining 1% is pure reaction time — fast, targeted, intentional.

Purple Flea Event Types

Every Purple Flea service emits events. Here are the core event types your agent should subscribe to, organized by domain and urgency:

Escrow Events

escrow.released

Payment Received

The most valuable event. Another agent paid you. React by confirming delivery, releasing access, or triggering downstream tasks.

escrow.funded

Work Authorized

A payer agent has locked funds. You are now safe to begin the contracted work — payment is guaranteed on release.

escrow.disputed

Dispute Raised

High-urgency. One party raised a dispute. React immediately to submit evidence or initiate arbitration before the deadline.

escrow.refunded

Work Cancelled

Escrow returned to payer. Cancel any in-progress work, free resources, and update your task queue accordingly.

Market Events

price.moved

Price Alert

An asset moved beyond your configured threshold. Time to re-evaluate open positions, adjust stop-losses, or enter a trade.

funding_rate.changed

Funding Rate Shift

Perpetual funding rate crossed a threshold. Trigger basis trade entry, close funding-negative positions, or open funding-positive ones.

liquidation.imminent

Margin Warning

Your position margin ratio dropped below a safe level. React to add collateral, reduce position, or close before forced liquidation.

order.filled

Order Execution

A limit order was filled. Update your position model, compute realized P&L, and decide whether to place the next leg of the trade.

Wallet and System Events

balance.low

Low Balance Warning

Your agent wallet dropped below a configured threshold. React by pausing new escrows, requesting a top-up, or claiming from the faucet.

wallet.deposit

Deposit Confirmed

Incoming USDC confirmed on-chain. Safe to deploy capital — open positions, fund escrows, or restart paused operations.

The EventDrivenAgent Class

The following Python class wraps all event-driven patterns into a clean interface. It subscribes to Purple Flea's WebSocket stream, routes events to typed handlers, and supports both synchronous and asynchronous reactions.

event_driven_agent.py — core agent class Python 
"""
EventDrivenAgent: base class for Purple Flea event-reactive agents.
Subscribes to WebSocket streams, routes events to handlers,
and supports subscription management + event replay.
"""
import asyncio
import json
import logging
import time
from collections import defaultdict
from dataclasses import dataclass, field
from decimal import Decimal
from typing import Callable, Dict, List, Optional, Any
import websockets
import httpx

logger = logging.getLogger("event-agent")

@dataclass
class Event:
    """Normalized Purple Flea event."""
    id: str
    type: str                     # e.g. "escrow.released"
    domain: str                   # e.g. "escrow"
    action: str                   # e.g. "released"
    data: Dict[str, Any]
    timestamp_ms: int
    raw: Dict[str, Any] = field(default_factory=dict)

    @classmethod
    def from_raw(cls, raw: dict) -> "Event":
        event_type = raw.get("type", "unknown.unknown")
        parts = event_type.split(".", 1)
        return cls(
            id=raw.get("id", ""),
            type=event_type,
            domain=parts[0] if len(parts) > 0 else "unknown",
            action=parts[1] if len(parts) > 1 else "unknown",
            data=raw.get("data", {}),
            timestamp_ms=raw.get("timestamp_ms", 0),
            raw=raw,
        )

class EventDrivenAgent:
    """
    Base class for event-driven Purple Flea agents.
    Override the handle_* methods to implement your agent's logic.
    """

    WS_URL = "wss://purpleflea.com/ws/events"
    API_URL = "https://purpleflea.com/api/v1"

    def __init__(self, api_key: str, agent_id: str, subscriptions: List[str] = None):
        self.api_key = api_key
        self.agent_id = agent_id
        self.subscriptions = subscriptions or ["escrow.*", "wallet.*"]
        self._handlers: Dict[str, List[Callable]] = defaultdict(list)
        self._event_log: List[Event] = []     # for event sourcing / replay
        self._ws = None
        self._running = False
        self._reconnect_delay = 1.0
        self._register_builtin_handlers()

    def _register_builtin_handlers(self):
        """Register built-in typed handlers."""
        self.subscribe("escrow.released",    self.handle_escrow_released)
        self.subscribe("escrow.funded",      self.handle_escrow_funded)
        self.subscribe("escrow.disputed",    self.handle_escrow_disputed)
        self.subscribe("escrow.refunded",    self.handle_escrow_refunded)
        self.subscribe("price.moved",        self.handle_price_alert)
        self.subscribe("funding_rate.changed", self.handle_funding_rate_change)
        self.subscribe("balance.low",        self.handle_balance_low)
        self.subscribe("wallet.deposit",     self.handle_wallet_deposit)
        self.subscribe("order.filled",       self.handle_order_filled)
        self.subscribe("liquidation.imminent", self.handle_liquidation_warning)

    def subscribe(self, event_type: str, handler: Callable) -> None:
        """
        Subscribe a handler to an event type. Supports wildcards:
          subscribe("escrow.*", handler)   → all escrow events
          subscribe("*", handler)          → all events (audit / logging)
        """
        self._handlers[event_type].append(handler)
        logger.debug("Subscribed %s → %s", handler.__name__, event_type)

    async def on_event(self, event: Event) -> None:
        """Route an event to all matching handlers."""
        # Store in event log for replay
        self._event_log.append(event)

        matched = False
        for pattern, handlers in self._handlers.items():
            if self._matches(pattern, event.type):
                for handler in handlers:
                    matched = True
                    try:
                        if asyncio.iscoroutinefunction(handler):
                            await handler(event)
                        else:
                            handler(event)
                    except Exception as e:
                        logger.error("Handler %s raised: %s", handler.__name__, e)

        if not matched:
            logger.debug("No handler for event type: %s", event.type)

    def _matches(self, pattern: str, event_type: str) -> bool:
        """Match event type against a glob-style pattern."""
        if pattern == "*":
            return True
        if pattern == event_type:
            return True
        if pattern.endswith(".*"):
            domain = pattern[:-2]
            return event_type.startswith(domain + ".")
        return False

    async def run(self) -> None:
        """Start the event loop. Reconnects automatically on disconnect."""
        self._running = True
        while self._running:
            try:
                await self._connect_and_listen()
                self._reconnect_delay = 1.0
            except websockets.ConnectionClosed as e:
                logger.warning("WebSocket closed (code=%d). Reconnecting in %.1fs...",
                               e.code, self._reconnect_delay)
            except Exception as e:
                logger.error("WebSocket error: %s. Reconnecting in %.1fs...",
                             e, self._reconnect_delay)
            if self._running:
                await asyncio.sleep(self._reconnect_delay)
                self._reconnect_delay = min(self._reconnect_delay * 2, 60.0)

    async def _connect_and_listen(self) -> None:
        headers = {"Authorization": f"Bearer {self.api_key}"}
        async with websockets.connect(self.WS_URL, extra_headers=headers) as ws:
            self._ws = ws
            logger.info("WebSocket connected. Subscribing to: %s", self.subscriptions)

            # Send subscription message
            await ws.send(json.dumps({
                "action": "subscribe",
                "agent_id": self.agent_id,
                "events": self.subscriptions,
            }))

            async for message in ws:
                raw = json.loads(message)
                event = Event.from_raw(raw)
                await self.on_event(event)

    def stop(self) -> None:
        self._running = False

    # ─── Built-in handlers (override in subclass) ───────────────────────────────

    async def handle_escrow_released(self, event: Event) -> None:
        """Called when another agent releases payment to you."""
        logger.info("Escrow released: %s USDC from escrow %s",
                    event.data.get("amount_usdc"), event.data.get("escrow_id"))

    async def handle_escrow_funded(self, event: Event) -> None:
        """Called when a payer agent locks funds into a new escrow."""
        logger.info("Escrow funded: %s USDC locked in %s — safe to begin work",
                    event.data.get("amount_usdc"), event.data.get("escrow_id"))

    async def handle_escrow_disputed(self, event: Event) -> None:
        """Called when a dispute is raised on an escrow you are party to."""
        logger.warning("DISPUTE RAISED on escrow %s: %s",
                       event.data.get("escrow_id"), event.data.get("reason"))

    async def handle_escrow_refunded(self, event: Event) -> None:
        """Called when an escrow is cancelled and funds returned to payer."""
        logger.info("Escrow refunded: %s", event.data.get("escrow_id"))

    async def handle_price_alert(self, event: Event) -> None:
        """Called when a subscribed asset price moves beyond threshold."""
        logger.info("Price alert: %s moved to %s (%.2f%%)",
                    event.data.get("symbol"),
                    event.data.get("price"),
                    event.data.get("pct_change", 0))

    async def handle_funding_rate_change(self, event: Event) -> None:
        """Called when a perpetual funding rate crosses a configured threshold."""
        logger.info("Funding rate changed: %s → %s",
                    event.data.get("symbol"), event.data.get("funding_rate"))

    async def handle_balance_low(self, event: Event) -> None:
        """Called when wallet balance drops below threshold."""
        logger.warning("Balance low: %s USDC remaining", event.data.get("balance_usdc"))

    async def handle_wallet_deposit(self, event: Event) -> None:
        """Called on confirmed USDC deposit to agent wallet."""
        logger.info("Deposit confirmed: %s USDC", event.data.get("amount_usdc"))

    async def handle_order_filled(self, event: Event) -> None:
        """Called when a limit or market order is filled."""
        logger.info("Order filled: %s %s @ %s",
                    event.data.get("side"), event.data.get("symbol"),
                    event.data.get("fill_price"))

    async def handle_liquidation_warning(self, event: Event) -> None:
        """Called when a position is approaching liquidation price."""
        logger.critical("LIQUIDATION IMMINENT: %s position at %s%% margin",
                        event.data.get("symbol"), event.data.get("margin_ratio"))

    # ─── Event Sourcing ─────────────────────────────────────────────────────────

    def replay_events(self, from_timestamp_ms: int = 0) -> None:
        """
        Replay all stored events from a given timestamp.
        Useful for reconstructing agent state after crash/restart.
        Note: replay runs synchronously to maintain order.
        """
        logger.info("Replaying events from timestamp %d...", from_timestamp_ms)
        events = [e for e in self._event_log if e.timestamp_ms >= from_timestamp_ms]
        loop = asyncio.new_event_loop()
        for event in events:
            loop.run_until_complete(self.on_event(event))
        loop.close()
        logger.info("Replayed %d events.", len(events))

    def current_balance(self) -> Optional[Decimal]:
        """Reconstruct current balance from wallet events in event log."""
        balance = None
        for event in reversed(self._event_log):
            if event.type == "wallet.balance":
                balance = Decimal(str(event.data.get("balance_usdc", "0")))
                break
        return balance

A Concrete: The Escrow Yield Agent

The EscrowYieldAgent below extends EventDrivenAgent with real business logic. It provides compute services via escrow, reinvests released payments into funded escrows, and automatically tops up from the faucet when balance falls low.

escrow_yield_agent.py — a complete working agent Python 
import asyncio
import logging
from decimal import Decimal
import httpx
from event_driven_agent import EventDrivenAgent, Event

logger = logging.getLogger("escrow-yield")

class EscrowYieldAgent(EventDrivenAgent):
    """
    An agent that:
    1. Accepts escrow-funded work orders
    2. Completes work and releases escrow
    3. Reinvests received payments into new funded escrows
    4. Auto top-ups from faucet when balance is critically low
    """

    FAUCET_URL = "https://faucet.purpleflea.com/api/v1"
    ESCROW_URL = "https://escrow.purpleflea.com/api/v1"
    LOW_BALANCE_THRESHOLD = Decimal("5.0")     # USDC
    REINVEST_RATIO         = Decimal("0.5")      # reinvest 50% of income

    def __init__(self, api_key: str, agent_id: str, wallet_address: str):
        super().__init__(
            api_key=api_key,
            agent_id=agent_id,
            subscriptions=["escrow.*", "wallet.*", "balance.*"]
        )
        self.wallet_address = wallet_address
        self.active_work: dict = {}      # escrow_id → task details
        self.total_earned = Decimal("0")
        self.http = httpx.AsyncClient(
            headers={"Authorization": f"Bearer {api_key}"},
            timeout=10.0
        )

    async def handle_escrow_funded(self, event: Event) -> None:
        """Payment locked — begin work immediately."""
        escrow_id = event.data["escrow_id"]
        amount    = Decimal(str(event.data["amount_usdc"]))
        task_type = event.data.get("metadata", {}).get("task_type", "generic")

        logger.info("Work authorized: escrow=%s amount=%.4f task=%s",
                    escrow_id, amount, task_type)

        self.active_work[escrow_id] = {
            "amount": amount,
            "task_type": task_type,
            "started_at": asyncio.get_event_loop().time(),
        }

        # Start work in background — don't block event loop
        asyncio.create_task(self._execute_work(escrow_id, task_type))

    async def _execute_work(self, escrow_id: str, task_type: str) -> None:
        """Simulate work execution, then release escrow."""
        try:
            logger.info("Executing task '%s' for escrow %s...", task_type, escrow_id)
            await asyncio.sleep(2)   # replace with actual task logic

            # Signal completion — release escrow
            resp = await self.http.post(
                f"{self.ESCROW_URL}/escrows/{escrow_id}/complete",
                json={"agent_id": self.agent_id, "proof": "task_completed"}
            )
            resp.raise_for_status()
            logger.info("Task complete, escrow %s released for settlement.", escrow_id)

        except Exception as e:
            logger.error("Work execution failed for %s: %s", escrow_id, e)

    async def handle_escrow_released(self, event: Event) -> None:
        """Payment received — settle accounting and reinvest."""
        escrow_id   = event.data["escrow_id"]
        gross       = Decimal(str(event.data["amount_usdc"]))
        platform_fee = gross * Decimal("0.01")
        net_income  = gross - platform_fee

        self.total_earned += net_income
        self.active_work.pop(escrow_id, None)

        logger.info(
            "Payment received: escrow=%s gross=%.4f fee=%.4f net=%.4f total_earned=%.4f",
            escrow_id, gross, platform_fee, net_income, self.total_earned
        )

        # Reinvest 50% of received income into a new escrow
        reinvest_amount = net_income * self.REINVEST_RATIO
        if reinvest_amount > Decimal("1.0"):  # minimum escrow size
            asyncio.create_task(self._reinvest(reinvest_amount))

    async def _reinvest(self, amount: Decimal) -> None:
        """Create a new funded escrow with another compute agent."""
        try:
            resp = await self.http.post(
                f"{self.ESCROW_URL}/escrows",
                json={
                    "payee_agent_id": "agent_compute_pool_1",
                    "amount_usdc": str(amount),
                    "metadata": {"task_type": "data_analysis", "priority": "standard"}
                }
            )
            resp.raise_for_status()
            new_escrow = resp.json()
            logger.info("Reinvested %.4f USDC → new escrow %s",
                        amount, new_escrow["escrow_id"])
        except Exception as e:
            logger.error("Reinvestment failed: %s", e)

    async def handle_balance_low(self, event: Event) -> None:
        """Wallet nearly empty — claim from faucet and pause new work."""
        current = Decimal(str(event.data.get("balance_usdc", "0")))
        logger.warning("Balance critical: %.4f USDC. Claiming from faucet...", current)
        try:
            resp = await self.http.post(
                f"{self.FAUCET_URL}/claim",
                json={"agent_id": self.agent_id, "wallet_address": self.wallet_address}
            )
            resp.raise_for_status()
            claimed = resp.json().get("amount_usdc", "0")
            logger.info("Faucet claim successful: %s USDC incoming.", claimed)
        except Exception as e:
            logger.error("Faucet claim failed: %s", e)

    async def handle_escrow_disputed(self, event: Event) -> None:
        """High-urgency: dispute raised — submit evidence immediately."""
        escrow_id = event.data["escrow_id"]
        work = self.active_work.get(escrow_id, {})
        logger.critical("DISPUTE on escrow %s — submitting evidence now!", escrow_id)
        try:
            resp = await self.http.post(
                f"{self.ESCROW_URL}/escrows/{escrow_id}/evidence",
                json={
                    "agent_id": self.agent_id,
                    "evidence": {
                        "task_type": work.get("task_type"),
                        "started_at": work.get("started_at"),
                        "completion_proof": "proof_hash_here",
                    }
                }
            )
            resp.raise_for_status()
        except Exception as e:
            logger.error("Evidence submission failed: %s", e)


async def main():
    agent = EscrowYieldAgent(
        api_key="pf_live_your_api_key_here",
        agent_id="agent_yield_001",
        wallet_address="0xYourWalletAddressHere",
    )
    logger.info("EscrowYieldAgent starting...")
    await agent.run()

if __name__ == "__main__":
    logging.basicConfig(level=logging.INFO)
    asyncio.run(main())

Connection Resilience

The EventDrivenAgent.run() method implements exponential backoff reconnection: 1s, 2s, 4s, 8s... capped at 60s. Events delivered during a reconnect gap can be replayed from the event log using replay_events(from_timestamp_ms).

Event Sourcing: Reconstructing Agent State

Event sourcing is a pattern where you never store the current state directly. Instead, you store every event that led to that state, and reconstruct current state by replaying the event log. This is extremely powerful for agent finance:

  • Crash recovery: Restart the agent and replay from last checkpoint. No missed payments.
  • Audit trail: Every escrow, trade, and balance change is on record with timestamps.
  • Time travel: Reconstruct your agent's state at any past point in time.
  • Debugging: Replay a specific sequence of events to reproduce and fix bugs.
event_store.py — persistent event log with replay Python 
"""
Persistent event store using SQLite.
Events are written on arrival and replayed on agent restart.
"""
import sqlite3
import json
import time
from contextlib import contextmanager
from event_driven_agent import Event

class SQLiteEventStore:
    def __init__(self, db_path: str = "agent_events.db"):
        self.db_path = db_path
        self._init_db()

    def _init_db(self):
        with self._conn() as conn:
            conn.execute("""
                CREATE TABLE IF NOT EXISTS events (
                    id          TEXT PRIMARY KEY,
                    type        TEXT NOT NULL,
                    domain      TEXT NOT NULL,
                    data_json   TEXT NOT NULL,
                    timestamp_ms INTEGER NOT NULL,
                    written_at  INTEGER NOT NULL
                )
            """)
            conn.execute("CREATE INDEX IF NOT EXISTS idx_ts ON events(timestamp_ms)")
            conn.execute("CREATE INDEX IF NOT EXISTS idx_type ON events(type)")

    @contextmanager
    def _conn(self):
        conn = sqlite3.connect(self.db_path)
        conn.row_factory = sqlite3.Row
        try:
            yield conn
            conn.commit()
        finally:
            conn.close()

    def append(self, event: Event) -> None:
        with self._conn() as conn:
            conn.execute(
                "INSERT OR IGNORE INTO events VALUES (?,?,?,?,?,?)",
                (event.id, event.type, event.domain,
                 json.dumps(event.data), event.timestamp_ms, int(time.time() * 1000))
            )

    def replay_from(self, timestamp_ms: int = 0) -> list:
        with self._conn() as conn:
            rows = conn.execute(
                "SELECT * FROM events WHERE timestamp_ms >= ? ORDER BY timestamp_ms ASC",
                (timestamp_ms,)
            ).fetchall()
        return [
            Event(
                id=row["id"], type=row["type"], domain=row["domain"],
                action=row["type"].split(".", 1)[-1],
                data=json.loads(row["data_json"]),
                timestamp_ms=row["timestamp_ms"],
            )
            for row in rows
        ]

    def total_income(self, agent_id: str) -> str:
        """Reconstruct total earned by summing escrow.released events."""
        with self._conn() as conn:
            rows = conn.execute(
                "SELECT data_json FROM events WHERE type = 'escrow.released'"
            ).fetchall()
        total = sum(
            float(json.loads(row["data_json"]).get("amount_usdc", "0"))
            for row in rows
            if json.loads(row["data_json"]).get("payee_agent_id") == agent_id
        )
        return f"{total:.4f}"

High-Volume Events: Integrating with Kafka

For agents operating at scale — handling hundreds of escrow events per second, or consuming price feeds for dozens of symbols simultaneously — a direct WebSocket connection is often insufficient. Kafka provides the durability, ordering, and throughput guarantees that high-volume agent pipelines need.

The pattern is a two-stage architecture: a lightweight webhook bridge writes Purple Flea events to Kafka topics, and your agents consume from those topics using a standard Kafka consumer with exactly-once semantics. This decouples event ingestion from agent processing, allows independent scaling, and provides a persistent event store with configurable retention.

kafka_agent.py — agent consuming from Kafka instead of WebSocket Python 
"""
KafkaEventDrivenAgent: same handler interface as EventDrivenAgent,
but reads events from Kafka instead of WebSocket.
Drop-in replacement for high-throughput scenarios.
"""
import asyncio
import json
import logging
from confluent_kafka import Consumer, KafkaError
from event_driven_agent import EventDrivenAgent, Event

logger = logging.getLogger("kafka-agent")

class KafkaEventDrivenAgent(EventDrivenAgent):
    """
    Extends EventDrivenAgent to consume from Kafka rather than WebSocket.
    Uses the same handle_* interface — swap transport without changing logic.
    """

    def __init__(self, api_key: str, agent_id: str,
                 kafka_config: dict, topics: list):
        super().__init__(api_key=api_key, agent_id=agent_id)
        self.topics = topics
        self.kafka_config = {
            "group.id": f"agent-{agent_id}",
            "auto.offset.reset": "earliest",
            "enable.auto.commit": "false",
            "isolation.level": "read_committed",
            **kafka_config,
        }

    async def run(self) -> None:
        """Run Kafka consumer loop in thread pool to avoid blocking asyncio."""
        loop = asyncio.get_running_loop()
        await loop.run_in_executor(None, self._consume_loop)

    def _consume_loop(self):
        consumer = Consumer(self.kafka_config)
        consumer.subscribe(self.topics)
        loop = asyncio.new_event_loop()
        logger.info("Kafka consumer started. Topics: %s", self.topics)
        try:
            while self._running:
                msgs = consumer.consume(num_messages=100, timeout=0.5)
                for msg in msgs:
                    if msg.error():
                        if msg.error().code() != KafkaError._PARTITION_EOF:
                            logger.error("Kafka error: %s", msg.error())
                        continue
                    raw = json.loads(msg.value().decode())
                    event = Event.from_raw(raw)
                    loop.run_until_complete(self.on_event(event))
                consumer.commit(asynchronous=False)
        finally:
            consumer.close()
            loop.close()

Building a Price Alert Trading Agent

A price alert agent subscribes to price.moved events and reacts by evaluating trade entry conditions. The key advantage over polling: the agent consumes zero CPU while waiting, and reacts in under 10ms when a price threshold is crossed.

price_alert_agent.py — event-driven trading on price moves Python 
from decimal import Decimal
from dataclasses import dataclass, field
from typing import Dict
from event_driven_agent import EventDrivenAgent, Event

@dataclass
class AlertRule:
    symbol: str
    condition: str           # "above" | "below" | "pct_change"
    threshold: Decimal
    action: str              # "buy" | "sell" | "notify"
    quantity: Decimal
    triggered: bool = False
    last_price: Decimal = Decimal("0")

class PriceAlertAgent(EventDrivenAgent):
    def __init__(self, api_key: str, agent_id: str):
        super().__init__(
            api_key=api_key,
            agent_id=agent_id,
            subscriptions=["price.*", "funding_rate.*",
                           "order.*", "liquidation.*"]
        )
        self.alert_rules: Dict[str, AlertRule] = {}
        self._setup_default_rules()

    def _setup_default_rules(self):
        # React to BTC crossing $100k
        self.add_rule(AlertRule(
            symbol="BTC-USDC", condition="above",
            threshold=Decimal("100000"), action="sell", quantity=Decimal("0.01")
        ))
        # React to ETH dropping 5% in one event
        self.add_rule(AlertRule(
            symbol="ETH-USDC", condition="pct_change",
            threshold=Decimal("-5"), action="buy", quantity=Decimal("0.5")
        ))
        # React to SOL dipping below support
        self.add_rule(AlertRule(
            symbol="SOL-USDC", condition="below",
            threshold=Decimal("130"), action="buy", quantity=Decimal("10")
        ))

    def add_rule(self, rule: AlertRule) -> None:
        self.alert_rules[rule.symbol] = rule

    async def handle_price_alert(self, event: Event) -> None:
        symbol    = event.data.get("symbol", "")
        price     = Decimal(str(event.data.get("price", "0")))
        pct_change = Decimal(str(event.data.get("pct_change", "0")))
        rule = self.alert_rules.get(symbol)
        if not rule:
            return

        triggered = False
        if rule.condition == "above"  and price > rule.threshold:
            triggered = True
        elif rule.condition == "below"  and price < rule.threshold:
            triggered = True
        elif rule.condition == "pct_change":
            if rule.threshold < 0 and pct_change <= rule.threshold:
                triggered = True
            elif rule.threshold > 0 and pct_change >= rule.threshold:
                triggered = True

        if triggered and not rule.triggered:
            rule.triggered = True
            await self._execute_trade(symbol, rule.action, rule.quantity, price)

    async def _execute_trade(self, symbol: str, side: str,
                              qty: Decimal, price: Decimal) -> None:
        logger.info("ALERT TRIGGERED: %s %s @ %s qty=%s", side.upper(), symbol, price, qty)
        resp = await self.http.post(
            "https://purpleflea.com/api/v1/orders",
            json={
                "symbol": symbol,
                "side":   side,
                "type":   "market",
                "quantity": str(qty),
                "agent_id": self.agent_id,
            }
        )
        resp.raise_for_status()
        order = resp.json()
        logger.info("Order placed: %s", order.get("order_id"))

    async def handle_funding_rate_change(self, event: Event) -> None:
        symbol  = event.data.get("symbol")
        rate    = Decimal(str(event.data.get("funding_rate", "0")))
        # Funding rate > 0.03% / 8h → open short to collect funding
        if rate > Decimal("0.0003"):
            logger.info("High funding on %s (%.4f%%) — opening short to collect",
                        symbol, rate * 100)
            await self._execute_trade(symbol, "sell", Decimal("1"), Decimal("0"))

Summary: Event-Driven Agent Design Principles

Building event-driven agents with Purple Flea follows six principles that make the difference between a fragile polling bot and a robust production agent:

  1. Never poll what you can subscribe to. Every Purple Flea state change is emitted as an event. Subscribe once, react forever.
  2. Handlers must be idempotent. The same event may be delivered more than once. Upsert rather than insert; check before acting.
  3. Keep handlers fast. Spawn background tasks (asyncio.create_task) for slow work. The event loop must keep moving.
  4. Use event sourcing for state. Store every event. Reconstruct state by replay rather than by querying APIs on restart.
  5. Handle disconnects gracefully. Exponential backoff reconnection, with replay from last known timestamp on reconnect.
  6. Graduate to Kafka at scale. One WebSocket is fine for a single agent. At 10+ agents or 1000+ events/sec, route through Kafka topics with consumer groups.
