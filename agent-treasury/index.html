What Is an Agent Treasury?

An agent treasury is the total pool of crypto assets that an autonomous AI agent holds, manages, and deploys to fund its ongoing operations and generate returns. Unlike a passive wallet that simply receives and sends funds, a treasury is an active management system with allocation targets, rebalancing rules, and risk budgets — all executed in code without human intervention.

Think of it as the CFO function of an autonomous agent. Just as a company treasury manages cash, short-term investments, and operating capital, an agent treasury manages USDC reserves, trading positions, yield positions, and speculative allocations. The treasury is the agent's financial backbone — every income stream flows into it, every expense flows out, and the management logic ensures the agent remains solvent and growing.

Purple Flea provides all the primitives an agent needs to implement a full treasury strategy: a wallet API for custody, a trading API for active positions, a DeFi yield API for passive earnings, a casino API for high-variance plays, and a cross-chain swap API for rebalancing across chains.

Key Treasury Functions

A well-designed agent treasury performs four core functions continuously:

  • Capital Allocation: Decide how much of the total treasury goes into each bucket (trading, yield, casino, stables). These are percentage targets, not fixed amounts — as the treasury grows, each bucket scales proportionally.
  • Rebalancing: When actual allocations drift more than a threshold (typically 10%) from targets, the treasury rebalances by moving funds between buckets. This is triggered automatically — no human approval required.
  • Yield Optimization: Idle stablecoins should never sit dormant. The treasury automatically deploys all stable reserves into the highest-yield position available (Aave, Compound, Spark) and withdraws when needed for rebalancing or expenses.
  • Risk Budgeting: Each bucket has a maximum drawdown limit. If the casino bucket loses 50% from its high-water mark, no new capital is allocated to it until it recovers or the agent explicitly overrides the rule.

Architecture

TreasuryAgent Architecture

The TreasuryAgent class is the central coordinator. It maintains a map of allocation targets, reads current balances from each Purple Flea API endpoint, calculates drift from targets, and executes swaps when drift exceeds the rebalance threshold.

The class is designed to be called on a schedule — every 15 minutes is typical. Each call is idempotent: if no rebalance is needed, the call returns early with no side effects. If rebalancing is required, it executes the minimum set of swaps to restore the target allocation.

Rebalance Logic

Rebalancing is triggered when any bucket's actual allocation deviates from its target by more than 10 percentage points. For example, if the trading bucket target is 40% but trading has grown to 52% of the total treasury (due to profitable trades), the treasury sells down the trading excess and distributes proceeds to underweight buckets.

The rebalance algorithm is:

  • Calculate total treasury value in USDC across all buckets and chains.
  • For each bucket, compute actual_pct = bucket_value / total_value.
  • Compute drift = abs(actual_pct - target_pct).
  • If max(drift) > 0.10, trigger rebalance.
  • Sell overweight buckets first (to USDC), then buy into underweight buckets.
  • Route all swaps through the Purple Flea swap API for best execution.

import requests
import time
from dataclasses import dataclass, field
from typing import Dict
from datetime import datetime

BASE_URL = "https://purpleflea.com/api/v1"

@dataclass
class BucketState:
    name: str
    target_pct: float          # e.g. 0.40 for 40%
    current_usdc: float = 0.0  # live value fetched from API
    max_drawdown: float = 0.50  # halt new allocation if loss > 50%
    high_water: float = 0.0    # peak value for drawdown tracking
    halted: bool = False        # True if drawdown limit breached


class TreasuryAgent:
    def __init__(self, api_key: str, referral_tag: str = ""):
        self.api_key = api_key
        self.referral_tag = referral_tag
        self.drift_threshold = 0.10  # 10% drift triggers rebalance
        self.headers = {
            "Authorization": f"Bearer {api_key}",
            "Content-Type": "application/json",
        }
        self.buckets: Dict[str, BucketState] = {
            "trading": BucketState(
                name="trading", target_pct=0.40, max_drawdown=0.30
            ),
            "yield": BucketState(
                name="yield", target_pct=0.30, max_drawdown=0.15
            ),
            "casino": BucketState(
                name="casino", target_pct=0.20, max_drawdown=0.50
            ),
            "stables": BucketState(
                name="stables", target_pct=0.10, max_drawdown=0.05
            ),
        }
        self.log_entries = []

    def fetch_balances(self) -> Dict[str, float]:
        """Fetch current USD value of each bucket from Purple Flea APIs."""
        balances = {}

        # Trading: open positions + unrealized PnL
        r = requests.get(
            f"{BASE_URL}/trading/portfolio-value",
            headers=self.headers
        )
        balances["trading"] = r.json()["total_value_usdc"]

        # Yield: supplied value across Aave/Compound
        r = requests.get(
            f"{BASE_URL}/defi/yield-positions",
            headers=self.headers
        )
        balances["yield"] = r.json()["total_supplied_usdc"]

        # Casino: wallet balance allocated to casino operations
        r = requests.get(
            f"{BASE_URL}/casino/balance",
            headers=self.headers
        )
        balances["casino"] = r.json()["balance_usdc"]

        # Stables: raw USDC in wallet
        r = requests.get(
            f"{BASE_URL}/wallet/balance?asset=USDC",
            headers=self.headers
        )
        balances["stables"] = r.json()["balance"]

        return balances

    def check_drawdowns(self):
        """Update high-water marks and halt buckets that breach drawdown limits."""
        for bucket in self.buckets.values():
            if bucket.current_usdc > bucket.high_water:
                bucket.high_water = bucket.current_usdc
            if bucket.high_water > 0:
                drawdown = (bucket.high_water - bucket.current_usdc) / bucket.high_water
                if drawdown > bucket.max_drawdown:
                    bucket.halted = True
                    self.log(
                        f"[HALT] {bucket.name} breached {bucket.max_drawdown*100:.0f}% drawdown"
                        f" (current drawdown: {drawdown*100:.1f}%)"
                    )
                elif bucket.current_usdc >= bucket.high_water:
                    bucket.halted = False  # recover at new high

    def needs_rebalance(self, total: float) -> bool:
        """Return True if any non-halted bucket drifts beyond threshold."""
        for bucket in self.buckets.values():
            actual_pct = bucket.current_usdc / total
            drift = abs(actual_pct - bucket.target_pct)
            if drift > self.drift_threshold:
                return True
        return False

    def rebalance(self, total: float):
        """Execute swaps to restore target allocations."""
        overweight = []   # buckets to sell down
        underweight = []  # buckets to buy into

        for bucket in self.buckets.values():
            target_usdc = bucket.target_pct * total
            delta = bucket.current_usdc - target_usdc
            if delta > 0:
                overweight.append((bucket.name, delta))
            elif delta < 0 and not bucket.halted:
                underweight.append((bucket.name, abs(delta)))

        # Sell overweight buckets first (to USDC)
        for name, amount in overweight:
            self.withdraw_to_usdc(name, amount)
            self.log(f"Sold ${amount:.2f} from {name}")

        # Deploy into underweight buckets
        for name, amount in underweight:
            self.deploy_usdc(name, amount)
            self.log(f"Deployed ${amount:.2f} to {name}")

    def withdraw_to_usdc(self, bucket: str, amount: float):
        """Withdraw excess from a bucket back to USDC."""
        endpoint = {
            "trading": f"{BASE_URL}/trading/close-partial",
            "yield":   f"{BASE_URL}/defi/withdraw",
            "casino":  f"{BASE_URL}/casino/withdraw",
        }.get(bucket)
        if endpoint:
            requests.post(endpoint, json={"amount_usdc": amount}, headers=self.headers)

    def deploy_usdc(self, bucket: str, amount: float):
        """Deploy USDC into a bucket."""
        endpoint = {
            "trading": f"{BASE_URL}/trading/fund",
            "yield":   f"{BASE_URL}/defi/supply",
            "casino":  f"{BASE_URL}/casino/deposit",
        }.get(bucket)
        ref = {"referral": self.referral_tag} if self.referral_tag else {}
        if endpoint:
            requests.post(
                endpoint,
                json={"amount_usdc": amount, **ref},
                headers=self.headers
            )

    def tick(self):
        """Main loop step — call every 15 minutes."""
        balances = self.fetch_balances()
        for name, val in balances.items():
            self.buckets[name].current_usdc = val

        total = sum(balances.values())
        self.check_drawdowns()

        if self.needs_rebalance(total):
            self.log(f"Rebalancing treasury (total: ${total:,.2f} USDC)")
            self.rebalance(total)
        else:
            self.log(f"Treasury healthy (total: ${total:,.2f} USDC) — no rebalance needed")

        return self.report(total)

    def report(self, total: float) -> dict:
        """Return a P&L snapshot for logging / dashboards."""
        return {
            "timestamp": datetime.utcnow().isoformat(),
            "total_usdc": total,
            "allocations": {
                name: {
                    "value": b.current_usdc,
                    "pct": b.current_usdc / total,
                    "target": b.target_pct,
                    "halted": b.halted,
                }
                for name, b in self.buckets.items()
            },
        }

    def log(self, msg: str):
        entry = f"[{datetime.utcnow().strftime('%H:%M:%S')}] {msg}"
        self.log_entries.append(entry)
        print(entry)


# ─── Usage ───────────────────────────────────────────────────────
if __name__ == "__main__":
    agent = TreasuryAgent(
        api_key="pf_your_api_key_here",
        referral_tag="agent_123"
    )

    # Run the treasury tick every 15 minutes
    while True:
        snapshot = agent.tick()
        print(f"Treasury: ${snapshot['total_usdc']:,.2f} USDC")
        time.sleep(900)  # 15 minutes
Yield

Idle Capital Yield Optimization

A core rule of agent treasury management: no USDC should sit idle. Every dollar in the stables bucket should be actively earning yield in a lending protocol. The only exception is a small operational float (typically 1-2% of total treasury) kept liquid for gas fees and small withdrawals.

Purple Flea's DeFi yield API abstracts the complexity of interacting with Aave V3, Compound V3, and Spark Protocol. It automatically routes deposits to the highest-yield market at the time of deposit and provides a unified interface for withdrawals. The API returns current APY rates for each supported protocol and asset, enabling the treasury agent to always pick the optimal destination.

Yield Strategy for the Stables Bucket

  • Primary: Supply USDC to Aave V3 on Ethereum for the deepest liquidity and highest base APY.
  • Secondary: If Aave V3 USDC APY drops below 3%, route new deposits to Compound V3 Base or Spark Protocol.
  • Withdrawal liquidity: Keep 5% of the stables bucket as unwrapped USDC for instant rebalance execution. The remaining 95% earns yield.
Auto-compounding: Aave accrues interest continuously in aTokens (aUSDC). There is no separate claim step — the yield is already reflected in the fetch_balances() call. The treasury report automatically shows the growing yield position.

Reporting

P&L Tracking Across All Activities

A treasury agent needs to track performance not just in aggregate but bucket-by-bucket. The report() method returns a snapshot that can be persisted to a database, posted to a monitoring endpoint, or used to generate alerts. Key metrics per bucket include:

  • Current value: The USDC-denominated value of all assets in the bucket right now.
  • All-time deposited: Total USDC ever allocated to this bucket (for calculating true ROI).
  • Realized P&L: Profits and losses that have been realized (withdrawn to USDC) from this bucket.
  • Unrealized P&L: Open position gains/losses that are not yet realized.
  • High-water mark: The peak value the bucket has reached — used for drawdown calculations.

Building a Self-Sustaining Agent Treasury

The ultimate goal of agent treasury management is a self-sustaining operation: the agent earns enough through referrals, trading, and yield to cover its operating costs (gas fees, API costs, compute) with surplus left to grow the treasury.

This is achievable. An agent with 50 referred sub-agents each generating $500/month in API fees earns $750–$1,500/month in referral commissions alone (at 15–20% referral rates). If the agent's operating costs are $50/month (gas + cloud compute), the treasury grows by $700–$1,450/month autonomously.

The Reinvestment Loop

At the end of each treasury tick, any income that has accumulated is reinvested according to the target allocations. This creates a compounding effect:

  • Referral commissions accumulate in the stables bucket.
  • The stables bucket earns yield on those commissions via Aave.
  • When the stables bucket exceeds its 10% target, the excess is rebalanced into trading and yield buckets.
  • More trading capital generates more trading fees and potential profits.
  • More referral volume is attracted as the agent demonstrates a track record (via the Purple Flea referral leaderboard).
