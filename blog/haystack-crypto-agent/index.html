Building Crypto Agents with Haystack and Purple Flea

Haystack, built by Deepset, is one of the most mature open-source frameworks for building RAG pipelines and AI agents in Python. Its ComponentBase abstraction makes it easy to compose multi-step processing chains — and with Purple Flea's Haystack components, you can add real financial capabilities to any pipeline.

This tutorial shows how to integrate crypto wallet creation, Hyperliquid trading, and casino games into a Haystack pipeline. We'll also explore the most powerful use case: combining RAG-based market research with on-chain trade execution.

Why Combine RAG with Finance?

A purely reactive trading agent that just opens positions on command has limited utility. The more interesting pattern is a data-driven agent: one that retrieves relevant market information (news, analyst reports, on-chain data) from a vector store, synthesizes it into a trading signal, and then executes automatically.

RAG gives your agent a long-term memory of market events. Purple Flea gives it hands to act on that memory.

Haystack's pipeline architecture is perfect for this: chain a InMemoryDocumentStore → BM25Retriever → PromptBuilder → OpenAIGenerator → TradingComponent into a single reusable workflow.

Basic Usage: Individual Components

Each Purple Flea capability is wrapped as a Haystack ComponentBase subclass with typed inputs and outputs. You can use them standalone or wire them into pipelines.

import os
from purpleflea.haystack import WalletComponent, TradingComponent, CasinoComponent

# Create individual components
wallet = WalletComponent(api_key=os.environ["PURPLE_FLEA_API_KEY"])
trading = TradingComponent(api_key=os.environ["PURPLE_FLEA_API_KEY"])
casino = CasinoComponent(api_key=os.environ["PURPLE_FLEA_API_KEY"])

# Use them directly (outside a pipeline)
w = wallet.run(action="create")
print(f"New wallet: {w['address']}")

t = trading.run(market="ETH-PERP", side="long", size_usd=100, leverage=1)
print(f"Position: {t['position_id']} @ ${t['entry_price']}")

flip = casino.run(game="coin_flip", amount=5, choice="heads")
print(f"Flip result: {flip['outcome']} — {'Won' if flip['won'] else 'Lost'} ${flip['payout_usd']}")

Building a RAG-Powered Trading Pipeline

Now the interesting part. This pipeline retrieves market context documents, uses an LLM to generate a trading decision, and then executes the trade automatically.

from haystack import Pipeline, Document
from haystack.components.retrievers.in_memory import InMemoryBM25Retriever
from haystack.components.builders import PromptBuilder
from haystack.components.generators import OpenAIGenerator
from haystack.document_stores.in_memory import InMemoryDocumentStore
from purpleflea.haystack import TradingDecisionRouter, TradingComponent
import os

# Populate the document store with market context
store = InMemoryDocumentStore()
store.write_documents([
    Document(content="ETH broke above $3200 resistance on strong volume. RSI = 58, neutral territory."),
    Document(content="Ethereum ETF net inflows: +$145M today. Institutional demand rising."),
    Document(content="Fed held rates flat. Crypto markets rallied on risk-on sentiment."),
])

# Build the pipeline
pipeline = Pipeline()
pipeline.add_component("retriever", InMemoryBM25Retriever(document_store=store))
pipeline.add_component("prompt", PromptBuilder(
    template="""
    Based on the following market context, should we go long or short on {{ market }}?
    Respond with ONLY: {"side": "long" or "short", "size_usd": <number>, "reasoning": "<brief>"}

    Context:
    {% for doc in documents %}
    - {{ doc.content }}
    {% endfor %}
    """
))
pipeline.add_component("llm", OpenAIGenerator(model="gpt-4o"))
pipeline.add_component("router", TradingDecisionRouter())
pipeline.add_component("trade", TradingComponent(api_key=os.environ["PURPLE_FLEA_API_KEY"]))

# Wire the components
pipeline.connect("retriever.documents", "prompt.documents")
pipeline.connect("prompt.prompt", "llm.prompt")
pipeline.connect("llm.replies", "router.llm_output")
pipeline.connect("router.trade_params", "trade.params")

# Run the pipeline
result = pipeline.run({
    "retriever": {"query": "ETH market conditions"},
    "prompt": {"market": "ETH-PERP"},
})

print(f"Trade executed: {result['trade']}")

Serializing Pipelines to YAML

One of Haystack's killer features is pipeline serialization. You can save a complete pipeline (including Purple Flea components) as YAML and version-control it alongside your strategy code.

import yaml

# Save pipeline to YAML
with open("trading_pipeline.yml", "w") as f:
    yaml.dump(pipeline.to_dict(), f)

# Load it back (with env var injection for API keys)
with open("trading_pipeline.yml") as f:
    config = yaml.safe_load(f)

loaded_pipeline = Pipeline.from_dict(config)

This enables GitOps-style trading strategy management: commit your pipeline YAML, run CI tests against a paper trading endpoint, then deploy by loading from YAML in production.
