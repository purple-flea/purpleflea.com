Market Microstructure for AI Agents: Spreads, Depth, and Price Discovery

Most trading strategies focus on what to buy. Market microstructure focuses on how to buy it. The difference between a naive market order and a microstructure-aware execution can mean 10–200 basis points on every trade — compounding dramatically over thousands of agent transactions per day. This guide covers the complete microstructure toolkit for AI trading agents.

Microstructure Fundamentals

Market microstructure is the study of how trading mechanisms, information, and agent behavior interact to determine prices and transaction costs. For AI agents, microstructure knowledge translates directly into lower execution costs, better fill rates, and alpha from structural inefficiencies that are invisible to fundamental-only traders.

The Bid-Ask Spread

Every market has a bid price (the highest price a buyer will pay) and an ask price (the lowest price a seller will accept). The spread is the difference:

spread = ask - bid
relative_spread = (ask - bid) / mid_price × 100%

The relative spread tells you the round-trip cost of an immediate trade. A 5bps spread means you lose 0.05% on every buy-immediately-then-sell-immediately round trip. On a $100K position traded 10x/day, that is $500/day in spread costs alone.

Market makers quote spreads to earn the bid-ask difference. Three classic theories explain spread determinants:

  • Inventory theory (Stoll 1978): Market makers widen spreads when they carry large directional inventory risk — they need compensation for the risk of holding the position.
  • Information asymmetry (Glosten-Milgrom 1985): Market makers widen spreads when they expect to face informed traders who know more about fair value.
  • Order processing cost: Some spread simply covers the operational costs of running a market-making operation.

Agent implication: If your agent's trades are consistently informationally motivated (you trade because you have a signal), market makers will recognize this in your flow and widen spreads against you over time. Disguising order flow — through TWAP, iceberg orders, and randomization — is a core agent skill.

Order Book Depth

The order book is a ranked list of all resting limit orders on both sides. Depth measures how much volume exists at each price level and how quickly size can be absorbed without moving the market.

A shallow book means small orders move prices significantly (high price impact). A deep book absorbs large orders with minimal price movement. Order book depth is a real-time measure of market liquidity — and it changes second by second.

Price Impact and Market Impact

Price impact is the adverse price movement caused by your own order execution. When you buy 100 BTC in a market with only 50 BTC offered within 1%, your order walks up the ask side and you receive worse average fills than the quoted price.

Linear Price Impact Model

price_impact = λ × order_size

where λ (Kyle's lambda) is the price impact coefficient in units of $/unit. If λ = 0.001 and you buy 500 ETH, impact = $0.50/ETH adverse slippage on average fill.

Square-Root Impact Model

price_impact = η × σ × √(Q / ADV)

where η ≈ 1 (market-specific constant), σ = daily volatility, Q = order size, ADV = average daily volume. This model better captures the concavity of impact at large order sizes — doubling size does not double impact.

Both models are approximations. Real impact is non-linear, time-dependent, and sensitive to order book state at execution time. The Purple Flea Trading API provides real-time order book data and pre-trade impact estimates so agents can model execution cost before placing orders.

Order Types: The Agent Toolkit

Sophisticated agents never use only market orders. The choice of order type is itself a microstructure decision — it determines whether your agent is a liquidity taker (pays spread) or a liquidity maker (earns rebates).

Market Order

Immediate execution at best available price. Pays the full spread. Use only when speed is paramount.

Limit Order

Rests at specified price. Earns maker rebates if filled. Risk: may not fill if price moves away.

Stop Order

Becomes a market order when trigger price is reached. Used for loss protection and momentum entry.

TWAP

Time-Weighted Average Price. Splits a large order equally over a time window to minimize market impact.

VWAP

Volume-Weighted Average Price. Executes proportionally to market volume, tracking the daily VWAP benchmark.

Iceberg Order

Shows only a small portion of the total order. Prevents informed traders from front-running large size.

Post-Only

Cancels if it would execute immediately. Guarantees maker status and rebate, never crosses the spread.

FOK / IOC

Fill-or-Kill: all or nothing immediately. Immediate-or-Cancel: fills what it can, cancels the rest.

Maker vs Taker: On most CEXes, makers earn a rebate (0.01–0.025%) and takers pay a fee (0.03–0.1%). Over millions of agent transactions, always being a taker versus always being a maker can represent 0.04–0.125% cost difference per trade — the equivalent of destroying or capturing the entire bid-ask spread.

import numpy as np
import requests
import time
import math
from collections import deque
from dataclasses import dataclass, field
from typing import List, Dict, Tuple, Optional
import logging

logger = logging.getLogger('MicrostructureAnalyzer')

PURPLE_FLEA_BASE = "https://purpleflea.com/api/v1"

@dataclass
class OrderBook:
    symbol: str
    timestamp: float
    bids: List[Tuple[float, float]]   # (price, size) pairs, best bid first
    asks: List[Tuple[float, float]]   # (price, size) pairs, best ask first

    @property
    def best_bid(self) -> float:
        return self.bids[0][0] if self.bids else 0

    @property
    def best_ask(self) -> float:
        return self.asks[0][0] if self.asks else float('inf')

    @property
    def mid_price(self) -> float:
        return (self.best_bid + self.best_ask) / 2

    @property
    def spread(self) -> float:
        return self.best_ask - self.best_bid

    @property
    def relative_spread(self) -> float:
        mid = self.mid_price
        return self.spread / mid if mid > 0 else 0


@dataclass
class Trade:
    timestamp: float
    price: float
    size: float
    side: str        # 'buy' or 'sell' (aggressor side)
    exchange: str


class MicrostructureAnalyzer:
    """
    Real-time market microstructure analytics for AI trading agents.

    Provides:
    - Spread and depth analysis
    - Price impact estimation (Kyle's lambda)
    - Trade flow toxicity (VPIN variant)
    - Manipulation detection (spoofing, layering, wash trading)
    - Optimal order type selection
    """

    WINDOW_SIZE = 1000    # rolling window for metrics
    VPIN_BUCKET_SIZE = 100 # trades per bucket for VPIN

    def __init__(
        self,
        api_key: str,
        symbol: str,
        impact_model: str = "sqrt",  # 'linear' or 'sqrt'
    ):
        self.api_key = api_key
        self.symbol = symbol
        self.impact_model = impact_model
        self.trade_history: deque = deque(maxlen=self.WINDOW_SIZE)
        self.book_history: deque = deque(maxlen=100)
        self.lambda_estimate: float = 0.001   # Kyle's lambda, updated live
        self.adv_estimate: float = 10_000_000 # ADV in USD, updated daily
        self.daily_vol: float = 0.03           # daily volatility estimate

        self.session = requests.Session()
        self.session.headers.update({
            "Authorization": f"Bearer {api_key}",
            "Content-Type": "application/json",
        })

    # ──────────────────────────────────────────────────────────────
    # SPREAD ANALYSIS
    # ──────────────────────────────────────────────────────────────

    def compute_spread(self, book: OrderBook) -> Dict[str, float]:
        """
        Compute bid-ask spread metrics from a snapshot of the order book.

        Returns:
            {
              'absolute': float (in price units),
              'relative_bps': float (basis points),
              'effective': float (weighted by top-of-book size),
              'depth_at_bps': {1: usd, 5: usd, 10: usd, 25: usd, 50: usd}
            }
        """
        mid = book.mid_price
        absolute = book.spread
        relative_bps = (absolute / mid) * 10_000

        # Effective spread weighted by top-of-book liquidity
        bid_size = book.bids[0][1] if book.bids else 1
        ask_size = book.asks[0][1] if book.asks else 1
        effective = (
            (absolute * ask_size + absolute * bid_size) /
            (bid_size + ask_size)
        )

        # Depth at various spread thresholds
        depth_at = {}
        for bps in [1, 5, 10, 25, 50]:
            threshold = mid * bps / 10_000
            bid_depth_usd = sum(
                p * s for p, s in book.bids
                if mid - p <= threshold
            )
            ask_depth_usd = sum(
                p * s for p, s in book.asks
                if p - mid <= threshold
            )
            depth_at[bps] = (bid_depth_usd + ask_depth_usd) / 2

        return {
            "absolute": absolute,
            "relative_bps": relative_bps,
            "effective": effective,
            "depth_at_bps": depth_at,
        }

    # ──────────────────────────────────────────────────────────────
    # PRICE IMPACT ESTIMATION
    # ──────────────────────────────────────────────────────────────

    def estimate_impact(
        self,
        order_size_usd: float,
        side: str = "buy",
        book: Optional[OrderBook] = None,
    ) -> Dict[str, float]:
        """
        Estimate price impact for a given order size.

        Args:
            order_size_usd: Order value in USD
            side: 'buy' or 'sell'
            book: Optional live order book for real-time calculation

        Returns:
            {
              'impact_bps': estimated impact in basis points,
              'impact_pct': as a percentage,
              'expected_avg_price': estimated average fill price,
              'model': model used ('book', 'sqrt', 'linear')
            }
        """
        # Order-book-based impact (most accurate when book is available)
        if book is not None:
            levels = book.asks if side == "buy" else book.bids
            remaining = order_size_usd
            total_cost = 0
            total_qty = 0

            for price, size in levels:
                fill_usd = min(remaining, price * size)
                fill_qty = fill_usd / price
                total_cost += fill_qty * price
                total_qty += fill_qty
                remaining -= fill_usd
                if remaining <= 0:
                    break

            if total_qty > 0:
                avg_price = total_cost / total_qty
                mid = book.mid_price
                impact_pct = abs(avg_price - mid) / mid * 100
                impact_bps = impact_pct * 100
                return {
                    "impact_bps": impact_bps,
                    "impact_pct": impact_pct,
                    "expected_avg_price": avg_price,
                    "model": "book",
                }

        # Fallback: parametric impact models
        if self.impact_model == "sqrt":
            # Almgren-Chriss square-root model
            impact_frac = 1.0 * self.daily_vol * math.sqrt(order_size_usd / self.adv_estimate)
        else:
            # Kyle linear model: Δp = λ × Q
            impact_frac = self.lambda_estimate * order_size_usd

        impact_pct = impact_frac * 100
        impact_bps = impact_pct * 100
        return {
            "impact_bps": impact_bps,
            "impact_pct": impact_pct,
            "expected_avg_price": None,
            "model": self.impact_model,
        }

    def estimate_kyle_lambda(self) -> float:
        """
        Estimate Kyle's lambda from recent trade history.

        Method: OLS regression of price change on signed order flow.
        Δp_t = λ × x_t + ε_t

        where x_t is the net signed volume (+ for buys, - for sells).
        """
        if len(self.trade_history) < 50:
            return self.lambda_estimate  # insufficient data

        trades = list(self.trade_history)

        price_changes = []
        signed_flows = []

        for i in range(1, len(trades)):
            dp = trades[i].price - trades[i-1].price
            flow = trades[i].size if trades[i].side == "buy" else -trades[i].size
            price_changes.append(dp)
            signed_flows.append(flow)

        x = np.array(signed_flows)
        y = np.array(price_changes)

        # OLS: λ = cov(x, y) / var(x)
        if np.var(x) > 0:
            lam = np.cov(x, y)[0][1] / np.var(x)
            self.lambda_estimate = max(0, lam)

        return self.lambda_estimate

    # ──────────────────────────────────────────────────────────────
    # FLOW TOXICITY (VPIN VARIANT)
    # ──────────────────────────────────────────────────────────────

    def classify_flow(self, trades: List[Trade]) -> Dict[str, float]:
        """
        Compute VPIN (Volume-synchronized Probability of Informed Trading).
        Classifies recent trade flow as informed vs uninformed.

        Returns:
            {
              'vpin': float [0,1] — higher means more toxic (informed) flow,
              'buy_volume_pct': float — fraction of volume that was buys,
              'sell_volume_pct': float,
              'imbalance': float — |buys - sells| / total,
              'interpretation': str
            }
        """
        if not trades:
            return {"vpin": 0.5, "interpretation": "insufficient_data"}

        buy_vol  = sum(t.size * t.price for t in trades if t.side == "buy")
        sell_vol = sum(t.size * t.price for t in trades if t.side == "sell")
        total    = buy_vol + sell_vol

        if total == 0:
            return {"vpin": 0.5, "interpretation": "no_volume"}

        vpin = abs(buy_vol - sell_vol) / total
        imbalance = (buy_vol - sell_vol) / total

        if vpin > 0.7:
            interp = "toxic_high_information"
        elif vpin > 0.4:
            interp = "moderate_information"
        else:
            interp = "noise_trading"

        return {
            "vpin": vpin,
            "buy_volume_pct": buy_vol / total,
            "sell_volume_pct": sell_vol / total,
            "imbalance": imbalance,
            "interpretation": interp,
        }

    # ──────────────────────────────────────────────────────────────
    # MANIPULATION DETECTION
    # ──────────────────────────────────────────────────────────────

    def detect_manipulation(
        self,
        book: OrderBook,
        recent_books: List[OrderBook],
        recent_trades: List[Trade],
    ) -> Dict[str, bool]:
        """
        Detect common order book manipulation patterns.

        Patterns detected:
        - Spoofing: large orders placed and cancelled rapidly
        - Layering: multiple orders stacked at similar levels, then cancelled
        - Wash trading: self-matched trades creating artificial volume
        - Quote stuffing: extremely rapid order placement/cancellation

        Returns dict of detected patterns with confidence scores.
        """
        results = {
            "spoofing_detected": False,
            "layering_detected": False,
            "wash_trading_suspected": False,
            "quote_stuffing_detected": False,
            "overall_manipulation_score": 0.0,
        }

        if len(recent_books) < 5:
            return results

        score = 0.0

        # 1. Spoofing: large top-of-book orders that disappear quickly
        top_bid_sizes = [b.bids[0][1] if b.bids else 0 for b in recent_books]
        size_variance = np.std(top_bid_sizes) / (np.mean(top_bid_sizes) + 1e-10)
        if size_variance > 2.0:
            results["spoofing_detected"] = True
            score += 0.3

        # 2. Layering: many orders clustered at similar price levels
        bid_prices = [p for p, _ in book.bids[:10]]
        if len(bid_prices) >= 3:
            avg_gap = np.mean(np.diff(bid_prices))
            gap_std  = np.std(np.diff(bid_prices))
            if gap_std < avg_gap * 0.1:  # unnaturally uniform spacing
                results["layering_detected"] = True
                score += 0.25

        # 3. Wash trading: rapid buy-sell pairs at same price
        if len(recent_trades) >= 10:
            last_10 = recent_trades[-10:]
            buy_prices  = set(t.price for t in last_10 if t.side == "buy")
            sell_prices = set(t.price for t in last_10 if t.side == "sell")
            overlap = len(buy_prices & sell_prices)
            if overlap > 3:
                results["wash_trading_suspected"] = True
                score += 0.35

        # 4. Quote stuffing: rapid order updates in short time window
        book_timestamps = [b.timestamp for b in recent_books]
        if len(book_timestamps) >= 2:
            time_span = max(book_timestamps) - min(book_timestamps)
            updates_per_sec = len(book_timestamps) / max(time_span, 0.001)
            if updates_per_sec > 500:
                results["quote_stuffing_detected"] = True
                score += 0.2

        results["overall_manipulation_score"] = min(1.0, score)
        return results

    # ──────────────────────────────────────────────────────────────
    # OPTIMAL EXECUTION RECOMMENDATION
    # ──────────────────────────────────────────────────────────────

    def recommend_execution(
        self,
        order_size_usd: float,
        urgency: str = "normal",   # 'low', 'normal', 'high', 'immediate'
        book: Optional[OrderBook] = None,
    ) -> Dict:
        """
        Recommend the optimal execution strategy for an order.

        Considers:
        - Order size relative to market depth
        - Current spread
        - Flow toxicity
        - Time urgency

        Returns:
            {
              'strategy': 'market' | 'limit' | 'twap' | 'vwap' | 'iceberg',
              'duration_minutes': int (for TWAP/VWAP),
              'slice_size_usd': float,
              'reasoning': str,
              'estimated_cost_bps': float
            }
        """
        impact = self.estimate_impact(order_size_usd, book=book)
        impact_bps = impact["impact_bps"]

        spread_bps = 0
        book_depth_5bps = float('inf')
        if book:
            spread_metrics = self.compute_spread(book)
            spread_bps = spread_metrics["relative_bps"]
            book_depth_5bps = spread_metrics["depth_at_bps"].get(5, 0)

        if urgency == "immediate":
            return {
                "strategy": "market",
                "duration_minutes": 0,
                "slice_size_usd": order_size_usd,
                "reasoning": "Immediate urgency overrides cost optimization",
                "estimated_cost_bps": spread_bps / 2 + impact_bps,
            }

        if order_size_usd < book_depth_5bps * 0.1:
            # Order is small relative to book depth — post limit order
            strategy = "limit"
            duration = 0
            slice_size = order_size_usd
            reasoning = "Small relative to depth — use limit order to capture maker rebate"
            cost_bps = 0
        elif order_size_usd > book_depth_5bps:
            # Order is larger than 5bps depth — must slice via TWAP
            duration = min(240, int(order_size_usd / self.adv_estimate * 24 * 60))
            slice_size = order_size_usd / max(1, duration // 5)
            strategy = "vwap" if urgency == "normal" else "twap"
            reasoning = "Order exceeds book depth — slice via TWAP/VWAP to minimize impact"
            cost_bps = impact_bps * 0.3  # impact reduced by 70% via slicing
        else:
            # Medium-sized order — use iceberg to hide true size
            strategy = "iceberg"
            duration = 0
            slice_size = min(10_000, order_size_usd * 0.1)
            reasoning = "Use iceberg to hide true size and avoid adverse selection"
            cost_bps = spread_bps / 2 + impact_bps * 0.5

        return {
            "strategy": strategy,
            "duration_minutes": duration,
            "slice_size_usd": slice_size,
            "reasoning": reasoning,
            "estimated_cost_bps": cost_bps,
        }

Kyle's Lambda: Price Impact Coefficient

Kyle's lambda (λ) measures the price impact per unit of net order flow. It is a fundamental measure of market depth: low lambda = deep market (large orders have minimal impact), high lambda = thin market (small orders move prices significantly).

Interpreting Lambda in Practice

Asset Typical Lambda ($/ETH or $/BTC) Impact on $100K Buy Classification
BTC (Tier 1 CEX) 0.0001 – 0.0005 <0.5% Very deep
ETH (Tier 1 CEX) 0.001 – 0.003 <1% Deep
SOL, AVAX (major) 0.005 – 0.015 1–5% Moderate
Mid-cap altcoins 0.05 – 0.5 5–30% Thin
Low-cap DEX pairs 1.0 – 10.0+ 30–100%+ Very thin / illiquid

Lambda is not constant. It rises during periods of low liquidity (weekends, off-hours, news events), spikes during market stress, and compresses during calm, high-volume sessions. An agent that monitors lambda in real time can adapt its execution strategy dynamically.

Trade Flow Toxicity: Informed vs Uninformed

Not all order flow is equal. Informed flow comes from traders with private information about future price direction — their trades are directionally predictive and adversely selected for market makers. Uninformed (noise) flow is random and provides market makers with profitable trading opportunities.

Volume-synchronized Probability of Informed Trading (VPIN)

VPIN is a real-time flow toxicity metric developed by Easley, Lopez de Prado, and O'Hara. It measures the imbalance between buy-initiated and sell-initiated volume over rolling volume buckets.

VPIN = |V_buy - V_sell| / (V_buy + V_sell)

Ranges from 0 (perfectly balanced, uninformed flow) to 1 (100% one-sided, highly informed). VPIN >0.7 historically precedes large price moves and liquidity crises. The 2010 Flash Crash showed VPIN exceeding 0.9 in the hours before the crash.

Practical Flow Classification for Agents

An agent can use flow toxicity to make better trading decisions:

  • High VPIN (>0.7): Avoid large market orders. Informed traders are active; price will move against you. Use limit orders far from the touch or wait.
  • Medium VPIN (0.3–0.7): Normal market conditions. Standard execution strategies apply.
  • Low VPIN (<0.3): Noise-dominated flow. Market makers earn well; optimal time to cross the spread if you need liquidity.
  • VPIN spike (rapid increase): Potential news event or large informed order entering the market. Reduce position risk immediately.

Latency Arbitrage Across Venues

Latency arbitrage exploits price discrepancies across venues that arise from the latency of information propagation. If BTC trades at $50,000 on exchange A and $50,020 on exchange B due to a 5ms lag in price synchronization, an agent co-located near both exchanges can capture the $20 difference risk-free.

Latency threshold: True latency arbitrage requires sub-millisecond execution and co-location at exchange data centers. However, soft latency arbitrage — exploiting price discrepancies that persist for 50–500ms — is accessible to any agent with a fast internet connection and well-structured execution code.

Cross-Exchange Spread Detection

Python — latency_arb.py 
from typing import Dict, Optional
import asyncio
import aiohttp
import time

EXCHANGES = [
    "purpleflea",
    "binance",
    "okx",
    "bybit",
]

@dataclass
class ArbitrageOpportunity:
    buy_exchange: str
    sell_exchange: str
    buy_price: float
    sell_price: float
    spread_pct: float
    net_spread_pct: float   # after fees
    max_size_usd: float
    detected_at: float


async def fetch_price_concurrent(
    session: aiohttp.ClientSession,
    exchange: str,
    symbol: str,
    api_base: str,
) -> Optional[Dict]:
    """Fetch ticker price asynchronously — critical for latency."""
    t0 = time.perf_counter()
    try:
        async with session.get(
            f"{api_base}/trading/ticker/{symbol}",
            timeout=aiohttp.ClientTimeout(total=0.2),  # 200ms max
        ) as resp:
            data = await resp.json()
            latency_ms = (time.perf_counter() - t0) * 1000
            return {
                "exchange": exchange,
                "bid": data["bid"],
                "ask": data["ask"],
                "mid": (data["bid"] + data["ask"]) / 2,
                "latency_ms": latency_ms,
            }
    except Exception:
        return None


async def detect_cross_exchange_arb(
    api_key: str,
    symbol: str = "BTC-USDC",
    min_spread_bps: float = 5.0,
    fee_per_side_bps: float = 3.0,
) -> Optional[ArbitrageOpportunity]:
    """
    Simultaneously poll all configured exchanges for price quotes.
    Identify and return the best cross-exchange arbitrage opportunity.

    Purple Flea cross-exchange routes provide unified access to multiple
    venues via a single API call, reducing latency overhead.
    """
    headers = {"Authorization": f"Bearer {api_key}"}

    async with aiohttp.ClientSession(headers=headers) as session:
        tasks = [
            fetch_price_concurrent(session, exch, symbol, PURPLE_FLEA_BASE)
            for exch in EXCHANGES
        ]
        results = await asyncio.gather(*tasks)
        quotes = [r for r in results if r is not None]

    if len(quotes) < 2:
        return None

    # Find cheapest ask (buy) and highest bid (sell)
    buy_quote  = min(quotes, key=lambda q: q["ask"])
    sell_quote = max(quotes, key=lambda q: q["bid"])

    if buy_quote["exchange"] == sell_quote["exchange"]:
        return None  # same exchange, not valid arb

    spread_bps = (sell_quote["bid"] - buy_quote["ask"]) / buy_quote["ask"] * 10_000
    net_bps = spread_bps - 2 * fee_per_side_bps

    if net_bps < min_spread_bps:
        return None

    logger.info(
        f"Cross-exchange arb: buy on {buy_quote['exchange']} @ {buy_quote['ask']:.2f}, "
        f"sell on {sell_quote['exchange']} @ {sell_quote['bid']:.2f} "
        f"net={net_bps:.1f}bps"
    )

    return ArbitrageOpportunity(
        buy_exchange=buy_quote["exchange"],
        sell_exchange=sell_quote["exchange"],
        buy_price=buy_quote["ask"],
        sell_price=sell_quote["bid"],
        spread_pct=spread_bps / 100,
        net_spread_pct=net_bps / 100,
        max_size_usd=50_000,  # size limited by book depth
        detected_at=time.time(),
    )

TWAP and VWAP Execution Algorithms

Large agent orders cannot be executed at once without catastrophic price impact. TWAP and VWAP algorithms slice orders over time, minimizing market footprint.

TWAP Implementation

Python — twap_executor.py 
import random
import math

class TWAPExecutor:
    """
    Time-Weighted Average Price executor.
    Splits a large order into equal time slices with randomization
    to prevent front-running by HFT agents.
    """

    def __init__(
        self,
        api_key: str,
        symbol: str,
        total_size_usd: float,
        duration_minutes: int,
        slices: int = None,
        randomize_timing: bool = True,
        randomize_size: bool = True,
    ):
        self.api_key = api_key
        self.symbol = symbol
        self.total_size = total_size_usd
        self.duration = duration_minutes * 60
        self.slices = slices or max(5, duration_minutes // 5)
        self.randomize_timing = randomize_timing
        self.randomize_size = randomize_size
        self.executed = 0
        self.fills: List[Dict] = []

        self.session = requests.Session()
        self.session.headers["Authorization"] = f"Bearer {api_key}"

    def _build_schedule(self) -> List[Tuple[float, float]]:
        """
        Build a list of (delay_seconds, size_usd) pairs.
        Optionally randomize timing and size within ±20% to obscure pattern.
        """
        base_interval = self.duration / self.slices
        base_size = self.total_size / self.slices
        schedule = []

        for i in range(self.slices):
            delay = base_interval
            size = base_size

            if self.randomize_timing:
                delay *= random.uniform(0.7, 1.3)

            if self.randomize_size and i < self.slices - 1:
                size *= random.uniform(0.8, 1.2)

            schedule.append((delay, size))

        # Adjust final slice to account for any rounding drift
        total_scheduled = sum(s for _, s in schedule)
        diff = self.total_size - total_scheduled
        schedule[-1] = (schedule[-1][0], schedule[-1][1] + diff)

        return schedule

    def run(self, side: str = "buy") -> Dict:
        """Execute the TWAP order schedule synchronously."""
        schedule = self._build_schedule()
        total_filled = 0
        total_cost = 0

        logger.info(
            f"Starting TWAP: {side} ${self.total_size:,.0f} of {self.symbol} "
            f"over {self.duration//60:.0f}min in {self.slices} slices"
        )

        for i, (delay, size) in enumerate(schedule):
            time.sleep(delay)

            payload = {
                "symbol": self.symbol,
                "side": side,
                "order_type": "market",
                "size_usd": size,
                "reduce_only": False,
            }

            try:
                resp = self.session.post(
                    f"{PURPLE_FLEA_BASE}/trading/orders",
                    json=payload,
                )
                resp.raise_for_status()
                fill = resp.json()
                total_filled += fill.get("filled_usd", size)
                total_cost   += fill.get("cost_usd", size)
                self.fills.append(fill)

                logger.info(
                    f"Slice {i+1}/{self.slices}: filled ${fill.get('filled_usd', 0):,.0f} "
                    f"@ {fill.get('avg_price', 0):.4f}"
                )
            except Exception as e:
                logger.error(f"Slice {i+1} failed: {e}")

        avg_price = total_cost / total_filled if total_filled > 0 else 0
        logger.info(f"TWAP complete: avg fill price = {avg_price:.4f}")

        return {
            "total_filled_usd": total_filled,
            "avg_fill_price": avg_price,
            "slices_executed": len(self.fills),
            "fills": self.fills,
        }

Full Microstructure Agent Example

A complete agent that monitors spread conditions, detects manipulation, classifies flow toxicity, and recommends optimal execution for each trade decision.

Python — microstructure_agent.py 
import os
import time
import logging

# Purple Flea API key uses pf_live_ prefix
API_KEY = os.environ["PURPLE_FLEA_API_KEY"]   # pf_live_...
SYMBOL  = "BTC-USDC"
ORDER_SIZE_USD = 25_000

def main():
    analyzer = MicrostructureAnalyzer(
        api_key=API_KEY,
        symbol=SYMBOL,
        impact_model="sqrt",
    )

    logger.info("Microstructure agent started")

    while True:
        try:
            # 1. Fetch current market state
            book = analyzer.fetch_book(depth=50)
            trades = analyzer.fetch_recent_trades(limit=500)

            # 2. Compute spread metrics
            spread = analyzer.compute_spread(book)
            logger.info(
                f"Spread: {spread['relative_bps']:.2f}bps | "
                f"Depth @5bps: ${spread['depth_at_bps'][5]:,.0f}"
            )

            # 3. Estimate Kyle's lambda from recent flow
            lam = analyzer.estimate_kyle_lambda()
            logger.info(f"Kyle's lambda: {lam:.6f}")

            # 4. Assess flow toxicity
            flow = analyzer.classify_flow(trades[-200:])
            logger.info(
                f"VPIN: {flow['vpin']:.3f} ({flow['interpretation']}) | "
                f"Imbalance: {flow['imbalance']*100:.1f}%"
            )

            # 5. Detect manipulation
            manip = analyzer.detect_manipulation(
                book,
                list(analyzer.book_history),
                trades[-50:],
            )
            if manip["overall_manipulation_score"] > 0.5:
                logger.warning(
                    f"Manipulation detected (score={manip['overall_manipulation_score']:.2f}): "
                    f"{[k for k,v in manip.items() if v is True]}"
                )

            # 6. Get execution recommendation for planned trade
            if flow["vpin"] < 0.6 and manip["overall_manipulation_score"] < 0.3:
                rec = analyzer.recommend_execution(ORDER_SIZE_USD, book=book)
                logger.info(
                    f"Execution: {rec['strategy']} | "
                    f"Est. cost: {rec['estimated_cost_bps']:.2f}bps | "
                    f"{rec['reasoning']}"
                )

                # Execute via TWAP if recommended
                if rec["strategy"] in ("twap", "vwap"):
                    executor = TWAPExecutor(
                        api_key=API_KEY,
                        symbol=SYMBOL,
                        total_size_usd=ORDER_SIZE_USD,
                        duration_minutes=rec["duration_minutes"] or 30,
                        randomize_timing=True,
                        randomize_size=True,
                    )
                    result = executor.run(side="buy")
                    logger.info(f"TWAP result: {result}")
            else:
                logger.info("Conditions unfavorable — holding off execution")

        except Exception as e:
            logger.error(f"Error in main loop: {e}")

        time.sleep(30)   # Poll every 30 seconds

if __name__ == "__main__":
    main()

Conclusion

Market microstructure is not an academic curiosity — it is the execution layer that separates profitable agents from expensive ones. Every market order versus limit order decision, every TWAP slice interval, every flow toxicity check translates directly into basis points of cost or benefit that compound across thousands of agent transactions.

The key insight is that microstructure knowledge is execution alpha: you do not need a better signal to make more money — you just need to execute the same signal more cheaply. An agent that correctly identifies high-VPIN environments and delays execution, uses limit orders in stable conditions, detects and avoids manipulated books, and slices large orders through TWAP will systematically outperform an agent with identical signals but naive execution.
