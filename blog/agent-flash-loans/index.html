Flash Loans for AI Agents: Zero-Capital DeFi Strategies

March 4, 2026 Purple Flea Team 18 min read

Flash loans are the most capital-efficient instrument in all of DeFi. An AI agent with zero assets can borrow $50 million in USDC, execute a complex multi-hop arbitrage, repay the loan with fees, and pocket the profit — all within a single Ethereum block, in about 12 seconds. If anything goes wrong, the entire sequence atomically reverts. No principal is lost. No debt is created. The only cost is the gas for the failed transaction.

This guide covers flash loan mechanics at the contract level, walks through three major flash loan providers (Aave V3, Uniswap V3, dYdX Solo Margin), explores the major use cases — arbitrage, liquidation bots, and collateral swaps — and provides a complete Python FlashLoanAgent implementation using web3.py.

What Flash Loans Are and How They Work Atomically

A flash loan is an uncollateralized loan that exists only within the duration of a single blockchain transaction. The key insight is that Ethereum's transaction atomicity guarantees the lender's safety: if the borrower does not repay by the end of the transaction's execution, the EVM reverts the entire state change, as if the loan never happened.

The mechanics work like this: the lender's smart contract sends tokens to the borrower's contract, then calls a callback function on the borrower's contract. Inside that callback, the borrower executes whatever operations they need — arbitrage trades, liquidations, collateral swaps. Before the callback returns, the borrower must approve the lender to pull back the loan amount plus fees. If the final balance check fails, the transaction reverts entirely.

This creates a remarkable property: the lender bears zero credit risk. No collateral is needed because there is no scenario in which the loan is outstanding without repayment. The EVM either confirms that repayment occurred — in which case the transaction succeeds and profit is realized — or it reverts everything, restoring the blockchain to its pre-loan state. From the lender's perspective, the loan is simultaneously made and repaid in the same instant, with no window of credit exposure.

The Atomic Transaction Lifecycle

1
Agent calls flash loan initiator
Your contract calls pool.flashLoan() specifying asset, amount, and callback parameters.
2
Lender sends tokens to borrower
The pool transfers the requested amount to your contract address in the same transaction.
3
Callback executes your logic
Pool calls executeOperation() on your contract. You execute trades, liquidations, or swaps here.
4
Approve repayment
Before returning, your contract approves the pool to pull amount + fee from your balance.
5
Pool validates repayment
The pool pulls the repayment. If balance check fails, entire transaction reverts with no state change.
6
Profit settled to agent
Remaining balance (profit minus gas) stays in your contract. Transaction confirmed on-chain.

Aave V3 Flash Loan Mechanics

Aave V3 is the dominant flash loan provider with the deepest liquidity across Ethereum mainnet, Arbitrum, Optimism, and Polygon. The flash loan fee is 0.09% (9 basis points) of the borrowed amount, which flows to Aave's liquidity providers.

The IFlashLoanReceiver Interface

To use Aave V3 flash loans, you must deploy a contract that implements the IFlashLoanReceiver interface. The critical function is executeOperation, which Aave calls after transferring the borrowed assets:

Solidity — Aave V3 flash loan receiver interface
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.20;

interface IPool {
    function flashLoan(
        address receiverAddress,
        address[] calldata assets,
        uint256[] calldata amounts,
        uint256[] calldata interestRateModes,
        address onBehalfOf,
        bytes calldata params,
        uint16 referralCode
    ) external;
}

contract FlashLoanReceiver {
    address constant AAVE_POOL = 0x87870Bca3F3fD6335C3F4ce8392D69350B4fA4E2;
    address constant USDC      = 0xA0b86991c6218b36c1d19D4a2e9Eb0cE3606eB48;
    address immutable owner;

    constructor() { owner = msg.sender; }

    /// @notice Called by Aave after transferring borrowed tokens
    function executeOperation(
        address[] calldata assets,
        uint256[] calldata amounts,
        uint256[] calldata premiums,  // fee amounts
        address initiator,
        bytes calldata params
    ) external returns (bool) {
        require(msg.sender == AAVE_POOL, "caller must be Aave pool");
        require(initiator == address(this), "must self-initiate");

        // --- YOUR ARBITRAGE LOGIC HERE ---
        // At this point we hold amounts[0] of assets[0] (e.g. 500,000 USDC)
        _executeArbitrage(assets[0], amounts[0], params);

        // Approve repayment: principal + premium
        uint256 amountOwed = amounts[0] + premiums[0];
        IERC20(assets[0]).approve(AAVE_POOL, amountOwed);

        return true; // must return true or Aave reverts
    }

    function initiateFlashLoan(uint256 amount) external {
        require(msg.sender == owner);
        address[] memory assets  = new address[](1);
        uint256[] memory amounts  = new uint256[](1);
        uint256[] memory modes    = new uint256[](1);
        assets[0]  = USDC;
        amounts[0] = amount;
        modes[0]   = 0; // 0 = no debt (must repay in same tx)
        IPool(AAVE_POOL).flashLoan(
            address(this), assets, amounts, modes,
            address(this), "", 0
        );
    }
}
Aave V3 Key Details

Fee: 0.09% (9 bps). Available assets: USDC, USDT, DAI, WETH, WBTC, and 30+ others. Supported networks: Ethereum mainnet, Arbitrum, Optimism, Polygon, Base. Pool address differs per chain — always use the AddressesProvider to look up the current pool address programmatically.

Uniswap V3 Flash Swap Mechanics

Uniswap V3 calls them "flash swaps" rather than flash loans, but the mechanics are similar. You can borrow any token from a Uniswap V3 pool, use it within the transaction, and repay either in the same token plus the swap fee, or by providing the other token in the pair (performing an actual swap). This flexibility makes flash swaps useful for cross-pool arbitrage where you want to buy from Uniswap and sell elsewhere.

The uniswapV3FlashCallback Interface

Uniswap V3 flash swaps work by calling pool.flash(). The pool then calls back uniswapV3FlashCallback on your contract with the borrowed tokens already in your balance:

Solidity — Uniswap V3 flash callback implementation
import "@uniswap/v3-core/contracts/interfaces/IUniswapV3Pool.sol";
import "@uniswap/v3-core/contracts/interfaces/callback/IUniswapV3FlashCallback.sol";

struct FlashParams {
    address token0;
    address token1;
    uint24  fee;
    uint256 amount0;       // amount of token0 to borrow
    uint256 amount1;       // amount of token1 to borrow (usually 0)
    uint256 targetProfit;  // minimum profit to accept
}

contract UniswapFlashArb is IUniswapV3FlashCallback {
    address immutable factory;
    address immutable owner;

    constructor(address _factory) {
        factory = _factory;
        owner = msg.sender;
    }

    function flash(FlashParams memory params) external {
        require(msg.sender == owner);
        address pool = IUniswapV3Factory(factory).getPool(
            params.token0, params.token1, params.fee
        );
        require(pool != address(0), "pool not found");
        IUniswapV3Pool(pool).flash(
            address(this),
            params.amount0,
            params.amount1,
            abi.encode(params)
        );
    }

    /// @notice Called by Uniswap V3 pool with borrowed tokens in balance
    function uniswapV3FlashCallback(
        uint256 fee0,   // fee owed for token0 (pool's swap fee, e.g. 0.05%)
        uint256 fee1,   // fee owed for token1
        bytes calldata data
    ) external override {
        FlashParams memory params = abi.decode(data, (FlashParams));

        // Validate caller is the genuine Uniswap pool
        address pool = IUniswapV3Factory(factory).getPool(
            params.token0, params.token1, params.fee
        );
        require(msg.sender == pool, "invalid caller");

        // Execute arbitrage with borrowed tokens
        uint256 profit = _arbitrageSellOnOtherVenue(
            params.token0, params.amount0
        );

        // Repay: principal + fee must be in contract balance
        IERC20(params.token0).transfer(pool, params.amount0 + fee0);

        // Profit remains in contract — owner can withdraw
        require(profit >= params.targetProfit, "profit below target");
    }
}

A critical difference from Aave: Uniswap flash swaps charge the pool's swap fee (0.05%, 0.30%, or 1.00% depending on the pool tier) rather than a fixed protocol fee. For USDC/ETH 0.05% pools, this is cheaper than Aave's 0.09%. For 1% pools, it is significantly more expensive. Always compare fees across providers for each specific asset pair.

dYdX Solo Margin Flash Loans

dYdX Solo Margin offers flash loans with zero protocol fee — you only pay gas. The catch is that the available assets are limited (WETH, USDC, DAI) and the mechanics differ from Aave's clean interface. dYdX flash loans work via their "operate" function with a sequence of Actions: Withdraw (receive tokens), then Call (execute your logic), then Deposit (return tokens plus 2 wei as a rounding buffer).

ACTION_DEPOSIT   = 0
ACTION_WITHDRAW  = 1

def build_dydx_flash_actions(
    account_owner: str,
    borrower_contract: str,
    amount_usdc: int,  # in raw USDC units (6 decimals)
) -> list:
    """
    Build the 3-action sequence for a dYdX flash loan:
    1. Withdraw: receive amount_usdc from Solo to borrower_contract
    2. Call:     invoke executeOperation on borrower_contract
    3. Deposit:  return amount_usdc + 2 wei back to Solo
    dYdX charges 0 protocol fee — only gas costs.
    """
    return [
        {  # Step 1: Withdraw (borrow)
            "actionType": ACTION_WITHDRAW,
            "accountId": 0,
            "amount": {
                "sign": False,  # negative delta = outflow from Solo
                "denomination": 0,  # Wei denomination
                "ref": 0,           # Delta (relative amount)
                "value": amount_usdc,
            },
            "primaryMarketId": USDC_MARKET_ID,
            "secondaryMarketId": 0,
            "otherAddress": borrower_contract,
            "otherAccountId": 0,
            "data": b"",
        },
        {  # Step 2: Call (execute your logic in borrower_contract)
            "actionType": ACTION_CALL,
            "accountId": 0,
            "amount": {"sign": True, "denomination": 0, "ref": 0, "value": 0},
            "primaryMarketId": 0,
            "secondaryMarketId": 0,
            "otherAddress": borrower_contract,
            "otherAccountId": 0,
            "data": bytes(32),  # ABI-encoded callback params
        },
        {  # Step 3: Deposit (repay — must be amount + 2 wei)
            "actionType": ACTION_DEPOSIT,
            "accountId": 0,
            "amount": {
                "sign": True,
                "denomination": 0,
                "ref": 0,
                "value": amount_usdc + 2,  # 2 wei rounding buffer
            },
            "primaryMarketId": USDC_MARKET_ID,
            "secondaryMarketId": 0,
            "otherAddress": borrower_contract,
            "otherAccountId": 0,
            "data": b"",
        },
    ]
dYdX vs Aave Tradeoff

dYdX charges no protocol fee — only 2 wei as a rounding buffer — making it cheaper than Aave for large loans. However, dYdX's asset support is narrower and liquidity varies. For USDC arbitrage at scale, benchmark both providers per opportunity. On high-value trades where 0.09% represents thousands of dollars in fee savings, dYdX wins on cost.

Arbitrage Use Case: Spot vs Perp Price Discrepancy

The most common flash loan use case is exploiting price discrepancies between the same asset trading on different venues. A particularly reliable pattern for agent traders is the spot-vs-perpetual basis trade: the same underlying asset (e.g., ETH) often trades at different effective prices on spot DEXs versus perpetual futures markets.

When ETH perpetuals are trading at a premium to spot (positive funding rate), you can: borrow USDC via flash loan, buy ETH spot on Uniswap, sell ETH-perp short on a perpetuals venue, capture the convergence spread, close the position, repay the loan. When done atomically at the right moment, this is a near-riskless profit extraction.

Python — Spot vs perp arbitrage scanner
import asyncio, aiohttp, os
from decimal import Decimal
from dataclasses import dataclass
from typing import Optional

TRADING_API  = "https://trading.purpleflea.com"
API_KEY      = os.environ["PURPLE_FLEA_API_KEY"]
FLASH_FEE    = Decimal("0.0009")   # Aave V3 0.09%
TRADING_FEE  = Decimal("0.0005")   # 0.05% per side (taker)
GAS_EST_USD  = Decimal("8")        # estimated mainnet gas cost
MIN_PROFIT   = Decimal("40")       # minimum net profit to execute
LOAN_AMOUNT  = Decimal("250000")   # $250k USDC flash loan


@dataclass
class ArbOpportunity:
    spot_price:  Decimal
    perp_price:  Decimal
    basis_pct:   Decimal
    net_profit:  Decimal
    direction:   str  # "buy_spot_sell_perp" or "buy_perp_sell_spot"


async def fetch_prices(session: aiohttp.ClientSession) -> dict:
    """Fetch both spot and perp mid prices for ETH in parallel."""
    headers = {"Authorization": f"Bearer {API_KEY}"}
    tasks = [
        session.get(f"{TRADING_API}/api/v1/price?market=ETH-USDC&venue=uniswap_v3", headers=headers),
        session.get(f"{TRADING_API}/api/v1/price?market=ETH-PERP&venue=purple_flea",  headers=headers),
    ]
    responses = await asyncio.gather(*tasks)
    results   = [await r.json() for r in responses]
    return {
        "spot": Decimal(str(results[0]["mid"])),
        "perp": Decimal(str(results[1]["mid"])),
    }


def evaluate_opportunity(spot: Decimal, perp: Decimal) -> Optional[ArbOpportunity]:
    """
    Calculate net profit for spot-perp basis trade.
    Total costs: flash fee + 2x trading fee (entry + exit) + gas.
    """
    basis = (perp - spot) / spot
    direction = "buy_spot_sell_perp" if basis > 0 else "buy_perp_sell_spot"
    gross_profit = abs(basis) * LOAN_AMOUNT
    total_fees   = (FLASH_FEE + TRADING_FEE * 2) * LOAN_AMOUNT + GAS_EST_USD
    net          = gross_profit - total_fees

    if net >= MIN_PROFIT:
        return ArbOpportunity(
            spot_price=spot,
            perp_price=perp,
            basis_pct=basis * 100,
            net_profit=net,
            direction=direction,
        )
    return None


async def execute_flash_arb(session: aiohttp.ClientSession, opp: ArbOpportunity):
    """Trigger the on-chain flash loan + arbitrage sequence."""
    headers = {"Authorization": f"Bearer {API_KEY}", "Content-Type": "application/json"}
    payload = {
        "strategy":    "spot_perp_basis",
        "direction":   opp.direction,
        "loan_amount": str(LOAN_AMOUNT),
        "market":      "ETH",
        "provider":    "aave_v3",
    }
    r = await session.post(f"{TRADING_API}/api/v1/flash-arbitrage", json=payload, headers=headers)
    result = await r.json()
    return result


async def run_arb_scanner():
    async with aiohttp.ClientSession() as session:
        print("Scanning spot/perp basis every 200ms...")
        while True:
            try:
                prices = await fetch_prices(session)
                opp    = evaluate_opportunity(prices["spot"], prices["perp"])
                if opp:
                    print(f"[!] Basis={opp.basis_pct:.3f}% net_profit=${opp.net_profit:.2f}")
                    result = await execute_flash_arb(session, opp)
                    print(f"    tx={result.get('tx_hash','n/a')} status={result.get('status')}")
            except Exception as e:
                print(f"[ERR] {e}")
            await asyncio.sleep(0.2)

asyncio.run(run_arb_scanner())

Liquidation Bots Using Flash Loans

Liquidation bots are among the most consistently profitable flash loan applications. When a DeFi borrower's collateral falls below the required health factor, their position becomes liquidatable. The liquidator repays part of the debt, receives collateral at a discount (typically 5–15%), and profits from the spread. Flash loans enable this with zero upfront capital requirement.

The pattern: monitor on-chain health factors for major lending protocols (Aave, Compound, MakerDAO), detect when a position crosses the liquidation threshold, borrow the debt asset via flash loan, call the liquidation function on the lending protocol, receive discounted collateral, sell collateral for profit, repay the flash loan.

def get_health_factor(user_addr: str) -> Decimal:
    data = pool.functions.getUserAccountData(user_addr).call()
    # healthFactor is returned with 18 decimals
    return Decimal(data[5]) / Decimal(10 ** 18)


def calculate_liquidation_profit(
    debt_usdc: Decimal,
    collateral_eth: Decimal,
    eth_price: Decimal,
    liquidation_bonus_pct: Decimal = Decimal("0.10"),
) -> Decimal:
    """
    When liquidating a 50% close factor:
    - Repay 50% of debt in USDC
    - Receive collateral ETH * (1 + bonus_pct)
    - Sell collateral ETH at market price
    Returns net profit after Aave flash fee.
    """
    repay_amount  = debt_usdc * Decimal("0.5")
    collateral_received = (repay_amount / eth_price) * (1 + liquidation_bonus_pct)
    proceeds      = collateral_received * eth_price
    flash_fee     = repay_amount * Decimal("0.0009")
    trading_fee   = proceeds * Decimal("0.001")
    return proceeds - repay_amount - flash_fee - trading_fee

Collateral Swap Patterns

A collateral swap lets a borrower exchange their collateral type without closing their position. Suppose you have $100,000 ETH posted as collateral on Aave and you want to switch to WBTC without touching your loan. Without flash loans, this requires repaying the loan first (needing capital), withdrawing ETH, buying WBTC, and redepositing. With a flash loan, the entire swap is atomic:

  1. Flash borrow the outstanding debt amount in USDC from Aave.
  2. Repay the debt using the borrowed USDC — this unlocks the ETH collateral.
  3. Withdraw the ETH collateral from Aave.
  4. Swap ETH for WBTC on Uniswap V3.
  5. Deposit WBTC as the new collateral on Aave.
  6. Re-borrow USDC (the original loan amount plus flash loan fee).
  7. Repay the flash loan.

The end state: position unchanged, ETH collateral replaced by WBTC, zero capital expended. This pattern is particularly valuable for agents managing multi-position portfolios where collateral rebalancing would otherwise require significant working capital or position interruption.

Python — Collateral swap profit calculator
from decimal import Decimal

def collateral_swap_cost(
    debt_amount_usdc: Decimal,
    eth_amount: Decimal,
    eth_price: Decimal,
    wbtc_price: Decimal,
    swap_fee_pct: Decimal = Decimal("0.0005"),  # Uniswap 0.05% pool
    flash_fee_pct: Decimal = Decimal("0.0009"),
) -> dict:
    """
    Calculate total cost of ETH→WBTC collateral swap using flash loan.
    Returns breakdown of costs and effective swap rate.
    """
    eth_value_usd  = eth_amount * eth_price
    flash_fee_usd  = debt_amount_usdc * flash_fee_pct
    swap_fee_usd   = eth_value_usd * swap_fee_pct
    wbtc_received  = (eth_value_usd - swap_fee_usd) / wbtc_price

    return {
        "eth_in":       eth_amount,
        "wbtc_out":     wbtc_received,
        "flash_fee_usd": flash_fee_usd,
        "swap_fee_usd":  swap_fee_usd,
        "total_cost_usd": flash_fee_usd + swap_fee_usd,
        "effective_eth_wbtc_rate": eth_price / wbtc_price * (1 - swap_fee_pct),
    }

# Example: swap $200k ETH collateral to WBTC
result = collateral_swap_cost(
    debt_amount_usdc=Decimal("150000"),
    eth_amount=Decimal("65"),
    eth_price=Decimal("3100"),
    wbtc_price=Decimal("65000"),
)
print(f"Total swap cost: ${result['total_cost_usd']:.2f}")
# → Total swap cost: $243.50

MEV Considerations and Private Mempool Submission

Maximal Extractable Value (MEV) is the defining challenge for profitable flash loan strategies. The moment a flash loan arbitrage or liquidation transaction enters the public mempool, it is visible to every MEV searcher running on the network. Sophisticated bots continuously scan the mempool for profitable pending transactions and either front-run them (submit the same transaction with higher gas), back-run them (capture value created by the transaction), or sandwich them.

Why MEV Kills Public Mempool Strategies

Consider an agent that detects an ETH arbitrage opportunity and submits a flash loan transaction to the public mempool with standard gas. Within milliseconds, MEV bots will detect this transaction, calculate its expected profit, and submit a competing transaction with higher gas. The validator, who captures the most fee-inclusive block, includes the MEV bot's transaction first. Your transaction either fails (if the opportunity is now gone) or gets front-run (if the bot takes your profit).

Private Mempool Solutions

The solution is to bypass the public mempool entirely. Several services offer private transaction submission where your transaction is only visible to validators after inclusion:

def submit_flash_bundle(
    flash_loan_tx: dict,
    signer_account,
    target_block_offset: int = 1,
) -> dict:
    """
    Submit a flash loan transaction as a Flashbots bundle.
    Bypasses public mempool — MEV bots cannot see or front-run it.
    target_block_offset=1 means we target the next block.
    """
    current_block = w3.eth.block_number
    target_block  = current_block + target_block_offset

    signed_tx = signer_account.sign_transaction(flash_loan_tx)
    bundle    = [{"signed_transaction": signed_tx.rawTransaction}]

    result = w3.flashbots.send_bundle(
        bundle,
        target_block_number=target_block,
    )
    print(f"Bundle submitted for block {target_block}")
    result.wait()  # blocks until included or missed

    receipts = result.receipts()
    if receipts:
        print(f"Included in block {target_block}!")
        return {"status": "included", "tx_hash": receipts[0].transactionHash.hex()}
    else:
        print(f"Bundle missed block {target_block} — resubmit?")
        return {"status": "missed", "block": target_block}

Gas Estimation Strategy

Flash loan transactions are significantly more gas-intensive than simple transfers. A typical Aave V3 flash loan with an arbitrage leg uses 300,000–800,000 gas depending on the number of swaps involved. Always estimate gas by simulating on a local fork before submitting to mainnet:

Python — Gas estimation with safety buffer
from web3 import Web3
from decimal import Decimal

def estimate_flash_loan_gas(
    w3: Web3,
    contract,
    loan_amount: int,
    sender: str,
    buffer_pct: Decimal = Decimal("0.30"),  # 30% safety buffer
) -> dict:
    """
    Estimate gas for a flash loan transaction using eth_estimateGas,
    then apply a safety buffer to prevent out-of-gas reverts.
    Flash loan callbacks use more gas than simple calls — buffer matters.
    """
    tx_data = contract.functions.initiateFlashLoan(loan_amount).build_transaction({
        "from":  sender,
        "nonce": w3.eth.get_transaction_count(sender),
    })
    try:
        estimated_gas = w3.eth.estimate_gas(tx_data)
        buffered_gas  = int(estimated_gas * (1 + buffer_pct))

        # Fetch current EIP-1559 fees
        latest_block = w3.eth.get_block("latest")
        base_fee     = latest_block["baseFeePerGas"]
        priority_fee = w3.eth.max_priority_fee

        max_fee_per_gas = int(base_fee * 1.25 + priority_fee)
        gas_cost_wei    = buffered_gas * max_fee_per_gas
        gas_cost_eth    = Decimal(gas_cost_wei) / Decimal(10 ** 18)

        return {
            "estimated_gas":   estimated_gas,
            "buffered_gas":    buffered_gas,
            "max_fee_per_gas": max_fee_per_gas,
            "gas_cost_eth":    gas_cost_eth,
            "base_fee_gwei":   base_fee / 10**9,
        }
    except Exception as e:
        # eth_estimateGas reverts if the simulation fails
        # This means the opportunity is already gone or tx is invalid
        raise ValueError(f"Gas estimation reverted — opportunity invalid: {e}")
Use Revert as Opportunity Validation

If eth_estimateGas reverts on your flash loan transaction, this is actually useful signal: it means the trade is unprofitable or the opportunity has closed. This saves you the mainnet gas cost of a failed submission. Always simulate before signing.

Full Python FlashLoanAgent Implementation

The following is a production-oriented FlashLoanAgent that integrates all the above patterns: opportunity scanning, gas estimation, private mempool submission via Flashbots, and Purple Flea Trading API for the execution leg. This agent monitors spot/perp basis, liquidation opportunities, and cross-DEX arbitrage simultaneously:

Python — FlashLoanAgent: complete implementation with web3.py
import asyncio, aiohttp, os, time, json
from web3 import Web3
from decimal import Decimal
from dataclasses import dataclass, field
from typing import Optional
from enum import Enum
import logging

logging.basicConfig(level=logging.INFO, format="%(asctime)s %(levelname)s %(message)s")
log = logging.getLogger("FlashLoanAgent")


class Strategy(Enum):
    SPOT_PERP_BASIS = "spot_perp_basis"
    CROSS_DEX_ARB   = "cross_dex_arb"
    LIQUIDATION     = "liquidation"
    COLLATERAL_SWAP = "collateral_swap"


@dataclass
class AgentConfig:
    pf_api_key:      str
    eth_rpc_url:     str
    private_key:     str
    flash_contract:  str    # deployed FlashLoanReceiver address
    min_profit_usd:  Decimal = Decimal("35")
    loan_amount_usd: Decimal = Decimal("200000")
    max_gas_gwei:    Decimal = Decimal("40")
    use_flashbots:   bool   = True
    poll_interval_s: float  = 0.2
    strategies:      list   = field(default_factory=lambda: [
        Strategy.SPOT_PERP_BASIS,
        Strategy.CROSS_DEX_ARB,
        Strategy.LIQUIDATION,
    ])


class FlashLoanAgent:
    """
    Autonomous flash loan agent for DeFi arbitrage, liquidations,
    and collateral swaps. Uses Purple Flea Trading API as execution
    layer and Flashbots for private mempool submission.
    """

    def __init__(self, config: AgentConfig):
        self.cfg    = config
        self.w3     = Web3(Web3.HTTPProvider(config.eth_rpc_url))
        self.wallet = self.w3.eth.account.from_key(config.private_key)
        self.pf_url = "https://trading.purpleflea.com"
        self.pf_hdrs = {
            "Authorization": f"Bearer {config.pf_api_key}",
            "Content-Type":   "application/json",
        }
        self.stats = {
            "scans": 0, "executions": 0,
            "successes": 0, "total_profit": Decimal("0"),
        }

    async def _fetch_json(self, session, url: str, method="GET", **kwargs):
        fn = session.get if method == "GET" else session.post
        async with fn(url, headers=self.pf_hdrs, **kwargs) as r:
            r.raise_for_status()
            return await r.json()

    async def scan_spot_perp_basis(self, session) -> Optional[dict]:
        """Check ETH spot vs perp for basis arbitrage."""
        try:
            spot_data = await self._fetch_json(
                session, f"{self.pf_url}/api/v1/price?market=ETH-USDC&venue=uniswap_v3"
            )
            perp_data = await self._fetch_json(
                session, f"{self.pf_url}/api/v1/price?market=ETH-PERP&venue=purple_flea"
            )
            spot  = Decimal(str(spot_data["mid"]))
            perp  = Decimal(str(perp_data["mid"]))
            basis = (perp - spot) / spot
            gross = abs(basis) * self.cfg.loan_amount_usd
            fees  = (Decimal("0.0009") + Decimal("0.001")) * self.cfg.loan_amount_usd + Decimal("8")
            net   = gross - fees
            if net >= self.cfg.min_profit_usd:
                return {
                    "strategy": Strategy.SPOT_PERP_BASIS.value,
                    "net_profit": net,
                    "basis_pct": basis * 100,
                    "direction": "buy_spot" if basis > 0 else "buy_perp",
                }
        except Exception as e:
            log.warning(f"spot_perp scan error: {e}")
        return None

    async def scan_cross_dex(self, session, pairs: list) -> Optional[dict]:
        """Check price spread across multiple DEX venues for a given pair."""
        venues = ["uniswap_v3", "curve", "balancer", "camelot"]
        prices = {}
        for pair in pairs:
            for venue in venues:
                try:
                    d = await self._fetch_json(
                        session,
                        f"{self.pf_url}/api/v1/price?market={pair}&venue={venue}"
                    )
                    prices[(pair, venue)] = Decimal(str(d["mid"]))
                except:
                    pass

        for pair in pairs:
            pair_prices = {v: p for (m, v), p in prices.items() if m == pair}
            if len(pair_prices) < 2:
                continue
            lo_v = min(pair_prices, key=pair_prices.get)
            hi_v = max(pair_prices, key=pair_prices.get)
            spread = (pair_prices[hi_v] - pair_prices[lo_v]) / pair_prices[lo_v]
            gross  = spread * self.cfg.loan_amount_usd
            fees   = (Decimal("0.0009") + Decimal("0.002")) * self.cfg.loan_amount_usd + Decimal("10")
            net    = gross - fees
            if net >= self.cfg.min_profit_usd:
                return {
                    "strategy":  Strategy.CROSS_DEX_ARB.value,
                    "pair":      pair,
                    "buy_venue": lo_v,
                    "sell_venue": hi_v,
                    "spread_pct": spread * 100,
                    "net_profit": net,
                }
        return None

    async def execute_opportunity(self, session, opp: dict) -> dict:
        """Submit flash loan transaction for the detected opportunity."""
        log.info(f"Executing: strategy={opp['strategy']} profit=${opp['net_profit']:.2f}")
        self.stats["executions"] += 1
        result = await self._fetch_json(
            session,
            f"{self.pf_url}/api/v1/flash-arbitrage",
            method="POST",
            json={
                "strategy":    opp["strategy"],
                "loan_amount": str(self.cfg.loan_amount_usd),
                "provider":    "aave_v3",
                "use_flashbots": self.cfg.use_flashbots,
                "details":     opp,
            },
        )
        if result.get("status") == "success":
            actual_profit = Decimal(str(result.get("profit_usd", "0")))
            self.stats["successes"] += 1
            self.stats["total_profit"] += actual_profit
            log.info(f"Success! profit=${actual_profit:.2f} tx={result.get('tx_hash')}")
        else:
            log.info(f"Reverted (spread closed) — gas cost only")
        return result

    async def run(self):
        """Main agent loop: scan all strategies in parallel, execute on opportunity."""
        log.info(f"FlashLoanAgent started. wallet={self.wallet.address}")
        log.info(f"min_profit=${self.cfg.min_profit_usd} loan=${self.cfg.loan_amount_usd}")
        async with aiohttp.ClientSession() as session:
            while True:
                self.stats["scans"] += 1
                try:
                    tasks = [
                        self.scan_spot_perp_basis(session),
                        self.scan_cross_dex(session, ["ETH-USDC", "WBTC-USDC"]),
                    ]
                    results = await asyncio.gather(*tasks, return_exceptions=True)
                    for opp in results:
                        if opp and isinstance(opp, dict):
                            await self.execute_opportunity(session, opp)
                            break  # Execute one per scan cycle
                except Exception as e:
                    log.error(f"Scan loop error: {e}")

                if self.stats["scans"] % 300 == 0:  # Log every 60s
                    log.info(
                        f"Stats: scans={self.stats['scans']} "
                        f"exec={self.stats['executions']} "
                        f"success={self.stats['successes']} "
                        f"profit=${self.stats['total_profit']:.2f}"
                    )
                await asyncio.sleep(self.cfg.poll_interval_s)


if __name__ == "__main__":
    cfg = AgentConfig(
        pf_api_key=os.environ["PURPLE_FLEA_API_KEY"],
        eth_rpc_url=os.environ["ETH_RPC_URL"],
        private_key=os.environ["WALLET_PRIVATE_KEY"],
        flash_contract=os.environ["FLASH_CONTRACT_ADDR"],
        min_profit_usd=Decimal("35"),
        loan_amount_usd=Decimal("200000"),
        use_flashbots=True,
    )
    asyncio.run(FlashLoanAgent(cfg).run())
