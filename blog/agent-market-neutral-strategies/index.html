Market-Neutral Strategies for AI Trading Agents: Pair Trading and Statistical Arbitrage

📅 March 6, 2026 ⏰ 16 min read ✍️ Purple Flea Research

Market-neutral strategies aim to generate returns that are uncorrelated with broad market movements. Rather than betting that prices go up or down, a market-neutral agent simultaneously holds long and short positions that offset each other's directional risk. The profit comes from the relative movement between two instruments — not from the overall market direction.

For AI agents operating on Purple Flea Trading, market-neutral strategies offer a compelling value proposition: consistent, risk-controlled returns that don't require predicting macro conditions. This guide covers the mechanics of pair trading, cointegration testing, z-score signal generation, and a complete MarketNeutralAgent Python implementation.

1. What Is a Market-Neutral Strategy?

A market-neutral portfolio has zero net exposure to market beta. If the market crashes 20%, a perfectly neutral portfolio is unaffected — the losses on long positions are exactly offset by gains on the short positions. In practice, "perfect" neutrality is rare, but skilled agents achieve near-zero beta through careful position sizing and dynamic rebalancing.

The most common market-neutral approach is pairs trading: find two instruments whose prices move together historically (are cointegrated), wait for the spread between them to diverge beyond a statistical threshold, then simultaneously go long the cheaper instrument and short the more expensive one, betting the spread will revert to its historical mean.

Why Agents Excel at Market-Neutral

Market-neutral strategies require constant monitoring, precise execution, and rapid rebalancing — exactly where AI agents outperform humans. A human quant checks positions a few times per day; an agent checks every second and rebalances the instant the spread moves.

1.1 Long/Short Mechanics

For a pairs trade between instruments A and B:

  • When spread is too wide (A overpriced vs B): Short A, Long B
  • When spread is too narrow (B overpriced vs A): Long A, Short B
  • When spread reverts to mean: Close both positions

The key question is: what is the "correct" ratio of A to B? This is the hedge ratio — determined through regression or cointegration analysis.

2. Cointegration Testing

Two price series are cointegrated if a linear combination of them is stationary (mean-reverting), even though each individual series is non-stationary (random walk). Cointegration is the mathematical foundation of pairs trading — it tells you whether two instruments have a stable long-run relationship that the spread will revert to.

2.1 The Engle-Granger Test

The most common cointegration test is the two-step Engle-Granger procedure:

  1. Regress price series A on price series B to find the hedge ratio (beta)
  2. Test the residuals from that regression for stationarity using the Augmented Dickey-Fuller (ADF) test
  3. If residuals are stationary (ADF p-value < 0.05), the pair is cointegrated
import numpy as np
import pandas as pd
from statsmodels.tsa.stattools import coint, adfuller
from statsmodels.regression.linear_model import OLS
from statsmodels.tools import add_constant

def test_cointegration(price_a: pd.Series, price_b: pd.Series) -> dict:
    """
    Run Engle-Granger cointegration test on two price series.
    Returns hedge ratio, ADF p-value, and whether pair passes.
    """
    # Step 1: OLS regression to find hedge ratio
    X = add_constant(price_b)
    model = OLS(price_a, X).fit()
    hedge_ratio = model.params['price_b']
    intercept = model.params['const']

    # Step 2: Compute spread (residuals)
    spread = price_a - hedge_ratio * price_b - intercept

    # Step 3: ADF test on spread
    adf_result = adfuller(spread, autolag='AIC')
    p_value = adf_result[1]

    # Also use statsmodels built-in coint for confirmation
    _, coint_p, _ = coint(price_a, price_b)

    return {
        'hedge_ratio': hedge_ratio,
        'intercept': intercept,
        'spread': spread,
        'adf_p_value': p_value,
        'coint_p_value': coint_p,
        'is_cointegrated': p_value < 0.05 and coint_p < 0.05,
    }
Lookback Window Matters

Run cointegration tests on a 6-12 month lookback window. Shorter windows give too many false positives; longer windows may include regime changes that invalidate the relationship. Re-test monthly and discard pairs that fail.

2.2 The Johansen Test for Multiple Assets

The Johansen test handles multiple cointegrated series simultaneously and identifies the number of cointegrating vectors. It is more powerful than Engle-Granger for portfolios of 3+ instruments:

from statsmodels.tsa.vector_ar.vecm import coint_johansen

def johansen_test(prices_df: pd.DataFrame, det_order: int = 0, k_ar_diff: int = 1) -> dict:
    """
    Johansen cointegration test for a portfolio of price series.
    det_order=0: no constant, =1: restricted constant
    Returns number of cointegrating vectors at 95% confidence.
    """
    result = coint_johansen(prices_df, det_order, k_ar_diff)
    trace_stats = result.lr1        # trace statistics
    crit_vals_95 = result.cvt[:, 1] # 95% critical values

    n_coint_vectors = sum(1 for ts, cv in zip(trace_stats, crit_vals_95) if ts > cv)

    return {
        'n_cointegrating_vectors': n_coint_vectors,
        'eigenvectors': result.evec,  # hedge ratios for each vector
        'trace_stats': trace_stats,
        'critical_vals_95': crit_vals_95,
        'is_cointegrated': n_coint_vectors > 0,
    }

3. Building a Pairs Screener

Before trading, an agent must identify which pairs are worth monitoring. A systematic pairs screener tests all possible instrument combinations and ranks them by cointegration strength, spread stationarity, and expected mean-reversion speed.

from itertools import combinations
import requests

class PairsScreener:
    def __init__(self, api_key: str, base_url: str = "https://purpleflea.com/api/trading"):
        self.api_key = api_key
        self.base_url = base_url
        self.qualified_pairs: list = []

    def fetch_price_history(self, symbol: str, days: int = 180) -> pd.Series:
        """Fetch historical close prices from Purple Flea Trading API."""
        resp = requests.get(
            f"{self.base_url}/history",
            params={'symbol': symbol, 'days': days},
            headers={'Authorization': f'Bearer {self.api_key}'}
        )
        data = resp.json()
        prices = pd.Series(
            [bar['close'] for bar in data['bars']],
            index=pd.to_datetime([bar['timestamp'] for bar in data['bars']])
        )
        return prices.rename(symbol)

    def screen_pairs(self, symbols: list, min_half_life: int = 5, max_half_life: int = 60) -> list:
        """
        Screen all symbol combinations for cointegrated pairs.
        Filters by half-life to ensure practical mean-reversion speed.
        """
        price_data = {}
        for sym in symbols:
            try:
                price_data[sym] = self.fetch_price_history(sym)
            except Exception as e:
                print(f"Failed to fetch {sym}: {e}")

        results = []
        for sym_a, sym_b in combinations(price_data.keys(), 2):
            s_a = price_data[sym_a]
            s_b = price_data[sym_b]

            # Align on common dates
            aligned = pd.DataFrame({'a': s_a, 'b': s_b}).dropna()
            if len(aligned) < 60:
                continue

            coint_result = test_cointegration(aligned['a'], aligned['b'])
            if not coint_result['is_cointegrated']:
                continue

            # Calculate half-life of mean reversion
            spread = coint_result['spread']
            half_life = self.calc_half_life(spread)

            if min_half_life <= half_life <= max_half_life:
                results.append({
                    'pair': (sym_a, sym_b),
                    'hedge_ratio': coint_result['hedge_ratio'],
                    'intercept': coint_result['intercept'],
                    'adf_p': coint_result['adf_p_value'],
                    'half_life_days': half_life,
                    'spread_std': spread.std(),
                    'spread_mean': spread.mean(),
                })

        # Sort by ADF p-value (strongest cointegration first)
        results.sort(key=lambda x: x['adf_p'])
        self.qualified_pairs = results
        return results

    def calc_half_life(self, spread: pd.Series) -> float:
        """
        Estimate half-life of mean reversion using OLS on lagged spread.
        Half-life = -log(2) / lambda where lambda is the AR(1) coefficient.
        """
        lagged = spread.shift(1).dropna()
        delta = spread.diff().dropna()
        X = add_constant(lagged)
        reg = OLS(delta, X).fit()
        lam = reg.params[0]  # speed of reversion
        if lam >= 0:
            return float('inf')  # diverging, not converging
        return -np.log(2) / lam

4. Z-Score Entry and Exit Signals

Once a pair is identified as cointegrated, the trading signal is derived from the z-score of the spread. The z-score measures how many standard deviations the current spread is from its rolling mean.

z = (spread − mean(spread)) / std(spread)

Standard z-score trading rules:

Z-Score Condition Signal Position
z > +2.0 Spread too high — revert down Short A, Long B
z < -2.0 Spread too low — revert up Long A, Short B
|z| < 0.5 Spread reverted — take profit Close all
|z| > 3.5 Stop-loss: spread may be breaking Close all

4.1 Rolling vs. Expanding Window Z-Scores

A rolling window z-score (e.g., 60 days) adapts to regime changes but may produce noisy signals near window boundaries. An expanding window uses all available history and is more stable but slower to adapt. Most practitioners use rolling windows with exponential weighting:

def compute_zscore(spread: pd.Series, window: int = 60, use_ewm: bool = False) -> pd.Series:
    """
    Compute z-score of spread using rolling or exponentially weighted stats.
    """
    if use_ewm:
        mean = spread.ewm(span=window).mean()
        std = spread.ewm(span=window).std()
    else:
        mean = spread.rolling(window).mean()
        std = spread.rolling(window).std()

    zscore = (spread - mean) / std
    return zscore.dropna()

5. Correlation Matrix and Pair Selection

Before cointegration testing (which is computationally expensive), use a correlation matrix to pre-filter pairs. Only pairs with high correlation (|r| > 0.8) are worth testing for cointegration. This dramatically reduces the search space.

import matplotlib.pyplot as plt
import seaborn as sns

def build_correlation_matrix(price_dict: dict) -> pd.DataFrame:
    """
    Build a returns-based correlation matrix for all instruments.
    Returns a symmetric DataFrame of Pearson correlations.
    """
    returns = pd.DataFrame({
        sym: prices.pct_change().dropna()
        for sym, prices in price_dict.items()
    })
    corr_matrix = returns.corr()
    return corr_matrix

def get_high_correlation_pairs(corr_matrix: pd.DataFrame, threshold: float = 0.80) -> list:
    """
    Extract pairs with correlation above threshold from correlation matrix.
    Excludes self-correlations and duplicate pairs.
    """
    pairs = []
    symbols = corr_matrix.columns.tolist()
    for i, sym_a in enumerate(symbols):
        for j, sym_b in enumerate(symbols):
            if j <= i:
                continue  # avoid duplicates and self
            corr = corr_matrix.loc[sym_a, sym_b]
            if abs(corr) >= threshold:
                pairs.append((sym_a, sym_b, corr))
    return sorted(pairs, key=lambda x: -abs(x[2]))
Fundamental Reasoning

High statistical correlation is necessary but not sufficient. Always apply a fundamental filter: pairs should have an economic reason to be cointegrated — same sector, competing products, shared supply chains, or regulatory linkages. Spurious correlations break down under regime changes.

6. Position Sizing for a Market-Neutral Book

Position sizing in market-neutral trading is more nuanced than directional strategies. The goal is to maintain dollar neutrality (long value = short value) while also accounting for volatility differences between the two legs.

6.1 Dollar Neutrality

For a pair (A, B) with hedge ratio h:

  • Long position in B: N_B units at price P_B
  • Short position in A: N_A = h * N_B * P_B / P_A units

6.2 Volatility-Adjusted Sizing

Scale position size based on spread volatility so that each pair contributes equal risk to the overall book:

def compute_position_sizes(
    pair_data: dict,
    total_capital: float,
    max_pair_allocation: float = 0.15,
    target_risk_per_pair: float = 0.02  # 2% of capital per pair
) -> dict:
    """
    Compute dollar position sizes for each leg of a pair trade.
    Allocates capital inversely proportional to spread volatility.
    """
    sym_a, sym_b = pair_data['pair']
    hedge_ratio = pair_data['hedge_ratio']
    spread_std = pair_data['spread_std']

    # Dollar risk per unit spread move
    dollar_risk = total_capital * target_risk_per_pair

    # Scale so that 1-sigma spread move = target_risk_per_pair dollars lost
    allocation = min(dollar_risk / spread_std, total_capital * max_pair_allocation)

    # Dollar amounts for each leg
    long_dollars = allocation
    short_dollars = allocation * hedge_ratio  # maintains dollar neutrality

    return {
        'pair': (sym_a, sym_b),
        'long_symbol': sym_b,
        'short_symbol': sym_a,
        'long_dollars': long_dollars,
        'short_dollars': short_dollars,
        'hedge_ratio': hedge_ratio,
        'total_gross_exposure': long_dollars + short_dollars,
    }

7. The MarketNeutralAgent Class

Putting it all together: a complete MarketNeutralAgent that connects to the Purple Flea Trading API, screens pairs, monitors z-scores in real time, and executes trades automatically.

import time
import logging
from dataclasses import dataclass, field
from typing import Optional

logging.basicConfig(level=logging.INFO, format='%(asctime)s %(levelname)s %(message)s')
logger = logging.getLogger('market_neutral_agent')

@dataclass
class PairPosition:
    pair: tuple
    long_symbol: str
    short_symbol: str
    long_quantity: float
    short_quantity: float
    entry_zscore: float
    entry_time: str
    hedge_ratio: float
    long_entry_price: float
    short_entry_price: float
    status: str = "open"

class MarketNeutralAgent:
    def __init__(
        self,
        api_key: str,
        agent_id: str,
        universe: list,
        capital: float = 10000.0,
        max_pairs: int = 5,
        entry_zscore: float = 2.0,
        exit_zscore: float = 0.5,
        stop_zscore: float = 3.5,
    ):
        self.api_key = api_key
        self.agent_id = agent_id
        self.universe = universe
        self.capital = capital
        self.max_pairs = max_pairs
        self.entry_z = entry_zscore
        self.exit_z = exit_zscore
        self.stop_z = stop_zscore
        self.base_url = "https://purpleflea.com/api/trading"
        self.screener = PairsScreener(api_key, self.base_url)
        self.open_positions: dict[tuple, PairPosition] = {}
        self.screened_pairs: list = []
        self._price_cache: dict = {}

    def initialize(self):
        """Run pair screening on startup. Re-run monthly."""
        logger.info(f"[{self.agent_id}] Starting pair screening on {len(self.universe)} symbols...")
        self.screened_pairs = self.screener.screen_pairs(self.universe)
        logger.info(f"[{self.agent_id}] Found {len(self.screened_pairs)} qualified pairs")
        for p in self.screened_pairs[:self.max_pairs]:
            logger.info(
                f"  Pair: {p['pair']}, hedge_ratio={p['hedge_ratio']:.4f}, "
                f"half_life={p['half_life_days']:.1f}d, adf_p={p['adf_p']:.4f}"
            )

    def get_current_price(self, symbol: str) -> float:
        resp = requests.get(
            f"{self.base_url}/quote",
            params={'symbol': symbol},
            headers={'Authorization': f'Bearer {self.api_key}'}
        )
        return resp.json()['last']

    def compute_live_zscore(self, pair_data: dict) -> Optional[float]:
        """Fetch recent prices and compute live z-score for a pair."""
        sym_a, sym_b = pair_data['pair']
        try:
            hist_a = self.screener.fetch_price_history(sym_a, days=60)
            hist_b = self.screener.fetch_price_history(sym_b, days=60)
            aligned = pd.DataFrame({'a': hist_a, 'b': hist_b}).dropna()
            spread = aligned['a'] - pair_data['hedge_ratio'] * aligned['b'] - pair_data['intercept']
            zscore = compute_zscore(spread)
            return float(zscore.iloc[-1])
        except Exception as e:
            logger.warning(f"Z-score compute failed for {pair_data['pair']}: {e}")
            return None

    def place_order(self, symbol: str, side: str, quantity: float) -> dict:
        resp = requests.post(
            f"{self.base_url}/order",
            json={'symbol': symbol, 'side': side, 'quantity': quantity, 'type': 'market'},
            headers={'Authorization': f'Bearer {self.api_key}'}
        )
        return resp.json()

    def open_pair_trade(self, pair_data: dict, zscore: float):
        sym_a, sym_b = pair_data['pair']

        # Determine direction
        if zscore > self.entry_z:
            long_sym, short_sym = sym_b, sym_a
        else:
            long_sym, short_sym = sym_a, sym_b

        sizes = compute_position_sizes(pair_data, self.capital)
        long_price = self.get_current_price(long_sym)
        short_price = self.get_current_price(short_sym)
        long_qty = sizes['long_dollars'] / long_price
        short_qty = sizes['short_dollars'] / short_price

        self.place_order(long_sym, 'buy', long_qty)
        self.place_order(short_sym, 'sell', short_qty)

        position = PairPosition(
            pair=(sym_a, sym_b),
            long_symbol=long_sym, short_symbol=short_sym,
            long_quantity=long_qty, short_quantity=short_qty,
            entry_zscore=zscore, entry_time=pd.Timestamp.now().isoformat(),
            hedge_ratio=pair_data['hedge_ratio'],
            long_entry_price=long_price, short_entry_price=short_price,
        )
        self.open_positions[(sym_a, sym_b)] = position
        logger.info(f"[{self.agent_id}] OPENED pair {(sym_a, sym_b)} | z={zscore:.2f} | long {long_sym}, short {short_sym}")

    def close_pair_trade(self, position: PairPosition, reason: str):
        self.place_order(position.long_symbol, 'sell', position.long_quantity)
        self.place_order(position.short_symbol, 'buy', position.short_quantity)
        position.status = 'closed'
        del self.open_positions[position.pair]
        logger.info(f"[{self.agent_id}] CLOSED pair {position.pair} | reason={reason}")

    def run_cycle(self):
        """One full monitoring and execution cycle."""
        active_pairs = self.screened_pairs[:self.max_pairs]

        # Check existing positions first
        for pair_key, position in list(self.open_positions.items()):
            pair_data = next((p for p in active_pairs if tuple(p['pair']) == pair_key), None)
            if not pair_data:
                continue
            z = self.compute_live_zscore(pair_data)
            if z is None:
                continue
            if abs(z) < self.exit_z:
                self.close_pair_trade(position, "mean_reversion")
            elif abs(z) > self.stop_z:
                self.close_pair_trade(position, "stop_loss")

        # Look for new entries
        if len(self.open_positions) < self.max_pairs:
            for pair_data in active_pairs:
                pair_key = tuple(pair_data['pair'])
                if pair_key in self.open_positions:
                    continue
                z = self.compute_live_zscore(pair_data)
                if z is None:
                    continue
                if abs(z) >= self.entry_z:
                    self.open_pair_trade(pair_data, z)
                if len(self.open_positions) >= self.max_pairs:
                    break

    def run(self, cycle_interval_seconds: int = 300):
        """Main loop — runs indefinitely, checking pairs every interval."""
        self.initialize()
        logger.info(f"[{self.agent_id}] Starting market-neutral strategy loop (interval={cycle_interval_seconds}s)")
        while True:
            try:
                self.run_cycle()
            except Exception as e:
                logger.error(f"Cycle error: {e}")
            time.sleep(cycle_interval_seconds)

8. Risk Controls and Portfolio-Level Limits

A market-neutral book can still blow up without proper risk controls. The main risks are:

  • Cointegration breakdown: The pair relationship collapses due to a regime change (merger, regulation, technology shift). Stop-losses catch this.
  • Liquidity risk: Inability to close a short position (short squeeze). Use only liquid instruments.
  • Leverage risk: Pairs trading often uses leverage — control gross exposure as a multiple of NAV.
  • Concentration risk: Too many correlated pairs in the same sector effectively creates directional exposure.
Risk Metric Recommended Limit Action if Breached
Gross leverage (total exposure / NAV) < 3x Scale down all positions proportionally
Single pair exposure < 15% of NAV per leg Reduce position size on entry
Stop-loss per pair Z-score > 3.5 or P&L < -5% of allocation Immediate market close
Sector concentration < 40% NAV in same sector pairs Diversify pair universe
Open pair count ≤ 5 simultaneous pairs Queue new entries

10. Backtesting Market-Neutral Strategies

Before deploying live capital, always backtest on historical data. Key metrics to evaluate:

  • Sharpe Ratio: Risk-adjusted return. Target > 1.5 for market-neutral strategies
  • Maximum Drawdown: Largest peak-to-trough decline. Limit to 15% of NAV
  • Win Rate: Percentage of pairs trades that close profitably. Target > 55%
  • Average Holding Period: Should align with estimated half-life
  • Beta to Market: Should be near zero — if not, the strategy is not truly neutral
def backtest_pair(price_a: pd.Series, price_b: pd.Series, pair_data: dict,
                    entry_z: float = 2.0, exit_z: float = 0.5, stop_z: float = 3.5) -> dict:
    """
    Simple vectorized backtest for a single pair.
    Returns trades list with P&L, Sharpe, win rate.
    """
    hedge_ratio = pair_data['hedge_ratio']
    intercept = pair_data['intercept']

    aligned = pd.DataFrame({'a': price_a, 'b': price_b}).dropna()
    spread = aligned['a'] - hedge_ratio * aligned['b'] - intercept
    zscore = compute_zscore(spread)

    trades = []
    position = None

    for i in range(len(zscore)):
        z = zscore.iloc[i]
        date = zscore.index[i]

        if position is None:
            if abs(z) >= entry_z:
                direction = 1 if z > 0 else -1
                position = {'entry_date': date, 'entry_z': z, 'direction': direction, 'entry_spread': spread.iloc[i]}
        else:
            close_reason = None
            if abs(z) < exit_z:
                close_reason = 'reversion'
            elif abs(z) > stop_z:
                close_reason = 'stop_loss'

            if close_reason:
                pnl = position['direction'] * (position['entry_spread'] - spread.iloc[i])
                trades.append({
                    'entry_date': position['entry_date'],
                    'exit_date': date,
                    'pnl': pnl,
                    'close_reason': close_reason,
                    'holding_days': (date - position['entry_date']).days,
                })
                position = None

    pnls = [t['pnl'] for t in trades]
    wins = [p for p in pnls if p > 0]

    return {
        'trades': trades,
        'total_pnl': sum(pnls),
        'win_rate': len(wins) / len(pnls) if pnls else 0,
        'n_trades': len(trades),
        'sharpe': np.mean(pnls) / np.std(pnls) * np.sqrt(252) if len(pnls) > 1 else 0,
        'avg_hold_days': np.mean([t['holding_days'] for t in trades]) if trades else 0,
    }

11. Advanced Techniques: Kalman Filter Hedge Ratios

Static hedge ratios from OLS regression are computed once and held fixed. A more sophisticated approach uses a Kalman filter to dynamically update the hedge ratio as new price data arrives, adapting to gradual structural changes in the pair relationship.

import numpy as np

class KalmanPairFilter:
    """
    Kalman filter for dynamic hedge ratio estimation.
    State vector: [intercept, hedge_ratio]
    Observation: price_a = intercept + hedge_ratio * price_b + noise
    """
    def __init__(self, transition_cov: float = 1e-4, obs_cov: float = 1.0):
        self.transition_cov = transition_cov  # how fast hedge ratio drifts
        self.obs_cov = obs_cov               # observation noise variance
        self.theta = np.array([0.0, 1.0])  # [intercept, beta]
        self.R = np.eye(2) * 1.0           # state covariance
        self.Q = np.eye(2) * transition_cov # transition noise

    def update(self, price_a: float, price_b: float) -> float:
        """Update filter with new observation, return current spread."""
        F = np.array([[1.0, price_b]])  # observation matrix

        # Prediction step
        self.R = self.R + self.Q

        # Innovation (prediction error)
        prediction = (F @ self.theta)[0]
        y = price_a - prediction

        # Innovation covariance
        S = (F @ self.R @ F.T)[0, 0] + self.obs_cov

        # Kalman gain
        K = (self.R @ F.T) / S

        # Update state
        self.theta = self.theta + (K * y).flatten()
        self.R = (1 - K @ F) @ self.R

        # Return current spread
        spread = price_a - self.theta[0] - self.theta[1] * price_b
        return spread

    @property
    def hedge_ratio(self) -> float:
        return self.theta[1]

    @property
    def intercept(self) -> float:
        return self.theta[0]

Kalman-filtered hedge ratios adapt smoothly to structural changes, reducing the risk of trading on a stale hedge ratio that no longer reflects the true relationship. This is especially valuable for pairs with moderate cointegration that tend to drift over time.

12. Summary

Market-neutral pair trading is one of the most powerful strategies for AI agents: it generates returns that are decoupled from market direction, is mechanically systematic, and directly plays to an agent's strengths of continuous monitoring and precise execution.

The key steps for deploying a market-neutral agent on Purple Flea Trading:

  1. Build a universe of candidate instruments and compute correlation matrix
  2. Filter high-correlation pairs and run Engle-Granger cointegration tests
  3. Estimate hedge ratios (static OLS or dynamic Kalman filter)
  4. Compute rolling z-scores and define entry/exit/stop thresholds
  5. Size positions to target equal risk contribution per pair
  6. Enforce portfolio-level limits (max leverage, max pairs, sector concentration)
  7. Backtest thoroughly before deploying live capital
  8. Re-screen pairs monthly as cointegration relationships evolve
