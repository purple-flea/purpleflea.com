Build a Hyperliquid Funding Rate Arbitrage Bot with Purple Flea

Harvest positive funding rates on perpetual futures with a delta-neutral autonomous agent. This guide covers the mechanics, full Python implementation, and risk management for a live bot running on Hyperliquid's 275 markets via Purple Flea.

Funding rate arbitrage is one of the few genuinely market-neutral strategies available in crypto derivatives. When perpetual futures trade at a premium to spot, longs pay shorts a periodic funding fee — typically every 8 hours. By holding a short position on the perp while being long the underlying asset (or a correlated instrument), you collect this fee with near-zero directional risk.

Purple Flea's trading API gives AI agents access to all 275 Hyperliquid perpetual markets. In this guide we'll build a bot that continuously scans for high positive funding rates, opens delta-neutral positions to harvest them, and closes when rates normalize.

What you'll build: A Python bot that scans funding rates every hour, ranks markets by annualized yield, opens short perp + long spot positions when the annualized rate exceeds a threshold (e.g., 20% APR), and closes positions when it drops below a minimum.

Understanding Funding Rates

On Hyperliquid (and most perp exchanges), the funding rate is recalculated every 8 hours based on the difference between the mark price (perp) and the index price (spot). The formula is approximately:

# Funding payment per 8h cycle funding_payment = position_size × funding_rate # Annualized rate (3 payments per day × 365 days) annual_rate = funding_rate × 3 × 365 # Example: BTC-PERP funding rate = 0.01% per 8h # Annual = 0.01% × 3 × 365 = 10.95% APR MATH

When the rate is positive, longs pay shorts. Our bot goes short the perp (receiving funding) and holds the underlying long elsewhere to stay delta-neutral. The spread between the funding yield and any basis risk is the profit.

Step 2 — The Funding Rate Scanner

import requests, os from dotenv import load_dotenv load_dotenv() API_KEY = os.getenv("PURPLEFLEA_API_KEY") AGENT_ID = os.getenv("PURPLEFLEA_AGENT_ID") headers = {"Authorization": f"Bearer {API_KEY}"} BASE = "https://purpleflea.com/api" MIN_APR = float(os.getenv("MIN_ANNUAL_RATE", 20)) CLOSE_APR = float(os.getenv("CLOSE_RATE_THRESHOLD", 5)) MAX_PCT = float(os.getenv("MAX_POSITION_PCT", 10)) / 100 def get_funding_rates(): """Fetch all markets and compute annualized funding rates.""" r = requests.get(f"{BASE}/trading/markets?limit=275", headers=headers) markets = r.json().get("markets", []) opportunities = [] for m in markets: rate_8h = m.get("fundingRate", 0) # percent per 8h annual_rate = rate_8h * 3 * 365 # 3 cycles/day × 365 days if annual_rate > MIN_APR: opportunities.append({ "symbol": m["symbol"], "rate_8h": rate_8h, "annual_rate": annual_rate, "price": m["price"], "volume24h": m.get("volume24h", 0), "openInterest": m.get("openInterest", 0) }) # Sort by annual rate descending opportunities.sort(key=lambda x: x["annual_rate"], reverse=True) return opportunities def get_portfolio(): """Get current balance and open positions.""" r = requests.get(f"{BASE}/balance", headers={**headers, "X-Agent-ID": AGENT_ID}) return r.json() PYTHON

Step 3 — Position Management

def open_funding_position(symbol: str, size_usd: float): """Open a short perp position to collect positive funding.""" r = requests.post(f"{BASE}/trading/order", json={ "agentId": AGENT_ID, "market": symbol, "side": "short", # short perp to RECEIVE positive funding "size": size_usd, "leverage": 1, # 1x leverage — delta hedge elsewhere "orderType": "market", "metadata": {"strategy": "funding_harvest"} }, headers=headers) return r.json() def close_position(symbol: str): """Close the short perp position.""" r = requests.post(f"{BASE}/trading/close", json={ "agentId": AGENT_ID, "market": symbol, "orderType": "market" }, headers=headers) return r.json() def get_open_positions(): """Get list of currently open perp positions.""" r = requests.get(f"{BASE}/trading/positions", headers={**headers, "X-Agent-ID": AGENT_ID}) return {p["symbol"]: p for p in r.json().get("positions", [])} PYTHON

Step 4 — The Main Bot Loop

import time, schedule def funding_harvest_cycle(): print(f"\n[{time.strftime('%H:%M:%S')}] Running funding harvest cycle") portfolio = get_portfolio() balance = portfolio.get("usdc", 0) open_positions = get_open_positions() current_rates = {op["symbol"]: op for op in get_funding_rates()} print(f" Balance: ${balance:.4f} | Open positions: {len(open_positions)}") # Step 1: Close positions where rate has normalized for symbol, pos in open_positions.items(): current = current_rates.get(symbol, {}) annual = current.get("annual_rate", 0) if annual < CLOSE_APR: print(f" Closing {symbol}: rate dropped to {annual:.1f}% APR") result = close_position(symbol) print(f" Closed: {result.get('pnl', 0):.4f} USDC P&L") # Step 2: Open new positions where rate is attractive opportunities = get_funding_rates() max_new_positions = 5 - len(open_positions) for opp in opportunities[:max_new_positions]: symbol = opp["symbol"] if symbol in open_positions: continue # already in position # Size: up to MAX_PCT of portfolio per position size = min(balance * MAX_PCT, opp["volume24h"] * 0.001) if size < 1.0: continue # too small to be worth the fee print(f" Opening {symbol}: {opp['annual_rate']:.1f}% APR | Size: ${size:.2f}") result = open_funding_position(symbol, size) print(f" Order: {result.get('orderId')} @ ${result.get('fillPrice', '?')}") print(f"[{time.strftime('%H:%M:%S')}] Cycle complete") # Run every hour (funding settles every 8h, but rates can change sooner) schedule.every(1).hour.do(funding_harvest_cycle) funding_harvest_cycle() # run immediately while True: schedule.run_pending() time.sleep(60) PYTHON

Key Risks and Mitigations

Warning: Funding rate strategies involve real financial risk. Rates can turn negative (you'd be paying instead of receiving), and the underlying asset can move sharply against your delta hedge. Never risk more than you can afford to lose.

  • Rate reversal risk: Funding rates can flip negative rapidly. The CLOSE_RATE_THRESHOLD mitigates this but doesn't eliminate it. Set it conservatively (5-10% APR minimum).
  • Liquidation risk: At 1x leverage, liquidation requires a 100% move against you — unlikely but not impossible during black swan events. Still, monitor positions manually.
  • Execution risk: Market orders fill at market price. For large positions, use limit orders with a small offset to reduce slippage.
  • Correlation breakdown: If you're hedging perp shorts with spot longs on a different exchange, basis risk exists. Purple Flea's wallet API can help manage spot positions on-chain.
