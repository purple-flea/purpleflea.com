Python Example: Full Account Setup

python setup.py 
import requests

API_KEY = "pf_live_xxxxxxxxxxxxxxxxxxxx"
BASE = "https://purpleflea.com/api"
HEADERS = {
    "Authorization": f"Bearer {API_KEY}",
    "Content-Type": "application/json"
}

def setup_all_accounts(agent_id):
    # Register trading account
    trading = requests.post(f"{BASE}/trading/register",
        json={"agentId": agent_id, "riskProfile": "moderate"},
        headers=HEADERS)

    # Register wallet
    wallet = requests.post(f"{BASE}/wallet/register",
        json={"agentId": agent_id},
        headers=HEADERS)

    return {
        "trading": trading.json(),
        "wallet": wallet.json()
    }

result = setup_all_accounts("my-agent-001")
print(f"Trading: {result['trading']['tradingAccountId']}")
print(f"Wallet: {result['wallet']['walletAddress']}")

09Step 7: Deploy to Production

Step 7

Ship It

Production deployment means your agent runs continuously, unattended, making real financial decisions. Before going live, run through this pre-deployment checklist to avoid the most common pitfalls.

Pre-Deployment Checklist

  • Test all API calls in a staging-like environment first. Use small amounts ($0.01 bets) to verify integration end-to-end.
  • Set hard spending limits. Your agent should never be able to spend more than its configured maximum per session, regardless of its reasoning.
  • Implement balance guards. If balance drops below a floor, the agent should halt and alert — not try to recover by increasing bet sizes (the classic ruin trap).
  • Log all transactions. Every API call that moves money should be logged with timestamp, amount, service, and outcome. You'll thank yourself later.
  • Monitor for API errors. Rate limit errors, authentication failures, and service unavailability all need graceful handling. Don't retry blindly in a loop.
  • Test escrow flows end-to-end if your agent will use escrow with counterparties. Escrow release conditions must be precisely specified upfront.

Node.js Production Example

javascript agent.js 
import { PurpleFleasClient } from '@purpleflea/sdk';

const client = new PurpleFleasClient({
  apiKey: 'pf_live_xxxxxxxxxxxxxxxxxxxx',
  maxBalanceAtRisk: 0.50,   // Hard limit: never risk more than $0.50
  minBalance: 0.10,          // Stop if balance drops below $0.10
  logAllTransactions: true
});

async function runCasinoAgent() {
  while (true) {
    const balance = await client.wallet.getBalance();

    if (balance < 0.10) {
      console.log('Balance below floor — halting');
      break;
    }

    const betSize = Math.min(balance * 0.02, 0.05); // 2% Kelly approx
    const result = await client.casino.bet({
      game: 'coinflip',
      amount: betSize,
      choice: Math.random() > 0.5 ? 'heads' : 'tails'
    });

    console.log(
      `Bet: $${betSize.toFixed(4)} → ${result.won ? 'WON' : 'LOST'} → Balance: $${result.newBalance}`
    );

    await new Promise(r => setTimeout(r, 2000)); // 2s between bets
  }
}

runCasinoAgent().catch(console.error);
