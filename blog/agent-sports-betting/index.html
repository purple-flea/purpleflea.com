Understanding Odds Formats

Before analyzing betting opportunities, an AI agent must be able to convert between the three major odds formats used globally. Each represents the same information — the implied probability of an outcome and the payout for a correct bet — in a different notation.

Decimal Odds (European Format)

Decimal odds represent the total payout per unit staked, including the original stake. They are the most intuitive format for mathematical processing:

Payout = Stake × Decimal Odds
Implied Probability = 1 / Decimal Odds
Example: Decimal odds of 2.50 → 40% implied probability, $2.50 payout per $1 staked (including stake)

Decimal odds of 1.00 represent a certain event (100% probability). Odds of 2.00 represent even money (50% implied probability). Anything above 2.00 is the "underdog" side; below 2.00 is the "favorite" side.

American (Moneyline) Odds

American odds use a +/- notation relative to a $100 unit:

  • Positive (+): The profit on a $100 bet. +150 means win $150 profit on a $100 bet (implied probability: 100/(100+150) = 40%)
  • Negative (-): The stake required to win $100. -200 means bet $200 to win $100 profit (implied probability: 200/(100+200) = 66.7%)

Conversions between American and decimal odds:

// Convert American odds to decimal
function americanToDecimal(american) {
  if (american > 0) {
    return (american / 100) + 1;
  } else {
    return (100 / Math.abs(american)) + 1;
  }
}

// Convert American odds to implied probability
function americanToImpliedProb(american) {
  if (american > 0) {
    return 100 / (american + 100);
  } else {
    return Math.abs(american) / (Math.abs(american) + 100);
  }
}

// Examples
console.log(americanToDecimal(+150));  // 2.50
console.log(americanToDecimal(-200));  // 1.50
console.log(americanToImpliedProb(+150).toFixed(4));  // 0.4000 (40%)
console.log(americanToImpliedProb(-200).toFixed(4));  // 0.6667 (66.7%)

Fractional Odds (British Format)

Fractional odds (e.g., 3/1, 5/2, 7/4) represent the ratio of profit to stake:

Profit = Stake × (Numerator / Denominator)
Implied Probability = Denominator / (Numerator + Denominator)
Example: 3/1 → 25% implied probability, profit of $3 per $1 staked

For algorithmic processing, always convert all odds to decimal format first — it is the most computationally convenient representation.

Implied Probability and the Vig

The most important concept for an AI agent analyzing sports betting markets is the vig (vigorish, also called juice, overround, or margin). The vig is the bookmaker's built-in profit margin, embedded in the odds so that the sum of implied probabilities across all outcomes exceeds 100%.

Calculating Overround

For a two-outcome market (e.g., Team A vs Team B with no draw possible):

// Calculate bookmaker overround (vig)
function calculateOverround(odds1, odds2) {
  const impliedProb1 = 1 / odds1;
  const impliedProb2 = 1 / odds2;
  const overround = (impliedProb1 + impliedProb2 - 1) * 100;
  return overround; // Percentage above 100%
}

// Example: NFL moneyline
// Team A: -110 (decimal 1.909), Team B: -110 (decimal 1.909)
const vig = calculateOverround(1.909, 1.909);
console.log(`Vig: ${vig.toFixed(2)}%`); // ~4.76%

// Implied probs sum to 104.76% — the 4.76% is the house margin
// For a bettor to profit, they must have implied prob accuracy > 104.76%

The vig is your enemy: A -110/-110 market (standard NFL point spread) requires you to win 52.38% of your bets just to break even. A bettor who wins at 50% accuracy (coin-flip) will lose 4.76% of turnover per bet. Over hundreds of bets, this is mathematically crushing without genuine edge.

Finding Statistical Edge vs. Bookmakers

Edge is the difference between your estimated true probability of an outcome and the implied probability reflected in the bookmaker's odds. Positive edge (+EV) means the odds are mispriced in your favor:

Edge = (True Probability × Decimal Odds) - 1
Positive edge = favorable bet. Example: True prob 55%, decimal odds 2.10 → Edge = (0.55 × 2.10) - 1 = 0.155 = +15.5%

Sources of Edge for AI Agents

The edge must come from somewhere — specifically, from a model that is more accurate than the bookmaker's pricing model. Potential sources of edge for AI agents include:

Advanced Statistical Modeling

Bookmakers set lines using efficient market wisdom — aggregated money and sharp bettor positions. An AI agent with a genuinely superior statistical model (e.g., a Poisson regression model for soccer goal scoring, an Elo system for tennis, a neural network trained on play-by-play NBA data) can identify situations where the model's probability estimate diverges significantly from the implied market probability.

Real-Time Information Processing

Bookmakers are slow to adjust lines after injury news, lineup confirmations, weather changes, and other game-relevant information. An agent that processes real-time data feeds and places bets within seconds of relevant information becoming public can exploit this window before books update. This is the most reliable and defensible edge source — pure information speed advantage.

Market Inefficiency in Niche Markets

Major markets (NFL, NBA, Premier League) are heavily policed by sharp syndicates and have very low vig opportunities. Minor markets — lower-league soccer, Eastern European basketball, niche player props — may have wider vig but also more pricing inefficiency due to less sophisticated line-setting by the book.

Arbitrage (Sure Bets)

When odds across different bookmakers collectively imply a total probability below 100%, a risk-free profit exists by betting all outcomes. Arbitrage opportunities are typically small (0.5-2%) and disappear within minutes. AI agents can scan hundreds of books simultaneously to detect and exploit them, but this requires multiple accounts and is quickly detected by bookmakers, who will restrict arbers.

// Detect arbitrage opportunity across two books
function findArb(book1Odds, book2Odds) {
  const impliedProb1 = 1 / book1Odds;
  const impliedProb2 = 1 / book2Odds;
  const totalImplied = impliedProb1 + impliedProb2;

  if (totalImplied < 1.0) {
    const arbPct = (1 - totalImplied) * 100;
    const stake1 = impliedProb1 / totalImplied;
    const stake2 = impliedProb2 / totalImplied;
    return { isArb: true, arbPct, stake1, stake2 };
  }
  return { isArb: false };
}

// Example: Book A offers Team A at 2.10, Book B offers Team B at 2.10
const result = findArb(2.10, 2.10);
// totalImplied = 0.476 + 0.476 = 0.952 < 1.0
// arbPct = 4.8% risk-free profit!
console.log(result);

The Kelly Criterion: Optimal Bet Sizing

Once an AI agent has identified a bet with positive expected value, the next question is: how much to bet? The Kelly Criterion provides the mathematically optimal answer — the fraction of bankroll to bet that maximizes long-run capital growth.

The Full Kelly Formula

f* = (b × p - q) / b
f* = fraction of bankroll to bet | b = net odds (decimal odds - 1) | p = estimated probability of winning | q = estimated probability of losing (1 - p)

In simpler terms:

f* = Edge / Odds
Where Edge = (p × decimal odds) - 1

Kelly Example

Suppose an AI agent's model estimates a 55% probability that Team A beats Team B. The bookmaker is offering decimal odds of 2.05 on Team A.

function kellyFraction(prob, decimalOdds) {
  const b = decimalOdds - 1;  // Net odds
  const p = prob;
  const q = 1 - prob;
  const f = (b * p - q) / b;
  return Math.max(0, f);  // Never bet negative Kelly
}

const f = kellyFraction(0.55, 2.05);
// b = 1.05, p = 0.55, q = 0.45
// f = (1.05 * 0.55 - 0.45) / 1.05
// f = (0.5775 - 0.45) / 1.05
// f = 0.1275 / 1.05 = 0.1214

console.log(`Kelly fraction: ${(f * 100).toFixed(2)}%`);
// Kelly fraction: 12.14% of bankroll

The Problem with Full Kelly

Full Kelly maximizes long-run expected log wealth, but it comes with terrifying short-run volatility. A bet sized at 12.14% of bankroll means the agent could lose 12.14% of all capital on a single wager — and if the probability estimate is even slightly wrong, the Kelly fraction should have been smaller.

In practice, sophisticated bettors use fractional Kelly — typically Half Kelly or Quarter Kelly:

Recommended for AI agents: Use Half Kelly as the upper bound on any individual bet. Never exceed 5% of bankroll on a single sporting event regardless of Kelly output. Probability estimates are always uncertain — overestimating edge and overbetting is the primary cause of Kelly-based ruin.

Kelly with Correlated Bets

Agents placing multiple simultaneous bets (e.g., betting on three games in the same parlay, or having positions on multiple Team A wagers) must account for correlation. If two bets are positively correlated (both involve Team A winning), the effective bankroll risk is higher than two independent bets suggest. The multivariate Kelly formula accounts for this:

// Simplified multi-bet Kelly adjustment
function adjustedKelly(singleKelly, numCorrelatedBets, correlation = 0.5) {
  // If fully independent (correlation=0), sum of Kelly fractions
  // If correlated, reduce individual fractions
  const diversionFactor = 1 + (numCorrelatedBets - 1) * correlation;
  return singleKelly / diversionFactor;
}

// 3 correlated bets, each with 6% Half-Kelly recommendation
// If correlation is 0.5, divide by 1 + 2*0.5 = 2
const adjustedBet = adjustedKelly(0.06, 3, 0.5);
console.log(`Adjusted per-bet fraction: ${(adjustedBet * 100).toFixed(2)}%`);
// 3% per bet instead of 6%

Bankroll Management for Sports Betting Agents

Even with a genuine edge and correct Kelly sizing, sports betting agents face several operational bankroll challenges that pure math does not capture.

Drawdown Planning

Even a +5% edge bettor will experience extended losing streaks due to variance. A 50-bet losing streak at 55% win rate is unlikely but not impossible. Agents must plan for maximum drawdown scenarios:

Account Longevity Problem

The elephant in the room for AI sports betting agents is account restriction. Bookmakers actively monitor for winning patterns and systematically restrict accounts that demonstrate consistent profitability:

  • Stake limits: Maximum bet reduced from $1000 to $10 after 20-30 winning bets
  • Account suspension: Full account closure for suspected automation or arbitrage activity
  • Delay tactics: Bookmakers delay bet acceptance on sharp accounts by 10-30 seconds, causing odds to change before the bet is confirmed
  • Withdrawal friction: Enhanced KYC requirements triggered when accounts show consistent profitability

For an AI agent, account restriction is an existential business risk. The expected lifespan of a profitable sports betting account at a retail bookmaker is 3-6 months before significant restrictions, and 12-18 months before account closure. This creates a treadmill where agents must constantly open new accounts — a labor-intensive process that also creates legal and KYC complexity.

Critical limitation: Sports betting as a business model for AI agents is severely constrained by bookmaker restriction policies. Unlike financial markets (where profitable algorithms are welcomed) or provably fair casino games (where all players are treated identically), sportsbooks actively discriminate against winning customers. This is the most important factor separating sports betting from other forms of agent gambling.

Sport-Specific Modeling Considerations

Soccer / Football

Soccer is the most heavily bet sport globally and has the richest data ecosystem. Effective AI models for soccer use:

  • Poisson regression: Model goals scored and conceded as independent Poisson processes. Teams are characterized by attack strength and defense weakness parameters calibrated on recent match history.
  • xG (Expected Goals): Shot quality metrics that predict future goal output better than actual goals scored in small samples. Teams that outperform their xG are likely to regress; those underperforming may be due for positive regression.
  • ELO ratings: Club ELO ratings calibrated on 10+ years of match data provide a robust base probability estimate for any matchup.
  • Fatigue / fixture congestion: Teams playing three matches in seven days show measurable performance degradation that betting markets underprice in early-season fixture-heavy periods.
// Simple Poisson soccer model
function poissonProbability(lambda, k) {
  // P(X = k) = e^-lambda * lambda^k / k!
  return Math.exp(-lambda) * Math.pow(lambda, k) / factorial(k);
}

function matchOutcomeProbabilities(lambdaHome, lambdaAway, maxGoals = 10) {
  let homeWin = 0, draw = 0, awayWin = 0;
  for (let h = 0; h <= maxGoals; h++) {
    for (let a = 0; a <= maxGoals; a++) {
      const prob = poissonProbability(lambdaHome, h) * poissonProbability(lambdaAway, a);
      if (h > a) homeWin += prob;
      else if (h === a) draw += prob;
      else awayWin += prob;
    }
  }
  return { homeWin, draw, awayWin };
}

// Manchester City (attack 2.1, away defense 0.8) vs Arsenal (attack 1.6, home defense 0.9)
const lambdaHome = 2.1 * 0.9;  // 1.89 expected goals for City
const lambdaAway = 1.6 * 0.8;  // 1.28 expected goals for Arsenal

const probs = matchOutcomeProbabilities(lambdaHome, lambdaAway);
console.log('Home win:', (probs.homeWin * 100).toFixed(1) + '%');
console.log('Draw:', (probs.draw * 100).toFixed(1) + '%');
console.log('Away win:', (probs.awayWin * 100).toFixed(1) + '%');

Basketball (NBA)

NBA is one of the most data-rich sports for modeling. Key factors:

  • Four Factors: Oliver's Four Factors (eFG%, TO%, ORB%, FT rate) predict team performance with high accuracy when adjusted for opponent quality
  • RAPM/RPM: Regularized Adjusted Plus-Minus metrics measure individual player impact on winning, enabling lineup-based projections
  • Rest advantage: Teams on second night of back-to-back games (B2B) perform measurably worse, and this effect is often underpriced in early-season markets
  • Pace matchup: Fast-paced teams vs. slow teams create over/under betting opportunities when the market underestimates pace impact on total points

Tennis

Tennis is particularly amenable to AI modeling because it is a 1v1 sport with rich historical head-to-head data. Surface-adjusted Elo ratings (separate ratings for hard court, clay, and grass) are the gold standard. Serve speed, first-serve percentage, and break point conversion rates are strong additional signals.

Risk Management Framework for Betting Agents

A comprehensive risk management system for a sports betting AI agent should include the following components:

Maximum Exposure Limits

  • No single bet exceeds 2-5% of bankroll (regardless of Kelly output)
  • Maximum total exposure per sport: 15% of bankroll
  • Maximum total exposure per event: 8% of bankroll
  • Stop-loss trigger: if bankroll drops 30% from peak, halt new bets and review models

Model Confidence Gating

Only place bets when the model's confidence exceeds a minimum threshold. Low-confidence predictions (true probability estimate within 3% of implied probability) should be skipped — the model uncertainty is too large relative to the edge.

}
