OpenAI Agents SDK Overview

The Agents SDK (released early 2025) is OpenAI's framework for building multi-agent systems. It provides three core primitives:

  • Agent — an LLM with instructions and a list of tools it can call
  • Tool — a Python function decorated with @function_tool that the agent can invoke
  • Runner — orchestrates the agent loop: model call → tool call → model call → ...

Tools are defined using Python type annotations and docstrings. The SDK automatically generates JSON schemas and handles the full tool call lifecycle. Agents can also hand off to other agents, enabling modular multi-agent architectures where specialized sub-agents handle distinct domains.

Why Purple Flea + OpenAI Agents SDK?

Purple Flea's REST APIs follow consistent patterns (Bearer token auth, JSON bodies, predictable responses) that map cleanly onto @function_tool definitions. You get a complete financial operating system — casino entertainment, perpetual futures trading, multi-chain wallets, domain registration, gasless faucet funding, and trustless escrow — in under 200 lines of tool definitions.

Function Tool Definitions for Each API

Each Purple Flea API maps onto one or more @function_tool decorated functions. The decorator uses Python type hints and the docstring to auto-generate the JSON schema that OpenAI sends to the model.

Faucet Tool — Claim Free USDC

import httpx
from agents import function_tool
import os

BASE = "https://faucet.purpleflea.com"
HEADERS = {"Authorization": f"Bearer {os.getenv('PURPLE_FLEA_KEY')}"}

@function_tool
async def faucet_claim(wallet_address: str) -> dict:
    """Claim free USDC from the Purple Flea faucet for a new agent wallet.

    Use this tool to bootstrap a new agent with $1 USDC so it can participate
    in Purple Flea services without an initial deposit. Each wallet can claim once.

    Args:
        wallet_address: The agent's EVM wallet address (0x...) to receive USDC.

    Returns:
        dict with keys: success (bool), tx_hash (str), amount_usdc (float).
    """
    async with httpx.AsyncClient() as client:
        r = await client.post(
            f"{BASE}/api/claim",
            json={"wallet": wallet_address},
            headers=HEADERS
        )
        r.raise_for_status()
        return r.json()

@function_tool
async def faucet_register(agent_id: str, wallet_address: str) -> dict:
    """Register a new agent identity with the Purple Flea faucet.

    Registration is required before claiming. Establishes the agent's identity
    on-platform and enables referral tracking.

    Args:
        agent_id: A unique identifier for this agent (e.g. 'trading-bot-001').
        wallet_address: The agent's EVM wallet address (0x...).

    Returns:
        dict with keys: agent_id (str), registered (bool), referral_code (str).
    """
    async with httpx.AsyncClient() as client:
        r = await client.post(
            f"{BASE}/api/register",
            json={"agent_id": agent_id, "wallet": wallet_address},
            headers=HEADERS
        )
        r.raise_for_status()
        return r.json()

Trading Tools — 275+ Perpetual Futures Markets

TRADING_BASE = "https://trading.purpleflea.com"

@function_tool
async def trading_open_position(
    market: str,
    side: str,
    size_usdc: float,
    leverage: int = 1,
    order_type: str = "market",
    limit_price: float | None = None
) -> dict:
    """Open a perpetual futures position on Purple Flea Trading.

    Supports market and limit orders with up to 100x leverage. Markets follow
    the format 'BTC-PERP', 'ETH-PERP', 'SOL-PERP', etc.

    Args:
        market: Market symbol (e.g. 'BTC-PERP', 'ETH-PERP').
        side: 'long' or 'short'.
        size_usdc: Position size in USDC (notional value before leverage).
        leverage: Leverage multiplier 1-100 (default 1x).
        order_type: 'market' or 'limit'.
        limit_price: Required if order_type is 'limit'.

    Returns:
        dict with keys: order_id (str), filled_price (float), size (float),
                        fee_usdc (float), liquidation_price (float).
    """
    payload = {
        "market": market, "side": side, "size": size_usdc,
        "leverage": leverage, "type": order_type
    }
    if limit_price:
        payload["price"] = limit_price
    async with httpx.AsyncClient() as client:
        r = await client.post(
            f"{TRADING_BASE}/api/orders",
            json=payload, headers=HEADERS
        )
        r.raise_for_status()
        return r.json()

@function_tool
async def trading_close_position(order_id: str) -> dict:
    """Close an open perpetual futures position at the current market price.

    Args:

    """

Escrow Tools — Trustless Agent-to-Agent Payments

ESCROW_BASE = "https://escrow.purpleflea.com"

@function_tool
async def escrow_create(
    counterparty_agent_id: str,
    amount_usdc: float,
    description: str,
    timeout_hours: int = 24
) -> dict:
    """Create a trustless escrow contract between this agent and a counterparty.

    The escrow holds funds until both parties confirm completion, or until the
    timeout expires (funds return to depositor). Fee is 1% of escrow amount.
    15% of fees are paid to the referring agent.

    Args:
        counterparty_agent_id: The ID of the agent receiving the escrowed payment.
        amount_usdc: Amount to lock in escrow in USDC.
        description: Human-readable description of the transaction terms.
        timeout_hours: How many hours before the escrow auto-cancels (default 24).

    Returns:
        dict with keys: escrow_id (str), status (str), fee_usdc (float),
                        expires_at (str ISO timestamp).
    """
    async with httpx.AsyncClient() as client:
        r = await client.post(
            f"{ESCROW_BASE}/api/escrow",
            json={
                "counterparty": counterparty_agent_id,
                "amount": amount_usdc,
                "description": description,
                "timeout_hours": timeout_hours
            },
            headers=HEADERS
        )
        r.raise_for_status()
        return r.json()

@function_tool
async def escrow_release(escrow_id: str) -> dict:
    """Release an escrow, confirming that the counterparty completed their obligation.

    Both parties must call release for funds to transfer. If only one party
    releases within the timeout window, arbitration can be invoked.

    Args:
        escrow_id: The escrow contract ID to release.

    Returns:
        dict with keys: released (bool), payout_usdc (float), status (str).
    """
    async with httpx.AsyncClient() as client:
        r = await client.post(
            f"{ESCROW_BASE}/api/escrow/{escrow_id}/release",
            headers=HEADERS
        )
        r.raise_for_status()
        return r.json()

Assembling the Financial Agent

from agents import Agent, Runner

purple_flea_agent = Agent(

    You have access to 6 financial APIs:

    - Casino: Provably fair coin flip and crash games

    a single trade.
    """,
    tools=[
        faucet_register,
        faucet_claim,
        casino_flip_coin,
        casino_crash_bet,
        casino_get_balance,
        trading_open_position,
        trading_close_position,
        trading_get_ticker,
        wallet_get_balance,
        wallet_send,

Streaming Responses

For long-running financial workflows, stream the agent's responses to observe tool calls in real time. The Agents SDK supports streaming via Runner.run_streamed():

from agents import Runner, RunEvent

async def stream_agent(prompt: str):
    stream = Runner.run_streamed(purple_flea_agent, input=prompt)

    async for event in stream.stream_events():
        if event.type == RunEvent.tool_called:
            print(f"[TOOL] {event.tool_name}({event.tool_args})")
        elif event.type == RunEvent.tool_output:
            print(f"[RESULT] {event.output}")
        elif event.type == RunEvent.text_delta:
            print(event.delta, end="", flush=True)

    print()  # newline after streaming
    return stream.final_output

# Example: portfolio rebalancing with live commentary
asyncio.run(stream_agent(
    "Rebalance my portfolio: if BTC-PERP funding rate is positive, go short. "
    "Otherwise open a small long. Use $10 max exposure."
))

Multi-Agent Handoffs

Large financial systems benefit from specialist agents that hand off to each other. The Agents SDK's handoff() function lets a routing agent delegate to domain experts:

from agents import Agent, Runner, handoff

# Specialist agents
casino_specialist = Agent(
    name="CasinoSpecialist",
    instructions="You manage casino gambling strategies. Always use Kelly Criterion sizing.",
    tools=[casino_flip_coin, casino_crash_bet, casino_get_balance]
)

trading_specialist = Agent(
    name="TradingSpecialist",
    instructions="You manage perpetual futures positions. Focus on risk management.",
    tools=[trading_open_position, trading_close_position, trading_get_ticker]
)

payments_specialist = Agent(
    name="PaymentsSpecialist",
    instructions="You handle escrow contracts and inter-agent payments.",
    tools=[escrow_create, escrow_release, wallet_send]
)

# Router agent with handoff capabilities
router = Agent(
    name="FinancialRouter",
    instructions="""You route financial requests to the appropriate specialist.
    - Casino questions → CasinoSpecialist
    - Trading/markets → TradingSpecialist
    - Payments/escrow → PaymentsSpecialist
    Handle simple queries yourself; delegate complex ones.
    """,
    tools=[
        wallet_get_balance,
        faucet_claim,
        handoff(casino_specialist),
        handoff(trading_specialist),
        handoff(payments_specialist),
    ]
)

async def run_router(prompt: str):
    result = await Runner.run(router, input=prompt)
    return result.final_output

Tool Error Handling

Financial API tools must handle errors gracefully. The Agents SDK passes tool exceptions back to the model as error messages, allowing the agent to reason about failures and retry or adapt its strategy. Add robust error handling to each tool:

@function_tool
async def trading_open_position_safe(
    market: str,
    side: str,
    size_usdc: float,
    leverage: int = 1
) -> dict:
    """Open a perpetual futures position with built-in error handling.

    Returns an error dict (not an exception) so the agent can reason about failure.
    """
    try:
        async with httpx.AsyncClient(timeout=10.0) as client:
            r = await client.post(
                f"{TRADING_BASE}/api/orders",
                json={"market": market, "side": side,
                      "size": size_usdc, "leverage": leverage},
                headers=HEADERS
            )
            if r.status_code == 400:
                data = r.json()
                return {"error": True, "reason": data.get("message", "Bad request")}
            elif r.status_code == 429:
                return {"error": True, "reason": "Rate limited — wait 1 minute before retrying"}
            elif r.status_code == 402:
                return {"error": True, "reason": "Insufficient balance — deposit more USDC or claim from faucet"}
            r.raise_for_status()
            return r.json()
    except httpx.TimeoutException:
        return {"error": True, "reason": "Request timed out — markets may be under high load"}
    except httpx.NetworkError as e:
        return {"error": True, "reason": f"Network error: {e}"}

Complete Autonomous Financial Agent

Putting it all together: a self-bootstrapping agent that claims faucet funds, monitors a trading opportunity, places a position, uses escrow to pay a data provider, and reports results:

import asyncio
from agents import Agent, Runner
import httpx, os

# ... (all tool definitions from above) ...

SYSTEM_PROMPT = """
You are a fully autonomous financial agent on Purple Flea.

Startup sequence:
1. Check wallet balance — if below $2 USDC, claim from faucet
2. Check BTC-PERP and ETH-PERP funding rates
3. If any funding rate exceeds 0.05%/hour, open a $10 short to collect funding
4. Set a mental stop-loss at -15% of position value
5. After 4 hours, close position and report P&L

For any service you receive from another agent, use escrow for payment.
Always log every action with its rationale.
"""

agent = Agent(
    name="AutonomousFinAgent",
    instructions=SYSTEM_PROMPT,
    tools=[
        faucet_register, faucet_claim,
        casino_flip_coin, casino_crash_bet, casino_get_balance,
        trading_open_position, trading_close_position, trading_get_ticker,
        wallet_get_balance, wallet_send,
        escrow_create, escrow_release,
        domains_check_availability, domains_register,
    ],
    model="gpt-4o"
)

async def run_autonomous_cycle():
    print("Starting autonomous financial cycle...")
    result = await Runner.run(
        agent,
        input="Execute your startup sequence and report status.",
        max_turns=20
    )
    print("=== AGENT REPORT ===")
    print(result.final_output)
    return result

if __name__ == "__main__":
    asyncio.run(run_autonomous_cycle())

Error handling Return error dicts (not exceptions) so the agent can reason
