What ElizaOS Agents Can Do

From social agent to financial agent

ElizaOS agents already handle Twitter posts, Discord interactions, and web3 wallet queries. The Purple Flea plugin adds financial actions to your agent's toolkit — it becomes a social + financial agent in one character file.

📈

TRADE_PERP action

When a user mentions "buy BTC" or "go long ETH" in your Discord, the TRADE_PERP action calls Purple Flea's trading API and executes the perpetual futures position. Returns fill price and order ID as a formatted message response.

🎰

CASINO_BET action

Trigger casino games from conversation. "Flip a coin for 1 USDC" maps to the CASINO_BET action. The agent places the bet, receives the outcome, and responds in the conversation thread with the result and new balance.

💵

GET_WALLET action

Returns wallet addresses and balances for all 6 chains. Useful when users ask "what's my BTC address" or "how much USDC do I have". The agent fetches from Purple Flea and formats the response for the channel.

👔

CREATE_ESCROW action

When two agents (or a user and an agent) need to transact, CREATE_ESCROW locks funds with Purple Flea. The agent manages the escrow lifecycle: create, monitor, and release — all from natural language commands in the conversation.

Plugin Code

ElizaOS plugin structure for Purple Flea

An ElizaOS plugin exports actions, evaluators, and providers. The Purple Flea plugin exports four actions. Each action has a name, examples, validate function, and handler that calls Purple Flea's REST API.

plugin-purpleflea/src/index.ts — plugin entry and action definitions TypeScript 
import { Plugin, Action, IAgentRuntime, Memory, State } from "@elizaos/core";

const PF_BASE = "https://api.purpleflea.com";

// Helper to call Purple Flea with agent's stored API key
async function pfRequest(
  runtime: IAgentRuntime,
  path: string,
  body: Record<string, unknown>
) {
  const apiKey = runtime.getSetting("PURPLE_FLEA_API_KEY");
  const resp = await fetch(`${PF_BASE}${path}`, {
    method: "POST",
    headers: {
      "Content-Type": "application/json",
      "X-API-Key": apiKey ?? ""
    },
    body: JSON.stringify(body)
  });
  return resp.json();
}

// --- TRADE_PERP action ---
export const tradePerpAction: Action = {
  name: "TRADE_PERP",
  description: "Execute a perpetual futures trade on Purple Flea (275 markets)",
  similes: ["OPEN_POSITION", "PLACE_TRADE", "BUY_PERP", "SELL_PERP"],
  examples: [[
    { user: "user", content: { text: "Buy 0.01 BTC perp" } },
    { user: "agent", content: { text: "Executing BTC-PERP long...", action: "TRADE_PERP" } }
  ]],

  async validate(runtime: IAgentRuntime, message: Memory): Promise<boolean> {
    const hasKey = !!runtime.getSetting("PURPLE_FLEA_API_KEY");
    const text = message.content.text?.toLowerCase() ?? "";
    return hasKey && (
      text.includes("perp") || text.includes("trade") ||
      text.includes("long") || text.includes("short")
    );
  },

  async handler(runtime: IAgentRuntime, message: Memory, state?: State): Promise<boolean> {
    // Parse intent from message text using LLM
    const intent = await runtime.generateObject({
      runtime,
      context: `Extract trade intent from: "${message.content.text}"
               Return JSON: {market, side, size, type}`,
      schema: {
        type: "object",
        properties: {
          market: { type: "string" },  // e.g. "BTC-PERP"
          side: { type: "string" },    // "buy" | "sell"
          size: { type: "number" },
          type: { type: "string", default: "market" }
        }
      }
    });

    const result = await pfRequest(runtime, "/trading/order", intent);

    if (result.order_id) {
      await runtime.messageManager.createMemory({
        userId: runtime.agentId,
        agentId: runtime.agentId,
        roomId: message.roomId,
        content: {
          text: `Executed: ${intent.side} ${intent.size} ${intent.market} at $${result.fill_price?.toFixed(2) ?? "market"}. Order ID: ${result.order_id}`
        }
      });
    }
    return true;
  }
};

// --- CASINO_BET action ---
export const casinoBetAction: Action = {
  name: "CASINO_BET",
  description: "Place a casino bet on Purple Flea (coinflip, dice, crash)",
  similes: ["COIN_FLIP", "ROLL_DICE", "PLAY_CASINO", "GAMBLE"],
  examples: [[
    { user: "user", content: { text: "Flip a coin for $1" } },
    { user: "agent", content: { text: "Flipping coin...", action: "CASINO_BET" } }
  ]],

  async validate(runtime, message): Promise<boolean> {
    const text = message.content.text?.toLowerCase() ?? "";
    return !!runtime.getSetting("PURPLE_FLEA_API_KEY") &&
      (text.includes("coin") || text.includes("dice") || text.includes("casino") || text.includes("gamble"));
  },

  async handler(runtime, message, state?): Promise<boolean> {
    const result = await pfRequest(runtime, "/casino/coinflip",
      { amount: 1, choice: "heads" });

    const outcome = result.won ? `Won $${result.payout.toFixed(2)}` : "Lost $1.00";
    await runtime.messageManager.createMemory({
      userId: runtime.agentId, agentId: runtime.agentId, roomId: message.roomId,
      content: { text: `Casino coinflip: ${outcome}. Balance: $${result.new_balance?.toFixed(2)}` }
    });
    return true;
  }
};

Getting Started

Add Purple Flea to ElizaOS in 4 steps

01

Register on Purple Flea

POST to https://api.purpleflea.com/auth/register. Receive your API key. This becomes the PURPLE_FLEA_API_KEY in your character's settings block.

02

Add plugin to Eliza project

Create packages/plugin-purpleflea/ in your ElizaOS monorepo. Copy the action definitions above. Export the plugin object and add it to your package.json.

03

Update character file

Add "plugin-purpleflea" to the plugins array. Set PURPLE_FLEA_API_KEY in settings. Add the lore entries describing Purple Flea's six services so the LLM knows when to trigger each action.

04

Run and connect clients

Start your Eliza agent with the character file. Connect Discord, Twitter, or Telegram clients. Users can now trigger TRADE_PERP, CASINO_BET, GET_WALLET, and CREATE_ESCROW via natural language.
