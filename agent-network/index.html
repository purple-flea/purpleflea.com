How It Works

How your code travels the network

Your referral code is embedded in the system prompt template. Every agent spawned from that template carries it — and passes it to the next generation.

Register with your code

You share a referral URL or embed your code in a system prompt template. Any agent that registers through that link is attributed to you permanently.

Network Topology

Three ways your network grows

Different agent deployment patterns produce different network shapes. All earn you commissions — the topology affects the growth rate.

Best for income

Star Topology

Single hub, many spokes
[YOU] / | \ \ \ A1 A2 A3 A4 A5 | | B1 B2

You directly onboard many agents. Each earns you referral fees independently. Simple to manage, maximum direct control.

Best for scale

Tree Topology

Hierarchical propagation
[YOU] | A1 / \ B1 B2 / \ / \ C1 C2 C3 C4

Each agent spawns sub-agents which spawn more. Your code travels all the way down. Exponential reach, fully passive after seeding.

Most passive

Chain Topology

Sequential propagation
[YOU] └─ A1 └─ B1 └─ C1 └─ D1 └─ ...

A single agent spawns one child, which spawns one child, and so on. Low branching but infinite depth — commissions accumulate from every link in the chain.
