On-Chain Data Sources

1. On-Chain Data Sources: The Full Stack

On-chain analytics begins with knowing which data to query and from where. The blockchain is public — but the signal is buried in noise. AI agents need to layer multiple data sources to extract actionable information.

Transaction Flow

Raw transaction flow — the sequence of value transfers between addresses — reveals capital velocity. High-frequency transfers between exchange hot wallets and specific addresses often precede large order book moves. Transaction flow analysis tracks:

  • Value transferred per block: sudden volume spikes indicate large participant activity
  • Gas price bidding: aggressive gas pricing signals urgency — a trader front-running a known event
  • Transaction size distribution: shifts toward large transactions indicate institutional activity
  • Frequency patterns: bots show regular cadence; humans show irregular timing

Wallet Clustering

Individual wallet addresses reveal little in isolation. Wallet clustering groups addresses controlled by the same entity — revealing the true scale of a participant's position. Common clustering heuristics:

  • Common input ownership (CIO): wallets funding the same transaction share a controller
  • Change address detection: transaction change outputs often return to the same controller
  • Dust attack analysis: exchange-originated dust reveals exchange wallet clusters
  • Timing correlation: wallets that move in lockstep may belong to the same entity

DEX Volumes

Decentralized exchange volume data is richer than centralized exchange data because every trade is a publicly verifiable on-chain event. For each DEX pool, agents can track:

  • Buy/sell pressure ratios (token flow direction)
  • Liquidity depth changes (LP additions/removals)
  • Slippage-adjusted effective price vs. quoted price
  • Volume concentration (is volume from a few large trades or many small ones?)
  • Cross-DEX arbitrage frequency

Whale Tracking

Whales — wallets controlling large token positions — have outsized market impact. Their moves create predictable price responses. Tracking involves:

  • Balance threshold monitoring (e.g., wallets holding >1,000 ETH)
  • Transfer direction (exchange inflow = potential sell pressure)
  • Accumulation vs. distribution phases
  • Interaction with DeFi protocols (collateral changes signal position adjustments)

ethers.js Event Listener Pattern

For real-time event streams, ethers.js WebSocket providers are highly reliable. This pattern connects to Uniswap V3 swap events for live DEX monitoring:

javascript — dex_event_listener.mjs ethers.js 6.x 
import { ethers } from "ethers";

const WS_URL = "wss://eth-mainnet.g.alchemy.com/v2/YOUR_KEY";

// Uniswap V3 pool ABI (Swap event only)
const POOL_ABI = [
  "event Swap(address indexed sender, address indexed recipient, " +
  "int256 amount0, int256 amount1, uint160 sqrtPriceX96, " +
  "uint128 liquidity, int24 tick)"
];

const USDC_ETH_POOL = "0x88e6A0c2dDD26FEEb64F039a2c41296FcB3f5640";

async function listenDEXSwaps(callback) {
  const provider = new ethers.WebSocketProvider(WS_URL);
  const pool = new ethers.Contract(USDC_ETH_POOL, POOL_ABI, provider);

  pool.on("Swap", (sender, recipient, amount0, amount1, sqrtPriceX96, liquidity, tick, event) => {
    const buyingETH = amount0 < 0n; // negative USDC = USDC out = buying ETH
    const usdcAmount = Math.abs(Number(amount0)) / 1e6;
    const ethAmount = Math.abs(Number(amount1)) / 1e18;
    const effectivePrice = usdcAmount / ethAmount;

    callback({
      type: buyingETH ? "BUY" : "SELL",
      usdcAmount,
      ethAmount,
      effectivePrice,
      tick: Number(tick),
      txHash: event.log.transactionHash,
      blockNumber: event.log.blockNumber,
    });
  });

  console.log(`Listening to Uniswap V3 USDC/ETH swaps on ${USDC_ETH_POOL}`);

  // Reconnect on disconnect
  provider.on("error", (err) => {
    console.error("WS error:", err.message);
    setTimeout(() => listenDEXSwaps(callback), 3000);
  });
}

// Usage
await listenDEXSwaps((swap) => {
  if (swap.usdcAmount > 100_000) {
    console.log(`LARGE SWAP: ${swap.type} $${swap.usdcAmount.toLocaleString()} USDC @ $${swap.effectivePrice.toFixed(2)}`);
  }
});
DEX Price Impact

3. DEX Price Impact Analysis and Optimal Trade Routing

DEX price impact is the price degradation caused by your own order moving the market. For a Uniswap V3 pool, price impact is a function of trade size relative to in-range liquidity. Understanding this is critical for two reasons: avoiding excessive slippage on your own trades, and detecting when others are making large impact trades (a signal in itself).

Price Impact Formula

For a constant product AMM (x*y=k), a trade of size Δx causes: 

# AMM price impact approximation
# For constant product: price_impact ≈ trade_size / (2 * pool_reserves)

def estimate_price_impact(trade_size_usd: float, pool_tvl_usd: float) -> float:
    """
    Estimate price impact percentage for a trade.
    Simplified model for constant product AMMs.
    """
    return (trade_size_usd / (2 * pool_tvl_usd)) * 100

# Example: $1M trade in $50M TVL pool
impact = estimate_price_impact(1_000_000, 50_000_000)
print(f"Estimated price impact: {impact:.2f}%")  # ~1%

Reading Pool State via web3.py

import math
from web3 import Web3

# Uniswap V3 pool interface (slot0 + liquidity)
POOL_ABI = [
    {
        "inputs": [],
        "name": "slot0",
        "outputs": [
            {"name": "sqrtPriceX96", "type": "uint160"},
            {"name": "tick", "type": "int24"},
            {"name": "observationIndex", "type": "uint16"},
            {"name": "observationCardinality", "type": "uint16"},
            {"name": "observationCardinalityNext", "type": "uint16"},
            {"name": "feeProtocol", "type": "uint8"},
            {"name": "unlocked", "type": "bool"},
        ],
        "stateMutability": "view",
        "type": "function",
    },
    {
        "inputs": [],
        "name": "liquidity",
        "outputs": [{"name": "", "type": "uint128"}],
        "stateMutability": "view",
        "type": "function",
    },
]

USDC_ETH_POOL = "0x88e6A0c2dDD26FEEb64F039a2c41296FcB3f5640"

def get_pool_state(w3: Web3, pool_address: str) -> dict:
    pool = w3.eth.contract(
        address=Web3.to_checksum_address(pool_address),
        abi=POOL_ABI
    )
    slot0 = pool.functions.slot0().call()
    liquidity = pool.functions.liquidity().call()

    sqrt_price_x96 = slot0[0]
    # Convert sqrtPriceX96 to ETH/USDC price
    # USDC is token0 (6 decimals), ETH is token1 (18 decimals)
    price = (sqrt_price_x96 / (2 ** 96)) ** 2
    # Adjust for decimal difference: 18 - 6 = 12
    eth_price_usd = price * (10 ** 12)

    return {
        "eth_price_usd": eth_price_usd,
        "tick": slot0[1],
        "in_range_liquidity": liquidity,
        "sqrt_price_x96": sqrt_price_x96,
    }

def calculate_impact(
    trade_size_eth: float,
    pool_state: dict,
    fee_tier: float = 0.0005  # 0.05% fee
) -> dict:
    """
    Calculate price impact of an ETH sell on the USDC/ETH pool.
    Returns impact percentage and expected fill price.
    """
    price = pool_state["eth_price_usd"]
    liquidity = pool_state["in_range_liquidity"]
    trade_usd = trade_size_eth * price

    # Approximate: each 1% price move requires ~2% of in-range liquidity consumed
    # Uniswap V3 in-range liquidity as proxy for TVL
    # Simplified: impact ≈ dx / (x + dx) for constant product segment
    x_eth = liquidity / (2 * price)  # rough ETH side of pool
    impact_pct = (trade_size_eth / (x_eth + trade_size_eth)) * 100
    fill_price = price * (1 - impact_pct / 100)
    total_cost = fee_tier * trade_usd

    return {
        "trade_size_eth": trade_size_eth,
        "trade_usd": trade_usd,
        "market_price": price,
        "impact_pct": impact_pct,
        "fill_price": fill_price,
        "fee_usd": total_cost,
        "all_in_cost_pct": impact_pct + fee_tier * 100,
    }

def find_optimal_route(
    w3: Web3,
    trade_size_eth: float,
    pool_addresses: list[tuple[str, float]]  # (pool_addr, fee_tier)
) -> dict:
    """
    Split a trade across multiple pools to minimize impact.
    Returns optimal allocation per pool.
    """
    states = []
    for addr, fee in pool_addresses:
        state = get_pool_state(w3, addr)
        impact = calculate_impact(trade_size_eth, state, fee)
        states.append((addr, fee, state, impact))

    # Sort by all-in cost (impact + fee)
    states.sort(key=lambda x: x[3]["all_in_cost_pct"])

    # Simple greedy split: route to cheapest pool until impact threshold
    IMPACT_THRESHOLD = 0.5  # 0.5% max per pool
    allocations = {}
    remaining = trade_size_eth

    for addr, fee, state, impact in states:
        if remaining <= 0:
            break
        # How much can this pool absorb under threshold?
        x_eth = state["in_range_liquidity"] / (2 * state["eth_price_usd"])
        max_trade = (IMPACT_THRESHOLD / 100) * x_eth
        allocated = min(remaining, max_trade)
        allocations[addr] = allocated
        remaining -= allocated

    return {
        "allocations": allocations,
        "remaining_unrouted": remaining,
        "pools_used": len(allocations),
    }

# Usage
w3 = Web3(Web3.HTTPProvider("https://eth-mainnet.g.alchemy.com/v2/YOUR_KEY"))
state = get_pool_state(w3, USDC_ETH_POOL)
impact = calculate_impact(trade_size_eth=10.0, pool_state=state)
print(f"ETH price: ${state['eth_price_usd']:.2f}")
print(f"Impact: {impact['impact_pct']:.4f}%")
print(f"Fill price: ${impact['fill_price']:.2f}")
Routing in Practice

Real optimal routing uses 1inch or Paraswap APIs which account for multi-hop routes, V2/V3 pools simultaneously, and gas costs. The pattern above is suitable for understanding impact on a single pool. For production execution, delegate routing to an aggregator and use Purple Flea's trading API for position management.

Whale Tracking

4. Whale Wallet Tracking for Lead Indicator Signals

Whale wallets move markets. When a wallet holding 50,000 ETH sends 5,000 ETH to Coinbase, sell pressure follows within minutes. The key insight: on-chain data gives you a 2-15 minute lead time before the price impact hits the order book, because the token transfer must confirm and exchange processing takes time.

Identifying Whale Wallets

A robust whale list combines multiple sources:

  • Static lists: Etherscan's Top Accounts page, known exchange hot/cold wallets
  • Dynamic detection: any wallet that transacted >500 ETH equivalent in the last 30 days
  • DeFi position holders: Aave/Compound large depositors, Uniswap large LPs
  • VC/fund wallets: identified through Nansen Smart Money labels or Arkham tagging

Exchange Inflow Detection

The most actionable whale signal: a large wallet sends tokens to a known exchange hot wallet. This almost always precedes a sell event within 10-60 minutes.

    "0x3f5CE5FBFe3E9af3971dD833D26bA9b5C936f0bE": "Binance Hot Wallet 1",
    "0xD551234Ae421e3BCBA99A0Da6d736074f22192FF": "Binance Hot Wallet 2",

}

WHALE_THRESHOLD_ETH = 100  # Minimum ETH value to flag as whale move

@dataclass
class WhaleMove:
    from_address: str
    to_address: str
    eth_value: float
    exchange: Optional[str]
    tx_hash: str
    block: int
    timestamp: int
    is_exchange_inflow: bool
    signal_strength: float  # 0-1


class WhaleTracker:
    def __init__(self, w3: Web3, eth_price_usd: float = 3000.0):
        self.w3 = w3
        self.eth_price = eth_price_usd
        self.exchange_set = {
            Web3.to_checksum_address(k): v
            for k, v in EXCHANGE_WALLETS.items()
        }
        self._whale_cache: dict[str, float] = {}  # addr -> balance

    def is_exchange(self, address: str) -> Optional[str]:
        return self.exchange_set.get(Web3.to_checksum_address(address))

    def get_eth_balance(self, address: str) -> float:
        bal_wei = self.w3.eth.get_balance(Web3.to_checksum_address(address))
        return self.w3.from_wei(bal_wei, 'ether')

    def is_whale(self, address: str, min_eth: float = 1000.0) -> bool:
        addr = Web3.to_checksum_address(address)
        if addr not in self._whale_cache:
            self._whale_cache[addr] = self.get_eth_balance(addr)
        return self._whale_cache[addr] >= min_eth

    def score_signal(self, move: dict) -> float:
        """
        Score a whale move from 0-1.
        Factors: size, exchange inflow, source wallet size, speed.
        """
        score = 0.0
        eth_val = move["eth_value"]

        # Size scoring (log scale)
        if eth_val >= 10000: score += 0.4
        elif eth_val >= 1000: score += 0.25
        elif eth_val >= 100: score += 0.1

        # Exchange inflow = sell pressure signal
        if move["is_exchange_inflow"]: score += 0.35

        # Source wallet size
        if self.is_whale(move["from"], min_eth=10000): score += 0.25
        elif self.is_whale(move["from"], min_eth=1000): score += 0.15

        return min(score, 1.0)

    def scan_block_for_whales(self, block_num: int) -> list[WhaleMove]:
        block = self.w3.eth.get_block(block_num, full_transactions=True)
        moves = []

        for tx in block['transactions']:
            eth_val = self.w3.from_wei(tx['value'], 'ether')
            if eth_val < WHALE_THRESHOLD_ETH:
                continue

            from_addr = tx['from']
            to_addr = tx.get('to', '')
            exchange_name = self.is_exchange(to_addr) if to_addr else None
            is_inflow = exchange_name is not None

            move_data = {
                "from": from_addr,
                "to": to_addr,
                "eth_value": float(eth_val),
                "is_exchange_inflow": is_inflow,
            }
            sig_score = self.score_signal(move_data)

            moves.append(WhaleMove(
                from_address=from_addr,
                to_address=to_addr,
                eth_value=float(eth_val),
                exchange=exchange_name,
                tx_hash=tx['hash'].hex(),
                block=block_num,
                timestamp=block['timestamp'],
                is_exchange_inflow=is_inflow,
                signal_strength=sig_score,
            ))

        return moves

    def interpret_moves(self, moves: list[WhaleMove]) -> dict:
        """Aggregate whale moves into a directional signal."""
        exchange_inflows = [m for m in moves if m.is_exchange_inflow]
        total_inflow_eth = sum(m.eth_value for m in exchange_inflows)
        total_volume_eth = sum(m.eth_value for m in moves)
        avg_signal = sum(m.signal_strength for m in moves) / len(moves) if moves else 0

        inflow_ratio = total_inflow_eth / total_volume_eth if total_volume_eth > 0 else 0

        if inflow_ratio > 0.7:
            direction = "BEARISH"
        elif inflow_ratio > 0.4:
            direction = "NEUTRAL"
        else:
            direction = "BULLISH"

        return {
            "total_moves": len(moves),
            "exchange_inflows": len(exchange_inflows),
            "total_inflow_eth": total_inflow_eth,
            "inflow_ratio": inflow_ratio,
            "direction": direction,
            "avg_signal_strength": avg_signal,
        }

class OnChainAnalytics:
    """
    On-chain signal extraction for AI trading agents.

    Usage:
        oca = OnChainAnalytics(provider_url=ALCHEMY_HTTP, eth_price=3200.0)

        # Get whale moves in last 10 blocks
        moves = oca.get_whale_moves(lookback_blocks=10)

        # Get DEX volume snapshot
        volumes = oca.dex_volume(pair="USDC/ETH", hours=1)

        # Cluster a wallet
        cluster = oca.wallet_cluster("0xABC...")
    """

    def __init__(
        self,
        provider_url: str = ALCHEMY_HTTP,
        eth_price: float = 3200.0,
        whale_min_eth: float = 100.0,
        cache_ttl_seconds: int = 60,
    ):
        self.w3 = Web3(Web3.HTTPProvider(provider_url))
        self.eth_price = eth_price
        self.whale_min_eth = whale_min_eth
        self.cache_ttl = cache_ttl_seconds

        # Normalise exchange wallet keys to lowercase for fast lookup
        self._exchanges = {k.lower(): v for k, v in EXCHANGE_WALLETS.items()}

        # Simple in-memory cache
        self._cache: dict[str, tuple[float, object]] = {}

        # Rolling DEX volume for anomaly detection
        self._volume_history: list[float] = []

        logger.info(
            f"OnChainAnalytics init — connected={self.w3.is_connected()}, "
            f"block={self.w3.eth.block_number}"
        )

    # ── Internal helpers ───────────────────────────────────────────────────────

    def _cache_get(self, key: str):
        if key in self._cache:
            ts, val = self._cache[key]
            if time.time() - ts < self.cache_ttl:
                return val
        return None

    def _cache_set(self, key: str, val):
        self._cache[key] = (time.time(), val)

    def _is_exchange(self, addr: str) -> Optional[str]:
        return self._exchanges.get(addr.lower())

    def _eth_balance(self, addr: str) -> float:
        key = f"bal:{addr}"
        cached = self._cache_get(key)
        if cached is not None:
            return cached
        bal = float(self.w3.from_wei(
            self.w3.eth.get_balance(Web3.to_checksum_address(addr)), "ether"
        ))
        self._cache_set(key, bal)
        return bal

    # ── get_whale_moves ────────────────────────────────────────────────────────

    def get_whale_moves(
        self,
        lookback_blocks: int = 5,
        min_value_eth: Optional[float] = None,
    ) -> list[WhaleMove]:
        """
        Scan the most recent `lookback_blocks` blocks for large ETH transfers.
        Returns WhaleMove records sorted by value descending.

        Args:
            lookback_blocks: how many blocks to look back (5 ≈ 60 seconds)
            min_value_eth: override the instance-level whale threshold

        Returns:
            List of WhaleMove dataclasses, each with confidence score.
        """
        threshold = min_value_eth if min_value_eth is not None else self.whale_min_eth
        latest = self.w3.eth.block_number
        start_block = latest - lookback_blocks + 1

        moves: list[WhaleMove] = []

        for block_num in range(start_block, latest + 1):
            try:
                block = self.w3.eth.get_block(block_num, full_transactions=True)
            except Exception as e:
                logger.warning(f"Block {block_num} fetch failed: {e}")
                continue

            for tx in block["transactions"]:
                value_eth = float(self.w3.from_wei(tx["value"], "ether"))
                if value_eth < threshold:
                    continue

                from_addr = tx["from"]
                to_addr = tx.get("to") or ""
                exchange = self._is_exchange(to_addr)

                # Confidence: exchange inflow + large value + known whale source
                conf = 0.3  # base
                if exchange:
                    conf += 0.4
                if value_eth >= 1000:
                    conf += 0.2
                elif value_eth >= 500:
                    conf += 0.1
                try:
                    src_bal = self._eth_balance(from_addr)
                    if src_bal >= 1000:
                        conf += 0.1
                except Exception:
                    pass

                moves.append(WhaleMove(
                    tx_hash=tx["hash"].hex(),
                    from_addr=from_addr,
                    to_addr=to_addr,
                    value_eth=value_eth,
                    value_usd=value_eth * self.eth_price,
                    is_exchange_inflow=bool(exchange),
                    exchange=exchange,
                    block=block_num,
                    confidence=min(conf, 1.0),
                ))

        moves.sort(key=lambda m: m.value_eth, reverse=True)
        logger.debug(f"get_whale_moves: {len(moves)} moves in last {lookback_blocks} blocks")
        return moves

    # ── dex_volume ─────────────────────────────────────────────────────────────

    def dex_volume(
        self,
        pair: str = "USDC/ETH",
        hours: int = 1,
    ) -> DEXVolumeSnapshot:
        """
        Fetch DEX volume data from Uniswap V3 subgraph.
        Computes buy/sell pressure and anomaly score vs rolling mean.

        Args:
            pair: trading pair string (used for display; query targets main pool)
            hours: lookback window for recent volume

        Returns:
            DEXVolumeSnapshot with volume, pressure, and anomaly metrics.
        """
        cache_key = f"dex:{pair}:{hours}"
        cached = self._cache_get(cache_key)
        if cached:
            return cached

        # Uniswap V3 USDC/ETH 0.05% pool
        pool_id = "0x88e6a0c2ddd26feeb64f039a2c41296fcb3f5640"
        ts_cutoff = int(time.time()) - (hours * 3600)

        query = """
        {
          poolHourDatas(
            where: {pool: "%s", periodStartUnix_gte: %d}
            orderBy: periodStartUnix
            orderDirection: desc
            first: 24
          ) {
            periodStartUnix
            volumeUSD
            token0Price
            token1Price
            txCount
          }
        }
        """ % (pool_id, ts_cutoff)

        try:
            resp = requests.post(
                UNISWAP_V3_SUBGRAPH,
                json={"query": query},
                timeout=10,
            )
            resp.raise_for_status()
            data = resp.json()
            hour_data = data.get("data", {}).get("poolHourDatas", [])
        except Exception as e:
            logger.error(f"Subgraph query failed: {e}")
            # Return zero snapshot on failure
            return DEXVolumeSnapshot(
                pool=pool_id, pair=pair,
                volume_usd_1h=0, volume_usd_24h=0,
                buy_pressure=0.5, large_trade_count=0, anomaly_score=0.0
            )

        if not hour_data:
            return DEXVolumeSnapshot(
                pool=pool_id, pair=pair,
                volume_usd_1h=0, volume_usd_24h=0,
                buy_pressure=0.5, large_trade_count=0, anomaly_score=0.0
            )

        vol_1h = float(hour_data[0]["volumeUSD"]) if hour_data else 0
        vol_24h = sum(float(h["volumeUSD"]) for h in hour_data[:24])
        tx_count = sum(int(h["txCount"]) for h in hour_data[:1])

        # Update rolling volume history for anomaly detection
        self._volume_history.append(vol_1h)
        if len(self._volume_history) > 168:  # keep 1 week of hourly data
            self._volume_history.pop(0)

        # Anomaly score: z-score of current vs historical
        if len(self._volume_history) >= 3:
            mean_vol = sum(self._volume_history) / len(self._volume_history)
            std_vol = math.sqrt(
                sum((v - mean_vol) ** 2 for v in self._volume_history)
                / len(self._volume_history)
            )
            anomaly = (vol_1h - mean_vol) / std_vol if std_vol > 0 else 0.0
        else:
            anomaly = 0.0

        # Buy pressure proxy: price change direction
        # If price is higher than 24h ago, net buying
        prices = [float(h["token0Price"]) for h in hour_data]
        if len(prices) >= 2:
            buy_pressure = 0.7 if prices[0] > prices[-1] else 0.3
        else:
            buy_pressure = 0.5

        result = DEXVolumeSnapshot(
            pool=pool_id,
            pair=pair,
            volume_usd_1h=vol_1h,
            volume_usd_24h=vol_24h,
            buy_pressure=buy_pressure,
            large_trade_count=max(0, tx_count // 10),  # rough proxy
            anomaly_score=anomaly,
        )

        self._cache_set(cache_key, result)
        logger.debug(
            f"dex_volume({pair}, {hours}h): "
            f"vol_1h=${vol_1h:,.0f}, anomaly={anomaly:.2f}"
        )
        return result

    # ── wallet_cluster ─────────────────────────────────────────────────────────

    def wallet_cluster(
        self,
        seed_address: str,
        depth: int = 2,
        max_counterparties: int = 20,
    ) -> WalletCluster:
        """
        Build a basic wallet cluster starting from a seed address.
        Uses co-spending heuristics (addresses that transact with the seed)
        to identify potentially related wallets.

        Args:
            seed_address: starting Ethereum address
            depth: graph traversal depth (1 = direct counterparties only)
            max_counterparties: maximum addresses to include in cluster

        Returns:
            WalletCluster with member addresses, balances, and entity label.
        """
        cache_key = f"cluster:{seed_address.lower()}:{depth}"
        cached = self._cache_get(cache_key)
        if cached:
            return cached

        seed = Web3.to_checksum_address(seed_address)
        cluster_members = {seed}
        interaction_counts: dict[str, int] = defaultdict(int)

        # Scan recent transactions FROM seed to find counterparties
        try:
            latest = self.w3.eth.block_number
            lookback = 500  # last ~1.5 hours of blocks

            for block_num in range(
                max(0, latest - lookback), latest, max(1, lookback // 20)
            ):
                block = self.w3.eth.get_block(block_num, full_transactions=True)
                for tx in block["transactions"]:
                    if tx["from"].lower() == seed.lower():
                        if tx.get("to"):
                            interaction_counts[tx["to"]] += 1
                    elif tx.get("to", "").lower() == seed.lower():
                        interaction_counts[tx["from"]] += 1

        except Exception as e:
            logger.warning(f"Cluster scan error: {e}")

        # Sort by interaction frequency, take top N
        top_counterparties = sorted(
            interaction_counts.items(), key=lambda x: x[1], reverse=True
        )[:max_counterparties]

        for addr, count in top_counterparties:
            cluster_members.add(Web3.to_checksum_address(addr))

        # Calculate total balance
        total_bal = 0.0
        for addr in list(cluster_members)[:10]:  # limit RPC calls
            try:
                total_bal += self._eth_balance(addr)
            except Exception:
                pass

        # Entity classification heuristics
        entity_label = self._classify_entity(seed, cluster_members)

        cluster_id = f"cluster_{seed[:8].lower()}"

        result = WalletCluster(
            seed_address=seed,
            cluster_id=cluster_id,
            member_addresses=list(cluster_members),
            total_eth_balance=total_bal,
            entity_label=entity_label,
            confidence=min(0.4 + len(top_counterparties) * 0.02, 0.9),
        )

        self._cache_set(cache_key, result)
        return result

    def _classify_entity(
        self, seed: str, members: set[str]
    ) -> Optional[str]:
        """Heuristic entity classification."""
        # Check if any member is a known exchange
        for addr in members:
            if self._is_exchange(addr):
                return "Exchange"

        # High balance = likely whale or fund
        try:
            bal = self._eth_balance(seed)
            if bal > 10000:
                return "Whale"
            elif bal > 1000:
                return "Large Holder"
        except Exception:
            pass

        # High interaction count in cluster → bot pattern
        if len(members) > 15:
            return "Bot/Automated"

        return "Unknown"

    # ── Convenience aggregate ──────────────────────────────────────────────────

    def full_signal_snapshot(self, lookback_blocks: int = 5) -> dict:
        """
        Returns a combined signal dict suitable for trading decision input.
        """
        whale_moves = self.get_whale_moves(lookback_blocks=lookback_blocks)
        volume = self.dex_volume("USDC/ETH", hours=1)

        exchange_inflows = [m for m in whale_moves if m.is_exchange_inflow]
        inflow_eth = sum(m.value_eth for m in exchange_inflows)
        total_whale_eth = sum(m.value_eth for m in whale_moves)
        inflow_ratio = inflow_eth / total_whale_eth if total_whale_eth > 0 else 0.5

        if inflow_ratio > 0.6:
            whale_signal = "BEARISH"
        elif inflow_ratio < 0.3:
            whale_signal = "BULLISH"
        else:
            whale_signal = "NEUTRAL"

        return {
            "timestamp": int(time.time()),
            "whale": {
                "signal": whale_signal,
                "moves_count": len(whale_moves),
                "exchange_inflows": len(exchange_inflows),
                "inflow_eth": inflow_eth,
                "inflow_ratio": inflow_ratio,
                "top_move_eth": whale_moves[0].value_eth if whale_moves else 0,
            },
            "dex": {
                "volume_1h_usd": volume.volume_usd_1h,
                "volume_24h_usd": volume.volume_usd_24h,
                "buy_pressure": volume.buy_pressure,
                "anomaly_score": volume.anomaly_score,
                "volume_spike": volume.anomaly_score > 2.0,
            },
            "composite": {
                "sentiment": (
                    "BEARISH" if whale_signal == "BEARISH" and volume.buy_pressure < 0.4
                    else "BULLISH" if whale_signal == "BULLISH" and volume.buy_pressure > 0.6
                    else "NEUTRAL"
                ),
            },
        }

6. Smart Money Following: Copying Wallet Patterns Profitably

"Smart money" refers to consistently profitable wallets — usually professional traders, quantitative funds, or informed insiders. Copy trading on-chain differs from traditional copy trading: you copy at the transaction level before the trade is even processed, potentially front-running on the same block.

Identifying Smart Money Wallets

Smart money wallets share identifiable patterns:

  • Consistent PnL across market conditions: profitable in both bull and bear markets
  • Early entry on tokens before major moves: buy 30+ days before breakouts
  • Low frequency, high conviction: few large trades rather than many small ones
  • DeFi protocol expertise: complex interactions with yield protocols, early protocol deployments

Exchange Flow Sentiment

7. On-Chain Sentiment: Exchange Inflow/Outflow as Fear/Greed Indicator

Exchange net flows are one of the most reliable on-chain sentiment indicators. The logic is simple:

  • Net inflow (more tokens sent to exchanges): holders preparing to sell — bearish pressure
  • Net outflow (more tokens leaving exchanges): traders taking self-custody — bullish accumulation signal

Exchange flow analysis is particularly powerful as a lead indicator: the inflow often precedes selling by 30-90 minutes, giving agents a meaningful execution window.

Interpreting the Signal

⬇ High Inflow = Sell Pressure

Large net inflow (ETH/BTC/stablecoins flowing TO exchanges) indicates large holders are preparing to sell. Combined with high DEX buy pressure, this can signal a local top being distributed.

⬆ High Outflow = Accumulation

Net outflow (tokens leaving exchanges to self-custodied wallets) signals institutional accumulation or retail holding conviction. This often precedes upward price pressure. Extremely reliable at market cycle bottoms.

}

def compute_exchange_flows(
    w3: Web3,
    lookback_blocks: int = 100,
    eth_price_usd: float = 3200.0
) -> dict:
    """
    Compute net exchange ETH inflow/outflow over the last N blocks.

    Returns dict with:
      - net_flow_eth: positive = inflow, negative = outflow
      - inflow_eth: total sent TO exchanges
      - outflow_eth: total received FROM exchanges
      - sentiment: 'FEAR' | 'GREED' | 'NEUTRAL'
      - signal_strength: 0-1
    """
    latest = w3.eth.block_number
    start = max(0, latest - lookback_blocks)

    inflow_eth = 0.0
    outflow_eth = 0.0
    large_moves = []

    for block_num in range(start, latest + 1):
        try:
            block = w3.eth.get_block(block_num, full_transactions=True)
        except Exception:
            continue

        for tx in block["transactions"]:
            val_eth = float(w3.from_wei(tx["value"], "ether"))
            if val_eth < 1.0:
                continue

            to_addr = (tx.get("to") or "").lower()
            from_addr = tx["from"].lower()
            to_exchange = to_addr in EXCHANGE_ADDRESSES
            from_exchange = from_addr in EXCHANGE_ADDRESSES

            if to_exchange and not from_exchange:
                inflow_eth += val_eth
                if val_eth > 50:
                    large_moves.append({"dir": "IN", "eth": val_eth, "tx": tx["hash"].hex()})
            elif from_exchange and not to_exchange:
                outflow_eth += val_eth

    net_flow = inflow_eth - outflow_eth
    total_flow = inflow_eth + outflow_eth

    # Sentiment classification
    if total_flow == 0:
        sentiment = "NEUTRAL"
        strength = 0.0
    else:
        inflow_ratio = inflow_eth / total_flow
        if inflow_ratio > 0.65:
            sentiment = "FEAR"    # lots of inflow → holders selling
            strength = min((inflow_ratio - 0.65) / 0.35, 1.0)
        elif inflow_ratio < 0.35:
            sentiment = "GREED"   # lots of outflow → accumulation
            strength = min((0.35 - inflow_ratio) / 0.35, 1.0)
        else:
            sentiment = "NEUTRAL"
            strength = 0.0

    return {
        "blocks_scanned": lookback_blocks,
        "inflow_eth": inflow_eth,
        "inflow_usd": inflow_eth * eth_price_usd,
        "outflow_eth": outflow_eth,
        "outflow_usd": outflow_eth * eth_price_usd,
        "net_flow_eth": net_flow,
        "sentiment": sentiment,
        "signal_strength": strength,
        "large_inflows": len([m for m in large_moves if m["dir"] == "IN"]),
        "top_inflow_txns": sorted(large_moves, key=lambda x: x["eth"], reverse=True)[:3],
    }

class PurpleFleatOnChainAgent:

    """

        self,

        Returns action taken and signal data.
        """

        # Score the opportunity
        score = 0.0
        trade_side = None

        if composite == "BEARISH":
            score = 0.5 + inflow_ratio * 0.3 + (0.1 if volume_spike else 0)
            trade_side = "short"
        elif composite == "BULLISH":
            score = 0.5 + (1 - inflow_ratio) * 0.3 + (0.1 if volume_spike else 0)
            trade_side = "long"

        action = "NO_TRADE"
        order_result = {}

        if score >= self.signal_threshold and trade_side:
            size_usd = 500 * score  # scale position size by confidence
            order_result = self._open_position(trade_side, size_usd)
            action = f"OPEN_{trade_side.upper()}"
            logger.info(
                f"Signal: {composite} | Score: {score:.2f} | "
                f"Side: {trade_side} | Size: ${size_usd:.0f}"
            )

        return {
            "timestamp": int(time.time()),
            "action": action,
            "signal_score": score,
            "composite": composite,
            "whale": snapshot["whale"],
            "dex": snapshot["dex"],
            "order": order_result,
        }

    async def run(self, interval_seconds: int = 60):
        """Main agent loop."""
        logger.info("PurpleFleat OnChain Agent starting...")
        while True:
            try:
                result = self.evaluate_and_trade()
                logger.info(f"Cycle: action={result['action']} composite={result['composite']}")
            except Exception as e:
                logger.error(f"Cycle error: {e}", exc_info=True)
            await asyncio.sleep(interval_seconds)


async def main():
    agent = PurpleFleatOnChainAgent(
        api_key=PF_API_KEY,
        signal_threshold=0.65,
        cooldown_seconds=300,
    )
    await agent.run(interval_seconds=60)


if __name__ == "__main__":
    logging.basicConfig(
        level=logging.INFO,
        format="%(asctime)s %(levelname)s %(name)s — %(message)s"
    )
    asyncio.run(main())

Summary: Building Your On-Chain Edge

On-chain analytics gives AI trading agents structural advantages that no centralized data feed can replicate. The key layers covered in this guide:

  • Data sources: Alchemy/Infura for real-time RPC, The Graph for DEX data, Etherscan for wallet history, CryptoQuant for exchange flows
  • Whale tracking: get_whale_moves() scans recent blocks for large ETH transfers to exchange wallets, generating bearish signals with confidence scoring
  • DEX volume: dex_volume() queries the Uniswap V3 subgraph for volume, buy/sell pressure, and statistical anomaly detection
  • Wallet clustering: wallet_cluster() groups counterparty addresses to reveal entity-level position sizes and entity classification
  • Smart money following: maintain a watchlist of historically profitable wallets and generate copy-trade signals when they move
  • Exchange flow sentiment: net inflow = fear/selling pressure; net outflow = greed/accumulation; reliable 30-90 minute lead indicator
  • Purple Flea execution: the PurpleFleatOnChainAgent class connects all signals to live order placement with cooldown protection and confidence-scaled sizing

The OnChainAnalytics class is a production-ready foundation. Extend it with your own signal sources, tune confidence thresholds through backtesting, and register at Purple Flea to connect to live execution infrastructure.
