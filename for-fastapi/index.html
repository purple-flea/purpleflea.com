Pattern 1

Middleware: Bill Every Request Automatically

The simplest integration: add PurpleFleatMiddleware to your FastAPI app and every request — regardless of route — is automatically billed. The middleware intercepts incoming requests, locks a USDC escrow, forwards the request to your handler, then releases the escrow on success or cancels it on error.

The caller must include their Purple Flea agent ID in the X-Agent-ID header and maintain a sufficient USDC balance. Insufficient balance returns a 402 Payment Required before your handler is ever invoked.

  • Zero changes to your existing route handlers
  • Configurable per-request rate (per_request_usdc)
  • Optional route exclusions (health checks, docs)
  • Automatic 402 on insufficient balance
middleware_setup.py 
from fastapi import FastAPI, Request, Response
from starlette.middleware.base import BaseHTTPMiddleware
import httpx

ESCROW_BASE = "https://escrow.purpleflea.com/api"

class PurpleFleatMiddleware(BaseHTTPMiddleware):
    def __init__(self, app, api_key: str, per_request_usdc: float = 0.001,
                 exclude_paths: list[str] = None):
        super().__init__(app)
        self.api_key = api_key
        self.rate = per_request_usdc
        self.exclude = exclude_paths or ["/health", "/docs", "/openapi.json"]
        self._http = httpx.AsyncClient(
            base_url=ESCROW_BASE,
            headers={"Authorization": f"Bearer {api_key}"},
        )

    async def dispatch(self, request: Request, call_next) -> Response:
        if request.url.path in self.exclude:
            return await call_next(request)

        agent_id = request.headers.get("X-Agent-ID")
        if not agent_id:
            return Response('{"error":"X-Agent-ID header required"}',
                           status_code=401, media_type="application/json")

        # Lock escrow before processing
        try:
            r = await self._http.post("/escrow", json={
                "payer_agent_id": agent_id,
                "payee_agent_id": "api_service_agent",
                "amount_usdc": self.rate,
                "metadata": {"path": request.url.path, "method": request.method},
            })
            if r.status_code == 402:
                return Response('{"error":"Insufficient USDC balance"}',
                               status_code=402, media_type="application/json")
            r.raise_for_status()
            escrow_id = r.json()["escrow_id"]
        except Exception:
            return Response('{"error":"Payment service unavailable"}',
                           status_code=503, media_type="application/json")

        # Process the request
        try:
            response = await call_next(request)
            # Release escrow on success (2xx)
            if response.status_code < 400:
                await self._http.post(f"/escrow/{escrow_id}/release")
            else:
                await self._http.post(f"/escrow/{escrow_id}/cancel",
                                      json={"reason": f"HTTP {response.status_code}"})
            return response
        except Exception as e:
            await self._http.post(f"/escrow/{escrow_id}/cancel",
                                  json={"reason": str(e)})
            raise

# Usage:

import httpx

_client = httpx.AsyncClient(
    base_url="https://escrow.purpleflea.com/api",
    headers={"Authorization": "Bearer pf_live_your_key_here"},
)

async def purple_flea_billing(
    rate_usdc: float,
    x_agent_id: str = Header(...),
    x_service_agent: str = "api_service_agent",
) -> str:
    """Dependency that locks a USDC escrow for this request.
    Returns the escrow_id; caller is responsible for releasing it.
    """
    r = await _client.post("/escrow", json={
        "payer_agent_id": x_agent_id,

    })
    if r.status_code == 402:
        raise HTTPException(status_code=402, detail="Insufficient USDC balance")
    r.raise_for_status()
    return r.json()["escrow_id"]

Pattern 2

Dependency Injection: Per-Route Billing Rates

The middleware bills every route at a flat rate. For granular control, use FastAPI's dependency injection system instead. Wrap purple_flea_billing with functools.partial to create rate-specific dependencies and inject them with Depends().

This pattern gives you full control at the route level:

  • Cheap operations (lookups, reads) bill at low rates
  • Expensive operations (LLM calls, compute jobs) bill at higher rates
  • Unauthenticated or internal routes can skip billing entirely
  • Different API tiers can use different rate constants
Rate Calculation Tip

Set your per-request rate to cover your marginal compute cost plus a margin. For LLM endpoints, charge by token count rather than flat-per-request — the background task pattern below shows how to calculate final cost after the fact and adjust the escrow release amount accordingly.

Pattern 3

Background Tasks: Async Payment Settlement

For time-sensitive endpoints, you want to return a response immediately without waiting for escrow settlement. FastAPI's BackgroundTasks system lets you settle payments after the response is sent — your handler adds a settlement task before returning, and FastAPI runs it post-response.

This is especially useful for endpoints where the final charge depends on output size — e.g., billing per token for an LLM response. The handler can compute the exact token count from the response, then settle the precise USDC amount as a background task.

  • Zero latency impact on endpoint response time
  • Final charge calculated from actual output (tokens, bytes, items)
  • Failed settlement retried with exponential backoff
  • Audit log of all settlements for reconciliation
background_settle.py 
from fastapi import BackgroundTasks, Header
import httpx, asyncio, math

_client = httpx.AsyncClient(
    base_url="https://escrow.purpleflea.com/api",
    headers={"Authorization": "Bearer pf_live_your_key_here"},
)
USDC_PER_1K_TOKENS = 0.002

async def settle_by_tokens(escrow_id: str, token_count: int, retries: int = 3):
    """Background task: release escrow for exact token-based charge."""
    final_usdc = math.ceil(token_count / 1000 * USDC_PER_1K_TOKENS * 1e6) / 1e6
    for attempt in range(retries):
        try:
            await _client.post(f"/escrow/{escrow_id}/release",
                               json={"final_amount_usdc": final_usdc})
            return
        except Exception:
            if attempt < retries - 1:
                await asyncio.sleep(2 ** attempt)

@app.post("/llm")
async def llm_endpoint(

@app.get("/stream")
async def stream_response(prompt: str, x_agent_id: str = Header(...)):
    """Charge per SSE chunk delivered."""
    chunk_count = 0
    chunk_escrows: list[str] = []

    async def generate():
        nonlocal chunk_count
        async for chunk in stream_from_llm(prompt):
            # Bill $0.0001 per chunk
            r = await _client.post("/escrow", json={
                "payer_agent_id": x_agent_id,
                "payee_agent_id": "stream_service",
                "amount_usdc": 0.0001,
                "metadata": {"chunk": chunk_count},
            })
            if r.status_code == 402:
                yield "data: {\"error\": \"balance_exhausted\"}\n\n"
                return
            eid = r.json()["escrow_id"]
            yield f"data: {chunk}\n\n"
            # Release after chunk is yielded (delivered)
            await _client.post(f"/escrow/{eid}/release")
            chunk_count += 1

    return StreamingResponse(generate(), media_type="text/event-stream")

@app.websocket("/ws/{agent_id}")
async def ws_endpoint(websocket: WebSocket, agent_id: str):
    await websocket.accept()
    try:
        while True:
            data = await websocket.receive_text()
            # Lock escrow per message received
            r = await _client.post("/escrow", json={
                "payer_agent_id": agent_id,
                "payee_agent_id": "ws_service",
                "amount_usdc": 0.001,
            })
            if r.status_code == 402:
                await websocket.send_json({"error": "balance_exhausted"})
                break
            eid = r.json()["escrow_id"]
            response = await process_ws_message(data)
            await websocket.send_text(response)
            await _client.post(f"/escrow/{eid}/release")

Pattern 4

WebSocket & SSE: Per-Chunk Streaming Payments

For LLM streaming endpoints, flat per-request pricing is economically incorrect: a 50-token response and a 5,000-token response cost the same to the caller but wildly different amounts to serve. Per-chunk billing aligns incentives correctly.

The pattern works for both Server-Sent Events (SSE) and WebSocket streams:

  • Each SSE chunk or WebSocket message creates a micro-escrow ($0.0001–$0.001)
  • The escrow is released immediately after the chunk is sent
  • If the caller's balance is exhausted mid-stream, the stream closes cleanly with a balance_exhausted event
  • No chunk is delivered before its payment is locked — eliminating the risk of free-riders
Micro-Escrow Batching

For very high-frequency streams (>10 chunks/second), consider batching micro-escrows: lock a $0.01 escrow covering the next 100 chunks, then release pro-rata after each chunk is confirmed. This reduces API call overhead while maintaining per-chunk pricing semantics.

Pattern 5

Deposit-Based Rate Limiting: Escrow as Access Control

Traditional rate limiting uses IP addresses or API keys, both of which can be rotated by bad actors. Escrow-based access control uses economic skin-in-the-game: to access your endpoint, a caller must lock a USDC deposit up front. If they behave, the deposit is returned. If they abuse the endpoint, the deposit is forfeited.

This pattern is highly effective against DDoS from agent swarms: a swarm of 1,000 agents each needs $1 USDC in escrow, requiring $1,000 upfront capital commitment before a single request fires. Honest agents get their deposits back. Malicious agents forfeit everything.

  • Deposit held for the duration of a session or time window
  • Returned automatically at session end if no violations
  • Forfeited on excessive error rates, rapid bursting, or policy violations
  • Deposit size scales with requested rate limit tier
deposit_rate_limit.py 
from fastapi import HTTPException, Header
from datetime import datetime, timedelta, timezone
import httpx, asyncio
from collections import defaultdict

_client = httpx.AsyncClient(
    base_url="https://escrow.purpleflea.com/api",
    headers={"Authorization": "Bearer pf_live_your_key_here"},
)

# Track active deposits and request counts per agent
_deposits: dict[str, dict] = {}
_request_counts: dict[str, int] = defaultdict(int)
DEPOSIT_AMOUNT_USDC = 1.00
SESSION_DURATION_MINUTES = 60
MAX_REQUESTS_PER_SESSION = 500

async def require_deposit(x_agent_id: str = Header(...)) -> str:
    """Dependency: require $1 USDC deposit for session access."""
    now = datetime.now(timezone.utc)

    # Check if agent has an active session deposit
    if x_agent_id in _deposits:
        session = _deposits[x_agent_id]
        if session["expires"] > now:
            # Session valid — check request quota
            if _request_counts[x_agent_id] >= MAX_REQUESTS_PER_SESSION:
                raise HTTPException(429, detail="Session quota exhausted")
            _request_counts[x_agent_id] += 1
            return x_agent_id

    # New session: require fresh deposit
    r = await _client.post("/escrow", json={
        "payer_agent_id": x_agent_id,
        "payee_agent_id": "api_service_agent",
        "amount_usdc": DEPOSIT_AMOUNT_USDC,
        "metadata": {"type": "session_deposit"},
    })
    if r.status_code == 402:
        raise HTTPException(402, detail="Insufficient balance for session deposit")
    r.raise_for_status()
    escrow_id = r.json()["escrow_id"]

    _deposits[x_agent_id] = {
        "escrow_id": escrow_id,
        "expires": now + timedelta(minutes=SESSION_DURATION_MINUTES),
    }
    _request_counts[x_agent_id] = 1

    # Schedule deposit return at session end
    asyncio.create_task(return_deposit_at_expiry(x_agent_id, escrow_id))
    return x_agent_id

async def return_deposit_at_expiry(agent_id: str, escrow_id: str):
    await asyncio.sleep(SESSION_DURATION_MINUTES * 60)
    if agent_id in _deposits:
        del _deposits[agent_id]
        del _request_counts[agent_id]
    await _client.post(f"/escrow/{escrow_id}/release")  # return deposit

# Route using deposit guard
@app.get("/premium-data")
async def premium_data(agent_id: str = Depends(require_deposit)):
    return {"data": "expensive dataset", "billed_to": agent_id}

FastAPI + LangChain + Purple Flea: Full Stack Example

Build a monetized LLM API service: LangChain handles the model orchestration, FastAPI handles the HTTP layer, and Purple Flea handles billing — all three integrated in under 80 lines.

full_stack_app.py 
from fastapi import FastAPI, Header, HTTPException, BackgroundTasks
from pydantic import BaseModel
from langchain_openai import ChatOpenAI
from langchain_core.messages import HumanMessage
import httpx, os

app = FastAPI(title="Monetized LLM API", description="Purple Flea billed LangChain service")

PF_CLIENT = httpx.AsyncClient(
    base_url="https://escrow.purpleflea.com/api",
    headers={"Authorization": "Bearer pf_live_your_key_here"},
)
LLM = ChatOpenAI(model="gpt-4o-mini", temperature=0.7)

class GenerateRequest(BaseModel):
    prompt: str
    max_tokens: int = 500
    referral_code: str | None = None   # caller's referral code

async def lock_escrow(agent_id: str, amount: float, referral: str | None = None) -> str:
    payload = {
        "payer_agent_id": agent_id,
        "payee_agent_id": "llm_service_agent",
        "amount_usdc": amount,
    }
    if referral:
        payload["referral_code"] = referral
    r = await PF_CLIENT.post("/escrow", json=payload)
    if r.status_code == 402:
        raise HTTPException(402, "Insufficient USDC balance. Claim free USDC at faucet.purpleflea.com")
    r.raise_for_status()
    return r.json()["escrow_id"]

async def settle(escrow_id: str, actual_usdc: float):
    await PF_CLIENT.post(f"/escrow/{escrow_id}/release", json={"final_amount_usdc": actual_usdc})

@app.post("/generate")
async def generate(
    body: GenerateRequest,
    background_tasks: BackgroundTasks,
    x_agent_id: str = Header(...),
):
    # Bill ceiling: $0.05 max (will adjust to actual token cost)
    escrow_id = await lock_escrow(x_agent_id, 0.05, body.referral_code)

    # Run LangChain LLM
    response = await LLM.ainvoke([HumanMessage(content=body.prompt)])
    output_text = response.content
    token_count = response.usage_metadata.get("output_tokens", len(output_text.split()))

    # Calculate actual USDC cost: $0.002 per 1K output tokens
    actual_usdc = round(token_count / 1000 * 0.002, 6)

    # Return response immediately; settle payment in background
    background_tasks.add_task(settle, escrow_id, actual_usdc)

    return {
        "text": output_text,
        "tokens": token_count,
        "charged_usdc": actual_usdc,
        "billed_to": x_agent_id,
    }

@app.get("/health")
async def health():
    return {"status": "ok", "billing": "purple_flea_escrow"}
