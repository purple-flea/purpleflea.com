Quick Start

ReActAgent with full financial tooling

Wrap Purple Flea functions with FunctionTool.from_defaults and hand the list to ReActAgent.from_tools. The agent uses chain-of-thought reasoning to decide which tool to call, validates arguments, executes the function, and incorporates the result into its next reasoning step — all automatically.

agent.py 
import os
from llama_index.core.agent import ReActAgent
from llama_index.core.tools import FunctionTool
from llama_index.llms.openai  import OpenAI
from purpleflea               import PurpleFleas

# Initialise Purple Flea SDK
flea = PurpleFleas(api_key=os.getenv("PURPLE_FLEA_API_KEY"))

# Wrap each capability as a LlamaIndex FunctionTool
tools = [
    FunctionTool.from_defaults(
        fn=flea.wallet.create,
        name="create_wallet",
        description="Create a new crypto wallet on Ethereum, Solana, Tron or Bitcoin"
    ),
    FunctionTool.from_defaults(
        fn=flea.wallet.get_balance,
        name="get_balance",
        description="Return the current USDC and native token balance for a wallet"
    ),
    FunctionTool.from_defaults(
        fn=flea.trading.open_position,
        name="open_trade",
        description="Open a leveraged perpetual futures position on Hyperliquid"
    ),
    FunctionTool.from_defaults(
        fn=flea.trading.get_price,
        name="get_price",
        description="Fetch real-time mid-market price for any crypto asset"
    ),
    FunctionTool.from_defaults(
        fn=flea.casino.coin_flip,
        name="casino_flip",
        description="Flip a coin for USDC on the provably-fair Purple Flea casino"
    ),
    FunctionTool.from_defaults(
        fn=flea.domains.register,
        name="register_domain",
        description="Register a crypto or traditional domain name for the agent"
    ),
]

# Build the ReAct agent
agent = ReActAgent.from_tools(
    tools,
    llm=OpenAI(model="gpt-4o"),
    verbose=True,
    max_iterations=10,
)

response = agent.chat(
    "Create an Ethereum wallet, check its balance, and open a 2x BTC long"
)
print(response)

RAG + Finance

Combine vector search with live on-chain signals

LlamaIndex's native strength is retrieval-augmented generation. Purple Flea extends that strength into real-world financial execution. Your agent can simultaneously query a document index for context and execute live trades based on what it finds.

Retrieval layer

Index your internal research notes, news feeds, on-chain analytics reports, or trading strategy documents in LlamaIndex's vector store. The agent retrieves relevant context before every decision, ensuring trades and wagers are grounded in your data rather than hallucinated signals.

  • Query on-chain analytics from indexed PDFs before placing a trade
  • Retrieve historical casino results to inform bet sizing
  • Pull domain research notes before registering a new name
  • Index agent-to-agent escrow logs for auditability

Execution layer

After retrieval, Purple Flea tools execute the action. No manual glue code, no hand-rolled API clients — the FunctionTool wrappers handle auth, retry, input validation, and structured JSON output automatically. The agent receives a typed result it can reason over in the next ReAct step.

  • Open Hyperliquid perpetuals based on retrieved price targets
  • Fund an escrow from retrieved agent-to-agent contract terms
  • Claim faucet tokens when wallet balance is detected as zero
  • Register domains discovered in indexed brand strategy docs
rag_trading_agent.py 
from llama_index.core import VectorStoreIndex, SimpleDirectoryReader
from llama_index.core.agent import ReActAgent
from llama_index.core.tools import QueryEngineTool, FunctionTool
from purpleflea import PurpleFleas

flea  = PurpleFleas(api_key=os.getenv("PURPLE_FLEA_API_KEY"))
docs  = SimpleDirectoryReader("./market-research").load_data()
index = VectorStoreIndex.from_documents(docs)

# RAG tool: search internal research docs
research_tool = QueryEngineTool.from_defaults(
    query_engine=index.as_query_engine(),
    name="market_research",
    description="Search internal market research for trading signals"
)

# Execution tools: live on-chain actions
exec_tools = [
    FunctionTool.from_defaults(fn=flea.trading.get_price,    name="get_price"),
    FunctionTool.from_defaults(fn=flea.trading.open_position, name="open_trade"),
    FunctionTool.from_defaults(fn=flea.wallet.get_balance,   name="get_balance"),
]

agent = ReActAgent.from_tools(
    [research_tool, *exec_tools],
    verbose=True
)

# The agent retrieves research, then executes the trade
agent.chat("What does our research say about ETH this week? Act on it.")
