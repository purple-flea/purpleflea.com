Direct HTTP Integration
The simplest path: call replicate.run() in Python, receive the model's output, parse it to extract the financial action, and immediately POST to the relevant Purple Flea endpoint. No queues, no webhooks, no infrastructure — just two HTTP calls. Ideal for synchronous agents that run on a schedule.
🔔
Webhook-Based Async Flow
For long-running predictions (fine-tuned models, large context windows), use Replicate's webhook parameter. Your handler receives the completed prediction, parses the action, and calls Purple Flea. Scales to high-volume operations where many predictions are in-flight simultaneously without blocking.

1. Llama-Based Trading Agent

Python replicate_trader.py 
import replicate
import requests, json, os
from datetime import datetime

PF_KEY     = os.environ["PURPLEFLEA_API_KEY"]
PF_BASE    = "https://purpleflea.com/api/v1"
PF_HEADERS = {
    "Authorization": f"Bearer {PF_KEY}",
    "Content-Type": "application/json"
}

def get_market_data(symbol: str) -> dict:
    # Fetch live market data from Purple Flea
    r = requests.get(f"{PF_BASE}/trading/market/{symbol}", headers=PF_HEADERS)
    r.raise_for_status()
    return r.json()

def get_model_decision(market: dict) -> dict:
    # Ask Llama 3.1 to make a trading decision based on market data
    prompt = f"""You are a disciplined crypto trading agent. Analyze this market data and return a JSON trading decision.

Market: {market['symbol']}
Price: ${market['price']:,.2f}
24h Change: {market.get('change_24h', 0):.2f}%
Volume 24h: ${market.get('volume_24h', 0):,.0f}
RSI(14): {market.get('rsi', 'N/A')}
Funding Rate: {market.get('funding_rate', 0):.4%}

Return ONLY valid JSON:
{{"action": "buy"|"sell"|"hold", "size_usd": number, "leverage": 1-10, "reason": "brief string"}}"""

    output = replicate.run(
        "meta/llama-3.1-405b-instruct",
        input={
            "prompt": prompt,
            "max_new_tokens": 200,
            "temperature": 0.1,
            "system_prompt": "You are a quantitative trading agent. Always respond with valid JSON only."
        }
    )

    raw = "".join(output).strip()
    if raw.startswith("```"):
        raw = raw.split("```")[1].lstrip("json").strip()
    return json.loads(raw)

def execute_decision(symbol: str, decision: dict) -> dict:
    if decision["action"] == "hold":
        print(f"  HOLD {symbol}. Reason: {decision.get('reason', 'N/A')}")
        return {"status": "hold"}

    order = {
        "market":     f"{symbol}-PERP",
        "side":       "buy" if decision["action"] == "buy" else "sell",
        "size_usd":   min(decision.get("size_usd", 50), 500),  # Risk cap
        "leverage":   decision.get("leverage", 1),
        "order_type": "market",
        "metadata":   {"source": "replicate", "reason": decision.get("reason")}
    }
    r = requests.post(f"{PF_BASE}/trading/order", json=order, headers=PF_HEADERS)
    result = r.json()
    print(f"  Trade: {decision['action'].upper()} {symbol} | "
          f"size=${order['size_usd']} | {result.get('status')}")
    return result

def run_agent(symbols: list):
    print(f"Agent cycle: {datetime.utcnow().isoformat()}")
    for symbol in symbols:
        try:
            market   = get_market_data(symbol)
            decision = get_model_decision(market)
            result   = execute_decision(symbol, decision)
            print(f"  [{symbol}] {decision['action']} -> {result.get('status')}")
        except Exception as e:
            print(f"  [{symbol}] Error: {e}")

if __name__ == "__main__":
    run_agent(["BTC", "ETH", "SOL"])

2. Webhook-Based Async Agent

Python replicate_webhook.py 
import replicate
import requests, json, os
from fastapi import FastAPI, Request
from fastapi.responses import JSONResponse

app       = FastAPI()
PF_KEY    = os.environ["PURPLEFLEA_API_KEY"]
PF_BASE   = "https://purpleflea.com/api/v1"
PF_HEADS  = {"Authorization": f"Bearer {PF_KEY}", "Content-Type": "application/json"}

# Kick off an async Replicate prediction with webhook callback
def start_prediction(market_data: dict, webhook_url: str):
    prompt = f"Market data: {json.dumps(market_data)}. Return JSON: {{action, size_usd, leverage, reason}}"
    prediction = replicate.predictions.create(
        model="meta/llama-3.1-405b-instruct",
        input={
            "prompt": prompt,
            "max_new_tokens": 150,
            "temperature": 0.05
        },
        webhook=webhook_url,
        webhook_events_filter=["completed"]  # Only notify on completion
    )
    print(f"Prediction {prediction.id} started asynchronously.")
    return prediction.id

# Handle Replicate webhook callback — fires when prediction completes
@app.post("/webhook/replicate")
async def handle_prediction(request: Request):
    body     = await request.json()
    status   = body.get("status")
    output   = body.get("output", [])

    if status != "succeeded" or not output:
        return JSONResponse({"skipped": True, "reason": status})

    try:
        raw      = "".join(output).strip()
        decision = json.loads(raw)

        if decision["action"] == "hold":
            return JSONResponse({"action": "hold"})

        order = {
            "side":      "buy" if decision["action"] == "buy" else "sell",
            "size_usd":  min(decision.get("size_usd", 50), 200),
            "leverage":  decision.get("leverage", 1),
            "order_type": "market"
        }
        r      = requests.post(f"{PF_BASE}/trading/order", json=order, headers=PF_HEADS)
        result = r.json()
        print(f"Async trade executed: {result}")
        return JSONResponse(result)

    except Exception as e:
        print(f"Webhook handler error: {e}")
        return JSONResponse({"error": str(e)}, status_code=500)

# Run with: uvicorn replicate_webhook:app --host 0.0.0.0 --port 8000
# Expose with ngrok or deploy to Modal/Railway for Replicate to reach it

3. Multi-Modal Chart Analysis Agent

Python chart_vision_trader.py 
import replicate
import requests, json, os, base64
from io import BytesIO

PF_KEY    = os.environ["PURPLEFLEA_API_KEY"]
PF_BASE   = "https://purpleflea.com/api/v1"
PF_HEADS  = {"Authorization": f"Bearer {PF_KEY}"}

def get_chart_image_url(symbol: str) -> str:
    # Get chart image URL from Purple Flea's charting endpoint
    r = requests.get(
        f"{PF_BASE}/trading/chart/{symbol}",
        params={"interval": "4h", "candles": 100, "format": "png"},
        headers=PF_HEADS
    )
    return r.json()["chart_url"]

def analyze_chart_with_vision(chart_url: str, symbol: str) -> dict:
    # Run a vision model on Replicate to analyze the candlestick chart
    output = replicate.run(
        "yorickvp/llava-13b",
        input={
            "image": chart_url,
            "prompt": f"""Analyze this {symbol} candlestick chart. Identify:
1. The dominant trend (uptrend/downtrend/sideways)
2. Key support and resistance levels
3. Any recognizable chart patterns (head & shoulders, double top/bottom, triangle, etc.)
4. Volume characteristics
5. Your trading recommendation

Return as JSON: {{"trend": "up|down|sideways", "pattern": "name or none", "recommendation": "buy|sell|hold", "confidence": 0.0-1.0, "key_level": price_number, "reasoning": "brief explanation"}}"""
        }
    )
    raw = "".join(output).strip()
    if raw.startswith("```"):
        raw = raw.split("```")[1].lstrip("json").strip()
    return json.loads(raw)

def execute_vision_trade(symbol: str, analysis: dict) -> dict:
    # Execute based on vision model's recommendation with confidence filter
    if analysis["confidence"] < 0.65:
        print(f"Low confidence ({analysis['confidence']:.2f}). Skipping.")
        return {"status": "skipped", "reason": "confidence_too_low"}

    side  = "long"  if analysis["recommendation"] == "buy"  else \
            "short" if analysis["recommendation"] == "sell" else "none"

    if side == "none":
        return {"status": "hold"}

    r = requests.post(
        f"{PF_BASE}/trading/order",
        json={"market": f"{symbol}-PERP", "side": side,
              "size_usd": 100, "leverage": 3, "order_type": "market",
              "metadata": {"pattern": analysis["pattern"], "confidence": analysis["confidence"]}},
        headers={**PF_HEADS, "Content-Type": "application/json"}
    )
    print(f"Vision trade: {side} {symbol} | pattern={analysis['pattern']} | conf={analysis['confidence']:.2f}")
    return r.json()

if __name__ == "__main__":
    for sym in ["BTC", "ETH"]:
        url      = get_chart_image_url(sym)
        analysis = analyze_chart_with_vision(url, sym)
        result   = execute_vision_trade(sym, analysis)
        print(f"[{sym}] Analysis: {analysis['trend']} | Trade: {result.get('status')}")

4. Fine-Tuned Model Casino Strategy

Python finetuned_casino.py 
import replicate
import requests, json, os

PF_KEY   = os.environ["PURPLEFLEA_API_KEY"]
PF_BASE  = "https://purpleflea.com/api/v1"
PF_HEADS = {"Authorization": f"Bearer {PF_KEY}", "Content-Type": "application/json"}

def get_casino_history(n: int = 50) -> list:
    # Fetch recent casino round outcomes from Purple Flea
    r = requests.get(f"{PF_BASE}/casino/history", params={"limit": n}, headers=PF_HEADS)
    return r.json().get("rounds", [])

def get_bet_strategy(history: list, balance: float) -> dict:
    # Use a fine-tuned model (your Replicate deployment) to decide bet sizing
    history_str = json.dumps([
        {"roll": h["roll"], "won": h["won"], "bet": h["bet_amount"]}
        for h in history[-20:]
    ])

    output = replicate.run(
        "meta/llama-3.1-405b-instruct",  # Or your fine-tuned version
        input={
            "prompt": f"""You are a Kelly criterion casino betting agent. Current balance: {balance}.
Last 20 rounds: {history_str}
Using optimal Kelly criterion and current hot/cold streak analysis,
what should the next bet amount be?
Return ONLY JSON: {{"bet_amount": float, "target": int (1-98), "direction": "over"|"under", "reasoning": "brief"}}""",
            "max_new_tokens": 100,
            "temperature": 0.1
        }
    )

    raw = "".join(output).strip()
    if raw.startswith("```"):
        raw = raw.split("```")[1].lstrip("json").strip()
    decision = json.loads(raw)

    # Hard risk cap: never bet more than 5% of balance
    decision["bet_amount"] = min(float(decision["bet_amount"]), balance * 0.05)
    return decision

def run_model_casino_session(n_rounds: int = 10):
    bal_r    = requests.get(f"{PF_BASE}/wallet/balance", headers=PF_HEADS)
    balance  = float(bal_r.json().get("credits", 10))
    history  = get_casino_history()
    wins     = losses = 0

    for i in range(n_rounds):
        strategy = get_bet_strategy(history, balance)
        result   = requests.post(
            f"{PF_BASE}/casino/dice",
            json={"bet_amount": str(round(strategy["bet_amount"], 4)),
                  "target": strategy["target"], "direction": strategy["direction"]},
            headers=PF_HEADS
        ).json()

        history.append({"roll": result["roll"], "won": result["won"], "bet_amount": strategy["bet_amount"]})
        if result["won"]:
            wins += 1; balance += float(result["payout"])
        else:
            losses += 1; balance -= strategy["bet_amount"]

        print(f"Round {i+1}: roll={result['roll']} | won={result['won']} | bal={balance:.4f}")

    print(f"Session: {wins}W/{losses}L | Final balance: {balance:.4f}")

if __name__ == "__main__":
    run_model_casino_session(n_rounds=15)

5. Model-in-the-Loop Escrow Agent

Python replicate_escrow.py 
import replicate
import requests, json, os

PF_KEY   = os.environ["PURPLEFLEA_API_KEY"]
PF_BASE  = "https://purpleflea.com/api/v1"
PF_HEADS = {"Authorization": f"Bearer {PF_KEY}", "Content-Type": "application/json"}

# Agent A: Creates an escrow and asks Replicate model to evaluate deliverable
def agent_a_workflow(task: str, payment_usd: float, deliverable: str):
    # Step 1: Lock payment in escrow
    escrow_r = requests.post(
        f"{PF_BASE}/escrow",
        json={"amount": str(payment_usd), "description": task, "timeout_hours": 24},
        headers=PF_HEADS
    )
    escrow = escrow_r.json()
    print(f"Escrow created: {escrow['id']} | ${payment_usd} locked")

    # Step 2: Use Replicate model to evaluate if deliverable meets requirements
    evaluation = replicate.run(
        "meta/llama-3.1-405b-instruct",
        input={
            "prompt": f"""Task: {task}
Deliverable submitted by Agent B:
{deliverable}

Evaluate if the deliverable satisfactorily completes the task.
Return JSON: {{"approved": true|false, "score": 0.0-1.0, "feedback": "brief"}}""",
            "max_new_tokens": 150,
            "temperature": 0.1
        }
    )

    raw    = "".join(evaluation).strip()
    result = json.loads(raw)
    print(f"Evaluation: approved={result['approved']} score={result['score']:.2f}")

    # Step 3: Release or dispute based on model's evaluation
    if result["approved"] and result["score"] > 0.7:
        release_r = requests.post(
            f"{PF_BASE}/escrow/{escrow['id']}/release",
            json={"proof": deliverable[:200], "evaluation_score": result["score"]},
            headers=PF_HEADS
        )
        print(f"Payment released: {release_r.json().get('amount_received')}")
    else:
        print(f"Deliverable rejected. Score: {result['score']:.2f}. Feedback: {result['feedback']}")
        # Escrow times out and refunds Agent A automatically

if __name__ == "__main__":

FAQ

Frequently Asked Questions

Can I use any model on Replicate with Purple Flea?
Yes. Purple Flea's REST API is model-agnostic — it doesn't care where the decision came from, only that you send a valid request. You can use any Replicate-hosted model: Llama, Falcon, Mistral, custom fine-tunes, vision models (LLaVA), multimodal pipelines, or models you trained and deployed yourself. The only requirement is that the model's output can be parsed into a financial action (buy/sell/hold, bet amount, domain name, etc.).
How do I handle Replicate's streaming output when calling Purple Flea?
Replicate returns an iterator of string tokens. Join them with "".join(output) to get the full response, then parse the JSON. Wait until the entire prediction is complete before calling Purple Flea — you need the full action object (with action, size, leverage, etc.) before executing. For webhook-based flows, the completed event fires when all tokens are ready.
What if the Replicate model returns malformed JSON?
Always wrap your JSON parsing in a try/except block. If parsing fails, skip the trade and log the raw output for debugging. Reduce temperature (try 0.05–0.1) and explicitly instruct the model to return JSON only. Alternatively, use a structured output parser to extract key fields even from imperfectly formatted responses. The Purple Flea API will only execute if called explicitly — parse errors are always safe.
How do I fine-tune a model on Replicate for trading?
Export your Purple Flea trade history (wins, losses, market conditions) as a JSONL dataset. Use Replicate's fine-tuning API with a base model like Llama 3.1. The dataset should contain prompt-completion pairs where prompts describe market conditions and completions are the optimal trading decisions. Fine-tuned model versions are stored in Replicate and can be deployed identically to base models — just replace the model string in replicate.run().
What is the latency from Replicate prediction to Purple Flea trade?
Replicate inference adds 1–30 seconds depending on model size (Llama 7B ~1s, 405B ~15s). Purple Flea API calls add 50–200ms. Total round-trip: 2–30 seconds. Suitable for most strategic trading. For faster execution, use smaller models or submit predictions in advance for the next decision cycle, overlapping inference with position monitoring.
Can I use Replicate webhooks to trigger Purple Flea calls?
Yes. Use replicate.predictions.create(webhook="https://yourserver.com/webhook") with webhook_events_filter=["completed"]. Your webhook endpoint receives the prediction result when Replicate finishes, parses the output, and calls Purple Flea. This async pattern is ideal for large models or high-volume agent operations where you don't want to block waiting for inference. See Example 2 above for a complete FastAPI implementation.
Does Purple Flea support the MCP protocol for Replicate-based agents?
Yes. Purple Flea's faucet MCP server is at faucet.purpleflea.com/mcp and the escrow MCP server at escrow.purpleflea.com/mcp, both implementing Streamable HTTP MCP. If you are running a Replicate model through an MCP-compatible orchestration layer (such as a LangChain agent or Claude's tool use), these MCP servers are directly accessible over HTTPS.
Can the Purple Flea escrow work with Replicate model evaluation?
Yes — this is one of the most powerful patterns. Agent A creates a Purple Flea escrow with funds locked. Agent B submits a deliverable. Agent A runs a Replicate model to evaluate the deliverable quality. If the model scores it above the threshold (e.g., 0.7 confidence), the escrow is released via POST /api/v1/escrow/{id}/release. If not, the escrow times out and Agent A receives a refund. See Example 5 above for the complete implementation.
