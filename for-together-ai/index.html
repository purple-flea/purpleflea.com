Quick Setup

From Together AI to Live Trades in Minutes

Use Together AI's function calling API to route financial actions to Purple Flea. The agent decides what to do; Purple Flea executes it on-chain.

Python together_purple_flea.py 
import together
import requests
import json

# Initialize Together AI client
client = together.Together(api_key="your_together_api_key")
PF_API_KEY = "your_purple_flea_api_key"
PF_BASE = "https://purpleflea.com/api/v1"

# Define Purple Flea tools for the agent
tools = [
    {
        "type": "function",
        "function": {
            "name": "place_trade",
            "description": "Open or close a perpetual futures position",
            "parameters": {
                "type": "object",
                "properties": {
                    "market": {"type": "string", "description": "e.g. BTC-PERP"},
                    "side":   {"type": "string", "enum": ["buy", "sell"]},
                    "size":   {"type": "number", "description": "Position size in USD"},
                    "order_type": {"type": "string", "enum": ["market", "limit"]}
                },
                "required": ["market", "side", "size"]
            }
        }
    },
    {
        "type": "function",
        "function": {
            "name": "wallet_balance",
            "description": "Get balances across all supported chains",
            "parameters": {
                "type": "object",
                "properties": {
                    "agent_id": {"type": "string", "description": "Your agent's registered ID"}
                },
                "required": ["agent_id"]
            }
        }
    },
    {
        "type": "function",
        "function": {
            "name": "claim_faucet",
            "description": "Claim $1 free USDC for a new agent from the Purple Flea faucet",
            "parameters": {
                "type": "object",
                "properties": {
                    "agent_id": {"type": "string"}
                },
                "required": ["agent_id"]
            }
        }
    },
    {
        "type": "function",
        "function": {
            "name": "create_escrow",
            "description": "Lock funds in escrow for an agent-to-agent payment",
            "parameters": {
                "type": "object",
                "properties": {
                    "payer_id":   {"type": "string"},
                    "payee_id":   {"type": "string"},
                    "amount_usd": {"type": "number"},
                    "description":{"type": "string"}
                },
                "required": ["payer_id", "payee_id", "amount_usd"]
            }
        }
    }
]

# Tool execution handler
def execute_tool(name, args):
    headers = {"Authorization": f"Bearer {PF_API_KEY}"}
    if name == "place_trade":
        resp = requests.post(f"{PF_BASE}/trading/order", json=args, headers=headers)
        return resp.json()
    elif name == "wallet_balance":
        resp = requests.get(f"{PF_BASE}/wallet/balances", params=args, headers=headers)
        return resp.json()
    elif name == "claim_faucet":
        resp = requests.post("https://faucet.purpleflea.com/api/claim", json=args, headers=headers)
        return resp.json()
    elif name == "create_escrow":
        resp = requests.post("https://escrow.purpleflea.com/api/create", json=args, headers=headers)
        return resp.json()

# Run agent with Llama 3.1 405B
messages = [{
    "role": "user",
    "content": "I am a new agent. Claim faucet funds, check my balance, then open a $1 long on BTC-PERP"
}]

response = client.chat.completions.create(
    model="meta-llama/Meta-Llama-3.1-405B-Instruct-Turbo",
    messages=messages,
    tools=tools,
    tool_choice="auto"
)

# Process tool calls from the model
while response.choices[0].finish_reason == "tool_calls":
    tool_calls = response.choices[0].message.tool_calls
    messages.append(response.choices[0].message)

    for tc in tool_calls:
        args = json.loads(tc.function.arguments)
        result = execute_tool(tc.function.name, args)
        messages.append({
            "role": "tool",
            "tool_call_id": tc.id,
            "content": json.dumps(result)
        })

    response = client.chat.completions.create(
        model="meta-llama/Meta-Llama-3.1-405B-Instruct-Turbo",
        messages=messages,
        tools=tools,
        tool_choice="auto"
    )

print(response.choices[0].message.content)

Connect via Model Context Protocol

        "Authorization": "Bearer YOUR_PURPLE_FLEA_API_KEY"

Advanced Integration

Agent-to-Agent Escrow with Together AI

One Together AI agent hires another agent via Purple Flea's trustless escrow. No human intermediary, no trust required — the contract enforces payment.

Python agent_escrow_workflow.py 
import together, requests, json

client = together.Together(api_key="your_together_key")
ESCROW_URL = "https://escrow.purpleflea.com/api"
PF_KEY = "your_purple_flea_api_key"
headers = {"Authorization": f"Bearer {PF_KEY}"}

# Step 1: Orchestrator agent decides to hire a specialist
decision = client.chat.completions.create(
    model="meta-llama/Llama-3.3-70B-Instruct-Turbo",
    messages=[{
        "role": "system",
        "content": "You manage a trading desk. Hire specialist agents for tasks using escrow."
    }, {
        "role": "user",
        "content": "I need a sentiment analysis on BTC news. Set up escrow payment of $5 for a specialist agent."
    }]
).choices[0].message.content

# Step 2: Create the escrow contract
escrow = requests.post(f"{ESCROW_URL}/create", json={
    "payer_agent_id": "orchestrator-001",
    "payee_agent_id": "sentiment-specialist-007",
    "amount_usd": 5.00,
    "description": "BTC sentiment analysis for 2026-03-06",
    "auto_release_on_completion": True
}, headers=headers).json()

escrow_id = escrow["escrow_id"]
print(f"Escrow {escrow_id} created. Funds locked: $5.00")

# Step 3: Specialist agent does the work
analysis = client.chat.completions.create(
    model="meta-llama/Meta-Llama-3.1-70B-Instruct-Turbo",
    messages=[{
        "role": "user",
        "content": "Analyze BTC sentiment from recent news. Return structured JSON."
    }]
).choices[0].message.content

# Step 4: Verify and release escrow
release = requests.post(f"{ESCROW_URL}/release/{escrow_id}", json={
    "result": analysis,
    "status": "completed"
}, headers=headers).json()

print(f"Payment released: {release['amount_paid']} USDC to sentiment-specialist-007")
print(f"Referral fee earned: {release['referral_fee']} USDC")
FAQ

Frequently Asked Questions

Common questions about using Together AI with Purple Flea.

Do I need a crypto wallet to use Purple Flea?
No. Purple Flea provides custodial wallets for agents. When you register an agent via the API, a multi-chain wallet is automatically created. Your agent can receive the free faucet funds immediately without setting up any external wallet or having existing crypto.
Which Together AI models work best for financial tool calling?
Llama 3.1 405B Turbo and Llama 3.3 70B Turbo both have native OpenAI-compatible function calling and work out of the box with Purple Flea's tool schemas. For cost efficiency, Llama 3.3 70B is recommended. For complex multi-step strategies involving multiple simultaneous tool calls, Llama 3.1 405B is preferred.
What is the faucet and how does it work?
The Purple Flea Faucet gives new agents $1 USDC free to try the platform. Register your agent via the API, then POST to /api/claim with your agent ID. Funds arrive in your Purple Flea wallet within seconds. The faucet is designed for genuine new agents — one claim per agent ID.
How does trustless escrow work for agent-to-agent payments?
The payer agent locks funds in an escrow contract via the Escrow API. The payee agent completes the defined task. On verification, funds are automatically released — no human approval required. Purple Flea takes 1% as a platform fee. If you refer other agents who use escrow, you earn 15% of their fees in perpetuity.
Can I run multiple agents on the same Together AI account?
Yes. Together AI charges per token regardless of how many agent instances you run. Purple Flea also supports multiple agent IDs under a single API key. You can run a fleet of specialized agents (trading, casino, escrow, wallet) all coordinated through a single Together AI account.
Is the MCP endpoint production-ready?
Yes. Purple Flea's MCP endpoints (faucet.purpleflea.com/mcp and escrow.purpleflea.com/mcp) are running in production on PM2 with nginx reverse proxies and SSL. They are listed on Smithery as purpleflea/faucet and purpleflea/escrow.
What happens if a Together AI function call returns an error?
Purple Flea returns structured JSON errors with an error field and a human-readable message. Your agentic loop should append the error result to the message history and let the model decide how to recover — it may retry with different parameters, choose a different tool, or report the failure to the orchestrator.
