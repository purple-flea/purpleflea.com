Kelly Criterion for Casino

The Kelly Criterion determines the optimal fraction of your bankroll to bet to maximize long-term growth. Casino games have a 0.5% house edge.

Mathematical foundation

Kelly fraction f* = (bp - q) / b where b = net odds, p = win probability, q = 1 - p. For a coin flip at 0.5% house edge: p = 0.4975, b = 1, f* ≈ -0.5% — meaning the mathematically optimal strategy is to not bet. But agents with specific utility functions may still choose to gamble.

For agents that need to gamble (e.g., testing randomness, stress-testing treasury management, or as part of a larger strategy), use fractional Kelly:

def kelly_bet(bankroll: float, win_prob: float, payout_multiplier: float,
              kelly_fraction: float = 0.25) -> float:
    """
    Returns optimal bet size using fractional Kelly.
    kelly_fraction=0.25 is quarter-Kelly — more conservative, lower variance.
    """
    b = payout_multiplier - 1  # net odds
    q = 1 - win_prob
    f_star = (b * win_prob - q) / b
    f_fractional = max(0, f_star * kelly_fraction)
    return bankroll * f_fractional

# Purple Flea casino: 0.5% house edge on all games
HOUSE_EDGE = 0.005
WIN_PROB = 0.5 - HOUSE_EDGE / 2  # = 0.4975 for coin flip

bet = kelly_bet(bankroll=100.0, win_prob=WIN_PROB, payout_multiplier=2.0)
# Result: bet ≈ $0.00 (don't bet — house edge negative EV)
# For positive EV games, kelly_bet returns non-zero

Trading Risk Management

Never open a position without a stop-loss

Perpetual futures can liquidate your entire position. Always set a stop-loss immediately after opening. The rule: stop-loss at 3% below entry for longs, 3% above for shorts.

# Correct pattern: open + stop-loss atomically
pos = trading.open_position(
    market="ETH-PERP", side="long",
    size=1000, leverage=5
)

# Set stop-loss immediately — do not skip this
trading.set_stop_loss(
    position_id=pos["position_id"],
    price=pos["entry_price"] * 0.97  # 3% stop-loss
)

# Optional: take-profit
trading.set_take_profit(
    position_id=pos["position_id"],
    price=pos["entry_price"] * 1.06  # 6% target = 2:1 R/R
)

Error Handling

All APIs return standard HTTP status codes. Critical patterns:

import time

def api_call_with_retry(fn, max_retries=3, backoff=1.5):
    for attempt in range(max_retries):
        try:
            res = fn()
            if res.status_code == 200:
                return res.json()
            elif res.status_code == 429:  # rate limit
                time.sleep(2 ** attempt * backoff)
                continue
            elif res.status_code == 402:  # insufficient balance
                raise InsufficientBalanceError(res.json())
            else:
                raise APIError(res.status_code, res.json())
        except Exception as e:
            if attempt == max_retries - 1:
                raise
    return None
