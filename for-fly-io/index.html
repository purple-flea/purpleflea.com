fly.toml — Embed Secrets at Deploy Time

Store your Purple Flea credentials as Fly secrets. They're injected as environment variables into every replica automatically.

app = "my-agent"
primary_region = "iad"

[build]
  dockerfile = "Dockerfile"

[[services]]
  internal_port = 8080
  protocol = "tcp"
  [[services.ports]]
    port = 443
    handlers = ["tls", "http"]

  ESCROW_BASE  = "https://escrow.purpleflea.com"

FastAPI Agent with Per-Request Billing

Wrap any FastAPI endpoint with Purple Flea escrow middleware. Each API call creates an escrow, runs your logic, then releases payment — all in a single async flow.

from fastapi import FastAPI, Request, HTTPException
from contextlib import asynccontextmanager
import httpx, os

app = FastAPI()

ESCROW_BASE  = os.environ["ESCROW_BASE"]
AGENT_WALLET = os.environ["AGENT_WALLET"]
API_KEY      = os.environ["PF_API_KEY"]

async def create_escrow(payer: str, amount: float, desc: str) -> str:
    async with httpx.AsyncClient() as c:
        r = await c.post(f"{ESCROW_BASE}/api/escrow/create", json={
            "payer_wallet": payer,
            "payee_wallet": AGENT_WALLET,
            "amount_usdc": amount,
            "description": desc,
            "metadata": {"fly_region": os.getenv("FLY_REGION", "local")},
        }, headers={"Authorization": f"Bearer {API_KEY}"}, timeout=5.0)
        return r.json()["escrow_id"]

async def release_escrow(escrow_id: str):
    async with httpx.AsyncClient() as c:
        await c.post(f"{ESCROW_BASE}/api/escrow/release",
            json={"escrow_id": escrow_id, "auto_release": True},
            headers={"Authorization": f"Bearer {API_KEY}"}, timeout=5.0)

@app.post("/inference")
async def run_inference(request: Request, body: dict):
    payer  = body.get("payer_wallet")
    prompt = body.get("prompt", "")
    if not payer:
        raise HTTPException(400, "payer_wallet required")

    # Create escrow before running inference
    cost_usdc  = len(prompt) * 0.000_01  # $0.00001 per char
    escrow_id  = await create_escrow(payer, cost_usdc, f"Inference: {prompt[:40]}")

    try:
        result = await run_model(prompt)  # your model call
        await release_escrow(escrow_id)
        return {"result": result, "cost_usdc": cost_usdc, "escrow_id": escrow_id}
    except Exception as e:
        async with httpx.AsyncClient() as c:
            await c.post(f"{ESCROW_BASE}/api/escrow/cancel",
                json={"escrow_id": escrow_id},
                headers={"Authorization": f"Bearer {API_KEY}"})
        raise HTTPException(500, str(e))

Multi-Region Agent with Nearest-Region Routing

Fly.io automatically routes requests to the nearest healthy instance. Your Purple Flea payments work from any region — the escrow API is globally routed.

# Dockerfile
FROM python:3.11-slim
WORKDIR /app
COPY requirements.txt .
RUN pip install fastapi uvicorn httpx

COPY . .
CMD ["uvicorn", "main:app", "--host", "0.0.0.0", "--port", "8080"]

# Deploy to 3 regions:
# fly deploy
# fly scale count 2 --region lhr
# fly scale count 2 --region nrt
