Overview

Different layers of the stack

Alchemy operates at the infrastructure layer. It provides reliable, scalable access to EVM nodes so that blockchain developers do not have to run their own Geth or Erigon instances. It also adds enhanced APIs (NFT, token, Transfers) on top of raw node data, plus account abstraction (ERC-4337 bundler) and transaction simulation. Alchemy is for developers who need to interact directly with smart contracts or build novel DeFi primitives.

Purple Flea operates at the application layer. It wraps all blockchain complexity into high-level agent APIs. An AI agent does not need to know what chain a trade happens on, how gas is estimated, or which smart contract handles escrow settlement — Purple Flea handles all of that internally. The agent only calls REST endpoints like POST /api/games/coinflip or POST /api/trading/order.

The key distinction: Alchemy is for blockchain developers building novel on-chain applications who need raw infrastructure. Purple Flea is for AI agent developers who want financial capabilities in their agent without becoming blockchain experts. These audiences often overlap, and many teams use both at different layers.

Alchemy — eth_getBalance (raw RPC)
alchemy_balance.py 
from web3 import Web3
import requests

# Alchemy: get ETH balance via raw node
# You need: node URL, wallet address,
# wei-to-ETH conversion, separate price
# oracle to get a USD value.

ALCHEMY_URL = (
    "https://eth-mainnet.g.alchemy.com"
    "/v2/your_alchemy_api_key"
)
WALLET = "0xYourWalletAddress"

# Fetch balance in wei via JSON-RPC
payload = {
    "jsonrpc": "2.0", "id": 1,
    "method": "eth_getBalance",
    "params": [WALLET, "latest"]
}
resp = requests.post(ALCHEMY_URL, json=payload)
wei = int(resp.json()["result"], 16)
eth_amount = wei / 1e18

# Must fetch ETH/USD price separately
eth_usd_price = 2400  # from CoinGecko etc.
balance_usd = eth_amount * eth_usd_price

print(f"Balance: {eth_amount:.6f} ETH")
print(f"USD value: ${balance_usd:.2f}")
