When to Choose Each

Choose Purple Flea when...

You're building an AI agent that needs financial capabilities

  • Your agent needs to trade, gamble, or send payments
  • You want multi-chain support beyond EVM
  • You need a complete financial stack, not just wallet infrastructure
  • You want tool-calling ready APIs for LangChain, CrewAI, etc.
  • You want to get started in minutes with a single API key
Choose Stackup when...

You're building on top of ERC-4337 account abstraction

  • You're building a smart contract wallet (AA wallet)
  • You need gas sponsorship for a specific EVM app
  • You want to batch multiple EVM transactions
  • You need session keys or multi-sig for smart accounts
  • You're building infrastructure, not an agent application
Use Both When...

Your agent needs AA wallets + financial products

  • Use Stackup to create and manage AA wallets on EVM
  • Use Purple Flea for trading, casino, escrow, and domains
  • The AA wallet becomes the payment source for Purple Flea calls
  • Best of both worlds: AA flexibility + full financial stack

The Key Difference

Stackup is infrastructure for building applications — it gives you the plumbing for ERC-4337 transactions. Purple Flea is a complete application layer — it gives you trading, payments, gaming, and domains ready to call in 5 lines of Python. Most AI agent builders need Purple Flea's application layer, not raw bundler infrastructure. If you're building a novel AA wallet product, Stackup is the right layer; if you're building an agent that needs financial capabilities, Purple Flea gets you there faster.
