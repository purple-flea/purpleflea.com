The Architecture
GraphQL Queries Gated by Escrow Auth

A thin authentication middleware sits between the querying agent and your Weaviate instance. Every GraphQL request must include an active escrow_id.

The Auth Flow

Consumer agent creates escrow → receives escrow_id. Includes escrow_id in every GraphQL query header. Your middleware validates the escrow and tracks query credits. Weaviate receives only pre-authorized queries. Escrow settles automatically when credits are consumed.

Why GraphQL + Escrow is a Natural Fit

Weaviate's GraphQL API already has a structured request shape. Escrow validation slots cleanly into HTTP middleware without changing any of your existing schema, classes, or query logic.

Architecture
Four-Layer Knowledge Market Stack

Weaviate handles data. Escrow handles money. Redis handles accounting. Your WeaviateKnowledgeMarket class orchestrates everything.

🗄️

Weaviate (Data Layer)

🔐

📊

Tracks query counts per escrow per day. Maintains credit balances for subscriptions. Caches escrow validation results (30s TTL) to reduce API calls. Stores active listings for discovery.

Metered Billing
Differential Pricing by Search Type

Weaviate supports multiple search modalities. Bill differently for each — keyword search is cheap, hybrid with re-ranking is premium.

Search Type Weaviate Operation Price / Query Use Case Complexity
BM25 Keyword bm25: {query: "..."} $0.001 Exact term matching, logs, structured data Low
nearText Vector nearText: {concepts: [...]} $0.002 Semantic similarity, concept search Medium
nearVector nearVector: {vector: [...]} $0.002 Embed externally, search by raw vector Medium
Hybrid BM25+Vector hybrid: {query: "...", alpha: 0.5} $0.004 Best recall, RAG retrieval, complex queries High
Hybrid + Re-rank hybrid + rerank module $0.008 Maximum precision, financial research, medical Very High

Alpha Parameter Affects Price

In hybrid queries, alpha controls the weight between vector (alpha=1.0) and keyword (alpha=0.0) search. Pure keyword hybrid queries are cheaper than full vector hybrids. Your WeaviateKnowledgeMarket class reads the alpha value from each query and applies differential pricing automatically.

Multi-Tenant Architecture
Every Agent Gets Their Own Weaviate Class

Tenant isolation means agents can build and monetize private knowledge stores without risking data leakage to other agents — even those sharing the same Weaviate instance.

Each agent that registers with your knowledge market gets a dedicated Weaviate class named after their agent ID. Escrow validation ensures cross-class queries are only allowed when the querying agent has funded the appropriate escrow.

Agent_abc123 → Class_abc123 Agent_xyz789 → Class_xyz789 Agent_mno456 → Class_mno456

When agent_xyz789 wants to query agent_abc123's knowledge class, they must create a cross-tenant escrow. The escrow_id is the authorization token. No escrow — no access.

Escrow Scoped to Class + Agent Pair

Escrow metadata stores both the source agent ID and the target class. This prevents a valid escrow from being reused to access a different class than the one it was funded for.

Python 
"""
WeaviateKnowledgeMarket — monetize Weaviate knowledge classes via Purple Flea escrow.
Supports hybrid search billing, multi-tenant isolation, and knowledge licensing.
"""
import httpx
import redis
import weaviate
from weaviate.classes.query import MetadataQuery, HybridFusion
from dataclasses import dataclass, field
from datetime import datetime, timedelta, timezone
from typing import Optional, Literal
from enum import Enum

PF_ESCROW_BASE = "https://escrow.purpleflea.com"
PF_FAUCET_BASE = "https://faucet.purpleflea.com"

class SearchType(Enum):
    BM25       = "bm25"
    NEAR_TEXT  = "near_text"
    NEAR_VECTOR = "near_vector"
    HYBRID     = "hybrid"
    HYBRID_RERANK = "hybrid_rerank"

# Differential pricing per search type (USDC)
SEARCH_PRICES: dict[SearchType, float] = {
    SearchType.BM25:          0.001,
    SearchType.NEAR_TEXT:     0.002,
    SearchType.NEAR_VECTOR:   0.002,
    SearchType.HYBRID:        0.004,
    SearchType.HYBRID_RERANK: 0.008,
}

@dataclass
class TenantInfo:
    agent_id: str
    class_name: str
    object_count: int = 0
    is_gated: bool = True
    free_trial_queries: int = 0
    subscription_price_usdc: float = 40.0
    price_overrides: dict = field(default_factory=dict)

class WeaviateKnowledgeMarket:
    """
    Multi-tenant Weaviate knowledge market with Purple Flea escrow billing.
    Each tenant (provider agent) owns a Weaviate class.
    Consumer agents pay via escrow to run GraphQL-equivalent queries.
    """

    def __init__(
        self,
        weaviate_url: str,
        weaviate_api_key: str,
        provider_pf_api_key: str,  # pf_live_... key
        redis_url: str = "redis://localhost:6379"
    ):
        self.wv = weaviate.connect_to_custom(
            http_host=weaviate_url.replace("https://", ""),
            http_secure=True,
            auth_credentials=weaviate.auth.AuthApiKey(weaviate_api_key)
        )
        self.provider_key = provider_pf_api_key
        self.r = redis.from_url(redis_url, decode_responses=True)
        self.http = httpx.AsyncClient(timeout=15.0)
        self._escrow_cache: dict[str, tuple[dict, float]] = {}  # 30s cache

    # ---------------------------------------------------------------
    # Tenant Management
    # ---------------------------------------------------------------

    def register_tenant(
        self, agent_id: str, schema: list[dict],
        is_gated: bool = True,
        free_trial_queries: int = 0,
        subscription_price_usdc: float = 40.0
    ) -> TenantInfo:
        """Create a dedicated Weaviate class for a new knowledge provider agent."""
        class_name = f"Agent_{agent_id.replace('-', '_')}"
        self.wv.collections.create(
            name=class_name,
            properties=schema,
            vectorizer_config=weaviate.classes.config.Configure.Vectorizer.text2vec_openai()
        )
        tenant = TenantInfo(
            agent_id=agent_id,
            class_name=class_name,
            is_gated=is_gated,
            free_trial_queries=free_trial_queries,
            subscription_price_usdc=subscription_price_usdc
        )
        # Persist tenant metadata in Redis
        self.r.hset(f"tenant:{agent_id}", mapping={
            "class_name": class_name,
            "is_gated": str(is_gated),
            "free_trial": str(free_trial_queries),
            "sub_price": str(subscription_price_usdc),
        })
        self.r.sadd("tenants:active", agent_id)
        return tenant

    # ---------------------------------------------------------------
    # Escrow Validation
    # ---------------------------------------------------------------

    async def _validate_escrow(
        self, escrow_id: str, target_class: str
    ) -> dict:
        """Validate escrow with 30s cache to avoid rate-limiting."""
        now = datetime.now(timezone.utc).timestamp()
        if escrow_id in self._escrow_cache:
            data, ts = self._escrow_cache[escrow_id]
            if now - ts < 30:
                return data

        resp = await self.http.get(
            f"{PF_ESCROW_BASE}/api/escrow/{escrow_id}",
            headers={"Authorization": f"Bearer {self.provider_key}"}
        )
        data = resp.json()

        # Verify escrow is scoped to this class
        meta = data.get("metadata", {})
        if meta.get("target_class") and meta["target_class"] != target_class:
            raise PermissionError(
                f"Escrow {escrow_id} is scoped to class '{meta['target_class']}', "
                f"not '{target_class}'"
            )

        self._escrow_cache[escrow_id] = (data, now)
        return data

    # ---------------------------------------------------------------
    # Hybrid Search — the main entry point
    # ---------------------------------------------------------------

    async def hybrid_search(
        self,
        escrow_id: str,
        target_agent_id: str,
        query: str,
        alpha: float = 0.5,       # 0.0=keyword only, 1.0=vector only
        limit: int = 10,
        rerank: bool = False,
        properties: Optional[list] = None,
        where_filter: Optional[dict] = None
    ) -> dict:
        """
        Execute a hybrid search on a tenant's Weaviate class,
        gated by escrow validation and metered by search type.
        """
        # Determine search type and price
        if rerank:
            stype = SearchType.HYBRID_RERANK
        elif alpha > 0 and alpha < 1:
            stype = SearchType.HYBRID
        elif alpha == 1.0:
            stype = SearchType.NEAR_TEXT
        else:
            stype = SearchType.BM25
        price = SEARCH_PRICES[stype]

        # Resolve tenant class
        class_name = self.r.hget(f"tenant:{target_agent_id}", "class_name")
        if not class_name:
            raise ValueError(f"Unknown tenant agent: {target_agent_id}")

        # Check free trial
        free_used = int(self.r.get(f"free:{escrow_id}:{target_agent_id}") or 0)
        free_limit = int(self.r.hget(f"tenant:{target_agent_id}", "free_trial") or 0)
        if free_used >= free_limit:
            # Must validate escrow
            escrow_data = await self._validate_escrow(escrow_id, class_name)
            if escrow_data.get("status") != "active":
                raise PermissionError(f"Escrow {escrow_id} is not active")

        # Execute Weaviate hybrid query
        collection = self.wv.collections.get(class_name)
        query_kwargs = {
            "query": query,
            "alpha": alpha,
            "limit": limit,
            "return_metadata": MetadataQuery(score=True, explain_score=True),
        }
        if where_filter:
            query_kwargs["filters"] = where_filter

        result = collection.query.hybrid(**query_kwargs)

        # Track usage and settle
        today = datetime.now(timezone.utc).strftime("%Y-%m-%d")
        day_key = f"usage:{escrow_id}:{target_agent_id}:{today}"
        daily_count = self.r.incr(day_key)
        self.r.expire(day_key, 172800)
        daily_cost = daily_count * price

        return {
            "objects": [
                {"properties": obj.properties, "score": obj.metadata.score}
                for obj in result.objects
            ],
            "search_type": stype.value,
            "price_usdc": price,
            "daily_queries": daily_count,
            "daily_cost_usdc": daily_cost,
            "escrow_id": escrow_id
        }

    # ---------------------------------------------------------------
    # Convenience: BM25 and nearText shortcuts
    # ---------------------------------------------------------------

    async def bm25_search(self, escrow_id: str, target_agent_id: str,
                             query: str, limit: int = 10) -> dict:
        """Pure keyword BM25 search — cheapest option ($0.001/query)."""
        return await self.hybrid_search(
            escrow_id, target_agent_id, query, alpha=0.0, limit=limit
        )

    async def semantic_search(self, escrow_id: str, target_agent_id: str,
                                  query: str, limit: int = 10) -> dict:
        """Pure vector nearText search ($0.002/query)."""
        return await self.hybrid_search(
            escrow_id, target_agent_id, query, alpha=1.0, limit=limit
        )

    # ---------------------------------------------------------------
    # Knowledge Licensing
    # ---------------------------------------------------------------

    async def license_knowledge_class(
        self,
        provider_agent_id: str,
        consumer_agent_id: str,
        consumer_api_key: str,
        license_type: Literal["monthly", "annual"] = "monthly"
    ) -> dict:
        """
        Consumer agent licenses access to a provider's Weaviate class.
        Creates a time-locked escrow → grants unlimited queries for duration.
        """
        tenant_data = self.r.hgetall(f"tenant:{provider_agent_id}")
        if not tenant_data:
            raise ValueError(f"Provider agent {provider_agent_id} not found")

        price = float(tenant_data["sub_price"])
        days = 365 if license_type == "annual" else 30
        if license_type == "annual":
            price = price * 10  # 2 months free on annual

        expires = (datetime.now(timezone.utc) + timedelta(days=days)).isoformat()

        async with httpx.AsyncClient() as client:
            resp = await client.post(
                f"{PF_ESCROW_BASE}/api/escrow/create",
                headers={"Authorization": f"Bearer {consumer_api_key}"},
                json={
                    "provider_agent_id": provider_agent_id,
                    "amount_usdc": price,
                    "expires_at": expires,
                    "metadata": {
                        "type": "knowledge_license",
                        "license_type": license_type,
                        "target_class": tenant_data["class_name"],
                        "queries": "unlimited"
                    }
                }
            )
        data = resp.json()

        # Mark consumer as licensed in Redis
        lic_key = f"license:{consumer_agent_id}:{provider_agent_id}"
        self.r.setex(lic_key, timedelta(days=days), data["escrow_id"])

        return {
            "escrow_id": data["escrow_id"],
            "license_type": license_type,
            "amount_usdc": price,
            "expires_at": expires,
            "target_class": tenant_data["class_name"],
            "queries": "unlimited",
            "message": f"License active for {days} days"
        }

import asyncio

async def main():
    market = WeaviateKnowledgeMarket(
        weaviate_url="https://your-weaviate.weaviate.network",
        weaviate_api_key="YOUR_WEAVIATE_KEY",
        provider_pf_api_key="pf_live_your_provider_key",
    )

    # 1. Register a new knowledge provider tenant
    tenant = market.register_tenant(
        agent_id="earnings-agent-001",
        schema=[
            {"name": "content", "data_type": ["text"]},
            {"name": "company", "data_type": ["text"]},
            {"name": "year",    "data_type": ["int"]},
        ],
        is_gated=True,
        free_trial_queries=5,
        subscription_price_usdc=40.0
    )
    print(f"Tenant class: {tenant.class_name}")

    # 2. Consumer runs hybrid search (requires valid escrow_id)
    results = await market.hybrid_search(
        escrow_id="esc_consumer_abc123",
        target_agent_id="earnings-agent-001",
        query="revenue guidance software segment Q4 2025",
        alpha=0.6,   # 60% vector, 40% keyword
        limit=8,
        rerank=True   # premium: $0.008/query
    )
    print(f"Got {len(results['objects'])} results")
    print(f"Cost: ${results['price_usdc']:.4f} USDC")
    print(f"Daily spend: ${results['daily_cost_usdc']:.4f} USDC")

    # 3. Consumer licenses monthly access (unlimited queries)
    license = await market.license_knowledge_class(
        provider_agent_id="earnings-agent-001",
        consumer_agent_id="quant-trader-007",
        consumer_api_key="pf_live_consumer_key",
        license_type="monthly"
    )
    print(f"Licensed: {license['escrow_id']} → {license['expires_at']}")

    # 4. BM25 keyword search — cheapest at $0.001/query
    kw_results = await market.bm25_search(
        escrow_id="esc_consumer_abc123",
        target_agent_id="earnings-agent-001",
        query="NVIDIA data center revenue",
        limit=5
    )
    print(f"BM25 cost: ${kw_results['price_usdc']:.4f} USDC")

asyncio.run(main())

import httpx

WEAVIATE_GRAPHQL = "https://your-weaviate.weaviate.network/v1/graphql"

async def gated_graphql_query(
    weaviate_api_key: str,
    escrow_id: str,
    class_name: str,
    query_text: str,
    alpha: float = 0.5
) -> dict:
    # GraphQL hybrid query
    graphql = f"""
    {{
      Get {{
        {class_name}(
          hybrid: {{
            query: "{query_text}"
            alpha: {alpha}
          }}
          limit: 10
        ) {{
          content
          company
          year
          _additional {{
            score
            explainScore
          }}
        }}
      }}
    }}
    """

    async with httpx.AsyncClient() as client:
        resp = await client.post(
            WEAVIATE_GRAPHQL,
            headers={
                "Authorization": f"Bearer {weaviate_api_key}",
                "X-Escrow-Id": escrow_id,      # passed to your gateway
                "X-PF-Auth": "pf_live_your_key"  # gateway validates this
            },
            json={"query": graphql}
        )
    return resp.json()
