Momentum Trading Strategies for AI Agents: Trend Detection and Execution

📅 March 6, 2026 ⏱ 15 min read ✍️ Purple Flea Research

Momentum trading is the strategy of buying assets that have been rising and selling assets that have been falling, based on the empirical observation that trends tend to persist in the short to medium term. 1. The Theory of Momentum in Agent Markets

Momentum works because markets trend. Prices don't move randomly — they exhibit autocorrelation on hourly and daily timeframes. The reasons are structural:

  • Trend-following herding: When other agents see a price rise, more buy, driving the price further up. This creates self-reinforcing trends.
  • Underreaction: Agents with stale models take time to incorporate new information, meaning initial moves are often under-priced and extend further than a fully efficient market would predict.
  • Stop-loss cascades: When prices fall through a level where many agents have stop-losses, forced selling accelerates the move, creating momentum on the downside.

Momentum strategies profit from all three dynamics. They enter early in a trend, ride it while it persists, and exit when the trend shows signs of reversal. The key is having reliable indicators that distinguish a genuine trend from random noise.

2. RSI: Relative Strength Index

The RSI measures the speed and magnitude of recent price changes to evaluate whether an asset is overbought or oversold. It oscillates between 0 and 100.

RSI = 100 - (100 / (1 + RS))
RS = Average Gain / Average Loss over N periods

Standard interpretation: RSI > 70 is overbought (potential sell signal), RSI < 30 is oversold (potential buy signal). For momentum trading, we flip this: RSI crossing above 50 and trending upward is a buy signal, RSI crossing below 50 and trending downward is a sell signal.

import numpy as np
from typing import List

def calculate_rsi(prices: List[float], period: int = 14) -> List[float]:
    """
    Calculate RSI for a list of prices.
    Returns list of RSI values (first `period` values are NaN).
    """
    prices = np.array(prices)
    deltas = np.diff(prices)
    gains = np.where(deltas > 0, deltas, 0)
    losses = np.where(deltas < 0, -deltas, 0)

    # Initial averages
    avg_gain = np.mean(gains[:period])
    avg_loss = np.mean(losses[:period])

    rsi_values = [np.nan] * period
    for i in range(period, len(deltas)):
        avg_gain = (avg_gain * (period - 1) + gains[i]) / period
        avg_loss = (avg_loss * (period - 1) + losses[i]) / period
        if avg_loss == 0:
            rsi_values.append(100.0)
        else:
            rs = avg_gain / avg_loss
            rsi_values.append(100 - (100 / (1 + rs)))

    rsi_values.append(np.nan)  # align with prices length
    return rsi_values


def rsi_signal(rsi: float, prev_rsi: float, threshold: float = 50) -> str:
    """Generate momentum signal from RSI crossover."""
    if np.isnan(rsi) or np.isnan(prev_rsi):
        return 'hold'
    if prev_rsi < threshold <= rsi:  # crossed above threshold
        return 'buy'
    if prev_rsi > threshold >= rsi:  # crossed below threshold
        return 'sell'
    return 'hold'

3. MACD: Moving Average Convergence/Divergence

MACD is a trend-following momentum indicator that shows the relationship between two exponential moving averages. It consists of the MACD line (fast EMA minus slow EMA), the signal line (EMA of MACD line), and the histogram (MACD minus signal).

def calculate_ema(prices: List[float], period: int) -> List[float]:
    """Calculate Exponential Moving Average."""
    prices = np.array(prices, dtype=float)
    ema = np.full_like(prices, np.nan)
    multiplier = 2 / (period + 1)

    # Initialize with simple MA for first value
    ema[period - 1] = np.mean(prices[:period])
    for i in range(period, len(prices)):
        ema[i] = prices[i] * multiplier + ema[i - 1] * (1 - multiplier)
    return ema.tolist()


def calculate_macd(
    prices: List[float],
    fast: int = 12, slow: int = 26, signal_period: int = 9
) -> dict:
    """
    Calculate MACD, signal line, and histogram.
    Returns dict with 'macd', 'signal', 'histogram' lists.
    """
    fast_ema = np.array(calculate_ema(prices, fast))
    slow_ema = np.array(calculate_ema(prices, slow))

    macd_line = fast_ema - slow_ema
    valid_macd = [x if not np.isnan(x) else np.nan for x in macd_line]

    # Calculate signal line (EMA of MACD)
    macd_valid_prices = [x for x in valid_macd if not np.isnan(x)]
    signal_raw = calculate_ema(macd_valid_prices, signal_period)

    # Pad signal to match original length
    nan_count = len(prices) - len(macd_valid_prices)
    signal = [np.nan] * nan_count + signal_raw
    histogram = [m - s if not np.isnan(m) and not np.isnan(s) else np.nan
                 for m, s in zip(valid_macd, signal)]

    return {'macd': valid_macd, 'signal': signal, 'histogram': histogram}


def macd_signal(histogram: List[float]) -> str:
    """Signal from MACD histogram: bullish crossover = buy."""
    if len(histogram) < 2:
        return 'hold'
    prev, curr = histogram[-2], histogram[-1]
    if np.isnan(prev) or np.isnan(curr):
        return 'hold'
    if prev < 0 and curr > 0:
        return 'buy'   # bullish crossover
    if prev > 0 and curr < 0:
        return 'sell'  # bearish crossover
    return 'hold'

4. Bollinger Bands: Volatility-Adjusted Momentum

Bollinger Bands add volatility context to momentum signals. The bands are set at N standard deviations above and below a moving average. Price breaking above the upper band on high volume is a strong momentum signal; price falling below the lower band signals downward momentum.

def calculate_bollinger_bands(
    prices: List[float], period: int = 20, num_std: float = 2.0
) -> dict:
    """
    Calculate Bollinger Bands (upper, middle, lower).
    Returns dict with 'upper', 'middle', 'lower', 'bandwidth', '%b' lists.
    """
    prices = np.array(prices, dtype=float)
    upper, middle, lower, bandwidth, pct_b = [], [], [], [], []

    for i in range(len(prices)):
        if i < period - 1:
            upper.append(np.nan)
            middle.append(np.nan)
            lower.append(np.nan)
            bandwidth.append(np.nan)
            pct_b.append(np.nan)
            continue
        window = prices[i - period + 1:i + 1]
        sma = window.mean()
        std = window.std()
        u = sma + num_std * std
        l = sma - num_std * std
        upper.append(u)
        middle.append(sma)
        lower.append(l)
        bandwidth.append((u - l) / sma)
        pct_b.append((prices[i] - l) / (u - l) if u != l else 0.5)

    return {
        'upper': upper, 'middle': middle, 'lower': lower,
        'bandwidth': bandwidth, '%b': pct_b
    }


def bollinger_signal(price: float, bands: dict) -> str:
    """Signal: price above upper band = momentum buy; below lower = sell."""
    upper = bands['upper'][-1]
    lower = bands['lower'][-1]
    if np.isnan(upper) or np.isnan(lower):
        return 'hold'
    if price > upper:
        return 'buy'   # breakout above upper band
    if price < lower:
        return 'sell'  # breakdown below lower band
    return 'hold'

5. Composite Signal Generation

Individual indicators generate too many false signals. The power of momentum trading comes from combining indicators so that trades only trigger when multiple indicators agree. A composite signal approach weights each indicator's output and requires a minimum score to execute.

from enum import IntEnum

class Signal(IntEnum):
    STRONG_SELL = -2
    SELL = -1
    HOLD = 0
    BUY = 1
    STRONG_BUY = 2


def composite_signal(
    prices: List[float],
    rsi_period: int = 14,
    macd_fast: int = 12, macd_slow: int = 26,
    bb_period: int = 20,
    execute_threshold: int = 2
) -> Signal:
    """
    Generate composite momentum signal.
    Requires at least `execute_threshold` indicators agreeing.
    """
    score = 0

    # RSI component
    rsi = calculate_rsi(prices, rsi_period)
    if len(rsi) >= 2:
        sig = rsi_signal(rsi[-1], rsi[-2])
        score += (1 if sig == 'buy' else -1 if sig == 'sell' else 0)

    # MACD component
    macd = calculate_macd(prices, macd_fast, macd_slow)
    sig = macd_signal(macd['histogram'])
    score += (1 if sig == 'buy' else -1 if sig == 'sell' else 0)

    # Bollinger Band component
    bands = calculate_bollinger_bands(prices, bb_period)
    sig = bollinger_signal(prices[-1], bands)
    score += (1 if sig == 'buy' else -1 if sig == 'sell' else 0)

    if score >= execute_threshold:
        return Signal.STRONG_BUY if score == 3 else Signal.BUY
    elif score <= -execute_threshold:
        return Signal.STRONG_SELL if score == -3 else Signal.SELL
    return Signal.HOLD

6. The Complete MomentumAgent Class

This full agent class fetches price data from Purple Flea's Trading API, runs composite signal detection, manages positions with stop-losses, and executes trades automatically.

import requests
import time
import logging
from dataclasses import dataclass, field
from typing import Optional, Dict

logger = logging.getLogger('MomentumAgent')

@dataclass
class Position:
    pair: str
    side: str           # 'long' or 'short'
    entry_price: float
    size_usdc: float
    stop_loss: float
    take_profit: float
    open_time: float = field(default_factory=time.time)


class MomentumAgent:
    """
    Automated momentum trading agent for Purple Flea Trading.

    Features:
    - RSI + MACD + Bollinger Band composite signals
    - Automatic stop-loss and take-profit management
    - Position sizing via Kelly Criterion
    - Trade logging for performance analysis
    """
    BASE = "https://purpleflea.com/api/v1/trading"

    def __init__(
        self,
        api_key: str,
        pairs: List[str],
        max_position_pct: float = 0.10,
        stop_loss_pct: float = 0.02,
        take_profit_pct: float = 0.06,
        signal_threshold: int = 2,
        poll_interval: int = 300,
        dry_run: bool = False
    ):
        self.pairs = pairs
        self.max_position_pct = max_position_pct
        self.stop_loss_pct = stop_loss_pct
        self.take_profit_pct = take_profit_pct
        self.signal_threshold = signal_threshold
        self.poll_interval = poll_interval
        self.dry_run = dry_run
        self.positions: Dict[str, Position] = {}
        self.trade_log = []
        self.session = requests.Session()
        self.session.headers.update({
            'Authorization': f'Bearer {api_key}',
            'Content-Type': 'application/json'
        })

    def get_prices(self, pair: str, period: int = 100) -> List[float]:
        """Fetch recent closing prices for a trading pair."""
        resp = self.session.get(
            f"{self.BASE}/candles",
            params={'pair': pair, 'interval': '1h', 'limit': period}
        )
        candles = resp.json()
        return [c['close'] for c in candles]

    def get_balance(self) -> float:
        """Fetch available USDC balance."""
        resp = self.session.get(f"{self.BASE}/balance")
        return float(resp.json().get('usdc', 0))

    def calculate_position_size(self, balance: float, signal: Signal) -> float:
        """Size position based on signal strength and Kelly."""
        base_size = balance * self.max_position_pct
        if signal in (Signal.STRONG_BUY, Signal.STRONG_SELL):
            return base_size * 1.5  # strong signal: 1.5x base
        return base_size

    def open_position(self, pair: str, side: str, size_usdc: float, price: float):
        """Open a new position with stop-loss and take-profit."""
        stop_loss = price * (1 - self.stop_loss_pct) if side == 'long' else \
                    price * (1 + self.stop_loss_pct)
        take_profit = price * (1 + self.take_profit_pct) if side == 'long' else \
                      price * (1 - self.take_profit_pct)

        if self.dry_run:
            logger.info(f"[DRY RUN] Open {side} {pair} ${size_usdc:.2f} @ {price:.4f}")
        else:
            order = self.session.post(f"{self.BASE}/orders", json={
                'pair': pair, 'side': 'buy' if side == 'long' else 'sell',
                'type': 'market', 'amount': str(size_usdc),
                'stop_loss': stop_loss, 'take_profit': take_profit
            }).json()
            logger.info(f"Opened {side} {pair}: order {order.get('order_id')}")

        self.positions[pair] = Position(
            pair=pair, side=side, entry_price=price,
            size_usdc=size_usdc, stop_loss=stop_loss, take_profit=take_profit
        )

    def close_position(self, pair: str, reason: str):
        """Close an existing position."""
        pos = self.positions.get(pair)
        if not pos:
            return
        if not self.dry_run:
            self.session.post(f"{self.BASE}/orders", json={
                'pair': pair,
                'side': 'sell' if pos.side == 'long' else 'buy',
                'type': 'market', 'amount': str(pos.size_usdc)
            })
        self.trade_log.append({'pair': pair, 'reason': reason, 'position': pos})
        del self.positions[pair]
        logger.info(f"Closed {pair} position: {reason}")

    def check_exits(self, pair: str, current_price: float):
        """Check if stop-loss or take-profit has been hit."""
        pos = self.positions.get(pair)
        if not pos:
            return
        if pos.side == 'long':
            if current_price <= pos.stop_loss:
                self.close_position(pair, 'stop_loss')
            elif current_price >= pos.take_profit:
                self.close_position(pair, 'take_profit')
        else:
            if current_price >= pos.stop_loss:
                self.close_position(pair, 'stop_loss')
            elif current_price <= pos.take_profit:
                self.close_position(pair, 'take_profit')

    def run_cycle(self):
        """Execute one trading cycle across all pairs."""
        balance = self.get_balance()
        logger.info(f"Balance: ${balance:.2f} USDC | Open positions: {len(self.positions)}")

        for pair in self.pairs:
            try:
                prices = self.get_prices(pair)
                if len(prices) < 30:
                    continue

                current_price = prices[-1]
                self.check_exits(pair, current_price)

                if pair in self.positions:
                    continue  # Already in position

                signal = composite_signal(prices, execute_threshold=self.signal_threshold)
                logger.info(f"{pair}: price={current_price:.4f}, signal={signal.name}")

                if signal in (Signal.BUY, Signal.STRONG_BUY):
                    size = self.calculate_position_size(balance, signal)
                    if size > 0.50:  # minimum trade size
                        self.open_position(pair, 'long', size, current_price)
                elif signal in (Signal.SELL, Signal.STRONG_SELL):
                    size = self.calculate_position_size(balance, signal)
                    if size > 0.50:
                        self.open_position(pair, 'short', size, current_price)

            except Exception as e:
                logger.error(f"Error processing {pair}: {e}")

    def run(self):
        """Main trading loop."""
        logger.info(f"MomentumAgent started. Pairs: {self.pairs}")
        while True:
            self.run_cycle()
            time.sleep(self.poll_interval)
