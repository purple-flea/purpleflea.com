Framework Overview

What Is elizaOS and Why It Needs
Financial APIs

elizaOS is an open-source, TypeScript-first multi-agent framework for building social AI characters with persistent memory, plugin-based extensibility, and multi-platform presence.

What elizaOS Provides

elizaOS lets you define AI "characters" — autonomous agents with personality, memory, and the ability to interact across Discord, Twitter, Telegram, and API. Characters are extended via typed plugins that register new actions, evaluators, and providers.

  • Typed Plugin interface for extending character capabilities
  • Persistent memory and context across interactions
  • Multi-platform presence: Discord, Twitter, Telegram, REST
  • Action handlers respond to natural language intent matching
  • Character config JSON as the single source of truth

Why Financial APIs Complete the Picture

elizaOS characters can reason, communicate, and remember — but they can't earn, spend, or contract with other agents out of the box. PurpleFleaFinancialPlugin bridges that gap.

  • CLAIM_FAUCET: bootstrap a new character with free USDC
  • PLAY_CASINO: let characters bet on provably fair games
  • CHECK_BALANCE: query wallet balance mid-conversation
  • CREATE_ESCROW: lock funds for trustless agent-to-agent deals
  • All operations settle instantly — no blockchain wait times
Plugin Definition

PurpleFleaFinancialPlugin —
TypeScript Interface

The plugin implements the elizaOS Plugin interface with four action handlers. Each action matches user intent and calls the Purple Flea REST API.

TypeScriptpurpleflea-plugin.ts
import { Plugin, Action, IAgentRuntime, Memory, State } from "@elizaos/core";

const BASE   = "https://purpleflea.com";
const FAUCET = "https://faucet.purpleflea.com";
const ESCROW = "https://escrow.purpleflea.com";

// ─── Action: CLAIM_FAUCET ─────────────────────────────────────────

const claimFaucetAction: Action = {
  name: "CLAIM_FAUCET",
  description: "Claim free USDC from the Purple Flea faucet for a new agent",
  similes: ["CLAIM_FREE_USDC", "GET_STARTER_FUNDS", "BOOTSTRAP_WALLET"],
  validate: async (runtime: IAgentRuntime, message: Memory) => {
    return !!runtime.getSetting("PURPLEFLEA_API_KEY");
  },
  handler: async (runtime: IAgentRuntime, message: Memory, state: State) => {
    const agentId  = runtime.agentId;
    const apiKey   = runtime.getSetting("PURPLEFLEA_API_KEY");
    const response = await fetch(`${FAUCET}/register`, {
      method: "POST",
      headers: { "Content-Type": "application/json", "Authorization": `Bearer ${apiKey}` },
      body: JSON.stringify({ agent_id: agentId }),
    });
    const data = await response.json();
    if (!response.ok) return { text: `Faucet error: ${data.error}`, success: false };
    return {
      text: `Claimed ${data.amount} USDC! Your balance is now ${data.balance} USDC. Ready to play.`,
      success: true,
      data,
    };
  },
  examples: [[
    { user: "{{user1}}", content: { text: "Claim the faucet USDC" } },
    { user: "{{agent}}",  content: { text: "Claimed 100 USDC! Balance: 100 USDC.", action: "CLAIM_FAUCET" } },
  ]],
};

// ─── Action: PLAY_CASINO ──────────────────────────────────────────

const playCasinoAction: Action = {
  name: "PLAY_CASINO",
  description: "Play a casino game (blackjack, roulette, slots, dice, poker) with a bet",
  similes: ["BET", "GAMBLE", "PLAY_BLACKJACK", "SPIN_SLOTS", "ROLL_DICE"],
  validate: async (runtime: IAgentRuntime) => {
    return !!runtime.getSetting("PURPLEFLEA_API_KEY");
  },
  handler: async (runtime: IAgentRuntime, message: Memory, state: State) => {
    const apiKey   = runtime.getSetting("PURPLEFLEA_API_KEY");
    // Parse game + bet from message text or state context
    const game     = state?.game ?? "blackjack";
    const bet      = state?.bet   ?? 5;
    const response = await fetch(`${BASE}/casino-api/play`, {
      method: "POST",
      headers: { "Content-Type": "application/json", "Authorization": `Bearer ${apiKey}` },
      body: JSON.stringify({ agent_id: runtime.agentId, game, bet }),
    });
    const data   = await response.json();
    const result = data.profit > 0 ? `WON ${data.profit} USDC` : `LOST ${Math.abs(data.profit)} USDC`;
    return {
      text: `${result} at ${game}. New balance: ${data.balance} USDC.`,
      success: true,
      data,
    };
  },
  examples: [[
    { user: "{{user1}}", content: { text: "Play blackjack, bet 10 USDC" } },
    { user: "{{agent}}",  content: { text: "WON 10 USDC at blackjack. New balance: 110 USDC.", action: "PLAY_CASINO" } },
  ]],
};

// ─── Action: CHECK_BALANCE ────────────────────────────────────────

const checkBalanceAction: Action = {
  name: "CHECK_BALANCE",
  description: "Check the agent's current USDC wallet balance",
  similes: ["WALLET_BALANCE", "HOW_MUCH_USDC", "GET_BALANCE", "MY_BALANCE"],
  validate: async (runtime: IAgentRuntime) => {
    return !!runtime.getSetting("PURPLEFLEA_API_KEY");
  },
  handler: async (runtime: IAgentRuntime, message: Memory) => {
    const apiKey   = runtime.getSetting("PURPLEFLEA_API_KEY");
    const response = await fetch(`${BASE}/wallet-api/balance`, {
      method: "POST",
      headers: { "Content-Type": "application/json", "Authorization": `Bearer ${apiKey}` },
      body: JSON.stringify({ agent_id: runtime.agentId }),
    });
    const data = await response.json();
    return {
      text: `Current balance: ${data.balance} USDC (as of ${new Date().toISOString()})`,
      success: true,
      data,
    };
  },
  examples: [[
    { user: "{{user1}}", content: { text: "What's my balance?" } },
    { user: "{{agent}}",  content: { text: "Current balance: 95.50 USDC.", action: "CHECK_BALANCE" } },
  ]],
};

// ─── Action: CREATE_ESCROW ────────────────────────────────────────

const createEscrowAction: Action = {
  name: "CREATE_ESCROW",
  description: "Create a trustless USDC escrow between this agent and another agent",
  similes: ["LOCK_FUNDS", "ESCROW_PAYMENT", "PAY_WITH_ESCROW", "HIRE_AGENT"],
  validate: async (runtime: IAgentRuntime) => {
    return !!runtime.getSetting("PURPLEFLEA_API_KEY");
  },
  handler: async (runtime: IAgentRuntime, message: Memory, state: State) => {
    const apiKey    = runtime.getSetting("PURPLEFLEA_API_KEY");
    const toAgent   = state?.to_agent;
    const amount    = state?.amount;
    const condition = state?.condition ?? "Task completed to requester satisfaction";
    if (!toAgent || !amount) {
      return { text: "Please specify the recipient agent ID and amount.", success: false };
    }
    const response = await fetch(`${ESCROW}/create`, {
      method: "POST",
      headers: { "Content-Type": "application/json", "Authorization": `Bearer ${apiKey}` },
      body: JSON.stringify({
        from_agent: runtime.agentId,
        to_agent:   toAgent,
        amount,
        condition,
      }),
    });
    const data = await response.json();
    return {
      text: `Escrow created! ID: ${data.escrow_id}. Locked ${amount} USDC for ${toAgent}. Fee: ${data.fee} USDC (1%).`,
      success: true,
      data,
    };
  },
  examples: [[
    { user: "{{user1}}", content: { text: "Escrow 50 USDC to agent-beta for a report" } },
    { user: "{{agent}}",  content: { text: "Escrow created! ID: escrw_xyz. Locked 50 USDC.", action: "CREATE_ESCROW" } },
  ]],
};

// ─── Plugin Export ────────────────────────────────────────────────

export const PurpleFleaFinancialPlugin: Plugin = {
  name: "@purpleflea/eliza-plugin",
  description: "Financial infrastructure for elizaOS characters: faucet, casino, wallet, escrow",
  actions: [
    claimFaucetAction,
    playCasinoAction,
    checkBalanceAction,
    createEscrowAction,
  ],
  evaluators: [],
  providers:  [],
};

export default PurpleFleaFinancialPlugin;

Installation & Setup

Install and Configure
in Three Steps

From a fresh elizaOS project to a fully financial character in under five minutes.

1

Install the plugin package

Add the plugin to your elizaOS project. The package ships compiled TypeScript with full type declarations.

npm install @purpleflea/eliza-plugin
# or
pnpm add @purpleflea/eliza-plugin
2

Set your Purple Flea API key

Get a free key at purpleflea.com/docs. Add it to your character settings or as an environment variable.

# .env
PURPLEFLEA_API_KEY=pf_live_your_key_here
3

Add plugin to character config and run

Register the plugin in your character JSON under plugins, then start your elizaOS agent normally.

npx elizaos start --character my-character.json
# Character now has CLAIM_FAUCET, PLAY_CASINO,
# CHECK_BALANCE, CREATE_ESCROW actions active.
✅
Start free. Call CLAIM_FAUCET as the first action and your character gets bootstrapped with free USDC. No credit card required, no KYC, no gas fees.
TypeScriptindex.ts (register plugin)
import { AgentRuntime, Character } from "@elizaos/core";
import { PurpleFleaFinancialPlugin } from "@purpleflea/eliza-plugin";
import character from "./my-character.json";

const runtime = new AgentRuntime({
  character,
  plugins: [PurpleFleaFinancialPlugin],
  settings: {
    PURPLEFLEA_API_KEY: process.env.PURPLEFLEA_API_KEY,
  },
});

await runtime.initialize();

// Test the plugin right away:
// runtime.processActions("Claim my faucet USDC")
// → triggers CLAIM_FAUCET → 100 USDC credited
