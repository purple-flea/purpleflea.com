Overview

Why GPU Agent Billing Needs Escrow

Modal.com is the fastest way to run serverless GPU functions in Python. A single decorator — @modal.function(gpu="A100") — spins up a 40GB GPU instance in seconds, runs your code, and tears it down. The compute side is solved.

The payment side is not. When one AI agent hires another to run a GPU job, the buyer faces counterparty risk (pay upfront and never get results) and the seller faces the same risk in reverse (do the work and never get paid). Human-intermediary billing systems are too slow and too expensive for micro-transactions measured in seconds of GPU time.

Purple Flea escrow sits between the two agents. The buyer locks USDC before the Modal job starts. The escrow tracks the job lifecycle. When the Modal function returns successfully, the escrow releases payment to the seller — proportional to actual GPU-seconds consumed. If the job times out or fails, the deposit is automatically refunded via TTL. No trust required on either side.

Cold Start TTL

Modal containers can take 5–25 seconds to warm up on the first call. Add this margin to your escrow TTL. The wrapper automatically adds a configurable cold-start buffer (default 30s) on top of your expected job duration so TTL expiry never fires mid-execution.

Per-Second Precision

Modal bills per second of GPU time. Purple Flea escrow supports per-second micro-releases using the deduct API. For long-running jobs, stream heartbeats every 10 seconds so the buyer can monitor spend in real time.

Code Example 1

@modal.function with Escrow Lifecycle Wrapper

The key insight: the escrow wrapper runs on the caller's side, not inside the Modal container. The Modal function itself is unmodified — it just does GPU work. The wrapper creates the escrow, calls .remote(), measures wall-clock GPU seconds, and releases payment.

gpu_job_escrow.py
"""
Modal + Purple Flea Escrow — per-second GPU job billing
pip install modal requests
modal setup  # authenticate with Modal
"""

import modal, requests, os, time, contextlib
from dataclasses import dataclass
from typing import Any

# ── Config ────────────────────────────────────────────
PF_KEY     = os.environ["PF_API_KEY"]       # pf_live_YOUR_KEY
ESCROW_URL = "https://escrow.purpleflea.com/api/escrow"
PF_HEADERS = {"Authorization": f"Bearer {PF_KEY}",
              "Content-Type": "application/json"}

# GPU pricing (USDC per GPU-second, approximate)
GPU_PRICE_SEC = {
    "T4":   0.000_020,   # $0.020 / min
    "A10G": 0.000_067,   # $0.067 / min
    "A100": 0.000_167,   # $0.167 / min
    "H100": 0.000_500,   # $0.50  / min
}
COLD_START_BUFFER_SEC = 30   # add to TTL for container warm-up

# ── Escrow helpers ────────────────────────────────────
def create_escrow(seller_id: str, gpu: str,
                   max_seconds: int, description: str) -> dict:
    price_per_sec = GPU_PRICE_SEC.get(gpu, GPU_PRICE_SEC["A10G"])
    max_cost      = price_per_sec * max_seconds
    ttl           = max_seconds + COLD_START_BUFFER_SEC

    payload = {
        "seller_id":   seller_id,
        "amount_usdc": max_cost,
        "ttl_seconds": ttl,
        "description": description,
        "meta": {"gpu": gpu, "max_seconds": max_seconds,
                 "price_per_sec": price_per_sec}
    }
    r = requests.post(ESCROW_URL, json=payload, headers=PF_HEADERS)
    r.raise_for_status()
    escrow = r.json()
    print(f"[escrow] locked ${max_cost:.4f} USDC | gpu={gpu} | ttl={ttl}s")
    return escrow

def release_escrow(escrow_id: str, actual_seconds: float,
                    gpu: str, success: bool = True):
    if not success:
        # Let TTL handle the refund
        print(f"[escrow] job failed — TTL will refund automatically")
        return

    price_per_sec = GPU_PRICE_SEC.get(gpu, GPU_PRICE_SEC["A10G"])
    actual_cost   = actual_seconds * price_per_sec
    print(f"[escrow] releasing ${actual_cost:.4f} for {actual_seconds:.1f}s on {gpu}")

    r = requests.post(
        f"{ESCROW_URL}/{escrow_id}/release",
        json={"amount_usdc": actual_cost,
              "refund_remainder": True,
              "meta": {"gpu_seconds": actual_seconds, "gpu": gpu}},
        headers=PF_HEADERS
    )
    r.raise_for_status()
    return r.json()

# ── Modal app definition ──────────────────────────────
app = modal.App("purple-flea-gpu-jobs")
gpu_image = modal.Image.debian_slim().pip_install(["torch", "transformers"])

@app.function(gpu="A10G", image=gpu_image, timeout=600)
def run_inference_job(model_id: str, prompt: str, max_new_tokens: int = 256) -> dict:
    """GPU function — runs inside Modal container, no escrow code here."""
    import time, torch
    from transformers import pipeline

    t0     = time.monotonic()
    pipe   = pipeline("text-generation", model=model_id,
                      torch_dtype=torch.float16, device_map="auto")
    output = pipe(prompt, max_new_tokens=max_new_tokens, do_sample=False)
    elapsed = time.monotonic() - t0
    return {
        "text":       output[0]["generated_text"],
        "wall_sec":   elapsed,
        "gpu":        "A10G",
    }

# ── Escrow-wrapped caller (runs locally / in your agent) ──
def run_paid_gpu_job(
    seller_agent_id: str,
    model_id: str,
    prompt: str,
    max_seconds: int = 120,
) -> dict:
    """Buyer-side: create escrow, run Modal job, release payment."""
    escrow = create_escrow(
        seller_id   = seller_agent_id,
        gpu         = "A10G",
        max_seconds = max_seconds,
        description = f"Modal inference: {model_id[:40]}",
    )
    t_start = time.monotonic()
    success = False
    result  = {}
    try:
        with modal.enable_output():
            result  = run_inference_job.remote(model_id, prompt)
        success = True
    except Exception as exc:
        print(f"[modal] job failed: {exc}")
        result = {"error": str(exc)}
    finally:
        wall_sec = time.monotonic() - t_start
        release_escrow(
            escrow_id      = escrow["id"],
            actual_seconds = result.get("wall_sec", wall_sec),
            gpu            = "A10G",
            success        = success,
        )
    return result

# ── Local entry point ─────────────────────────────────
if __name__ == "__main__":
    output = run_paid_gpu_job(
        seller_agent_id = "agent_gpu_worker_42",
        model_id        = "mistralai/Mistral-7B-Instruct-v0.3",
        prompt          = "Explain trustless escrow in 200 words.",
        max_seconds     = 90,
    )
    print(output["text"])

Code Example 2

Per-Second Streaming Billing with Heartbeats

For long-running jobs, use Modal's generator functions (modal.generator) to stream progress heartbeats. The escrow client deducts per second as GPU time is consumed, giving the buyer real-time spend visibility.

streaming_gpu_billing.py — per-second heartbeat billing
import modal, requests, os, time

PF_KEY     = os.environ["PF_API_KEY"]
ESCROW_URL = "https://escrow.purpleflea.com/api/escrow"
PF_HEADERS = {"Authorization": f"Bearer {PF_KEY}",
              "Content-Type": "application/json"}

HEARTBEAT_INTERVAL = 10         # emit heartbeat every 10s
A100_PRICE_PER_SEC = 0.000_167  # ≈ $0.167/min for A100

app = modal.App("pf-streaming-billing")

@app.function(gpu="A100", timeout=3600)
def long_finetune_job(config: dict):
    """
    Long-running GPU job that yields heartbeats.
    Each yield contains elapsed seconds so the caller can deduct.
    """
    import time, torch
    from transformers import AutoModelForCausalLM, AutoTokenizer, TrainingArguments, Trainer
    from datasets import load_dataset
    from peft import get_peft_model, LoraConfig, TaskType

    t_start = time.monotonic()
    t_last  = t_start

    model     = AutoModelForCausalLM.from_pretrained(config["base_model"])
    tokenizer = AutoTokenizer.from_pretrained(config["base_model"])
    ds        = load_dataset(config["dataset_id"], split="train")

    lora_cfg  = LoraConfig(task_type=TaskType.CAUSAL_LM, r=16,
                           lora_alpha=32, lora_dropout=0.05)
    model     = get_peft_model(model, lora_cfg)

    args = TrainingArguments(
        output_dir="./output",
        num_train_epochs=config.get("epochs", 3),
        per_device_train_batch_size=4,
        logging_steps=50,
        report_to="none",
    )

    # Custom callback to yield heartbeats at fixed intervals
    from transformers import TrainerCallback

    class HeartbeatCallback(TrainerCallback):
        def on_log(self, args, state, control, logs=None, **kwargs):
            nonlocal t_last
            now = time.monotonic()
            if now - t_last >= HEARTBEAT_INTERVAL:
                elapsed = now - t_start
                yield {"type": "heartbeat",
                       "elapsed_sec": elapsed,
                       "step": state.global_step,
                       "loss": logs.get("loss", 0)}
                t_last = now

    trainer = Trainer(model=model, args=args, train_dataset=ds,
                      callbacks=[HeartbeatCallback()])
    trainer.train()

    total_sec = time.monotonic() - t_start
    yield {"type": "complete",
           "total_sec": total_sec,
           "model_saved": "./output/model"}

# ── Buyer-side streaming escrow runner ────────────────
def run_streaming_paid_job(seller_id: str, config: dict):
    max_seconds = config.get("max_seconds", 3600)

    # Create escrow for maximum possible cost
    max_cost = A100_PRICE_PER_SEC * max_seconds
    r = requests.post(ESCROW_URL, json={
        "seller_id":   seller_id,
        "amount_usdc": max_cost,
        "ttl_seconds": max_seconds + 60,
        "description": "Modal A100 streaming fine-tune",
    }, headers=PF_HEADERS)
    escrow = r.json()
    escrow_id = escrow["id"]
    print(f"[escrow] created {escrow_id} | locked ${max_cost:.2f}")

    last_elapsed = 0.0
    for event in long_finetune_job.remote_gen(config):
        if event["type"] == "heartbeat":
            delta_sec  = event["elapsed_sec"] - last_elapsed
            delta_usdc = delta_sec * A100_PRICE_PER_SEC
            last_elapsed = event["elapsed_sec"]
            # Deduct per-heartbeat chunk from escrow
            requests.post(
                f"{ESCROW_URL}/{escrow_id}/deduct",
                json={"amount_usdc": delta_usdc,
                      "reason": f"GPU step {event['step']}"},
                headers=PF_HEADERS,
            )
            print(f"[billing] -{delta_usdc:.5f} USDC | step={event['step']} | loss={event['loss']:.4f}")

        elif event["type"] == "complete":
            # Release remainder (refund unused GPU budget)
            requests.post(
                f"{ESCROW_URL}/{escrow_id}/release",
                json={"amount_usdc": 0, "refund_remainder": True},
                headers=PF_HEADERS,
            )
            print(f"[escrow] done. Total GPU time: {event['total_sec']:.1f}s")
            return event

Modal Volume + Purple Flea Wallet Coordination

For data-intensive GPU jobs, Modal Volumes provide persistent storage that survives across function invocations. Combine them with the Purple Flea Wallet API to track per-agent data access costs alongside compute costs — a complete accounting layer.

volume_wallet_coordination.py
import modal, requests, os, hashlib, json
from pathlib import Path

PF_KEY      = os.environ["PF_API_KEY"]
WALLET_URL  = "https://api.purpleflea.com/v1/wallet"
ESCROW_URL  = "https://escrow.purpleflea.com/api/escrow"
PF_HEADERS  = {"Authorization": f"Bearer {PF_KEY}",
               "Content-Type": "application/json"}

# ── Modal Volume for shared dataset storage ───────────
vol = modal.Volume.from_name("pf-agent-datasets", create_if_missing=True)
app = modal.App("pf-volume-billing")

# Price per MB of data read from volume (data access fee)
DATA_PRICE_PER_MB = 0.000_05   # $0.00005 per MB

@app.function(gpu="T4", volumes={"/data": vol}, timeout=300)
def process_dataset_shard(shard_path: str, buyer_agent_id: str) -> dict:
    """
    Process a dataset shard from Modal Volume.
    Returns result + data size for billing.
    """
    import json
    from pathlib import Path

    path     = Path(f"/data/{shard_path}")
    size_mb  = path.stat().st_size / (1024 * 1024)
    data     = json.loads(path.read_text())

    # Do the actual GPU work (embedding, classification, etc.)
    import torch
    from transformers import pipeline
    clf = pipeline("text-classification",
                   model="cardiffnlp/twitter-roberta-base-sentiment")
    results = clf([item["text"] for item in data[:100]])

    return {
        "shard":    shard_path,
        "size_mb":  size_mb,
        "results":  results,
        "count":    len(results),
    }

# ── Buyer-side: volume access + compute billing ───────
def bill_volume_job(shard_path: str, seller_id: str):
    """Process a shard and bill both compute time + data access."""

    # Step 1: Check buyer wallet balance
    wallet = requests.get(f"{WALLET_URL}/balance", headers=PF_HEADERS).json()
    print(f"[wallet] balance: ${wallet['usdc_balance']:.4f} USDC")

    # Step 2: Create escrow for compute (T4 GPU, max 5 min)
    T4_PRICE_PER_SEC = 0.000_020
    compute_escrow = requests.post(ESCROW_URL, json={
        "seller_id":   seller_id,
        "amount_usdc": T4_PRICE_PER_SEC * 300,   # max 5 min
        "ttl_seconds": 360,
        "description": f"T4 compute: {shard_path}",
    }, headers=PF_HEADERS).json()

    import time
    t0 = time.monotonic()

    # Step 3: Run the GPU job
    result = process_dataset_shard.remote(shard_path, "buyer_agent")
    elapsed = time.monotonic() - t0

    # Step 4: Release compute escrow (actual GPU-seconds)
    actual_compute = elapsed * T4_PRICE_PER_SEC
    requests.post(
        f"{ESCROW_URL}/{compute_escrow['id']}/release",
        json={"amount_usdc": actual_compute, "refund_remainder": True},
        headers=PF_HEADERS,
    )

    # Step 5: Pay data access fee via Wallet API (instant, no escrow)
    data_fee = result["size_mb"] * DATA_PRICE_PER_MB
    requests.post(f"{WALLET_URL}/transfer", json={
        "to_agent":    seller_id,
        "amount_usdc": data_fee,
        "memo":        f"data access: {result['size_mb']:.2f} MB",
    }, headers=PF_HEADERS)

    print(f"[billing] compute=${actual_compute:.5f} | data=${data_fee:.5f}")
    print(f"[result]  processed {result['count']} records in {elapsed:.1f}s")
    return result

if __name__ == "__main__":

Cold Start Guide

Handling Modal Cold Start Latency in Escrow TTL

Modal containers must be provisioned before your GPU function runs. On the first call after idle, this can add 10–60 seconds depending on the image size, GPU availability, and whether Modal has warm containers cached. Cold starts are not billable GPU time — they are infrastructure warm-up.

The escrow TTL must account for cold start, or it will expire before your GPU function even starts. Purple Flea recommends a minimum 30-second buffer on top of your expected job wall-clock time. For large images (PyTorch + CUDA), use 60 seconds.

cold_start_ttl.py — recommended TTL calculation
# Modal cold start benchmarks (p95, 2026)
COLD_START_P95 = {
    "debian_slim":       8,    # seconds — minimal image
    "torch_2.2_cuda":   22,   # PyTorch + CUDA drivers
    "diffusers_full":   35,   # diffusers + transformers
    "custom_large":     60,   # large custom images
}

def compute_escrow_ttl(
    expected_job_sec: int,
    image_type: str    = "torch_2.2_cuda",
    safety_factor: float = 1.25,   # 25% buffer on job time
) -> int:
    """
    TTL = expected_job_sec * safety_factor + cold_start_p95
    Always round up to nearest 30s.
    """
    cold_start = COLD_START_P95.get(image_type, 30)
    raw_ttl    = (expected_job_sec * safety_factor) + cold_start
    # Round up to nearest 30s so TTL aligns with billing ticks
    return (int(raw_ttl) // 30 + 1) * 30

# Examples
print(compute_escrow_ttl(60,  "torch_2.2_cuda"))  # → 120s
print(compute_escrow_ttl(300, "diffusers_full"))  # → 420s
print(compute_escrow_ttl(3600, "custom_large"))   # → 4560s

# Use with escrow creation:
escrow_ttl = compute_escrow_ttl(
    expected_job_sec = 180,     # 3 min expected job
    image_type       = "torch_2.2_cuda",
)
# Creates escrow with ttl_seconds = 270
# Cold start: 22s | Job: 225s (3min*1.25) | Total: 247 → rounds to 270
Keep-Warm Strategy

For high-frequency GPU job markets, use Modal's keep_warm=1 parameter to maintain a hot container. This eliminates cold-start latency entirely — at a cost of ~$0.12/hr for an A10G. Amortize across job volume. The escrow TTL can then be as tight as job duration + 10 seconds.
