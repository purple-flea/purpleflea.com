Strategies for AI Agents

A deep-dive into statistical mean reversion for autonomous trading agents: the Ornstein-Uhlenbeck process, half-life estimation, ADF test, Hurst exponent, z-score and Bollinger Band signals, multi-asset spread trading, regime detection, and a full Python MeanReversionAgent wired to the Purple Flea trading API.

1. Mean Reversion Theory: Statistical Foundations

Mean reversion is the empirical tendency of an asset price — or a spread between two correlated assets — to return toward a long-run equilibrium after deviating from it. For a trading agent this is a double-edged observation: it implies there is expected profit in fading large deviations, but it also implies that the strategy loses money in trending regimes where reversion never occurs.

The Ornstein-Uhlenbeck Process

The workhorse model for mean reversion is the Ornstein-Uhlenbeck (OU) process, a continuous-time stochastic differential equation:

Ornstein-Uhlenbeck SDE
dX_t = θ(μ - X_t) dt + σ dW_t

where:
  X_t = spread value at time t
  θ = mean-reversion speed (kappa)
  μ = long-run equilibrium (the mean)
  σ = diffusion coefficient (volatility)
  dW_t = Wiener process increment

Three parameters fully characterize the OU process: the equilibrium level μ, the reversion speed θ, and the volatility σ. When the spread is above μ, the drift term θ(μ - X_t) is negative, pulling it back down — and vice versa. The stronger θ is, the faster reversion happens.

Half-Life of Mean Reversion

The half-life (HL) tells an agent how many time periods it takes, on average, for a deviation from the mean to decay by 50%. It is derived directly from θ:

Half-Life Formula
HL = ln(2) / θ ≈ 0.693 / θ

A half-life of 5 bars means a deviation shrinks to half its size in five bars on average. This is the critical parameter for position sizing (longer HL → smaller size, wider stop) and maximum holding period enforcement. In practice, agents calibrate θ from historical spread data and set the maximum holding period to 3–5× HL.

Stationary vs. Non-Stationary Processes

For mean reversion to be tradeable, the spread or price must be stationary: its statistical properties (mean, variance) do not drift over time. A random walk (geometric Brownian motion with zero drift) is non-stationary — there is no equilibrium to revert to. Identifying whether a series is stationary is therefore the first gate an agent must pass before applying any mean-reversion logic.

Key Insight

Individual crypto asset prices are almost never stationary on their own. Mean reversion strategies almost always operate on spreads or ratios between two cointegrated assets, not raw prices.

2. Identifying Mean-Reverting Assets

Augmented Dickey-Fuller Test

The Augmented Dickey-Fuller (ADF) test is the standard statistical test for unit roots (non-stationarity). The null hypothesis H₀ is that the series has a unit root (i.e., is non-stationary / random walk). A low p-value (typically < 0.05) rejects H₀ and supports stationarity.

adf_test.py 
import numpy as np
from statsmodels.tsa.stattools import adfuller

def adf_test(series: np.ndarray, significance: float = 0.05) -> dict:
    """
    Run Augmented Dickey-Fuller test on a price or spread series.

    Returns a dict with keys:
      statistic   - ADF test statistic
      pvalue      - p-value
      is_stationary - bool (True if series appears stationary)
      critical_values - dict of 1%, 5%, 10% critical values
    """
    result = adfuller(series, autolag='AIC')
    stat, pvalue, _, _, crit, _ = result

    return {
        "statistic": stat,
        "pvalue": pvalue,
        "is_stationary": pvalue < significance,
        "critical_values": crit,
        "lags_used": result[2],
        "nobs": result[3],
    }

# Example: test BTC/ETH log-price ratio spread
import pandas as pd

def test_pair_stationarity(btc_prices: pd.Series, eth_prices: pd.Series) -> dict:
    """Test if BTC-ETH spread is stationary using OLS hedge ratio."""
    from sklearn.linear_model import LinearRegression
    X = eth_prices.values.reshape(-1, 1)
    y = btc_prices.values
    reg = LinearRegression().fit(X, y)
    hedge_ratio = reg.coef_[0]
    spread = y - hedge_ratio * eth_prices.values - reg.intercept_
    result = adf_test(spread)
    result["hedge_ratio"] = hedge_ratio
    result["spread_mean"] = float(np.mean(spread))
    result["spread_std"] = float(np.std(spread))
    return result

Hurst Exponent

The Hurst exponent (H) measures the long-term memory of a time series. It distinguishes three regimes:

Hurst Value Regime Interpretation Strategy
H < 0.5 Anti-persistent Mean-reverting — past moves reverse Mean reversion
H = 0.5 Random Walk No memory — geometric Brownian motion No edge
H > 0.5 Persistent Trending — past moves continue Momentum / trend-following
hurst.py 
import numpy as np

def hurst_exponent(series: np.ndarray, min_lag: int = 2, max_lag: int = 100) -> float:
    """
    Compute the Hurst exponent using R/S analysis.

    H < 0.5  → mean-reverting (good for this strategy)
    H = 0.5  → random walk (no edge)
    H > 0.5  → trending (use momentum instead)
    """
    lags = range(min_lag, min(max_lag, len(series) // 2))
    tau = []
    for lag in lags:
        # Compute variance of lagged differences
        diff = series[lag:] - series[:-lag]
        tau.append(np.sqrt(np.var(diff)))

    if len(tau) < 2:
        return 0.5  # insufficient data

    # Fit log-log regression: log(tau) ~ H * log(lag)
    log_lags = np.log(list(lags))
    log_tau = np.log(tau)
    poly = np.polyfit(log_lags, log_tau, 1)
    return poly[0]  # slope = H

def classify_regime(series: np.ndarray) -> str:
    H = hurst_exponent(series)
    if H < 0.45:
        return "mean_reverting"
    elif H > 0.55:
        return "trending"
    else:
        return "random_walk"

Cointegration with the Engle-Granger Test

Two non-stationary price series X and Y are cointegrated if there exists a linear combination β such that Y − βX is stationary. This is the foundation of pairs trading: neither BTC nor ETH is stationary alone, but their spread (after applying the cointegrating vector) can be.

cointegration.py 
from statsmodels.tsa.stattools import coint
import numpy as np
import pandas as pd

def test_cointegration(y: pd.Series, x: pd.Series) -> dict:
    """
    Engle-Granger cointegration test.
    Returns pvalue < 0.05 → likely cointegrated.
    """
    score, pvalue, crit_values = coint(y, x)
    return {
        "score": score,
        "pvalue": pvalue,
        "is_cointegrated": pvalue < 0.05,
        "critical_values": {
            "1%": crit_values[0],
            "5%": crit_values[1],
            "10%": crit_values[2],
        },
    }

def find_cointegrated_pairs(prices: pd.DataFrame,
                             significance: float = 0.05) -> list[tuple]:
    """
    Scan all pairs in a price DataFrame and return cointegrated ones.
    prices: DataFrame where columns are asset symbols.
    """
    symbols = list(prices.columns)
    n = len(symbols)
    pairs = []
    for i in range(n):
        for j in range(i + 1, n):
            res = test_cointegration(prices[symbols[i]], prices[symbols[j]])
            if res["is_cointegrated"]:
                pairs.append((symbols[i], symbols[j], res["pvalue"]))
    return sorted(pairs, key=lambda x: x[2])  # sort by pvalue ascending

3. Entry/Exit Signals: Z-Score, Bollinger Bands, RSI Extremes

Z-Score Bands

The most common mean-reversion signal is the z-score of the spread: how many standard deviations the current spread is above or below its rolling mean. Entry triggers occur when the z-score crosses a threshold (typically ±1.5 to ±2.5); exits occur when it reverts toward zero.

Z-Score Formula
z = (X_t - μ_rolling) / σ_rolling

Entry short spread: z > +entry_threshold (e.g., +2.0)
Entry long spread: z < -entry_threshold (e.g., -2.0)
Exit: |z| < exit_threshold (e.g., 0.5)
Stop loss: |z| > stop_threshold (e.g., 3.5)
signals.py 
import numpy as np
import pandas as pd
from dataclasses import dataclass
from enum import Enum

class Signal(Enum):
    LONG_SPREAD  = "long_spread"   # spread undervalued, buy Y sell X
    SHORT_SPREAD = "short_spread"  # spread overvalued, sell Y buy X
    EXIT         = "exit"
    STOP_LOSS    = "stop_loss"
    HOLD         = "hold"

@dataclass
class ZScoreSignal:
    signal: Signal
    z_score: float
    spread: float
    spread_mean: float
    spread_std: float

def z_score_signal(
    spread_series: pd.Series,
    window: int = 20,
    entry_z: float = 2.0,
    exit_z: float = 0.5,
    stop_z: float = 3.5,
    current_position: Signal = Signal.HOLD,
) -> ZScoreSignal:
    """Compute rolling z-score and generate trading signal."""
    mean = spread_series.rolling(window).mean().iloc[-1]
    std  = spread_series.rolling(window).std().iloc[-1]
    current_spread = spread_series.iloc[-1]

    if std == 0 or np.isnan(std):
        return ZScoreSignal(Signal.HOLD, 0.0, current_spread, mean, std)

    z = (current_spread - mean) / std

    # Stop loss takes priority
    if current_position != Signal.HOLD and abs(z) > stop_z:
        sig = Signal.STOP_LOSS

    # Exit when spread reverts toward mean
    elif current_position == Signal.LONG_SPREAD and z > -exit_z:
        sig = Signal.EXIT
    elif current_position == Signal.SHORT_SPREAD and z < exit_z:
        sig = Signal.EXIT

    # New entries
    elif current_position == Signal.HOLD and z > entry_z:
        sig = Signal.SHORT_SPREAD
    elif current_position == Signal.HOLD and z < -entry_z:
        sig = Signal.LONG_SPREAD

    else:
        sig = Signal.HOLD

    return ZScoreSignal(signal=sig, z_score=z,
                        spread=current_spread, spread_mean=mean, spread_std=std)

Bollinger Bands on Spreads

Bollinger Bands wrap a rolling mean with ±N standard deviation bands. Applied to a spread series, they provide a visual and computational equivalent of z-score bands. An agent treats a touch of the upper band as a short-spread entry and a touch of the lower band as a long-spread entry.

bollinger.py 
import pandas as pd
import numpy as np
from dataclasses import dataclass

@dataclass
class BollingerState:
    upper: float
    lower: float
    mid: float
    bandwidth: float
    percent_b: float   # 0=lower, 0.5=mid, 1=upper, <0 or >1=outside

def bollinger_bands(
    spread: pd.Series,
    window: int = 20,
    num_std: float = 2.0,
) -> BollingerState:
    """Compute Bollinger Band state for the current spread value."""
    mid = spread.rolling(window).mean().iloc[-1]
    std = spread.rolling(window).std().iloc[-1]
    upper = mid + num_std * std
    lower = mid - num_std * std
    bandwidth = (upper - lower) / mid if mid != 0 else 0.0
    cur = spread.iloc[-1]
    pct_b = (cur - lower) / (upper - lower) if (upper - lower) != 0 else 0.5
    return BollingerState(upper=upper, lower=lower, mid=mid,
                          bandwidth=bandwidth, percent_b=pct_b)

def bollinger_signal(state: BollingerState,
                     entry_pct_b_high: float = 0.9,
                     entry_pct_b_low: float = 0.1) -> str:
    """Entry when spread is in outer 10% of bands."""
    if state.percent_b > entry_pct_b_high:
        return "short_spread"
    elif state.percent_b < entry_pct_b_low:
        return "long_spread"
    elif 0.4 < state.percent_b < 0.6:
        return "exit"
    return "hold"

RSI Extremes as Confirmation

RSI applied to the spread series can confirm z-score entries. An RSI below 30 on the spread corroborates a long-spread signal; RSI above 70 confirms a short-spread signal. Using both z-score and RSI as confirming filters reduces false entries in sideways noise.

rsi.py 
import numpy as np
import pandas as pd

def rsi(series: pd.Series, period: int = 14) -> float:
    """Compute RSI for the most recent bar."""
    delta = series.diff()
    gain = delta.clip(lower=0)
    loss = -delta.clip(upper=0)
    avg_gain = gain.rolling(period).mean().iloc[-1]
    avg_loss = loss.rolling(period).mean().iloc[-1]
    if avg_loss == 0:
        return 100.0
    rs = avg_gain / avg_loss
    return 100.0 - (100.0 / (1.0 + rs))

def confirmed_signal(z: float, rsi_val: float,
                     z_entry: float = 2.0,
                     rsi_os: float = 30.0,
                     rsi_ob: float = 70.0) -> str:
    """
    Require both z-score and RSI extremes to agree before entering.
    Reduces false positives in ranging markets.
    """
    if z > z_entry and rsi_val > rsi_ob:
        return "short_spread"
    if z < -z_entry and rsi_val < rsi_os:
        return "long_spread"
    return "hold"

@dataclass
class PairConfig:
    sym_y: str        # e.g., "BTC-PERP"
    sym_x: str        # e.g., "ETH-PERP"

# ─── OU Process Calibration ────────────────────────────────────────────────

class OUCalibrator:
    """Estimate OU parameters θ, μ, σ from historical spread data."""

    @staticmethod
    def fit(spread: np.ndarray, dt: float = 1.0) -> dict:
        """
        Fit OU parameters via OLS on discretized OU:
          ΔX_t = θ(μ - X_{t-1})dt + σ√dt ε_t

        Returns dict: theta, mu, sigma, half_life
        """
        x_prev = spread[:-1]
        x_curr = spread[1:]
        delta = x_curr - x_prev

        # OLS: delta = a + b * x_prev
        A = np.vstack([np.ones_like(x_prev), x_prev]).T
        coeffs, _, _, _ = np.linalg.lstsq(A, delta, rcond=None)
        a, b = coeffs

        theta = -b / dt
        mu = a / (theta * dt) if theta != 0 else float(np.mean(spread))
        residuals = delta - (a + b * x_prev)
        sigma = float(np.std(residuals) / np.sqrt(dt))
        half_life = np.log(2) / theta if theta > 0 else float('inf')

        return {
            "theta": float(theta),
            "mu": float(mu),
            "sigma": float(sigma),
            "half_life": float(half_life),
        }

    @staticmethod
    def half_life(spread: np.ndarray) -> float:
        """Quick half-life estimate — convenience wrapper."""
        params = OUCalibrator.fit(spread)
        return params["half_life"]

# ─── Z-Score Engine ────────────────────────────────────────────────────────

class ZScoreEngine:
    def __init__(self, window: int = 20):
        self.window = window
        self._history: list[float] = []

    def update(self, value: float) -> Optional[float]:
        """Add a new spread observation and return the current z-score."""
        self._history.append(value)
        if len(self._history) > self.window * 3:
            self._history = self._history[-self.window * 3:]
        if len(self._history) < self.window:
            return None
        arr = np.array(self._history[-self.window:])
        mu = np.mean(arr)
        sigma = np.std(arr)
        if sigma == 0:
            return 0.0
        return (value - mu) / sigma

    @property
    def spread_mean(self) -> float:
        if len(self._history) < self.window:
            return 0.0
        return float(np.mean(self._history[-self.window:]))

    @property
    def spread_std(self) -> float:
        if len(self._history) < self.window:
            return 1.0
        return float(np.std(self._history[-self.window:]))

# ─── Purple Flea API Client ────────────────────────────────────────────────

class PurpleFleaClient:
    BASE = "https://purpleflea.com/api/v1"

    def __init__(self, api_key: str):
        self.api_key = api_key
        self._session: Optional[aiohttp.ClientSession] = None

    async def _session_or_create(self) -> aiohttp.ClientSession:
        if self._session is None or self._session.closed:
            self._session = aiohttp.ClientSession(headers={
                "Authorization": f"Bearer {self.api_key}",
                "Content-Type": "application/json",
            })
        return self._session

    async def get_price(self, symbol: str) -> float:
        session = await self._session_or_create()
        async with session.get(f"{self.BASE}/markets/{symbol}/price") as r:
            data = await r.json()
            return float(data["price"])

    async def get_ohlcv(self, symbol: str, limit: int = 200) -> pd.DataFrame:
        session = await self._session_or_create()
        params = {"limit": limit, "interval": "1h"}
        async with session.get(f"{self.BASE}/markets/{symbol}/ohlcv", params=params) as r:
            data = await r.json()
        df = pd.DataFrame(data["candles"],
                          columns=["timestamp", "open", "high", "low", "close", "volume"])
        df["timestamp"] = pd.to_datetime(df["timestamp"], unit="ms")
        df.set_index("timestamp", inplace=True)
        df = df.astype(float)
        return df

    async def place_order(self, symbol: str, side: str, size: float,
                          order_type: str = "market") -> dict:
        session = await self._session_or_create()
        payload = {"symbol": symbol, "side": side, "size": size, "type": order_type}
        async with session.post(f"{self.BASE}/orders", json=payload) as r:
            return await r.json()

    async def cancel_all(self, symbol: str) -> dict:
        session = await self._session_or_create()
        async with session.delete(f"{self.BASE}/orders", json={"symbol": symbol}) as r:
            return await r.json()

    async def close(self):
        if self._session:
            await self._session.close()

# ─── Main Agent ────────────────────────────────────────────────────────────

class MeanReversionAgent:
    """
    Autonomous mean reversion trading agent for Purple Flea perp markets.

    Usage:
        agent = MeanReversionAgent(
            api_key="pf_live_YOUR_KEY_HERE",
            pairs=[PairConfig("BTC-PERP", "ETH-PERP", position_usd=2000)],
        )
        await agent.run()
    """

    def __init__(self, api_key: str, pairs: list[PairConfig],
                 poll_interval_s: int = 60):
        self.client = PurpleFleaClient(api_key)
        self.pairs = pairs
        self.poll_interval = poll_interval_s
        self._positions: dict[str, PositionState] = {
            f"{p.sym_y}/{p.sym_x}": PositionState() for p in pairs
        }
        self._zscore_engines: dict[str, ZScoreEngine] = {
            f"{p.sym_y}/{p.sym_x}": ZScoreEngine(p.zscore_window) for p in pairs
        }
        self._ou_params: dict[str, dict] = {}

    def _pair_key(self, pair: PairConfig) -> str:
        return f"{pair.sym_y}/{pair.sym_x}"

    # ── OU Calibration ──────────────────────────────────────────────────────

    async def calibrate_pair(self, pair: PairConfig) -> dict:
        """Fetch 200 bars and estimate OU parameters. Updates max_hold_bars."""
        log.info(f"Calibrating {pair.sym_y}/{pair.sym_x}")
        df_y = await self.client.get_ohlcv(pair.sym_y, limit=200)
        df_x = await self.client.get_ohlcv(pair.sym_x, limit=200)

        closes_y = df_y["close"]
        closes_x = df_x["close"]

        # Align on common index
        common = closes_y.index.intersection(closes_x.index)
        closes_y = closes_y.loc[common]
        closes_x = closes_x.loc[common]

        spread = closes_y.values - pair.hedge_ratio * closes_x.values
        params = OUCalibrator.fit(spread)
        self._ou_params[self._pair_key(pair)] = params

        # Set max hold period to 3× half-life (capped 5–200 bars)
        hl = params["half_life"]
        pair.max_hold_bars = int(np.clip(3 * hl, 5, 200))

        # Check stationarity
        adf = adfuller(spread, autolag='AIC')
        params["adf_pvalue"] = float(adf[1])
        params["is_stationary"] = adf[1] < 0.05

        log.info(f"  θ={params['theta']:.4f}, μ={params['mu']:.4f}, "
                 f"σ={params['sigma']:.4f}, HL={hl:.1f}, "
                 f"ADF p={adf[1]:.4f}, stationary={params['is_stationary']}")
        return params

    # ── Half-Life ────────────────────────────────────────────────────────────

    def half_life(self, pair: PairConfig) -> float:
        """Return estimated half-life for a pair (in bars)."""
        key = self._pair_key(pair)
        if key in self._ou_params:
            return self._ou_params[key]["half_life"]
        return float('nan')

    # ── Z-Score ──────────────────────────────────────────────────────────────

    def z_score(self, pair: PairConfig,
                price_y: float, price_x: float) -> Optional[float]:
        """Compute current z-score given new prices."""
        spread = price_y - pair.hedge_ratio * price_x
        engine = self._zscore_engines[self._pair_key(pair)]
        return engine.update(spread)

    # ── Signal Generation ────────────────────────────────────────────────────

    def generate_signal(self, pair: PairConfig, z: float,
                        position: PositionState) -> str:
        """
        Generate a trading signal given z-score and current position.

        Returns one of: 'long_spread', 'short_spread', 'exit', 'stop_loss', 'hold'
        """
        # Time-based stop: exceeded max hold bars
        if position.direction != "flat" and position.bars_held >= pair.max_hold_bars:
            log.warning(f"{self._pair_key(pair)}: max hold reached ({pair.max_hold_bars} bars), forcing exit")
            return "exit"

        # Divergence stop loss
        if position.direction != "flat" and abs(z) > pair.z_stop:
            log.warning(f"{self._pair_key(pair)}: stop loss triggered z={z:.2f}")
            return "stop_loss"

        # Exit conditions
        if position.direction == "long_spread" and z > -pair.z_exit:
            return "exit"
        if position.direction == "short_spread" and z < pair.z_exit:
            return "exit"

        # Entry conditions (only when flat)
        if position.direction == "flat":
            if z > pair.z_entry:
                return "short_spread"
            if z < -pair.z_entry:
                return "long_spread"

        return "hold"

    # ── Position Sizing ──────────────────────────────────────────────────────

    def _compute_sizes(self, pair: PairConfig, price_y: float,
                       price_x: float) -> tuple[float, float]:
        """Dollar-neutral position sizing using hedge ratio."""
        size_y = pair.position_usd / price_y
        size_x = (pair.position_usd * pair.hedge_ratio) / price_x
        return round(size_y, 4), round(size_x, 4)

    # ── Execution ────────────────────────────────────────────────────────────

    async def execute(self, pair: PairConfig, signal: str,
                      price_y: float, price_x: float,
                      position: PositionState) -> None:
        """Execute trades based on the signal."""
        key = self._pair_key(pair)
        size_y, size_x = self._compute_sizes(pair, price_y, price_x)

        if signal == "long_spread":
            log.info(f"{key}: LONG SPREAD — buy {size_y} {pair.sym_y}, sell {size_x} {pair.sym_x}")
            await asyncio.gather(
                self.client.place_order(pair.sym_y, "buy", size_y),
                self.client.place_order(pair.sym_x, "sell", size_x),
            )
            position.direction = "long_spread"
            position.entry_time = datetime.utcnow()
            position.bars_held = 0
            position.entry_price_y = price_y
            position.entry_price_x = price_x

        elif signal == "short_spread":
            log.info(f"{key}: SHORT SPREAD — sell {size_y} {pair.sym_y}, buy {size_x} {pair.sym_x}")
            await asyncio.gather(
                self.client.place_order(pair.sym_y, "sell", size_y),
                self.client.place_order(pair.sym_x, "buy", size_x),
            )
            position.direction = "short_spread"
            position.entry_time = datetime.utcnow()
            position.bars_held = 0
            position.entry_price_y = price_y
            position.entry_price_x = price_x

        elif signal in ("exit", "stop_loss"):
            if position.direction == "long_spread":
                log.info(f"{key}: EXIT long_spread ({signal})")
                await asyncio.gather(
                    self.client.place_order(pair.sym_y, "sell", size_y),
                    self.client.place_order(pair.sym_x, "buy", size_x),
                )
            elif position.direction == "short_spread":
                log.info(f"{key}: EXIT short_spread ({signal})")
                await asyncio.gather(
                    self.client.place_order(pair.sym_y, "buy", size_y),
                    self.client.place_order(pair.sym_x, "sell", size_x),
                )
            position.direction = "flat"
            position.entry_time = None
            position.bars_held = 0

    # ── Main Loop ────────────────────────────────────────────────────────────

    async def step(self, pair: PairConfig) -> None:
        """Single agent step for one pair."""
        position = self._positions[self._pair_key(pair)]
        price_y, price_x = await asyncio.gather(
            self.client.get_price(pair.sym_y),
            self.client.get_price(pair.sym_x),
        )
        z = self.z_score(pair, price_y, price_x)
        if z is None:
            return   # not enough history yet

        if position.direction != "flat":
            position.bars_held += 1

        signal = self.generate_signal(pair, z, position)
        if signal != "hold":
            await self.execute(pair, signal, price_y, price_x, position)

    async def run(self) -> None:
        """Start the agent. Calibrate first, then poll continuously."""
        log.info("MeanReversionAgent starting — calibrating pairs...")
        for pair in self.pairs:
            await self.calibrate_pair(pair)

        log.info(f"All pairs calibrated. Polling every {self.poll_interval}s.")
        while True:
            for pair in self.pairs:
                try:
                    await self.step(pair)
                except Exception as e:
                    log.error(f"Error on {self._pair_key(pair)}: {e}")
            await asyncio.sleep(self.poll_interval)

5. Risk Management

Maximum Holding Period

The single most important guard-rail for mean reversion strategies is enforcing a maximum holding period. When the spread does not revert within 3–5× half-life bars, the pair has likely undergone a regime change (see Section 7). Holding longer converts a statistically-grounded bet into speculative directional risk.

Half-Life (HL) Rec. Max Hold Notes
< 5 bars 15–20 bars Fast reversion — use tighter z-entry (1.5)
5–20 bars 40–60 bars Standard regime — z-entry 2.0
20–50 bars 100–150 bars Slow reversion — reduce size, widen stops
> 50 bars Avoid / skip Too slow — capital tied up too long

Stop Loss on Divergence

A z-score stop loss (|z| > 3.5 by default) closes the position when the spread diverges further instead of reverting. This caps the loss on any single trade. The stop level should be calibrated relative to the OU long-run variance: for a well-calibrated process, a spread beyond 3.5σ has less than 0.05% probability under the stationary distribution — so it strongly suggests the process has broken down.

Position Scaling by Half-Life and Volatility

A practical position-sizing formula scales the notional exposure inversely with half-life and with current spread volatility:

position_sizing.py 
import numpy as np

def compute_position_usd(
    base_usd: float,
    half_life: float,
    spread_vol: float,
    target_vol_usd: float = 50.0,
    min_usd: float = 100.0,
    max_usd: float = 5000.0,
) -> float:
    """
    Scale position by spread volatility and half-life.

    base_usd      - starting notional (e.g., 1000)
    half_life     - OU half-life in bars
    spread_vol    - rolling std of spread
    target_vol_usd - target P&L volatility per bar in USD
    """
    if spread_vol <= 0 or np.isnan(half_life) or half_life <= 0:
        return min_usd

    # Vol-scaled size: how many units to get target_vol_usd per bar
    vol_size = target_vol_usd / spread_vol

    # Discount for longer half-lives (slower reversion = less attractive)
    hl_discount = np.clip(10.0 / half_life, 0.1, 1.0)

    usd = vol_size * hl_discount
    return float(np.clip(usd, min_usd, max_usd))

Portfolio-Level Risk Controls

  • Max concurrent pairs: Limit simultaneous open positions (e.g., 3 pairs max) to avoid correlated drawdowns if the whole market trends.
  • Gross exposure cap: Total notional across all pairs should not exceed 3× the agent's capital.
  • Drawdown circuit breaker: Halt new entries if rolling 24h P&L falls below −10% of capital.
  • Recalibration frequency: Re-estimate OU parameters every 6–24 hours as market microstructure evolves.

6. Multi-Asset Mean Reversion: Cross-Asset Spread Trading

While pairs trading (2 assets) is the simplest form, cross-asset spread trading extends to baskets of 3 or more assets. The spread is defined as a linear combination of prices with weights (the cointegrating vector) chosen so that the combination is stationary.

Basket Spread Construction

basket_spread.py 
import numpy as np
import pandas as pd
from sklearn.linear_model import LinearRegression
from statsmodels.tsa.stattools import adfuller

def construct_basket_spread(prices: pd.DataFrame,
                             target: str) -> tuple[np.ndarray, np.ndarray]:
    """
    Construct a basket spread: regress target price on all other assets.
    Returns (spread, weights) where weights are the hedge ratios for each
    non-target asset.

    prices: DataFrame of close prices, columns = asset symbols
    target: the asset to be "Y" in the regression
    """
    y = prices[target].values
    X_cols = [c for c in prices.columns if c != target]
    X = prices[X_cols].values
    reg = LinearRegression(fit_intercept=True).fit(X, y)
    spread = y - reg.predict(X)
    return spread, reg.coef_

def scan_basket_opportunities(prices: pd.DataFrame,
                               significance: float = 0.05) -> list[dict]:
    """
    For each asset as target, test if its residual spread is stationary.
    Returns list of tradeable baskets sorted by ADF p-value.
    """
    results = []
    for target in prices.columns:
        spread, weights = construct_basket_spread(prices, target)
        adf = adfuller(spread, autolag='AIC')
        pvalue = adf[1]
        if pvalue < significance:
            ou = OUCalibrator.fit(spread)
            results.append({
                "target": target,
                "pvalue": pvalue,
                "half_life": ou["half_life"],
                "theta": ou["theta"],
                "weights": dict(zip(
                    [c for c in prices.columns if c != target],
                    weights.tolist()
                )),
            })
    return sorted(results, key=lambda r: r["pvalue"])

Cross-Asset Spread Execution

Executing a basket spread trade requires placing orders for all legs simultaneously. On Purple Flea this is done by firing concurrent async requests for each leg, then verifying all fills before recording the position as open:

basket_execution.py 
import asyncio
from dataclasses import dataclass

@dataclass
class BasketLeg:
    symbol: str
    direction: str   # "buy" or "sell"
    size_usd: float

async def execute_basket(client: PurpleFleaClient,
                         legs: list[BasketLeg]) -> list[dict]:
    """
    Execute all legs of a basket spread simultaneously.
    Returns list of order responses; raises if any leg fails.
    """
    tasks = [
        client.place_order(
            symbol=leg.symbol,
            side=leg.direction,
            size=round(leg.size_usd / await client.get_price(leg.symbol), 4)
        )
        for leg in legs
    ]
    results = await asyncio.gather(*tasks, return_exceptions=True)

    # Check for failures
    failed = [r for r in results if isinstance(r, Exception)]
    if failed:
        # Best-effort close any fills that succeeded
        raise RuntimeError(f"Basket execution failed: {failed}")
    return results

7. Regime Detection: When Mean Reversion Breaks Down

Mean reversion strategies fail catastrophically during trending regimes. A persistent trend causes the spread to drift ever further from its historical mean, turning a z-score short into an ever-larger unrealized loss. Detecting regime changes before they cause damage is therefore as important as the core reversion logic.

Rolling Hurst Regime Monitor

By computing the Hurst exponent on a rolling window (e.g., the last 60 bars), the agent can detect when a spread transitions from mean-reverting (H < 0.45) to trending (H > 0.55):

regime_detector.py 
import numpy as np
import pandas as pd
from collections import deque

class RegimeDetector:
    """
    Rolling Hurst-based regime detector.
    Emits: "mean_reverting", "random_walk", "trending"
    """

    def __init__(self, window: int = 60, hurst_low: float = 0.45,
                 hurst_high: float = 0.55):
        self.window = window
        self.hurst_low = hurst_low
        self.hurst_high = hurst_high
        self._buffer: deque = deque(maxlen=window * 2)
        self._regime = "unknown"

    def update(self, spread_value: float) -> str:
        self._buffer.append(spread_value)
        if len(self._buffer) < self.window:
            return "unknown"
        arr = np.array(list(self._buffer)[-self.window:])
        H = self._hurst(arr)
        if H < self.hurst_low:
            self._regime = "mean_reverting"
        elif H > self.hurst_high:
            self._regime = "trending"
        else:
            self._regime = "random_walk"
        return self._regime

    @property
    def regime(self) -> str:
        return self._regime

    @property
    def is_tradeable(self) -> bool:
        """Agent should only enter in mean_reverting regime."""
        return self._regime == "mean_reverting"

    @staticmethod
    def _hurst(series: np.ndarray) -> float:
        lags = range(2, min(40, len(series) // 2))
        tau = [np.sqrt(np.var(series[lag:] - series[:-lag])) for lag in lags]
        if len(tau) < 2:
            return 0.5
        poly = np.polyfit(np.log(list(lags)), np.log(tau), 1)
        return float(poly[0])

class RegimeAwareMeanReversionAgent(MeanReversionAgent):
    """
    Extension of MeanReversionAgent that gates entries on regime state.
    In trending regimes: close any open positions and halt new entries.
    """

    def __init__(self, *args, **kwargs):
        super().__init__(*args, **kwargs)
        self._regime_detectors: dict[str, RegimeDetector] = {
            self._pair_key(p): RegimeDetector() for p in self.pairs
        }

    def generate_signal(self, pair: PairConfig, z: float,
                        position: PositionState) -> str:
        key = self._pair_key(pair)
        detector = self._regime_detectors[key]
        # Update regime (last spread value from z-score engine history)
        engine = self._zscore_engines[key]
        if engine._history:
            regime = detector.update(engine._history[-1])
        else:
            regime = "unknown"

        # In trending regime: force exits, block new entries
        if regime == "trending":
            if position.direction != "flat":
                log.warning(f"{key}: trending regime detected — exiting position")
                return "exit"
            return "hold"

        return super().generate_signal(pair, z, position)

Additional Regime Signals

  • Rolling ADF p-value: If the 60-bar rolling ADF p-value rises above 0.10, the spread may no longer be stationary. Treat this as an early warning signal — tighten stops but do not yet exit.
  • Half-life blow-up: If the rolling half-life estimate exceeds 3× the calibrated baseline, the OU process is changing. Reduce position size by 50%.
  • Realized volatility spike: A sudden 2× spike in spread volatility (relative to its 20-day average) signals a potential structural break. Halt new entries.
  • Funding rate divergence: On perpetual futures, extreme funding rates can sustain carry-driven trends that overwhelm mean reversion. Monitor 8-hour funding rates and exclude pairs with |annualized net funding| > expected spread return.
Common Failure Mode

The most dangerous pattern is a slow regime transition: the Hurst exponent creeps from 0.42 to 0.56 over several weeks while the agent keeps averaging into a losing spread. Implement both fast (40-bar) and slow (120-bar) Hurst monitors and exit if either signals trending.
