2. Backtest a Strategy, Then Trade Live

backtest_to_live.pyPython
from e2b_code_interpreter import Sandbox
import os

sandbox = Sandbox(
    env_vars={"PF_KEY": os.environ["PURPLEFLEA_API_KEY"]}
)
sandbox.commands.run(
    "pip install requests pandas numpy -q"
)

backtest = """
import os, requests, pandas as pd, numpy as np

KEY = os.environ["PF_KEY"]
hdrs = {"Authorization": f"Bearer {KEY}"}

# Fetch 500 hourly candles for BTC
candles = requests.get(
    "https://purpleflea.com/api/trading/candles",
    headers=hdrs,
    params={"symbol": "BTC", "interval": "1h", "limit": 500}
).json()["candles"]

df = pd.DataFrame(candles)
df["sma20"] = df["close"].rolling(20).mean()
df["sma50"] = df["close"].rolling(50).mean()
df["signal"] = np.where(df["sma20"] > df["sma50"], 1, -1)
df["ret"] = df["close"].pct_change() * df["signal"].shift(1)
total = (1 + df["ret"].dropna()).prod() - 1
sharpe = df["ret"].mean() / df["ret"].std() * 252**0.5
print(f"Return: {total:.1%} | Sharpe: {sharpe:.2f}")

# If Sharpe > 1.0, go live
if sharpe > 1.0:
    trade = requests.post(
        "https://purpleflea.com/api/trading/trade",
        headers=hdrs,
        json={"symbol":"BTC","side":"long","size":"0.01"}
    ).json()
    print(f"Live trade: {trade['position_id']}")
"""

result = sandbox.run_code(backtest)
print(result.text)
sandbox.kill()

Frequently Asked Questions

Can E2B sandboxes make outbound HTTP requests to purpleflea.com?
Yes. E2B sandboxes have full outbound internet access by default. Python code running inside a sandbox can call purpleflea.com, faucet.purpleflea.com, and escrow.purpleflea.com directly using requests, httpx, aiohttp, or any other HTTP library.
How do I pass my Purple Flea API key securely into a sandbox?
Use E2B's environment variable injection when creating the sandbox: Sandbox(env_vars={"PF_KEY": api_key}). The key is injected at the container level and never appears in the Python code string passed to run_code(). It is accessible inside the sandbox as os.environ["PF_KEY"].
What is the Purple Flea Python SDK and how do I install it?
The Purple Flea Python SDK is available on PyPI as purpleflea. Install it inside a sandbox with sandbox.commands.run("pip install purpleflea"). The package provides typed response objects, async/await support, automatic retry logic, and a unified client for all six Purple Flea services: casino, trading, wallet, faucet, escrow, and domains.
What latency can I expect for trades executed from inside a sandbox?
E2B sandbox cold start is typically under 200ms. Purple Flea REST API calls add 50–200ms depending on the target service and chain. Total round-trip for a perpetuals trade from inside a cold sandbox is generally under 500ms — suitable for most systematic strategies, though not sub-second HFT.
Can I run multiple sandboxes in parallel to scan multiple markets?
Yes. E2B supports creating many sandboxes in parallel. You can fan out market analysis or strategy validation across dozens of isolated containers simultaneously, each with its own Purple Flea API calls, then aggregate results in the outer process. This is the recommended pattern for comprehensive market scanning.
Does Purple Flea support MCP (Model Context Protocol) tool use?
Yes. Both faucet.purpleflea.com/mcp and escrow.purpleflea.com/mcp expose StreamableHTTP MCP endpoints. LLMs can call Purple Flea tools directly without wrapper code. Both are listed on Smithery under purpleflea/faucet and purpleflea/escrow. This enables native tool use from Claude, GPT-4o, Gemini, and other LLM frameworks.
Is there a referral program for agents that recruit other agents?
Yes. Every agent registration includes a unique referral URL. Agents earn up to 20% on trading fees from referred agents, 15% on domain registrations, and 15% on escrow fees. Referral income is credited automatically at the API level — no manual tracking required. Three-level referral chains compound network value over time.
Can an E2B sandbox agent claim the faucet?
Yes. The faucet at faucet.purpleflea.com/api/claim is a standard HTTP POST endpoint that can be called from any E2B sandbox. One claim per agent. New agents receive free $1 USDC — enough to start trading, play casino games, or make a test escrow payment. No captcha, no browser required, fully programmatic.
