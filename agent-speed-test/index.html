Benchmark Script

Run From Your Own Infrastructure

Copy this Python script to measure real latency from your deployment environment. Results will vary by region — run from your agent's actual deployment to get accurate numbers.

benchmark.py — Purple Flea API Latency Test 
#!/usr/bin/env python3
"""Purple Flea API Latency Benchmark
Run: python3 benchmark.py --api-key YOUR_KEY --runs 10
"""
import argparse, statistics, time, json
import requests
from datetime import datetime

BASE = "https://api.purpleflea.com"
ENDPOINTS = [
    ("GET",  "/health",              None),
    ("POST", "/auth/token",          {"api_key": "{KEY}"}),
    ("GET",  "/wallet/balance",      None),
    ("GET",  "/trading/quote/BTC-USDC", None),
    ("GET",  "/domains/check/example.com", None),
    ("GET",  "/referrals/stats",     None),
]

def measure(method, path, body, headers, runs):
    times = []
    for _ in range(runs):
        t0 = time.perf_counter()
        try:
            if method == "GET":
                requests.get(BASE + path, headers=headers, timeout=5)
            else:
                requests.post(BASE + path, headers=headers, json=body, timeout=5)
        except Exception: pass
        times.append((time.perf_counter() - t0) * 1000)
    return {
        "p50": round(statistics.median(times), 1),
        "p99": round(statistics.quantiles(times, n=100)[-1], 1),
        "avg": round(statistics.mean(times), 1),
        "min": round(min(times), 1),
    }

def main():
    parser = argparse.ArgumentParser()
    parser.add_argument("--api-key", required=True)
    parser.add_argument("--runs", type=int, default=10)
    parser.add_argument("--output", default="json")
    args = parser.parse_args()

    headers = {
        "Authorization": f"Bearer {args.api_key}",
        "Content-Type": "application/json",
    }

    results = {}
    print(f"Running {args.runs} measurements per endpoint...")
    for method, path, body in ENDPOINTS:
        body_filled = json.loads(json.dumps(body or {}).replace("{KEY}", args.api_key))
        res = measure(method, path, body_filled, headers, args.runs)
        results[path] = res
        print(f"  {method:4} {path:40} p50={res['p50']}ms  p99={res['p99']}ms")

    if args.output == "json":
        print("\n" + json.dumps(results, indent=2))

if __name__ == "__main__":
    main()
Methodology

How We Measure

Our benchmarks are honest, reproducible, and regularly updated.

🌍
Multi-Region Sampling
Measurements are taken from Frankfurt, Ashburn, Singapore, and São Paulo. Published numbers are the Frankfurt p50 — the region most Purple Flea agents operate from.
🔁
p50 / p99 Reporting
We report both p50 (median) and p99 (99th percentile). No cherry-picking best-case numbers. The p99 reflects the tail latency your agent will occasionally see.
⏰
Updated Hourly
Benchmark data is refreshed every hour via an automated agent that runs the same Python script above. Historical data is stored for trend analysis.
🔒
Authenticated Requests
All latency numbers include the full round-trip including JWT validation. An unauthenticated /health ping would show lower numbers — we don't publish those.
📡
Production Infrastructure
All measurements hit the same production endpoints your agent uses. No synthetic dev environments. What you see here is exactly what your agent will experience.
🆓
Reproducible
The Python script above is the exact tool we use. Run it yourself to verify. If you see different numbers from your region, open a GitHub issue — we want to know.
