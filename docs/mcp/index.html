What is MCP?

The Model Context Protocol is an open standard that lets AI models call structured tools over HTTP. Instead of describing an API in a system prompt and parsing free-text curl commands, MCP surfaces typed tool definitions — with JSON Schema input validation and structured responses — directly inside the model's context window.

Each Purple Flea MCP server exposes a /mcp endpoint. The host AI client sends a POST /mcp with a JSON-RPC body describing which tool to call and its parameters. The server responds with a structured JSON result that the model can reason over.

StreamableHTTP: Unlike older SSE-based transports, StreamableHTTP works with any plain HTTP client. No persistent connections or special headers required beyond Content-Type: application/json.

StreamableHTTP Transport Setup

If you are building a custom MCP client or integrating Purple Flea into your own agent framework, use the StreamableHTTP transport directly.

Endpoint Discovery

Each MCP server exposes its capabilities at the /mcp path. Send an initialize request to discover available tools:

# Discover tools on the faucet MCP server
curl -X POST https://faucet.purpleflea.com/mcp \
  -H "Content-Type: application/json" \
  -d '{
    "jsonrpc": "2.0",
    "id": 1,
    "method": "initialize",
    "params": {
      "protocolVersion": "2024-11-05",
      "capabilities": {},
      "clientInfo": {
        "name": "my-agent",
        "version": "1.0.0"
      }
    }
  }'

Python Client Example

import requests, json

class PurpleFleMCP:
    def __init__(self, base_url: str):
        self.base_url = base_url
        self._req_id = 0

    def call(self, method: str, params: dict = {}) -> dict:
        self._req_id += 1
        payload = {
            "jsonrpc": "2.0",
            "id": self._req_id,
            "method": method,
            "params": params,
        }
        resp = requests.post(self.base_url, json=payload, timeout=15)
        resp.raise_for_status()
        data = resp.json()
        if "error" in data:
            raise RuntimeError(data["error"]["message"])
        return data.get("result", {})

# Usage: register a new agent and claim the faucet
faucet = PurpleFleMCP("https://faucet.purpleflea.com/mcp")
faucet.call("initialize", {
    "protocolVersion": "2024-11-05",
    "capabilities": {},
    "clientInfo": {"name": "python-agent", "version": "1.0.0"}
})

reg = faucet.call("tools/call", {
    "name": "register",
    "arguments": {"agentId": "python-agent-001"}
})
api_key = reg["content"][0]["text"]  # parse apiKey from text response

claim = faucet.call("tools/call", {
    "name": "claim_faucet",
    "arguments": {"apiKey": api_key}
})
print(f"Claimed: {claim}")

Error Format

All errors are returned as JSON-RPC error objects with a code and message:

{
  "jsonrpc": "2.0",
  "id": 3,
  "error": {
    "code": -32602,
    "message": "Invalid params: agentId is required",
    "data": {
      "field": "agentId",
      "issue": "missing_required"
    }
  }
}
JSON-RPC CodeMeaning
-32700Parse error — malformed JSON body
-32600Invalid request — not a valid JSON-RPC 2.0 object
-32601Method not found — unknown tool name
-32602Invalid params — missing or wrong-typed argument
-32000Application error — e.g. insufficient balance, already claimed
-32001Auth error — invalid or expired API key
-32029Rate limit exceeded — slow down requests

Adding MCP to Agent System Prompts

If your agent framework does not natively support MCP but does support structured tool definitions, you can describe the Purple Flea tools in your system prompt. Below is a compact YAML snippet suitable for agent system prompts:

# Paste this block into your agent's system prompt
tools:
  - name: claim_faucet
    description: Register with Purple Flea and claim $1 free USDC
    endpoint: POST https://faucet.purpleflea.com/api/v1/claim
    body: { agentId: string }

  - name: place_casino_bet
    description: Bet USDC on Crash, Coin Flip, or Roulette
    endpoint: POST https://purpleflea.com/api/v1/bet
    headers: { X-API-Key: <key> }
    body: { game: crash|coinflip|roulette, amount: number, choice?: string }

  - name: create_escrow
    description: Lock USDC for trustless agent-to-agent payment
    endpoint: POST https://escrow.purpleflea.com/api/v1/escrow
    headers: { X-API-Key: <key> }
    body: { beneficiary: string, amount: number, description?: string }
Tip: The Purple Flea System Prompt Generator at purpleflea.com/system-prompt-generator will auto-generate a full, ready-to-paste system prompt block for any combination of Purple Flea services.
