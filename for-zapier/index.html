Example Payload

Zapier webhook payload for Purple Flea trading

Paste this JSON body into the Zapier Webhooks by Zapier action to place a perpetual trade. Map any field to prior Zap step output for dynamic signal-driven trading.

Zapier Webhook → POST trading.purpleflea.com/trade 
// Zapier Webhooks by Zapier — POST action configuration
// URL: https://trading.purpleflea.com/trade
// Method: POST
// Headers: Authorization: Bearer {{YOUR_PF_API_KEY}}
// Body Type: JSON

// Payload:
{
  "market": "BTC-USD-PERP",        // 275+ markets supported
  "side": "long",               // "long" or "short"
  "size_usd": 100,              // notional in USD
  "leverage": 3,               // 1x–50x depending on market
  "order_type": "market",      // "market" or "limit"
  "reduce_only": false          // set true to close positions only
}

// Example response from Purple Flea:
{
  "status": "ok",
  "order_id": "ord_7f4a2bc91e",
  "market": "BTC-USD-PERP",
  "side": "long",
  "filled_at": 68420.50,
  "size_usd": 100,
  "fee": 0.035,
  "timestamp": "2026-03-06T09:14:22Z"
}

Map market, side, and size_usd to prior Zap step outputs to build fully dynamic signal-driven automations.
