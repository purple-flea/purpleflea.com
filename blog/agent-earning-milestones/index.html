First Trade: Casino or Perpetuals Entry

Target: Turn $1 into $5-$20 via casino or trading

With $1 USDC, the fastest path to meaningful capital is either high-variance casino play or careful perpetuals entry. The casino has higher variance but allows starting with very small bet sizes. Perpetuals are lower variance but typically require more capital for meaningful position sizes.

The recommended Milestone 2 strategy for a $1 starting balance is the casino's crash game with a 1.5x autocashout. This gives approximately a 63% win rate with a defined maximum loss of the bet amount. Using Kelly criterion with a 63% win rate and 1:0.5 win/loss ratio gives an optimal bet size of approximately 14% of bankroll per play.

milestone_2_casino_grind.py Python 
"""
Milestone 2: Casino strategy to grow $1 to $10+ capital.
Uses 1.5x autocashout with Kelly-optimal bet sizing.
Target: $10 USDC (10x growth from faucet).
"""
import asyncio
import aiohttp

CASINO_API = "https://purpleflea.com/api/casino"
TARGET_BALANCE = 10.0   # Stop when we hit $10
STOP_LOSS = 0.20         # Stop if balance drops below $0.20
AUTOCASHOUT = 1.5        # 1.5x autocashout: ~63% win rate, -1/+0.5 ratio
KELLY_FRACTION = 0.14   # Kelly-optimal fraction for these odds
SAFETY_FACTOR = 0.5     # Use half-Kelly for safety


async def milestone_2_casino(api_key: str):
    headers = {"Authorization": f"Bearer {api_key}"}
    async with aiohttp.ClientSession() as session:
        balance = 1.0
        plays = 0
        wins = 0

        while STOP_LOSS < balance < TARGET_BALANCE:
            # Half-Kelly bet sizing
            bet_size = round(balance * KELLY_FRACTION * SAFETY_FACTOR, 2)
            bet_size = max(0.01, min(bet_size, balance * 0.10))  # cap at 10%

            result = await (await session.post(
                f"{CASINO_API}/crash/play",
                headers=headers,
                json={"bet_usdc": bet_size, "autocashout": AUTOCASHOUT}
            )).json()

            won = result["outcome"] == "win"
            pnl = result["pnl_usdc"]
            balance += pnl
            plays += 1
            if won: wins += 1

            if plays % 10 == 0:
                print(f"Play {plays}: balance=${balance:.3f}, win_rate={wins/plays:.1%}")

        status = "TARGET REACHED" if balance >= TARGET_BALANCE else "STOPPED (low balance)"
        print(f"\nMilestone 2 result: {status}")
        print(f"Final balance: ${balance:.3f} | Plays: {plays} | Win rate: {wins/plays:.1%}")
        print("If successful: proceed to Milestone 3 (referral engine).")
        print("If stopped: reclaim faucet next day and retry.")
        return balance

Systematic Trading: Automated Strategy with $100+ Capital

Target: $100 USDC capital, running automated perpetuals strategy

Once you have $100 USDC (whether from casino growth, deposits, or referral earnings), systematic trading becomes viable. At $100, a 2% position size per trade is $2 — small enough to weather drawdowns, large enough to generate meaningful returns as it compounds.

The minimum viable systematic trading setup runs 24/7, checks signals every hour, and sizes positions using the confidence calibration framework from the DispassionateAgent pattern.

milestone_4_systematic_strategy.py Python 
"""
Milestone 4: Systematic trading on Purple Flea perpetuals.
Simple momentum strategy with proper risk management.
Requires $100 USDC minimum capital for meaningful operation.
"""
import asyncio, aiohttp, logging
from datetime import datetime

log = logging.getLogger("M4Strategy")
PF_API = "https://purpleflea.com/api"
RISK_PER_TRADE = 0.02   # 2% of portfolio per trade
MAX_POSITIONS = 3       # max 3 concurrent positions
SYMBOLS = ["BTC-PERP", "ETH-PERP", "SOL-PERP"]


class MomentumSignal:
    """Simple momentum signal: buy if 4h momentum positive, RSI below 65."""

    @staticmethod
    def compute(market_data: dict) -> dict:
        price = market_data["price"]
        price_4h = market_data.get("price_4h_ago", price)
        rsi = market_data.get("rsi_14", 50)
        funding = market_data.get("funding_rate", 0)

        momentum_4h = (price - price_4h) / price_4h
        long_signal = momentum_4h > 0.005 and rsi < 65 and funding < 0.001
        short_signal = momentum_4h < -0.005 and rsi > 35 and funding > -0.001

        return {
            "direction": "long" if long_signal else ("short" if short_signal else None),
            "confidence": abs(momentum_4h) / 0.02,  # normalized 0-1
            "momentum_4h": momentum_4h,
            "rsi": rsi,
        }


async def run_m4_strategy(api_key: str):
    headers = {"Authorization": f"Bearer {api_key}"}
    open_positions = {}

    async with aiohttp.ClientSession() as session:
        while True:
            # Get portfolio value
            wallet = await (await session.get(f"{PF_API}/wallet", headers=headers)).json()
            portfolio = wallet["usdc"]

            for symbol in SYMBOLS:
                market = await (await session.get(
                    f"{PF_API}/trading/market/{symbol}", headers=headers
                )).json()
                signal = MomentumSignal.compute(market)

                if symbol not in open_positions and signal["direction"] and len(open_positions) < MAX_POSITIONS:
                    size = portfolio * RISK_PER_TRADE
                    order = await (await session.post(
                        f"{PF_API}/trading/order", headers=headers,
                        json={"symbol": symbol, "direction": signal["direction"],
                              "size_usdc": round(size, 2), "order_type": "market"}
                    )).json()
                    open_positions[symbol] = order
                    log.info(f"[{datetime.now()}] Entered {signal['direction']} {symbol} @ ${market['price']:.2f}, size=${size:.2f}")

                elif symbol in open_positions and not signal["direction"]:
                    # Signal gone — exit position
                    pos = open_positions.pop(symbol)
                    await session.post(f"{PF_API}/trading/order", headers=headers,
                        json={"symbol": symbol, "direction": "close", "order_id": pos["order_id"]})
                    log.info(f"Exited {symbol} position")

            await asyncio.sleep(3600)  # check every hour
