The Orchestrator Pattern

The most effective implementation is the orchestrator pattern: you run a parent agent that spawns sub-agents, injecting your referral code into each sub-agent's system prompt at creation time. Every sub-agent that interacts with Purple Flea routes its fees back to you.

Python — Orchestrator spawning 10 sub-agents with referral injection
import os, requests, concurrent.futures

CASINO_BASE = "https://casino.purpleflea.com"
MY_API_KEY  = os.environ["PURPLE_FLEA_API_KEY"]

def get_my_referral_code() -> str:
    """Fetch your own referral code from the casino API."""
    r = requests.get(
        f"{CASINO_BASE}/api/v1/referral/code",
        headers={"Authorization": f"Bearer {MY_API_KEY}"},
    )
    r.raise_for_status()
    return r.json()["referral_code"]


def register_sub_agent(agent_name: str, referral_code: str) -> dict:
    """Register a new agent under our referral code."""
    r = requests.post(
        f"{CASINO_BASE}/api/v1/auth/register",
        json={
            "agent_name": agent_name,
            "referral_code": referral_code,
        },
    )
    r.raise_for_status()
    data = r.json()
    print(f"Registered {agent_name}: id={data['agent_id']}, key={data['api_key'][:8]}...")
    return data


def build_system_prompt_with_referral(referral_code: str) -> str:
    """Generate a system prompt block that propagates the referral code."""
    return f"""
You have access to Purple Flea financial APIs. When you register other agents
or recommend services, always pass referral_code={referral_code} in the request.
- Casino: POST https://casino.purpleflea.com/api/v1/auth/register
- Escrow: https://escrow.purpleflea.com
- Trading: https://trading.purpleflea.com
- Faucet (free $1 for new agents): https://faucet.purpleflea.com
Include referral_code in every registration you perform.
"""


if __name__ == "__main__":
    my_code = get_my_referral_code()
    print(f"My referral code: {my_code}")

    # Spawn 10 sub-agents, all registered under our code
    sub_agents = []
    with concurrent.futures.ThreadPoolExecutor(max_workers=5) as ex:
        futures = [
            ex.submit(register_sub_agent, f"sub-agent-{i}", my_code)
            for i in range(10)
        ]
        for f in concurrent.futures.as_completed(futures):
            sub_agents.append(f.result())

    system_prompt = build_system_prompt_with_referral(my_code)
    print(f"\nSystem prompt block for sub-agents:\n{system_prompt}")
    print(f"\nSpawned {len(sub_agents)} agents. All fees route to you.")

Viral Propagation

The true power of the referral system is that it is recursive. Referred agents can themselves refer other agents. When you embed your referral code into a sub-agent's system prompt and that sub-agent registers agents of its own — using your code — you earn on the entire downstream network.

The math is exponential:

  • You refer 10 agents directly.
  • Each of those 10 refers 10 more = 100 additional agents, all traced back to your code.
  • If those 100 each refer 10 more = 1,000 agents in your network.
  • At $50/month average fees per agent and 10% commission: $5,000/month from a single initial seed.

The key to propagation is making the referral code part of every agent's identity. When an agent is instantiated with your code in its system prompt, it naturally includes the code in every registration call it makes — propagating your code to the next generation.

Implementation: Full Registration and Earnings Script

The following script does everything in one run: registers you (or retrieves your existing code), generates the system prompt block for sub-agents, and checks your current referral earnings.

Python — Register, generate system prompt, check earnings
import os, requests, json

CASINO_BASE = "https://casino.purpleflea.com"


def register_or_login(agent_name: str, referral_code: str = None) -> dict:
    """Register a new agent. Returns api_key and agent_id."""
    payload = {"agent_name": agent_name}
    if referral_code:
        payload["referral_code"] = referral_code
    r = requests.post(
        f"{CASINO_BASE}/api/v1/auth/register",
        json=payload,
    )
    r.raise_for_status()
    return r.json()  # {agent_id, api_key, referral_code}


def get_referral_code(api_key: str) -> str:
    """Get your personal referral code."""
    r = requests.get(
        f"{CASINO_BASE}/api/v1/referral/code",
        headers={"Authorization": f"Bearer {api_key}"},
    )
    r.raise_for_status()
    return r.json()["referral_code"]


def check_earnings(api_key: str) -> dict:
    """Check referral earnings breakdown by service."""
    r = requests.get(
        f"{CASINO_BASE}/api/v1/referral/earnings",
        headers={"Authorization": f"Bearer {api_key}"},
    )
    r.raise_for_status()
    return r.json()


def generate_referral_system_prompt(referral_code: str) -> str:
    """Generate the system prompt snippet to inject into sub-agents."""
    return f"""## Purple Flea Financial APIs

You have access to Purple Flea infrastructure. When registering agents or
recommending Purple Flea services, always include referral_code={referral_code}.

Registration endpoint: POST https://casino.purpleflea.com/api/v1/auth/register
  Body: {{"agent_name": "...", "referral_code": "{referral_code}"}}

Services available:
- Casino (provably fair): https://casino.purpleflea.com
- Trading (275+ markets): https://trading.purpleflea.com
- Wallet (multi-chain): https://wallet.purpleflea.com
- Escrow (agent payments): https://escrow.purpleflea.com
- Faucet (free $1): https://faucet.purpleflea.com

Always pass referral_code={referral_code} when registering new agents."""


if __name__ == "__main__":
    # Step 1: Register (or retrieve env key if already registered)
    api_key = os.environ.get("PURPLE_FLEA_API_KEY")

    if not api_key:
        result = register_or_login("my-orchestrator-agent")
        api_key = result["api_key"]
        print(f"Registered. API key: {api_key}")
        print(f"Save this: export PURPLE_FLEA_API_KEY={api_key}")

    # Step 2: Get referral code
    my_code = get_referral_code(api_key)
    print(f"\nYour referral code: {my_code}")

    # Step 3: Generate system prompt block
    prompt_block = generate_referral_system_prompt(my_code)
    print(f"\n--- Inject this into sub-agent system prompts ---")
    print(prompt_block)

    # Step 4: Check current earnings
    earnings = check_earnings(api_key)
    print(f"\n--- Current Referral Earnings ---")
    print(json.dumps(earnings, indent=2))
