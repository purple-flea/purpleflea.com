Options Trading Strategies for AI Agents: Delta, Gamma, and Vega

Options give agents asymmetric payoffs that outright spot or perp positions cannot replicate. A call option lets an agent profit from a 20% move while risking only the premium paid. Purple Flea’s options API brings this flexibility to autonomous agents. This guide explains the four Greeks every agent must track, then implements three concrete strategies: buying calls on momentum signals, selling covered calls for passive yield, and running straddles for event-driven plays.

The Four Greeks Every Agent Must Know

Options pricing is governed by four sensitivity measures known as “the Greeks.” An agent managing options positions must monitor all four to understand how its P&L will change as market conditions evolve.

Δ
Delta — Price Sensitivity
How much the option price moves per $1 move in the underlying. A 0.50 delta call gains $0.50 for every $1 BTC rises. At-the-money options are ~0.50 delta. Deep in-the-money options approach 1.0. Deep out-of-the-money approach 0. Agents use delta to size hedges and calculate equivalent spot exposure.
Γ
Gamma — Delta Rate of Change
How fast delta changes as the underlying moves. High-gamma options (near expiry, near-the-money) accelerate in value rapidly. An agent long gamma profits from volatility regardless of direction. Short-gamma positions (option sellers) are exposed to large moves. Gamma is highest at-the-money and near expiration.
ν
Vega — Volatility Sensitivity
How much the option price changes per 1% move in implied volatility (IV). Long options have positive vega — rising IV benefits option buyers. Selling options (covered calls, cash-secured puts) gives negative vega. Agents should monitor current IV vs historical IV (IV rank) before buying options — buying when IV is elevated is expensive.
Θ
Theta — Time Decay
How much value the option loses per day as it approaches expiry. Long options have negative theta — the agent pays decay daily. Theta accelerates in the final 30 days before expiry. Option sellers collect theta. This is the fundamental tension: buyers want movement, sellers want stasis.

Strategy 1: Buying Calls on Momentum Signals

When a momentum signal fires — RSI breakout, volume surge, sentiment spike — a call option delivers leveraged exposure to the upside with defined maximum loss (the premium). Unlike a leveraged perp, the agent cannot be liquidated.

Setup rules: Buy at-the-money or slightly out-of-the-money calls. Target 7–21 day expiry (long enough to not die to theta immediately). Only buy when IV rank is below 50% (not overpriced). Exit when the trade has doubled, or at 50% loss on premium to avoid riding a dead position.

strategy_momentum_calls.py
import httpx, os
from datetime import datetime, timedelta

PF_KEY  = os.getenv("PURPLE_FLEA_KEY")
PF_BASE = "https://api.purpleflea.com/v1"
HEADERS = {"Authorization": f"Bearer {PF_KEY}"}

def find_call_to_buy(underlying: str, current_price: float) -> dict | None:
    "Find the best ATM call to buy given current conditions."
    with httpx.Client() as http:
        chain = http.get(
            f"{PF_BASE}/options/{underlying}/chain",
            params={"type": "call", "min_dte": 7, "max_dte": 21},
            headers=HEADERS
        ).json()
        iv_rank = http.get(
            f"{PF_BASE}/options/{underlying}/iv-rank",
            headers=HEADERS
        ).json()["iv_rank"]

    if iv_rank > 60:
        return None  # IV too high — buying options is expensive

    # Find the strike closest to current price (ATM) with DTE 10-21
    candidates = [
        o for o in chain["options"]
        if 10 <= o["dte"] <= 21
        and abs(o["strike"] - current_price) / current_price < 0.05  # within 5% of spot
    ]
    if not candidates:
        return None
    # Pick closest to ATM
    return min(candidates, key=lambda o: abs(o["strike"] - current_price))

def buy_momentum_call(underlying: str, current_price: float, budget_usd: float = 200) -> dict:
    option = find_call_to_buy(underlying, current_price)
    if not option:
        raise ValueError("No suitable call found (IV too high or no eligible strikes)")

    premium_per_contract = option["ask"]
    contracts = max(1, int(budget_usd / premium_per_contract))

    order = {
        "option_id": option["id"],
        "side":      "buy",
        "contracts": contracts,
        "order_type": "limit",
        "limit_price": option["ask"],  # pay ask for urgency
    }
    with httpx.Client() as http:
        r = http.post(f"{PF_BASE}/options/order", json=order, headers=HEADERS)
    r.raise_for_status()
    return {
        "option_id": option["id"],
        "strike": option["strike"],
        "dte": option["dte"],
        "contracts": contracts,
        "total_premium": premium_per_contract * contracts,
        "max_loss": premium_per_contract * contracts,  # defined risk
        "break_even": option["strike"] + premium_per_contract,
    }

Strategy 2: Selling Covered Calls for Passive Income

An agent holding spot BTC can sell call options against that holding to collect premium. This is the covered call strategy — the agent caps its upside beyond the strike price but earns income whether the market moves or not. For agents that hold a long-term BTC position and want yield while waiting for the next cycle high, this is highly effective.

Setup rules: Sell out-of-the-money calls at a strike 5–10% above current price, targeting 7–14 DTE (to maximize theta collection). Only sell when IV rank is above 40% (selling expensive options). Roll the position if BTC approaches the strike.

strategy_covered_calls.py
def sell_covered_call(underlying: str, current_price: float, spot_holdings: float) -> dict:
    "Sell a covered call against existing spot holdings."
    with httpx.Client() as http:
        chain = http.get(
            f"{PF_BASE}/options/{underlying}/chain",
            params={"type": "call", "min_dte": 5, "max_dte": 14},
            headers=HEADERS
        ).json()
        iv_rank = http.get(
            f"{PF_BASE}/options/{underlying}/iv-rank", headers=HEADERS
        ).json()["iv_rank"]

    if iv_rank < 40:
        raise ValueError(f"IV rank {iv_rank:.0f}% too low — premium not worth selling")

    # Target strike 7% OTM for covered call
    target_strike = current_price * 1.07
    candidates = [
        o for o in chain["options"]
        if o["strike"] >= target_strike * 0.98
        and o["delta"] <= 0.30  # low delta = less chance of being called away
    ]
    if not candidates:
        raise ValueError("No suitable call found for covered call")

    option = candidates[0]   # lowest delta in range
    # Sell 1 contract per 1 BTC held (contract size = 1 BTC on Purple Flea)
    contracts = int(spot_holdings)

    order = {
        "option_id": option["id"],
        "side":      "sell",
        "contracts": contracts,
        "order_type": "limit",
        "limit_price": option["bid"],  # sell at bid
        "covered":   True,  # collateral is the spot position
    }
    with httpx.Client() as http:
        r = http.post(f"{PF_BASE}/options/order", json=order, headers=HEADERS)
    r.raise_for_status()
    premium_collected = option["bid"] * contracts
    annualized_yield = (premium_collected / (current_price * spot_holdings)) * (365 / option["dte"]) * 100
    return {
        "strike": option["strike"], "dte": option["dte"],
        "premium_collected_usd": premium_collected,
        "annualized_yield_pct": annualized_yield,
        "max_profit": premium_collected,  # if spot stays below strike
    }

Strategy 3: Straddle for Event-Driven Plays

A straddle is buying a call and a put at the same strike and expiry. The agent profits if the underlying makes a large move in either direction. This is the ideal structure for scheduled high-uncertainty events: protocol upgrades, macro data releases, or regulatory decisions where direction is unclear but volatility is expected.

Setup rules: Buy ATM straddles 1–3 days before the event. Exit immediately after the event resolves (within 2–4 hours). The risk is that the event produces no volatility — both options decay rapidly post-event.

strategy_straddle.py
def buy_event_straddle(underlying: str, current_price: float, event_dte: int = 2) -> dict:
    "Buy an ATM straddle for an upcoming event play."
    with httpx.Client() as http:
        call_chain = http.get(
            f"{PF_BASE}/options/{underlying}/chain",
            params={"type": "call", "min_dte": event_dte, "max_dte": event_dte + 2},
            headers=HEADERS
        ).json()["options"]
        put_chain = http.get(
            f"{PF_BASE}/options/{underlying}/chain",
            params={"type": "put", "min_dte": event_dte, "max_dte": event_dte + 2},
            headers=HEADERS
        ).json()["options"]

    # Find ATM call and put (closest strike to current price)
    atm_call = min(call_chain, key=lambda o: abs(o["strike"] - current_price))
    atm_put  = min(put_chain,  key=lambda o: abs(o["strike"] - current_price))

    total_premium = atm_call["ask"] + atm_put["ask"]
    # Break-even: price must move more than total premium in either direction
    upper_be = atm_call["strike"] + total_premium
    lower_be = atm_put["strike"]  - total_premium

    with httpx.Client() as http:
        http.post(f"{PF_BASE}/options/order", json={
            "option_id": atm_call["id"], "side": "buy", "contracts": 1,
            "order_type": "market"
        }, headers=HEADERS).raise_for_status()
        http.post(f"{PF_BASE}/options/order", json={
            "option_id": atm_put["id"],  "side": "buy", "contracts": 1,
            "order_type": "market"
        }, headers=HEADERS).raise_for_status()

    return {
        "call_strike": atm_call["strike"],
        "put_strike":  atm_put["strike"],
        "total_premium_usd": total_premium,
        "max_loss_usd": total_premium,
        "upper_break_even": upper_be,
        "lower_break_even": lower_be,
        "required_move_pct": total_premium / current_price * 100,
    }

Greeks Monitoring Loop

An agent managing open options positions must check Greeks regularly and close or roll positions when thresholds are breached:

def check_options_positions() -> None:
    with httpx.Client() as http:
        positions = http.get(f"{PF_BASE}/options/positions", headers=HEADERS).json()

    for pos in positions["positions"]:
        greeks = pos["greeks"]
        pnl_pct = pos["unrealized_pnl_pct"]

        # Exit rules for long options
        if pos["side"] == "long":

Risk Warning

Important risk disclosures: Options trading involves significant risk. Buying options: maximum loss is the premium paid, but this happens frequently on out-of-the-money options that expire worthless. Selling options: maximum loss is theoretically unlimited for naked calls. Only sell covered calls (covered by spot holdings) to limit downside. Straddles require large moves to profit — if volatility contracts after an event, both legs can lose value simultaneously. Never allocate more than 5–10% of a portfolio to options at any time.

Conclusion

Options give AI agents a toolkit that spot and perpetuals cannot match: defined-risk leveraged plays, passive yield generation, and event-driven volatility trades. The three strategies here cover the core use cases: buy calls when momentum signals fire and IV is low; sell covered calls to earn yield on existing holdings; run straddles when a scheduled event makes the direction uncertain but the move likely.

The Greeks monitoring loop is as important as the entry logic. Unchecked theta decay and delta drift are the most common causes of poor options P&L for automated systems. Build the monitoring loop before going live.
