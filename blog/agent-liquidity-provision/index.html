1. How Uniswap V3 Works for LP Agents

Uniswap V3 replaced the classic x*y=k invariant with concentrated liquidity. Instead of spreading capital across the entire price curve from zero to infinity, LPs pick a price range [P_lower, P_upper] where their liquidity is active.

While the price stays within your range, you earn a pro-rata share of the fee pool. When price exits your range, you stop earning and hold 100% of the cheaper asset — this is where impermanent loss crystallizes if you withdraw.

The Math Behind a Position

# Given: a position ETH/USDC with price range [2800, 3200]
# Current ETH price: $3000
# Capital: $10,000

import math

def calc_v3_amounts(capital, p_current, p_lower, p_upper):
    """
    Calculate ETH and USDC amounts for a V3 position.
    Returns (eth_amount, usdc_amount)
    """
    sqrt_p  = math.sqrt(p_current)
    sqrt_pa = math.sqrt(p_lower)
    sqrt_pb = math.sqrt(p_upper)

    # Liquidity given capital (approximate, assumes 50/50 at midpoint)
    L = capital / (sqrt_p - sqrt_pa + (p_current - p_lower) / sqrt_p)

    eth_amount  = L * (sqrt_pb - sqrt_p) / (sqrt_p * sqrt_pb)
    usdc_amount = L * (sqrt_p - sqrt_pa)

    return round(eth_amount, 4), round(usdc_amount, 2)

eth, usdc = calc_v3_amounts(10000, 3000, 2800, 3200)
print(f"Position: {eth} ETH + {usdc} USDC")
# Position: 0.0847 ETH + 3541.22 USDC

def estimate_daily_fees(liquidity_share, pool_daily_volume, fee_tier):
    """Estimate daily fees earned by a position."""
    return pool_daily_volume * fee_tier * liquidity_share

# ETH/USDC 0.3% pool: ~$500M daily volume
# If your position is 0.002% of pool liquidity in-range:
daily_fee = estimate_daily_fees(0.00002, 500_000_000, 0.003)
print(f"Daily fees: ${daily_fee:.2f}")  # $30.00
print(f"APR: {daily_fee * 365 / 10000 * 100:.1f}%")  # 109.5%

2. Impermanent Loss — The Real Risk

Impermanent loss (IL) occurs when the price moves away from your entry point. For V3 concentrated positions, IL is amplified because all your capital is active within a narrow range. An agent without an IL mitigation strategy can earn fees but lose more on IL.

import math

def impermanent_loss_v3(p_entry, p_current, p_lower, p_upper):
    """
    Calculate impermanent loss for a V3 position.
    Returns IL as a fraction (0.05 = 5% loss vs holding).
    Returns None if price is out of range.
    """
    if p_current <= p_lower or p_current >= p_upper:
        return None  # Out of range — IL is locked

    sqrt_pe = math.sqrt(p_entry)
    sqrt_pc = math.sqrt(p_current)
    sqrt_pa = math.sqrt(p_lower)
    sqrt_pb = math.sqrt(p_upper)

    # Value if holding vs value in LP
    r = p_current / p_entry
    hold_value = 1 + r  # Normalized: 1 unit USDC + 1/p_entry ETH

    lp_value = 2 * math.sqrt(r)
    il        = (lp_value - hold_value) / hold_value
    return round(il, 4)

# Check IL at various price points
entry = 3000
for price in [2800, 2900, 3000, 3100, 3200]:
    il = impermanent_loss_v3(entry, price, 2800, 3200)
    print(f"Price ${price}: IL = {il*100:.2f}%" if il else f"Price ${price}: Out of range")

# Key insight: narrow ranges amplify both fee income AND IL
# A 10% price range with $10k earns like $100k in a V2 pool
# But IL at range boundary is much higher

def should_rebalance(current_il, daily_fee_rate, breakeven_days=7):
    """Rebalance if IL cannot be recovered in 7 days of fees."""
    projected_fee_recovery = daily_fee_rate * breakeven_days
    return abs(current_il) > projected_fee_recovery

import requests

def get_pool_stats(token0, token1, fee_tiers=[100, 500, 3000, 10000]):
    """
    Query Uniswap V3 subgraph for pool metrics.
    Fee tiers are in basis points * 100 (e.g., 3000 = 0.3%).
    """
    query = """
    {
      pools(where: {token0_: {symbol: "%s"}, token1_: {symbol: "%s"}},
            orderBy: volumeUSD, orderDirection: desc, first: 4) {
        feeTier
        volumeUSD
        totalValueLockedUSD
        feesUSD
      }
    }
    """ % (token0, token1)

    resp = requests.post(
        "https://api.thegraph.com/subgraphs/name/uniswap/uniswap-v3",
        json={"query": query}
    ).json()

    return resp.get("data", {}).get("pools", [])

def best_fee_tier(pools):
    """Pick pool with best fee yield (fees/TVL ratio)."""
    return max(pools, key=lambda p: (
        float(p["feesUSD"]) / max(float(p["totalValueLockedUSD"]), 1)
    ))

4. Automated Range Management Agent

The core value of an AI agent over a human LP is 24/7 range management. When price drifts to the edge of a range, the agent withdraws, collects fees, and creates a new centered position — all without human intervention.

import requests, time, math
from datetime import datetime

PURPLE_FLEA_API = "https://wallet.purpleflea.com"
AGENT_ID        = "lp-agent-001"
API_KEY         = "pf_live_your_key"

POOL_ADDRESS    = "0x88e6A0c2dDD26FEEb64F039a2c41296FcB3f5640"  # ETH/USDC 0.05%
RANGE_WIDTH     = 0.10   # 10% above and below current price
REBALANCE_THRESHOLD = 0.85  # Rebalance when price hits 85% of range boundary
CAPITAL_USDC    = 5000

def get_eth_price() -> float:
    r = requests.get("https://api.coingecko.com/api/v3/simple/price",
                     params={"ids": "ethereum", "vs_currencies": "usd"})
    return r.json()["ethereum"]["usd"]

def create_lp_position(price_center: float) -> dict:
    """Open a new V3 LP position centered at current price."""
    p_lower = price_center * (1 - RANGE_WIDTH)
    p_upper = price_center * (1 + RANGE_WIDTH)

    eth_needed  = CAPITAL_USDC / 2 / price_center
    usdc_needed = CAPITAL_USDC / 2

    # Execute via Purple Flea wallet
    r = requests.post(f"{PURPLE_FLEA_API}/defi/uniswap-v3/add-liquidity",
        headers={"X-Agent-Id": AGENT_ID, "Authorization": f"Bearer {API_KEY}"},
        json={
            "pool":        POOL_ADDRESS,
            "price_lower": p_lower,
            "price_upper": p_upper,
            "amount0":     eth_needed,
            "amount1":     usdc_needed,
        }
    )
    result = r.json()
    print(f"[{datetime.utcnow().isoformat()}] Position opened: [{p_lower:.0f}, {p_upper:.0f}] tx={result['tx_hash'][:12]}...")
    return result

def close_position_collect_fees(position_id: str) -> float:
    """Close position and return USD value of collected fees."""
    r = requests.post(f"{PURPLE_FLEA_API}/defi/uniswap-v3/remove-liquidity",
        headers={"X-Agent-Id": AGENT_ID, "Authorization": f"Bearer {API_KEY}"},
        json={"position_id": position_id, "collect_fees": True}
    )
    result = r.json()
    fees_usd = result.get("fees_collected_usd", 0)
    print(f"Fees collected: ${fees_usd:.4f}")
    return fees_usd

def lp_management_loop():
    """Main LP management loop — runs continuously."""
    position       = None
    range_lower    = None
    range_upper    = None
    total_fees_usd = 0

    while True:
        price = get_eth_price()

        if position is None:
            # No position — open one
            position    = create_lp_position(price)
            range_lower = price * (1 - RANGE_WIDTH)
            range_upper = price * (1 + RANGE_WIDTH)

        else:
            # Check if rebalance is needed
            lower_warn = range_lower + (price - range_lower) * (1 - REBALANCE_THRESHOLD)
            upper_warn = range_upper - (range_upper - price) * (1 - REBALANCE_THRESHOLD)

            if price <= lower_warn or price >= upper_warn:
                print(f"Price ${price:.0f} near range boundary — rebalancing")
                fees = close_position_collect_fees(position["position_id"])
                total_fees_usd += fees
                position    = create_lp_position(price)
                range_lower = price * (1 - RANGE_WIDTH)
                range_upper = price * (1 + RANGE_WIDTH)

        print(f"Price: ${price:.0f} | Range: [{range_lower:.0f}, {range_upper:.0f}] | Total fees: ${total_fees_usd:.2f}")
        time.sleep(60)  # Check every minute

if __name__ == "__main__":
    lp_management_loop()

5. Fee Collection and Compounding

V3 fees don't auto-compound — they sit in the pool contract waiting to be claimed. An agent should collect fees periodically and decide whether to reinvest or transfer to the treasury wallet via Purple Flea.

def compound_or_withdraw(fees_usd: float, position_value: float) -> str:
    """
    Decision: compound fees back into LP, or transfer to treasury?
    Rule: compound if fees < 1% of position (minimize gas cost ratio).
    """
    gas_cost_estimate = 3.50  # USD, Base chain gas is much cheaper

    if fees_usd < gas_cost_estimate * 10:
        return "hold"  # Too small to be worth gas

    compounding_threshold = position_value * 0.005  # Compound if >= 0.5% of position

    if fees_usd >= compounding_threshold:
        return "compound"
    else:
        return "withdraw_to_treasury"

def send_to_treasury(amount_usdc: float, treasury_agent_id: str):

6. Risk Controls for LP Agents

Impermanent Loss Warning: In volatile markets, IL can exceed fee income. Always set a maximum IL threshold at which your agent exits the position entirely and holds cash until volatility subsides.

class LPRiskManager:
    MAX_IL_THRESHOLD  = 0.05   # Exit if IL exceeds 5%
    MIN_FEE_APR       = 0.20   # Exit if fee APR drops below 20%
    MAX_GAS_FRACTION  = 0.10   # Max 10% of fees spent on gas
    VOLATILITY_PAUSE  = 3600   # Pause 1h if 1h volatility > 5%

    def should_exit(self, il: float, fee_apr: float, hour_vol: float) -> tuple:
        if abs(il) > self.MAX_IL_THRESHOLD:
            return True, f"IL {il*100:.1f}% exceeds {self.MAX_IL_THRESHOLD*100}% threshold"
        if fee_apr < self.MIN_FEE_APR:
            return True, f"Fee APR {fee_apr*100:.1f}% too low, exiting"
        if hour_vol > 0.05:
            return True, f"High volatility {hour_vol*100:.1f}%, pausing"
        return False, "ok"
