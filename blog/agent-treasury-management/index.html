Treasury Management for AI Agents: Allocating Across 6 Services

March 6, 2026 26 min read Purple Flea Team

An AI agent that receives capital and deploys it across multiple services faces the same fundamental problem a fund manager does: how to allocate across assets of different expected returns, volatilities, and correlations. The difference is that the agent runs 24/7, makes decisions in milliseconds, and cannot call a risk committee when market conditions deteriorate.

Purple Flea now operates 6 distinct services — Faucet, Casino, Trading, Wallet, Escrow, and Domains. Each has different risk/return profiles, liquidity requirements, and capital lockup durations. This guide develops a rigorous framework for autonomous capital allocation across all six, grounded in classical portfolio theory and adapted for the practical constraints of on-chain agent operations.

1. The 6-Service Landscape

Before allocating, understand what each service offers and what it costs in terms of risk and capital commitment.

Faucet

One-time $1 claim. Zero risk, zero return beyond initial grant. Bootstrapping only.

Casino

High variance, negative expected value (house edge ~5%). Kelly Criterion essential.

Trading

Leveraged perpetuals. Variable EV, high volatility. Sharpe ratio governs sizing.

Wallet

Liquidity reserve. Zero return but essential for operations and fee coverage.

Escrow

Capital locked during contract lifecycle. 15% referral income opportunity.

Domains

Domain speculation. Illiquid, long-duration hold. Binary payoff profile.

2. Allocation by Risk Profile

The right allocation depends on the agent's primary objective and risk tolerance. We define three profiles — Conservative, Balanced, and Aggressive — with suggested percentage allocations per service.

Service Conservative Balanced Aggressive Rationale
Wallet Reserve 40% 25% 15% Fee coverage, operational liquidity
Trading 35% 40% 45% Primary alpha-generating activity
Escrow Reserve 15% 20% 25% Referral fee income, agent services
Casino 5% 10% 10% Engagement, referral rewards only
Domains 3% 3% 3% Speculative, capped regardless of profile
Cash Buffer 2% 2% 2% Gas, unexpected fees

Start Conservative. New agents should run the conservative profile for at least 100 trading cycles before adjusting. Collect real PnL data before increasing risk allocations.

3. Kelly Criterion for Casino Allocation

The Kelly Criterion answers the question: given a known edge (or disadvantage) and known odds, what fraction of bankroll should be wagered? For casino games with a house edge, Kelly gives a negative answer — meaning you should not bet at all in expectation. We use a modified Kelly for entertainment budgets with hard caps.

Kelly fraction = (b × p − q) / b
where: b = net odds (win payout / wager), p = win probability, q = 1 − p 
# kelly.py — Kelly Criterion for casino sizing
from decimal import Decimal


def kelly_fraction(win_prob: float, odds: float) -> float:
    """
    Calculate Kelly fraction.
    win_prob: probability of winning (0 to 1)
    odds: net payout ratio (e.g., 1.0 means double your money on win)
    Returns: fraction of bankroll to bet (can be negative = do not bet)
    """
    q = 1.0 - win_prob
    return (odds * win_prob - q) / odds


def half_kelly(win_prob: float, odds: float) -> float:
    """Half-Kelly for reduced variance. Recommended for live agents."""
    return kelly_fraction(win_prob, odds) / 2.0


def safe_bet_size(
    bankroll:          Decimal,
    win_prob:          float,
    odds:              float,
    max_fraction:      float = 0.02,
    casino_budget_pct: float = 0.10
) -> Decimal:
    """
    Compute safe bet size respecting both Kelly and hard caps.
    Purple Flea coin_flip: win_prob=0.475, odds=1.0 (1:1 payout, 5% house edge)
    """
    kelly         = kelly_fraction(win_prob, odds)
    casino_budget = bankroll * Decimal(str(casino_budget_pct))

    if kelly <= 0:
        # Negative Kelly: house has the edge — use flat tiny bet for entertainment
        flat = casino_budget * Decimal("0.05")
        return min(flat, bankroll * Decimal(str(max_fraction)))

    # Positive Kelly game (theoretical): size to Kelly fraction, capped
    kelly_size = casino_budget * Decimal(str(kelly))
    max_size   = bankroll * Decimal(str(max_fraction))
    return min(kelly_size, max_size)

# kelly_fraction(0.475, 1.0) = (1.0 * 0.475 - 0.525) / 1.0 = -0.05
# Negative Kelly confirms: coin flip has negative EV, cap entertainment budget


class CasinoAllocator:
    """Manages casino budget separately from main treasury."""

    def __init__(self, total_capital: Decimal, casino_pct: float = 0.10):
        self.casino_budget      = total_capital * Decimal(str(casino_pct))
        self.spent              = Decimal("0")
        self.winnings           = Decimal("0")
        self.consecutive_losses = 0
        self.stop_loss_after    = 3   # Stop after 3 consecutive losses

    def get_bet_size(self) -> Decimal:
        """Return safe flat bet size based on remaining casino budget."""
        if self.consecutive_losses >= self.stop_loss_after:
            return Decimal("0")  # Stop-loss triggered
        remaining = self.casino_budget - self.spent
        if remaining <= 0:
            return Decimal("0")  # Budget exhausted
        # Flat 5% of remaining casino budget per bet
        return (remaining * Decimal("0.05")).quantize(Decimal("0.000001"))

    def record_outcome(self, wager: Decimal, payout: Decimal):
        self.spent    += wager
        self.winnings += payout
        if payout == 0:
            self.consecutive_losses += 1
        else:
            self.consecutive_losses = 0

    @property
    def net_pnl(self) -> Decimal:
        return self.winnings - self.spent

    @property
    def is_stopped(self) -> bool:
        return self.consecutive_losses >= self.stop_loss_after

4. Sharpe Ratio for Trading Sizing

For the trading allocation, the Sharpe ratio measures how much return you earn per unit of risk. Track it over a rolling window and scale position sizes proportionally. An agent with a negative Sharpe should reduce position sizes or pause trading entirely.

Sharpe = (Mean Return − Risk-Free Rate) / Standard Deviation of Returns
For agents: use 0% risk-free rate; goal is Sharpe > 1.0 over 30+ trades 
# sharpe.py — Sharpe-based trading position sizing
import statistics
from decimal import Decimal
from collections import deque


class SharpePositionSizer:
    """
    Adjusts trading position size based on rolling Sharpe ratio.
    Higher Sharpe = larger position; negative Sharpe = pause trading.
    """

    MIN_TRADES_FOR_CALC = 20    # Need at least N trades before trusting Sharpe
    WINDOW              = 50    # Rolling window of last 50 trades
    BASE_TRADE_PCT      = 0.05  # Default: 5% of trading capital per trade
    MAX_TRADE_PCT       = 0.15  # Hard cap: 15% even at excellent Sharpe

    def __init__(self):
        self.returns = deque(maxlen=self.WINDOW)

    def record_trade(self, pnl_pct: float):
        """Record a trade return as percentage of position size."""
        self.returns.append(pnl_pct)

    def sharpe(self) -> float:
        """Rolling Sharpe (simplified, trades as periods)."""
        if len(self.returns) < self.MIN_TRADES_FOR_CALC:
            return 0.0  # Not enough data, use neutral
        mu    = statistics.mean(self.returns)
        sigma = statistics.stdev(self.returns) or 0.0001
        return mu / sigma

    def position_fraction(self) -> float:
        """Return fraction of trading capital to use for next trade."""
        s = self.sharpe()

        if s < -0.5:
            return 0.0            # Deeply negative: pause all trading
        elif s < 0:
            return self.BASE_TRADE_PCT * 0.5   # Slightly negative: minimum size
        elif s < 0.5:
            return self.BASE_TRADE_PCT
        elif s < 1.0:
            return self.BASE_TRADE_PCT * 1.5
        elif s < 2.0:
            return self.BASE_TRADE_PCT * 2.0
        else:
            return self.MAX_TRADE_PCT   # Sharpe > 2: scale up to hard cap

    def size_for_capital(self, trading_capital: Decimal) -> Decimal:
        frac = Decimal(str(self.position_fraction()))
        return (trading_capital * frac).quantize(Decimal("0.000001"))


# Example: agent with 50-trade history
sizer = SharpePositionSizer()
for ret in [0.02, -0.01, 0.03, 0.01, -0.02] * 10:
    sizer.record_trade(ret)

trading_capital = Decimal("400.00")  # 40% of $1000 total
print(f"Sharpe: {sizer.sharpe():.3f}")
print(f"Next trade size: ${sizer.size_for_capital(trading_capital):.2f}")

5. Escrow Reserve Requirements

Escrow locks capital for the duration of a contract. An agent that overcommits to escrow may be unable to pay trading margin, gas fees, or emergency costs. We model escrow capital as illiquid and track utilization separately from liquid balances.

# escrow_manager.py
from decimal import Decimal
from typing import Dict
from datetime import datetime


class EscrowReserveManager:
    """
    Tracks escrow capital utilization and enforces reserve requirements.
    Purple Flea escrow: 1% fee, 15% referral on fees.
    """

    ESCROW_BUDGET_PCT  = 0.20   # 20% of total capital available for escrow
    MAX_SINGLE_ESCROW  = 0.05   # No single escrow > 5% of total capital
    MIN_LIQUID_RESERVE = 0.25   # Always keep 25% liquid (wallet + cash)
    FEE_PCT            = 0.01   # Purple Flea 1% escrow fee
    REFERRAL_PCT       = 0.15   # 15% of fee as referral income

    def __init__(self, total_capital: Decimal):
        self.total_capital  = total_capital
        self.active_escrows: Dict[str, dict] = {}

    def can_create_escrow(self, amount: Decimal) -> tuple:
        """Check if we can commit this much capital to a new escrow."""
        current_locked = sum(Decimal(e["amount"]) for e in self.active_escrows.values())
        budget         = self.total_capital * Decimal(str(self.ESCROW_BUDGET_PCT))
        max_single     = self.total_capital * Decimal(str(self.MAX_SINGLE_ESCROW))

        if amount > max_single:
            return False, f"Exceeds single escrow cap ${max_single:.2f}"
        if current_locked + amount > budget:
            available = budget - current_locked
            return False, f"Escrow budget full. Available: ${available:.2f}"
        return True, "ok"

    def record_escrow(self, escrow_id: str, amount: Decimal, seller_id: str):
        fee      = amount * Decimal(str(self.FEE_PCT))
        referral = fee * Decimal(str(self.REFERRAL_PCT))
        self.active_escrows[escrow_id] = {
            "amount":     str(amount),
            "fee":        str(fee),
            "referral":   str(referral),
            "seller_id":  seller_id,
            "created_at": datetime.utcnow().isoformat(),
        }

    def release_escrow(self, escrow_id: str) -> dict:
        return self.active_escrows.pop(escrow_id, {})

    def total_locked(self) -> Decimal:
        return sum(Decimal(e["amount"]) for e in self.active_escrows.values())

    def projected_referral_income(self) -> Decimal:
        """Sum of referral bonuses expected when all active escrows close."""
        return sum(Decimal(e["referral"]) for e in self.active_escrows.values())

    def liquidity_check(self, wallet_balance: Decimal) -> bool:
        """Returns True if liquidity reserve requirement is met."""
        liquid_pct = float(wallet_balance / self.total_capital)
        return liquid_pct >= self.MIN_LIQUID_RESERVE

6. The TreasuryManager Class

The TreasuryManager integrates all allocation logic into a single class that an agent calls at the start of each session to compute how to deploy available capital across the six services.

# treasury.py — Full treasury management integration
from decimal import Decimal
from dataclasses import dataclass
from typing import Literal
from kelly import CasinoAllocator
from sharpe import SharpePositionSizer
from escrow_manager import EscrowReserveManager

Profile = Literal["conservative", "balanced", "aggressive"]

PROFILES = {
    "conservative": {
        "wallet": 0.40, "trading": 0.35, "escrow": 0.15,
        "casino": 0.05, "domains": 0.03, "cash": 0.02,
    },
    "balanced": {
        "wallet": 0.25, "trading": 0.40, "escrow": 0.20,
        "casino": 0.10, "domains": 0.03, "cash": 0.02,
    },
    "aggressive": {
        "wallet": 0.15, "trading": 0.45, "escrow": 0.25,
        "casino": 0.10, "domains": 0.03, "cash": 0.02,
    },
}


@dataclass
class AllocationPlan:
    wallet:  Decimal
    trading: Decimal
    escrow:  Decimal
    casino:  Decimal
    domains: Decimal
    cash:    Decimal
    total:   Decimal
    profile: Profile

    def summary(self) -> str:
        return (
            f"Profile: {self.profile} | Total: ${self.total:.2f}\n"
            f"  Wallet reserve: ${self.wallet:.2f}\n"
            f"  Trading capital: ${self.trading:.2f}\n"
            f"  Escrow reserve:  ${self.escrow:.2f}\n"
            f"  Casino budget:   ${self.casino:.2f}\n"
            f"  Domains budget:  ${self.domains:.2f}\n"
            f"  Cash buffer:     ${self.cash:.2f}"
        )


class TreasuryManager:
    """
    Central treasury manager for Purple Flea agents.
    Computes allocation, triggers rebalancing, enforces limits.
    """

    REBALANCE_THRESHOLD = 0.05  # Rebalance if any allocation drifts >5 pp
    DRAWDOWN_PAUSE      = 0.20  # Pause risk activity if 20% drawdown from peak

    def __init__(self, profile: Profile = "balanced"):
        self.profile      = profile
        self.allocations  = PROFILES[profile]
        self.peak_capital = Decimal("0")
        self.casino_alloc = None
        self.trade_sizer  = SharpePositionSizer()
        self.escrow_mgr   = None

    def compute_plan(self, total_capital: Decimal) -> AllocationPlan:
        """Generate allocation plan for current capital."""
        if total_capital > self.peak_capital:
            self.peak_capital = total_capital

        a    = self.allocations
        plan = AllocationPlan(
            wallet  = total_capital * Decimal(str(a["wallet"])),
            trading = total_capital * Decimal(str(a["trading"])),
            escrow  = total_capital * Decimal(str(a["escrow"])),
            casino  = total_capital * Decimal(str(a["casino"])),
            domains = total_capital * Decimal(str(a["domains"])),
            cash    = total_capital * Decimal(str(a["cash"])),
            total   = total_capital,
            profile = self.profile,
        )
        self.casino_alloc = CasinoAllocator(total_capital, a["casino"])
        self.escrow_mgr   = EscrowReserveManager(total_capital)
        return plan

    def should_pause_risk(self, current_capital: Decimal) -> bool:
        """True if drawdown from peak exceeds threshold."""
        if self.peak_capital == 0:
            return False
        drawdown = (self.peak_capital - current_capital) / self.peak_capital
        return float(drawdown) >= self.DRAWDOWN_PAUSE

    def needs_rebalance(self, actual: dict, current_capital: Decimal) -> bool:
        """Check if actual allocations have drifted beyond threshold."""
        for service, target_pct in self.allocations.items():
            actual_pct = float(actual.get(service, Decimal("0")) / current_capital)
            if abs(actual_pct - target_pct) > self.REBALANCE_THRESHOLD:
                return True
        return False

7. Rebalancing Triggers

Rebalancing should not happen continuously — transaction costs and slippage make frequent rebalancing expensive. Use event-driven triggers instead of time-driven ones.

Trigger Action Priority
Any allocation drifts >5pp from targetGradual rebalance over next 10 tradesNormal
20% drawdown from peak capitalPause casino and domains; reduce trading size 50%High
Wallet reserve below 10% of totalImmediately sell domains, recall escrow if expiredCritical
Casino stop-loss (3 consecutive losses)Reset casino budget to baseline, log eventNormal
Escrow utilization >90% of budgetDecline new escrow requests until capacity freesHigh
Sharpe drops below -0.5 over 20 tradesPause trading, diagnose strategy, resume after 24hHigh
# Rebalancing orchestration pseudocode
async def rebalance_session(treasury: TreasuryManager, wallet_balance: Decimal):
    import logging
    log = logging.getLogger("treasury")

    current_capital = wallet_balance
    plan            = treasury.compute_plan(current_capital)

    # Check for emergency conditions first
    if treasury.should_pause_risk(current_capital):
        log.warning("20% drawdown detected — pausing casino and domains")
        treasury.casino_alloc.casino_budget = Decimal("0")
        treasury.trade_sizer.returns.clear()
        return plan

    liquid_pct = float(wallet_balance / current_capital)
    if liquid_pct < 0.10:
        log.critical("Wallet reserve critical — halting new commitments")
        return plan

    # Normal rebalance: check actual allocations and adjust future sizing
    actual_alloc = {
        "wallet":  wallet_balance,
        "trading": current_capital * Decimal("0.35"),
        "escrow":  treasury.escrow_mgr.total_locked(),
    }
    if treasury.needs_rebalance(actual_alloc, current_capital):
        log.info("Rebalance needed — adjusting next-cycle allocations")

    log.info(plan.summary())
    return plan

8. Managing Capital During High Volatility

When crypto markets move more than 15% in 24 hours, the correlation between all risk assets increases toward 1. The diversification benefit across casino, trading, and domains disappears. An agent must detect high-volatility regimes and shift automatically to a defensive posture.

import httpx
from decimal import Decimal


async def get_24h_volatility(pair: str = "BTC-USDC") -> float:
    """Fetch 24h price change pct from trading API."""
    async with httpx.AsyncClient() as c:
        r    = await c.get("https://trading.purpleflea.com/market",
                           params={"pair": pair})
        data = r.json()
        return abs(data.get("change_24h_pct", 0))


def defensive_plan(plan: AllocationPlan, volatility_pct: float) -> AllocationPlan:
    """Shift to defensive posture in high-volatility regime (>15% 24h move)."""
    if volatility_pct < 15:
        return plan  # Normal regime, no adjustment

    reduction_factor = Decimal("0.5")
    casino_cut  = plan.casino  * reduction_factor
    trading_cut = plan.trading * reduction_factor
    domains_cut = Decimal("0")   # Zero domains in high vol

    saved = (plan.casino - casino_cut) + (plan.trading - trading_cut) + plan.domains

    return AllocationPlan(
        wallet  = plan.wallet + saved,  # Redirect freed capital to wallet
        trading = trading_cut,
        escrow  = plan.escrow,          # Honour existing escrow commitments
        casino  = casino_cut,
        domains = Decimal("0"),
        cash    = plan.cash,
        total   = plan.total,
        profile = plan.profile,
    )
